# exp03/ —— 迁移死亡代价实验

由 `exp02/verify2.py`（冻结基线 `c5a1f18`）复制并**只加一个机制**：迁移的代价作用于人口而不是储存。
规格与结果见 [`../docs/EXP-03-SPEC.md`](../docs/EXP-03-SPEC.md)。

`exp01/` 与 `exp02/` 都只读，本轮零改动。两条退化恒等式各自用对应基线**自己的**哈希函数判定。

```
verify3.py     引擎（EXP-02 复制 + move_mortality + 人口分项账 + mortseq 开关 + 定向场景）
run_tests.py   正确性 D1–D13。三态结果 PASS/FAIL/UNCOVERED；有 FAIL 则退出码 1
run_scan.py    112 次观察扫描。只报告现象，不判定通过与否
TESTS.txt      正确性完整输出（上次运行）
SCAN.txt       逐种子原始整数账 + 可读表 + 汇总 + H1 原始读数（上次运行）
```

## 怎么跑

```bash
cd exp03
python3 run_tests.py ; echo "exit=$?"    # 约 45 秒
python3 run_scan.py                      # 约 10 秒，112 次运行
```

无依赖，Python 3.9+。种子 `[0,12345,777,4242,99,31337,2026]`，`SIGMA_M ∈ {0,400}`，`MOVE_MORT_M ∈ {0,20,50,100}`。

## 这次得到了什么

**正确性 18 通过 / 0 失败 / 1 未覆盖。** 未覆盖那一项是真的没测到，不是通过：
`SIGMA=0 MORT=100 seed=777` 与 `SIGMA=400 MORT=100 seed=777` 两个组合的 A 区整个 300 年没发生过分裂，
所以"抑制 A 区分裂"无从生效——**隔离性本身 56/56 未被违反**，缺的是干预有效性的前提。

**机制确实在起作用**：7 种子**合计**的聚合读数里，`MOVE_MORT_M` 上升 ⇒ 迁移次数、人口、群体数、
累计人年全部下降，迁移死亡上升。逐种子看，`MORT=0 → 100` 的端点上 14/14 个（种子 × SIGMA）组合三项都下降，
但只有末人口 9/14、迁移 12/14、缺粮强度 11/14 是逐档单调的——中间档位的反弹逐条列在 `SCAN.txt` §4.3b，未做平滑。

**H1 本轮未完成正式的趋势推断。** 原始读数：`SIGMA=0` 档两个聚合指标都单调不减，`SIGMA=400` 档没有
同样趋势，逐种子有差异。没有预注册的检验统计量、没有空对照、没有噪声地板，所以**不宣布 H1 成立或不成立**。
（上一版曾用"聚合差 / 逐种子半极差 < 1"自动判定"未支持"并宣称样本没有分辨力——那是事后挑的判据，已删除。）

**初版 D11 的集成断言是空的**：写成 `macc == 期望 or macc < 1000`，后半句恒为真。独立复核用
"只改 `step` 内实际强度为 `min(mm+1,1000)`、保留单元测试不变"的注入证明了这一点。现已改为端到端
精确核对（出发人数/原余数/配置强度全部确定），并把该注入固化为 `poison-mortstrength` 回归。

## 结论边界（这几条必须一起读）

- 本实验**不检验**"决策是否有后果"这一总体命题，只检验"新增迁移死亡代价如何改变不同信息条件下的
  人口、缺粮与迁移结果"。
- 迁移死亡代价**适用于所有迁移**，不是只惩罚误判，所以它不是"对错误决策的罚款"。
- **不要把"死得更多所以缺粮总量下降"读成福利改善**——主指标是缺粮/需求（强度），并与累计人年并列。
- 全知臂"误判 0%"有一部分来自选择规则的定义，不是福利收益。
- **H1 成立与否都不能推出决策无效，也不构成禁止以后研究社会机制的依据。**
- 累加器是**确定性取整近似**，不产生方差、不产生尾部事件，不冒充个体随机死亡模型。
- 本轮**没有计算噪声地板**，也**未完成正式的趋势推断**；EXP-01/02 的已知限制原样继承且未修。
- 储存不因死亡而减少的理由是记账范围：**当前账本只记录可食用资源，不包含人体能量；人口死亡不自动扣减粮食库存。**
