## 这次得到了什么

**正确性 16 通过 / 0 失败 / 0 未覆盖。** 六个注入全部实测会红，其中三个只在构造场景里承重。

**机制确实在起作用**：优先阶段 92–206 笔转移、236–285 人年口粮，**真·分配改变 28–38 次**
（`RECIP_M=0` 时恒为 0）。判据是"逐对群体总额不同"，拆笔不算。

**本轮修掉一个实现错误**：优先阶段原来复用了"权重即上限"的分配器，导致**历史受助量意外成了
本轮回助的额度上限**（预算 10N、缺口 10N、只记得对方帮过 1N，就只优先给出 1N，其余落回普通池
被陌生群体分走）。已改用只管相对比例的 `proportional_share`，并加了 G14 / G15 两条定向回归
（旧实现上都会红）。历史仍然只是**排序依据，不是债务额度**。
**但聚合结果没有明显改善**：缺粮强度 0.790% → 0.803%，末人口 2881 → 2844，
好几个种子三档完全一样。**重复往来也没有随 `RECIP_M` 增加**——没有长出"关系网"。
如实保留，不调参、不强造关系或联盟。

**两个计数别混**：`repay`（回助）在 `RECIP_M=0` 时也有 93–189 笔，那是**碰巧**；
`recip_changed`（分配改变）才是"优先规则真的改变了分配"。
