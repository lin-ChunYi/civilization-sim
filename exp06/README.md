## 这次得到了什么

**正确性 14 通过 / 0 失败 / 0 未覆盖。** 六个注入全部实测会红，其中三个只在构造场景里承重。

**机制确实在起作用**：优先阶段 88–223 笔转移，**分配改变 46–154 次**（`RECIP_M=0` 时恒为 0）。
**但聚合结果没有明显改善**：缺粮强度 0.790% → 0.803%，末人口 2881 → 2844，
好几个种子三档完全一样。**重复往来也没有随 `RECIP_M` 增加**——没有长出"关系网"。
如实保留，不调参、不强造关系或联盟。

**两个计数别混**：`repay`（回助）在 `RECIP_M=0` 时也有 93–189 笔，那是**碰巧**；
`recip_changed`（分配改变）才是"优先规则真的改变了分配"。
