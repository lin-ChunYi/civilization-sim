# EXP-04 —— 同格信息交换（规格 + 实测结果）

**基线**：EXP-01 @ `20da486`、EXP-02 @ `c5a1f18`、EXP-03 @ `6b6af4f`，均冻结只读，本轮零改动。
**本文件取代** `docs/EXP-04-PROPOSAL.md`（方案仍留在库里作为对照），依据是批准时定死的两处澄清。
**状态**：已实现并运行。正确性 **15 通过 / 0 失败 / 0 未覆盖**；观察读数见 §5，**不做趋势推断**。

---

## 1. 只加一个机制

同一格上的**参与**群体交换各自对邻格的资源记忆。不加交易、战争、国家、宗教，不接 LLM，
不扩地图，不改人口与迁移公式。唯一的新参数是 `SHARE_M ∈ [0,1000]`（千分之一，参与概率）。

## 2. 触发条件（只有物理条件）

| 层 | 条件 |
|---|---|
| 空间 | 同一 tick、同一格上 `size>0` 的参与者 ≥ 2 |
| 时间 | 相位 6a（侦察）之后、6b（迁移决策）之前——当年交换到的信息可以影响当年的迁移 |
| 参与 | 每群体一次 counter-based 抽签：`rng(seed, S_SHARE, t, bid, 0) % 1000 < SHARE_M` |
| 没有别的条件 | 不看饥饿、不看亲缘、不看历史、不看规模。那些都会引入制度性状态 |

## 3. 合并规则与两处澄清

交换开始前对全部参与者的 `(mem, memt)` 取一份**快照**；所有合并只读这份快照。
对每个格键：取 `memt` 最大者，并列取 `band_id` 最小者；**只有严格比自己新才采纳**；
**时戳照抄来源，不刷新**。

> **澄清一（批准时定死）**：同格参与者之间**可以直接互相传**，A 直接传给 C **不算多跳**。
> 禁止的是在同一交换相位里读取**刚被本相位更新过**的中间结果再往下传。
> 实现方式就是上面这份快照；违反它的注入是 `poison-shareseq`。
>
> **澄清二（批准时定死）**：全知对照臂检查的是**行动与物质演化是否不变**（`material_hash`）。
> 它的记忆内容、信息账与诊断计数**会**随机制变化，那是预期之内，**不是模拟错误**。

**这个机制禁止了什么**（每条都配一个注入）：

| 禁止 | 注入 | 被谁抓 |
|---|---|---|
| 不读本相位刚更新的中间结果 | `shareseq` | E6（端到端精确核对 + 溯源） |
| 不凭空生成 | `sharefab` | E7 |
| 不刷新时戳 | `sharefresh` | E7 |
| 不跨格 | `sharecross` | E8 |
| 不携带物质 | `shareleak` | E9（**全局守恒查不出**，必须比物质哈希） |
| 只读诊断不得回灌规则 | `sharediag` | E12（定向场景；长跑上空转） |

## 4. 账：四本

| 账 | 恒等式 | 结果 |
|---|---|---|
| 能量守恒 | 沿用 EXP-01/02/03 | 每 tick 恒为 0（E1） |
| 人口恒等 | 期末 = 期初 + 出生 − 原死亡 − 迁移死亡 | 每 tick 恒为 0（E1） |
| **信息账（新增）** | 收到 = 采纳 + 拒绝 | 每 tick 恒为 0（E1） |
| 只读诊断 | 决策改变数、平均信息陈旧度 | 不参与规则（E12） |

**交换记录**：每一次采纳都在 `st['share_log']` 里留一条
`(tick, 格, 来源群体, 接收群体, 记忆的格, 值, 时戳)`——这就是"哪一年、哪个群体向谁传递了什么信息"。

## 5. 实测结果

```
cd exp04 && python3 run_tests.py ; echo "exit=$?"   -> 15 通过 / 0 失败 / 0 未覆盖，exit=0
cd exp04 && python3 run_scan.py                     -> 112 次运行（300 年），exit=0
```

### 5.1 正确性（完整输出见 `exp04/TESTS.txt`）

- **E3 三条逐步退化恒等全部成立**：`SHARE=0` 逐 tick 复现 EXP-03；再加 `MORT=0` 复现 EXP-02；
  再加 `SIGMA=0` 复现 EXP-01。各用对应基线**自己的**哈希函数判定，基线按路径只读加载。
- **E4 全知臂**：`material_hash` 在 `SHARE ∈ {0,1000}` 下逐 tick 相同，而 `state_hash` 不同
  （记忆确实变了，且该臂内确实发生过采纳）——两件事同时成立才算通过。
- **E6 端到端精确核对**：定向场景里，独立按规则重算的采纳记录与 `mem/memt` 与实际逐条相同；
  `poison-shareseq` 被抓到（它把"来源"记成了一个交换前并不持有该条目的群体）。
- **E9**：`poison-shareleak` 的全局守恒误差**始终是 0**，靠守恒账永远抓不到它；物质哈希在第 44 tick 抓到。
- **E12**：`sharediag` 在长跑上空转（长跑里诊断计数长期为 0），挂在定向场景上才承重——
  与 EXP-01「分裂冲突 175 次撞车 0 次」是同一课。
- **E13**：同一配置跑 120 年时诊断计数是 0，跑 300 年是非 0。**年数本身就是前提的一部分。**

### 5.3 三个预注册观察假说的原始读数

| | SIGMA=0 MORT=0 | SIGMA=0 MORT=50 | SIGMA=400 MORT=0 | SIGMA=400 MORT=50 |
|---|---|---|---|---|
| **G1** 与全知臂的缺粮强度差（SHARE 0 → 250 → 1000） | −0.049 → +0.010 → **+0.166** | +0.005 → −0.012 → **+0.044** | −0.011 → −0.025 → **+0.069** | −0.001 → −0.017 → **+0.070** |
| **G2** 平均信息陈旧度（年） | 4.51 → 4.62 → **1.75** | 4.50 → 4.53 → **3.03** | 4.90 → 4.26 → **2.03** | 4.05 → 3.70 → **2.26** |
| **G3** 决策改变数 | 0 → 21 → **267** | 0 → 6 → **89** | 0 → 18 → **147** | 0 → 9 → **73** |

**能说的（原始描述）**：

- **G2 方向明确**：`SHARE_M=1000` 时平均信息陈旧度在四个组合里都大幅下降（约降到 1/2 ～ 1/3）。
  信息确实变新了。
- **G3 不为 0**：交换确实改变过迁移目标，四个组合里都有。机制不是只改了不被读取的记忆。
- **G1 的方向与预想相反**：`SHARE_M=1000` 时记忆臂的缺粮强度**离全知臂更远**（四个组合一致），
  同时末人口更低（如 `SIGMA=0 MORT=0`：5202 → 4086）、累计人年更少、迁移次数更多。
  **这是一个否定读数，如实保留，不调参去追。**

**不能说的**：

- **本轮没有完成正式的趋势推断。** 没有预注册的检验统计量、没有空对照、没有噪声地板。
- **不能把"共享更多信息反而更差"解释成任何具体机制。** 一个看起来合理的故事（大家都知道同一个
  好格子 → 一起涌过去 → 更快耗尽）**尚未被测量**，属于 D 级猜测；要成立需要专门的定向实验
  （比如统计同一目标格的并发迁入），本轮**没有做**，也不打算顺手补。
- G1 读不到向好的方向，**不能推出"信息没有用"**：EXP-03 已经表明上下界之差本身在本样本上就不稳定。
- 不为追求趋势调参，不新增大规模扫描。

## 6. 读数须知与限制

1. 全知臂只跑 `SHARE=0`：E4 已逐 tick 证明它的行动与物质演化对 `SHARE_M` 不变。
2. 平均陈旧度 = `stale_sum / 迁移次数`，单位是年；迁移为 0 记"不适用"，不记 0。
3. 采纳率随 `SHARE_M` 上升而下降（35.7% → 5.5%），因为参与者一多，同一条记忆会被反复"收到"。
   分母口径是 (接收者 × 来源 × 条目) 三元组，收到 = 采纳 + 拒绝。
4. 继承 EXP-01/02/03 的全部已知限制：迁移储存损失结构性恒为零、默认样本无灭绝、
   多数假设为 D 级、跨版本存档兼容与人口学标定都没有做过。
