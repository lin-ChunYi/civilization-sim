# EXP-04 方案（待批准）—— 同格信息交换

**状态：方案，未实现。** 批准之前不写 `exp04/` 的任何一行代码。
基线：EXP-03 @ `6b6af4f`（冻结只读）。本方案**只加一个群体间互动机制，只加一个参数**。

## 1. 要回答什么问题

EXP-03 已经量出了信息条件的两个端点：**记忆臂**（只知道自己去过或侦察过的格，`UNKNOWN` 是一等状态）与
**全知臂**（读当年真值）。这两端之间目前没有任何中间态——信息要么私有，要么全知，**群体之间没有任何通路**。

EXP-04 问两件事：

1. **当信息可以沿物理接触在群体之间流动时，结果会不会向全知端移动、移动多少？**
2. **这条通路本身可不可验证？** 即能不能守住"不凭空生成、不多跳、不跨格、不携带物质、不刷新时戳"。

第 2 问是本轮的主交付物。任何未来的社会机制（交易、冲突、制度）都以"群体间存在一条可审计的信息通路"
为前提；先把这条通路建起来并测死，比先加一个更热闹的机制更省事。

**预注册的诚实前提**：EXP-03 测到的上下界之差**本身**在本样本上就不稳定（`SIGMA=0` 聚合单调、
`SIGMA=400` 不单调、逐种子符号不一致，且本轮未完成正式趋势推断）。所以本轮的观察部分**很可能读不到分辨**。
若如此就如实记"读不到"，**不调参、不换判据、不扩样本、不追单调**。

## 2. 动作由什么条件触发（只有物理条件）

| 层 | 条件 |
|---|---|
| 空间 | 同一 tick、同一格上 `size>0` 的群体数 ≥ 2 |
| 时间 | 相位 6a（侦察）之后、6b（迁移决策）之前——当年交换到的信息可以影响当年的迁移 |
| 参与 | 每群体一次 counter-based 抽签：`rng(seed, S_SHARE, t, bid, 0) % 1000 < SHARE_M`；不参与者既不发也不收 |
| 没有别的条件 | 不看饥饿、不看亲缘、不看历史、不看规模。任何这类条件都会引入制度性状态（信任、联盟、亲属），留到以后 |

`SHARE_M ∈ [0,1000]`（千分之一定点整数）是**本实验唯一的新参数**。
未触发不是"无效应"：账上记 `触发 0 次`，属于 `NOT_TRIGGERED` 的观测，不得写成机制无效。

**触发面已先行核实**（只读探针，在冻结的 EXP-03 引擎上测量，不含任何交换机制，见
[`probes/EXP-04-FEASIBILITY.txt`](../probes/EXP-04-FEASIBILITY.txt)）：

| 读数 | `SIGMA=0 MORT=0` | `SIGMA=400 MORT=50` |
|---|---|---|
| 有同格的 tick | 1270 / 2100（60.5%） | 1029 / 2100（49.0%） |
| 处于同格的群体人次 | 6459 / 34064（19.0%） | 2968 / 25109（11.8%） |
| 单格最多群体数 | 4 | 4 |
| 同格群体里**有新增条目**（自己 UNKNOWN、邻居已知） | 22.1% | 23.5% |
| 同格群体里**有可更新条目**（邻居时戳严格更新） | 89.7% | 91.0% |

触发面与信息落差都存在。这条检查是针对 EXP-01 的教训做的——分裂冲突在 175 次申请里撞车 0 次，
一个永不触发的机制不值得做。**这两个数只说明有东西可传，不说明传了结果会变好。**

## 3. 动作与合并规则（怎样核算）

交换开始前，对全部参与群体的 `(mem, memt)` 取一份**快照**；所有合并只读这份快照。

对参与群体 `x` 及同格的其他参与者集合 `S`，对快照中出现的每个格键 `j`：
候选 = `{(mem[j], memt[j], bid) : bid ∈ S ∪ {x}}` → 取 **`memt` 最大**者 → 并列取 **`band_id` 最小**者 →
写回 `x` 的 `mem[j] / memt[j]`。**时戳照抄来源，不刷新为当年。**

**这个机制禁止了什么（每条都配一个检验）**：

1. **不凭空生成**：交换后每条条目必须与快照里某个同格参与者的条目逐值相等（值与时戳成对）。
2. **不多跳**：一个 tick 内信息最多传一跳（所有人读同一份快照）。
3. **不跨格**：非同格群体之间不流动。
4. **不刷新时戳**：收到的陈旧值必须继续显示为陈旧。
5. **不携带物质与能量**：交换相位前后 `stock/store/size/bacc/dacc/macc` 逐字段不变。
   注意**全局守恒查不出群体间的储存转移**（总量不变），所以必须用相位内不变量，不能靠守恒账。
6. **不建立持久关系边**：只依赖"这一 tick 同格"，不留下任何关系状态。
7. **不改变全知臂**：全知臂不读 `mem`，机制对它**逐位无效**——这是必过检验，不是假设。

## 4. 账：三本

| 账 | 恒等式 | 本轮的变化 |
|---|---|---|
| 能量守恒 | 沿用 EXP-01/02/03 | 交换不参与，必须仍恒为 0 |
| 人口恒等 | 期末 = 期初 + 出生 − 原死亡 − 迁移死亡 | 交换不参与，必须仍恒为 0 |
| **信息账（新增）** | 收到条目数 = 采纳数 + 拒绝数（拒绝 = 时戳不更新，或并列时输给更小 `band_id`）；且采纳后的条目集合 ⊆ 快照并集 | 每 tick 记录：参与群体数、同格组数、发出 / 收到 / 采纳 / 拒绝条目数 |

观察层计数器（**只读，不得回灌规则**）：
**决策改变数**（同一 tick 分别用交换前、交换后的记忆各算一次迁移目标，比较是否不同）、
平均信息陈旧度 `stale_sum / mig_total`。

## 5. 怎样与无该机制的基线对照

| 对照 | 内容 | 性质 |
|---|---|---|
| 退化恒等 | `SHARE_M=0` 对 EXP-03 @ `6b6af4f` **逐 tick** 全同，用 EXP-03 **自己的**哈希函数判定，`importlib` 只读加载 | 必过 |
| 全知臂不变 | 全知臂在 `SHARE_M ∈ {0,250,1000}` 下逐位不变 | 必过 |
| 同种子配对 | 同 `seed × SIGMA × MORT` 下，`SHARE_M=0` 就是"无该机制"的基线，与 250 / 1000 配对比较，**不跨种子平均** | 观察 |
| 上界参照 | 全知臂继续作为信息上界，本轮不动它 | 观察 |

扫描规模：记忆臂 7 种子 × `SIGMA∈{0,400}` × `MORT∈{0,50}` × `SHARE∈{0,250,1000}` = 84 次；
全知臂 7 × 2 × 2 = 28 次（对 `SHARE_M` 不变，只跑一次）；合计 **112 次运行**，与 EXP-03 同量级。
同一张 64 格地图，300 年，既有参数一个不动。

## 6. 必过检验（二值 + 错误注入；注入必须实测会红）

| 编号 | 检验 | 对应注入 |
|---|---|---|
| E1 | 同种子逐位一致、内存快照续跑一致 | — |
| E2 | `SHARE_M=0` 对 EXP-03 逐 tick 退化恒等 | — |
| E3 | 全知臂对 `SHARE_M` 逐位不变 | — |
| E4 | 群体遍历正序 / 逆序逐位相同 | `poison-shareseq`：顺序链式合并（读已被本 tick 改过的记忆） |
| E5 | 一跳上限：构造 ≥3 群体同格场景，C 不得拿到"只有 A 有、B 在快照里没有"的条目 | 同上 |
| E6 | 溯源：每条条目都能在快照里找到同源 | `poison-fabricate`：把收到的值 +1 |
| E7 | 时戳不刷新 | `poison-freshstamp`：把收到条目的 `memt` 改成当年 |
| E8 | 相位内物质不变 | `poison-shareleak`：交换时顺带转移 1 单位 `store`（**全局守恒查不出它**） |
| E9 | `SHARE_M` 严格整数类型校验 → 越界 `ValueError` → 边界 `{0,1,999,1000}` 接受 | — |
| E10 | 独立 RNG 流 `S_SHARE`、键唯一；新增抽签不得扰动其他相位（由 E2/E3 承重） | — |
| E11 | 诊断计数器只读 | `poison-diagfeedback`：让"决策改变数"参与规则 |

三态结果 PASS / FAIL / UNCOVERED 沿用：**构造场景的前提缺失记未覆盖，不计入通过**；必过项失败返回退出码 1。
E4 / E5 **必须挂在定向构造场景上**，不许挂长跑。

## 7. 观察假说（不作为通过条件）

- **G1**：记忆臂的缺粮强度随 `SHARE_M` 上升向全知臂靠拢。
- **G2**：记忆臂的平均信息陈旧度随 `SHARE_M` 上升而下降。
- **G3**：决策改变数 > 0（机制真的改变了决策，而不是只改了不被读取的记忆）。

G3 是"机制生效"的直接计数，与 G1 / G2 分开报，不合成综合分。**预先声明**：
G1 读不到分辨**不能**推出"信息没有用"——EXP-03 已经表明上下界本身在本样本上就不稳定；
G1 成立也**不能**推出"决策有后果"这一总体命题。两个方向都不许外推。

## 8. 为什么是这个机制（三个被否掉的候选）

| 候选 | 否掉的理由 |
|---|---|
| 同格资源转移（赠予 / 分享） | 需要一条"什么时候给"的规则，而任何这样的规则都是制度（互惠、亲缘、地位），不是物理条件 |
| 以暴力索取资源 | 宪法允许的原语，但要同时引入冲突结算、伤亡、强度状态——那是战争，本轮排除 |
| 领地排斥 / 驱逐 | 需要"谁走"的裁决与强度比较，体量与战争相当 |
| 群体合并 | 改变实体生灭规则（id 血缘、账本归并），比信息交换重得多 |

信息交换是唯一一个同时满足：只依赖物理接触、不引入任何制度状态、不改任何物质账、
且在 `SHARE_M=0` 时与现有基线**逐位退化**的候选。
