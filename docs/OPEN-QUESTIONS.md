# 未解决问题与风险登记

Phase 0 结束时仍然没有答案的东西。分四类：**必须由人裁决的**、**必须由实验决定的**、**已知的材料缺口**、**我们承认无法验证的**。

一个项目的诚实度，可以直接读这份清单的长度。

## 2. 必须由实验决定（证据可以回答，只是还没做）

| # | 问题 | 决定什么 | 怎么回答 |
|---|---|---|---|
| E1 | **空壳内核的每 tick 固定开销地板** | 后面所有子系统的预算是不是幻想；也决定主网格分辨率能否维持在 H3 res 5 | 真实数据形状 + 真实 tick 数 + 真实日志写入，每条规则 trivial。两周可做完。**在它出数之前，所有性能数字都是纸上谈兵** |
| E2 | **1 ULP 扰动的发散时间 `T_div`** | (a) 是否必须 bit-exact；(b) 单条历史线的结论里有多少是数值噪声。若发散时间是 60 年，任何跨越 60 年以上的因果解释都必须在集合层面陈述 | 玩具世界里扰动一个 bit，测宏观量偏离到 O(1) 需要多少 tick |
| E3 | **taint tracking 的真实开销** | 读取集追踪能否常开。估计的 2–10× 是工程直觉，未做基准；若实际是 50×，整个因果方案需要重新设计 | 直接测 |
| E4 | **校准量里非等距的占比** | ADR-0002 的等变类和解是否成立。**若 > 50%，必须回到人裁决，在"要校准"与"要自主性"之间真的二选一** | 把打算用的校准量逐条标注等距/非等距并公布比例 |
| E5 | **`p_LLM` 是否校准** | LLM 分布输出这条路是否可行 | 在已知答案的情境上比对分布与经验频率；监测熵是否长期低于 `H(π)` 的一半 |
| E6 | **"有意义但不主导"的中间带是否存在** | 整个 LLM 架构假设是否成立 | 三支线对照（真 LLM / 均匀随机 / 冻结蒸馏策略）的 KS 距离是否双峰化 |
| E7 | **一次真实 View prompt 的实测 token 数** | 全部 LLM 预算建立在一个自述"无来源"的 2000/300 估计上 | 10 分钟能做完，能把一个 D 级数字变成 A 级 |
| E8 | **LOD 提升机制注入世界的力有多大** | 分辨率调度器是不是一条剧情通道 | 小地图跑"永不 promote"与"全程全 promote"两条对照，差异若大于种子间方差，历史主要是 LOD 调度器写的 |
| E9 | **判据在诱饵世界上的伪阳性率** | 整套涌现认证有没有判别力 | 三个诱饵世界（剧情树 / 纯外生 / 纯噪声）× 全套判据的通过矩阵。**任何在剧情树世界上不失败的判据不得进验收集** |
| E10 | **单次长跑时长 vs 机制变更间隔** | 当前架构能否产出一条可信历史线 | 两个数相除。若"一次长跑 30 天而我们平均 5 天改一次机制"，Phase 划分必须改 |

## 4. 我们承认无法验证

这份清单必须保持诚实，且**只能变长不能变短**（除非真的找到了验证方法）。

**因为学界没有共识**：
- 政体寿命分布的形状（四个互相矛盾的已发表答案：指数 τ≈220 / 饱和危险函数 / 指数 τ=298 / 幂律；而 Wand 2024 指出其中一个很可能是幸存者偏差）
- 中国识字率的任何数字
- 查士丁尼瘟疫的规模（两派差 600 倍）
- urban graveyard 效应的真实性与强度（"未解决的辩论"）
- 农业内卷（Huang 与李伯重/Allen 在同一批史料上得出相反结论）
- 道德神与社会复杂度的因果方向（相关 Nature 论文已撤稿，原作者团队的修正版结论已改为"战争与资源同时驱动两者"）

**因为没有经验散布可比**：
- 语言分化树的形状
- 思想运动的扩散
- 宗教内容的演化
- 前工业疫病死亡率的分布族（从未被正式检验）
- 史料密度偏倚的定量校正系数（本次检索中没有任何来源给出）

**因为这是我们自己发明的**：
- 涌现认证协议自身的判别力（没人证明它能把一个剧情树世界打回去；必须用诱饵世界标定，**在标定之前该协议的通过不构成证据**）
- 自主性的方差分解与全部接受带数字
- `U(t)`（世界内史学的可知性上界）能否真的算出来
- POM 的"多少条弱模式才够""模式之间如何加权"（原文与后续文献均未给出量化标准）
- 内生贡献度阈值 τ（Janssen 只给事实，不给可接受阈值）

**因为结构上不可能**：
- 只有被内核评估过的机会能成为缺席因——**从未被建模的可能性永远不会出现在任何因果报告里**，这不可修补
- 穿过 LLM 账本区的因果路径只有下界估计，且偏差方向已知（系统性低估一切通过人的认知起作用的因果路径）
- 慢变量干预的答案取决于我们如何设想它不发生（四种干预给出四个不同的数，这是真实的模态含混，不是我们的失败）
- 我们没有可 dock 的先例模型——检索不到任何已发表、ODD 级文档、经校准并公开代码的中国/东亚早期文明形成 ABM。**因此 docking 只能在我们自己的双实现之间做，永远只能提供 verification 级证据，不能提供 validation 级证据**

## 5. 残余风险（知道但没解决）

| 风险 | 说明 | 缓解 |
|---|---|---|
| **近失账本会加宽人类回路的剧情树入口** | 一旦看到"改革提案在三个时点差点通过，概率 0.11/0.19/0.07"，我们就会想"这个概率是不是太低了"，然后微调危险率参数。每次微调都有像样的局部理由，累积起来等于用人类回路做梯度下降 | 近失账本的聚合统计进预注册验收集；参数漂移审计（某参数被连续多次同向微调 = 警报）。**不充分，这是一个真实的、未解决的残余风险** |
| **精英被个体化、平民被聚合** | "精英过度生产"恰恰是核心机制之一，而我们把这个机制的观测能力集中在了它的一侧。任何"精英与平民的世系动力学差异"都可能是表示方式的产物 | 显式建模抽样权重；小地图上跑"平民也全个体化"的对照，测出表示方式贡献的那部分差异作为误差棒 |
| **最高杠杆期恰是最低证据期** | 路径依赖意味着靠近 t=0 的参数对三千年后影响最大，而前农业期几乎没有可校准量。最大的自由度落在最不可证伪的地方 | 早期取分布不取点值；"终态方差中来自 t=0 抽样的份额"是必填报告字段。
（原先还有一条"早期只允许 A/B 级证据支撑的机制生效"，**已删除**——它以绝对模拟年份为参数开关机制，是阶段门。证据不足的机制应当不实现，而不是让它在某个年份自动上线。见 `spec-world-state §7.4` 的取代说明） |
| **零通量可能让世界永远停在低复杂度** | 而我们无法区分"这是真实的生态约束"与"我们把窗口画错了" | 退路已写下：若牧业机制做不出来，诚实的做法是把世界缩回农业带并声明"本世界没有草原压力"，而不是偷偷打开外部通量接口 |
| **验证判据本身会 Goodhart 化** | 判据一进 CI，每次参数调优就是对判据做梯度上升。更深的问题是 POM 本身就是逆向参数化工具，同一批模式在数学上不能同时充当训练信号与验收信号 | 模式预算账本（看过 N 次自动降级为校准集）；封存验收集，开封即作废；验收集必须从尚未读过的文献中持续补新模式 |
| **决策登记表里有 7 处裁决是它自己的综合，没有任何来源，也没有被任何人审查过** | 包括 §5.5 的分层退出、§5.6 的分账比例、§5.7 的退路声明 | 已在 `docs/DECISIONS.md` §7 逐条列出以便日后追责 |

## 6. 下一步

`docs/DECISIONS.md` §7 给出的执行顺序，本文件同意：

> **先花一周签完 A 档，立刻写 60 秒 spike，然后在 spike 上跑金丝雀与因果隔离测试 —— 在这三件事完成之前，不要写任何机制。**

80 条决定看起来像一个需要半年的研究计划。它不是：A 档 33 条里有 20 条只需要一句话裁决加一个类型定义。**这份清单最可能的失败方式，就是它被当成了一个需要半年的研究计划。**

交叉审查把这一步具体化为 **M1 — 契约与毒药**，见 `docs/INTEGRATION-REVIEW.md` §4：第 0 周产出四份各一页的规范文本（《标识与确定性契约》《事件词汇裁决》《受控访问接口》《相位顺序 V2 与流表 v2》）签字，然后 6–8 周实现 6 个机制 + 三张小地图 + 9 个毒药构建。**它明确不是"跑一个像样的世界"，也不是把 80 条决定全部裁完。**

审查同时指出一个此前没人说破的风险：**四份规格产出之后，"从未跑通一次完整的三千年"这个头号失败模式的概率上升了**——现在有 8221 行规格、0 行内核。
