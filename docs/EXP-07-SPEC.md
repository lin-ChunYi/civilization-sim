# EXP-07 规格与实测结果：原始耕作与弃耕

**唯一新增机制**：群体可以把一部分折算劳动投到耕作上；耕地跨年保留在**地点**上，
没人维护就退化。其余一切照 EXP-06 原样。

引擎 `exp07/verify7.py`（由 `exp06/verify6.py` 复制而来，**旧引擎一个字节都没改**）。

---

## 0. 这一轮假设了什么、没有模拟什么

- **假定群体已经具备耕作能力**。不模拟农业的发明，不按年份解锁，不是历史定律。
- **耕地属于地点，不属于会移动的群体**。当年真正在那一格投入耕作的群体按劳动分成。
- **没有**土地所有权、地主、税收、灌溉、产权冲突。代码里没有 `settled`、没有 `form_village()`。
- **没有改动野外的 `cap` / `regen`**。所以**不能**报告"开垦消耗了多少森林"这类根本没模拟的结果。
- `FIELD_CAP_M` / `FIELD_DECAY_M` / `FARM_YIELD_M` 是**本项目自拟的实验假设（D 级）**，
  **不冒充中国史校准**。

---

## 1. 参数与单位

| 名字 | 值 | 说明 |
|---|---|---|
| `FARM_M` | 0–1000，严格整数，默认 0 | 人口里有多大比例的折算劳动投到耕作 |
| `FIELD_CAP_M` | 60 000 | 单格耕地规模上限（刻度） |
| `FIELD_DECAY_M` | 200 | 未维护耕地的年退化率（千分之一，**向上取整**） |
| `FARM_YIELD_M` | 2500 | 每单位维护过的耕地的年潜在产出（千分之一人年口粮） |

- 人口 N 对应 **N × 1000 个年度折算劳动刻度**；1000 刻度 = 1 个折算劳动年。
  现在没有年龄结构，**这是人口折算预算，不是说每个婴儿都在劳动**。
- 新状态 `field_m[格]`，开局全 0，不可通行格**始终**为 0。
- **1000 个 field 刻度显示为 1 个"耕作规模单位"** —— 不是亩、公顷，也不是人数。
- `FARM_M` 与三个常量都进 `params_fingerprint`；`field_m` 与新增累计账都进 `state_hash`
  （耕地是跨年保留的世界状态，漏了它，"只污染耕地"的一整类 bug 会安静通过）。
- 非法值一律拒绝：`bool` / 小数 / 负数 / 越界 / 字符串。

## 2. 年度顺序与公式

先冻结本 tick **人口变化之前**的 N、位置、储粮与旧耕地。相位 1（资源再生）不改。

### A. 劳动分工与野外采集

```
farm_effort_m     = N * FARM_M
forage_effort_m   = N*1000 - farm_effort_m
room              = max(0, N*NEED_PC*STORE_YEARS_M//1000 - 旧储粮)
collection_limit  = N*NEED_PC + room

claim = min(stock * forage_effort_m // (forage_effort_m + K_HALF*1000),
            collection_limit, stock)
```

之后沿用原来的同格比例结算与扣 stock 规则。
**`FARM_M=0` 时与原公式逐位相同**（分子分母同乘 1000 不改变整除结果）。
**不能"野外照拿全额、农业白赚一份"** —— 注入 `farmfree` 就是干这个的，它必须会红。

### B. 农业：在野外采集之后、援助 2c 之前统一结算

每个可通行格（**包括当年没人的格**）：

```
F        = 相位前的 field_m
L        = 该格所有群体的 farm_effort_m 之和
worked   = min(F, L)
unworked = F - worked
decayed  = (unworked*200 + 999) // 1000          # 向上取整
built    = min(60000 - (F - decayed), max(0, L - F))
field_next = F - decayed + built
```

已有地**先占用维护劳动**，剩下的才去开垦；没维护到的那部分退化。
容量不足时多投的劳动**本年不退回采集预算**，日志里同时记 `labour_m`（投入）
与 `labour_used_m`（有效）。**新建的地只影响下一年**：本年产出只用旧 `F`
（注入 `farmnow` 会让它当年就收，必须会红）。

产量复用相位 1 **同一个抽样点**的天气扰动（`(seed, S_CLIM, tick, cell, 0/1)`），
不新开随机流、不改变原抽样点：`SIGMA_M=0` 时 `weather_m = 1000`，否则 `1000 + u1 - u2`。

```
potential_kcal = worked * NEED_PC * 2500 * weather_m // 1000**3
```

潜在产出按各群体 `farm_effort_m` 的**相对比例**分配，整数余量按
（余数降序、`band_id` 升序）派发。**必须用 `proportional_share`**，
不能用把权重当额度上限的 `largest_remainder`。

每个群体：

```
crop = min(自己的产量份额, max(0, collection_limit - 已结算的野外采集量))
total_harvest = 野外采集量 + crop
```

**未采收量 = 潜在 − 实际采收**：不转给别人、不留到明年、不进可食用库存、
也不记成库存损耗 —— 就地作废。

只把**实际 crop 之和**计入 `inflow` 一次，同时记 `farm_harvest_cum` 作为来源分项。
野外采集仍然是库存内部转移，不重复计 `inflow`。

`total_harvest` 之后交给原来的援助、消费、腐损、人口、信息交换、迁移与分裂流程，
**这些公式一个字没改**。`field` 留在原格，不随迁移移动、不复制给分裂出来的子群体；
后来者实际来到之后按同一套规则使用。原有的资源记忆没有被扩充成"全图耕地知识"，
本轮**不声称**群体已经能为未来的农田做规划。

## 3. 必须成立的账

| 账 | 恒等式 | 函数 |
|---|---|---|
| 劳动预算 | 每群体 `耕作刻度 + 采集刻度 == 人数 × 1000` | `farm_labour_error` |
| 耕地 | `Σ field_m == 累计开垦 − 累计退化` | `field_ledger_error` |
| 产出 | `潜在 == 实际采收 + 未采收` | `farm_yield_error` |
| 入账来源 | `inflow == 资源再生入账 + 农业实际采收` | `inflow_source_error` |
| 资源 / 人口 / 信息 / 援助 / 援助记忆 | 与 EXP-06 相同 | 原有五个 |

**九本账在 42 组 300 年里全部恒等（42 / 42）。**

### 事件

`farm_log` 三类：`field_built`、`farm_harvest`、`field_decay`。
每条带内部 tick、真实事件格、参与者、投入与有效劳动、前后规模、实际数量与来源。
**同格同年同类型聚合成一条**，参与者明细保留。
**只有实际开垦 / 采收 / 退化 > 0 才生成对应事件**；零产量只留在年度数据里，不编"丰收"。
不把收获算成援助，不把开垦叫成"村庄成立"。

## 4. 四个受控相位（实测值）

`NEED_PC = 730000`。以下四场都是**独立构造的受控相位**，不是彼此的下一年。

| # | 输入 | 实测 |
|---|---|---|
| 1 | 20 人 / 旧储粮 5 人年 / 野外 60 人年 / 旧耕地 0 / `FARM_M=250` | 野外采集 **20 人年**，新建 field **5000**，农业产出 **0**。`FARM_M=0` 时野外采集为 **24 人年** |

| 4 | 储粮 + 野外采集已把采收限额用满 | 潜在 > 0，实际采收 **0**，差额全部计入未采收 |

## 5. 测试

```
python3 exp07/run_tests.py [--report 路径.json]   →  35 项全过 / 0 未覆盖
```

期望值**在测试文件里独立算**，不调用生产结算函数当答案。覆盖：四个受控相位、
零劳动、`FARM_M=1000`、多人竞争与余数、容量饱和、空格退化、迁移后耕地留存、
后来者使用、分裂不复制、非法值、遍历顺序（`order` / `revorder` / `cellrev`）、
完整快照恢复、九本账恒等、`FARM_M=0` 逐步退化。

**退化检验用 EXP-06 自己的字段与哈希口径**判定，
**不要求** EXP-07 的身份哈希等于 EXP-06 的（它本来就该不同）。
实测 7 个种子 × `SIGMA_M{0,400}` 的 60 年逐年哈希一致，120 年 `full_digest` 相同。

错误注入七个，**全部实测会红**：`farmfree`（白赚劳动）、`farmnow`（当年开垦当年收）、
`farmnodecay`（不退化）、`farmcap`（无视上限）、`farmgift`（未采收转给别人）、
`farmlimit`（无视采收限额）、`float`（浮点污染采集）。

> `float` 那条**自然跑里撞不到**：40 万次随机抽样只有 0.09% 的 `(stock, N, FARM_M)`
> 会让二进制浮点跨过整数边界。所以它挂的是一个**定向构造**：
> `stock=102 901 986、N=48、FARM_M=250` → 整数 56 128 356 / 浮点 56 128 355。
> 挂在长跑上的检验永远是绿的 —— 这正是 EXP-01 记下过的陷阱。

## 6. 42 组扫描（原始数据在 `docs/evidence/exp07-20260913/`）

7 种子 `[0,12345,777,4242,99,31337,2026]` × `SIGMA_M{0,400}` × `FARM_M{0,250,500}`，
各 300 年，`MOVE_MORT_M=50 / SHARE_M=1000 / AID_M=1000 / RECIP_M=1000`，记忆臂。

```
python3 exp07/run_scan.py --output-dir <目录>
```

中位数（每档 14 组）：

| FARM_M | 末人口 | 人年 | 缺粮‰ | 采收人年 | 未采收人年 | 耕地规模 | 居住中位 | 没挪过窝‰ | 末段中位 |
|---|---|---|---|---|---|---|---|---|---|
| 0 | 425 | 83 587 | 8 | 0 | 0 | 0 | 6 | 140 | 12 |
| 250 | 1530 | 178 573 | 0 | 63 950 | 48 215 | 435 318 | 2 | 690 | 47 |
| 500 | 1711 | 186 992 | 0 | 79 761 | 140 166 | 869 143 | 0 | 986 | 142 |

读数（只报告，不调参）：

1. **耕作明显抬高了人口与累计人年**，缺粮率从 8‰ 降到 0–2‰。
2. **未采收的比例很高**：`FARM_M=250` 时实收只占潜在的 58.2%，`FARM_M=500` 时只有 38.1%。
   原因是**采收限额**（当年需求 + 储存余量）先到顶，多出来的产出就地作废。
   这是规则的直接后果，不是损耗、不是浪费机制，模型里也没有"存不下就烂掉"的通道。
3. **有效劳动**在 `FARM_M=250` 时 100% 用上；`FARM_M=500` 时 99.5%，
   剩下的 0.5% 是撞到单格 60 000 上限投不下去的。
4. **"居住中位"这个数会把话读反**，必须和另外两列一起看：
   一个群体从分裂出来到末年都没挪过窝，它那一段**两端都被截断**，不进"居住中位"。
   所以 `FARM_M=500` 的"居住中位 0"**不是**"更不定居"，恰恰相反 ——
   **98.6% 的群体整段生命里一次都没换过格**，末段中位数 142 步。
   `FARM_M=0` 时这个比例只有 14%。
   即便如此，这**只是"这群人没动"**：模型里没有村落、没有产权、没有制度，
   **不能据此宣称出现了定居文明**。
5. 两个 `SIGMA_M` 档之间没有量级差别；耕作的效果不依赖资源波动是否开启。

## 7. 本轮**不得**宣称的

- 不得说"开垦消耗了森林 / 改变了野外承载力" —— `cap` / `regen` 一个字没改。
- 不得把"没挪过窝"说成定居文明、村落或制度。
- 不得把三个常量说成有史料依据；它们是 D 级实验假设。
- 不得说本轮模拟了农业的发明、技术进步或产权演化。
- 不得把"未采收"说成浪费或损耗机制 —— 它只是采收限额的算术后果。
