## 1. 新增的那一个机制

**迁移的代价作用于人口，而不是储存。**

```
群体每完成一次迁移（相位见 §3.1）：
    depart = 迁移前的实际人数              ← 不是初始人数
    macc  += depart × MOVE_MORT_M
    dead   = macc // 1000 ;  macc -= dead × 1000
    size   = depart − dead                 ← 幸存者带着储存一起走

类型：MOVE_MORT_M 必须是严格整数（排除 bool）；先查类型再查范围
范围：MOVE_MORT_M ∈ [0, 1000]。0 = 无代价（退化为 EXP-02）；1000 = 整群全灭
```

唯一实现在 `move_mortality(size, macc, mm) -> (dead, survivors, macc)`，定向检验直接打到这个函数上。

**为什么用累加器而不是 `size × mm // 1000` 直接取整**：后者有量化死区——在 `mm=20` 时对小于 50 人的群体损失恒为 0，而本世界群体典型规模就是 20–30 人，机制会对多数群体完全失效。累加器沿用既有 `bacc`/`dacc` 的写法，不引入新机械。

**口径声明**：这是一个**确定性取整近似**。它不产生方差、不产生尾部事件，**不冒充个体随机死亡模型**；它只保证长期比例正确，并把不足 1 人的部分留作余数而不是丢弃。

现有的 `MOVE_LOSS_M`（作用于储存、结构性恒为零）**保持原样不动**，本机制是另加一条代价通道，不是去修它。

## 2. 它要回答什么问题

**在迁移策略固定时，新增迁移死亡代价如何改变不同信息条件下的人口、缺粮与迁移结果。**

这个代价**适用于所有迁移**，不是只惩罚误判——因此它同时改变迁移的收益结构与人口规模，不能被读成"对错误决策的罚款"。

已有的测量事实（只陈述读数，不外推）：EXP-01 测到信息滞后 4.5 年、事后看错的迁移约 1.5%；两臂在缺粮与人口上互有高低、没有稳定方向；EXP-02 加入资源波动后误判率没有上升。**这些读数说明的是"在那些配置与样本下没有测到稳定的信息优势"，不能推出"决策没有后果"**——后者的证据要求远高于这两个切片。

## 3. 人口与粮食核算（完整定义）

### 3.1 迁移死亡的位置

相位顺序不变，迁移死亡加在**相位 6b 迁移结算内部**，即**本 tick 的消费（相位 3）之后**：

```
1 regen → 2 claim/allot → 3 consume（算出 E、结算当年吃用）→ 4 spoil
→ 5 demography（出生/原规则死亡）→ 6a scout → 6b migrate（含迁移死亡）
→ 7a extinct → 7b/7c/7d split → 8 log
```

- **出发人数** = 相位 5 之后、迁移那一刻的 `size`。
- **死亡人数** = 上式的 `dead`。**幸存人数** = `depart − dead`。
- **不回溯修改已结算的当年消费。** 当年的 `need`、`eat`、`deficit` 都按迁移前的人数算过了，迁移死亡不去改它们。这是一个明确的建模选择，不是疏漏。
- 储存**不因死亡而减少**：人不是能量，能量守恒式不变。

### 3.2 两条必须恒为零的账

```
能量守恒：Σstock + Σstore == 初始 + inflow − out_eat − out_spoil − out_move − out_lost
人口恒等：期末人口 == 期初人口 + 出生 − 原规则死亡 − 迁移死亡
```

人口恒等式里**迁移与分裂本身不增减全球人口**，所以差必须精确为 0。注意原规则用 `max(0, ·)` 截断，因此"声称的死亡数"未必等于实际死亡数——账上记的是**实际**死亡数。

### 3.3 累加器的归属与分配

- `macc` **每群体独立保存**。一个群体迁移不影响另一个群体的累加器。
- **分裂时显式分配**：子群体得 `macc // 2`，母群体保留 `macc − macc//2`。**余数总和不变。**
- **不迁移不累计**：没有迁移的 tick，迁移死亡增量必须为 0。
- **`MOVE_MORT_M = 1000` 全灭**：`dead == depart`，`size` 归零，群体在相位 7a 被移除，储存计入 `out_lost` **一次**。
  附一条结构性事实：能迁移必然 `E < 1`，而 `E < 1` 必然储存已被吃光，**所以死于迁移的群体储存恒为 0**（`out_lost` 不变不是漏记）。"只记一次"这条记账路径因此由一个直接构造的 `size=0, store>0` 状态单独覆盖，见 §4 D12(c2)。

### 3.4 新字段进入哪些校验

| 字段 | state_hash | 快照 | 运行身份 |
|---|---|---|---|
| `MOVE_MORT_M` | ✔（账本项） | ✔ | ✔（进参数指纹） |
| 群体 `macc` | ✔（进 `BAND_FIELDS`） | ✔ | ✖ |
| `mig_deaths_cum` / `births_cum` / `deaths_demo_cum` / `need_cum` / `personyear_cum` / `macc_global` | ✔ | ✔ | ✖ |

### 5.3 H1：本配置与本样本未支持

福利用两个指标衡量，**不合成综合分**：指标 A = 记忆臂缺粮强度 − 全知臂缺粮强度；指标 B = 全知臂人口 − 记忆臂人口。正值均表示全知臂更好。

| SIGMA | MORT=0 | 20 | 50 | 100 | A 单调不减 | B 单调不减 |
|---|---|---|---|---|---|---|
| 0 | A −0.049pp / B −126 | +0.001 / +17 | +0.005 / +32 | +0.024 / +128 | True | True |
| 400 | A −0.011pp / B −420 | −0.071 / −673 | −0.001 / +291 | −0.021 / −204 | False | False |

`SIGMA_M=0` 档两个指标都呈单调不减，看起来像支持。**但逐种子配对差直接否掉了这个读法**：

```
SIGMA_M=0  ：聚合差最大绝对值 / 对应档位逐种子半幅 = 0.39   各档正号数 [3,4,4,5]/7
SIGMA_M=400：聚合差最大绝对值 / 对应档位逐种子半幅 = 0.27   各档正号数 [4,2,2,2]/7
```

聚合差比种子间离散半幅小一个量级，逐种子符号接近对半。**结论：本配置与本样本未支持 H1。** 这是"未支持"，**不是"已证伪"**——本样本没有分辨力，不是给出了反向结论。

**本轮没有计算噪声地板**（同配置下换种子集合会有多大波动），所以即使某一档出现单调性，只要聚合差没有明显大于逐种子离散区间就不能当成结论。要把它变成结论需要更多种子与一个空对照，那不属于本切片。

**不能从这次结果得出的判断**（写在这里以免日后被误引）：不能说决策无效、不能说信息边界无用、不能说社会机制不值得研究。**H1 不成立不构成禁止以后研究社会机制的依据。**

## 6. 读数须知与限制

1. **迁移死亡代价适用于所有迁移，不是只惩罚误判。** 它同时改变迁移的收益结构与人口规模。
2. **不要把"死得更多所以缺粮总量下降"读成福利改善。** 主指标是缺粮/需求（强度），并与累计人年并列报告。
3. 全知臂误判恒为 0 有一部分来自选择规则的定义（读当年真值，按定义选不错），**不当福利收益**。
4. **指标方向不一致时不造综合赢家**，如实并列（`SIGMA=400` 档正是这种情形）。
5. 迁移为 0 时误判率记"不可计算(分母0)"，不记 0%。
6. `MORT=0` 档是退化档，与 EXP-02 一致（由 D7 判定，不由观察表判定）。
7. EXP-01/EXP-02 的已知限制**原样继承且未修**：`MOVE_LOSS_M` 结构性恒为零、默认样本无灭绝、饱和由分裂规则几何造成、均衡食物比与 LTP 的 0.668 有已量化偏差、多数假设为 D 级。
8. 仍然**未验证**：跨版本存档兼容、人口学标定、跨架构一致、多线程确定性、噪声地板。
