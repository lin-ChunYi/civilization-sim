# ADR-0002：地图基底跑扰动实例，世界边界零外部通量

- **状态**：提议（等待人类签字）
- **日期**：2026-09-10
- **相关**：`docs/CONSTITUTION.md` 互斥 1；`docs/spec/spec-world-state.md` §8、§10

这份 ADR 记录两个耦合的决定。它们都是不可逆的——改任一条都等于世界作废重跑。

---

## 决定 A：正式主线运行在一次性创生扰动基底上

### 决定了什么

1. **主线基底 = `T(真实东亚骨架, world_seed)`**：一次性、创生时应用、结果冻结、内容哈希为 `basemap_hash`。扰动算子包括东西镜像、旋转、河网局部重连、海平面偏移、走廊剪断/新开、降水梯度主轴旋转。**不是每 tick 扰动。**
2. **全面去名**：主线基底不含任何真实地名/水名/山名/族名。任何 agent 视图、任何 LLM prompt 都不得出现经纬度绝对值。
3. **未扰动的真实基底与全部考古/历史数据库（51,074 遗址点、7,083 个 ¹⁴C 年代、CHGIS、HYDE、CHELSA-TraCE21k）只存在于物理隔离的评估进程**：不同 crate、不同进程、不同目录、只读挂载，内核对它零可见性，CI 强制。
4. **关键补充——扰动算子必须声明它的等变类，校准量必须是该等变类下的不变量**：
   - **等距不变量**（镜像/旋转下精确不变的、只依赖协变量不依赖绝对坐标的统计量，如 `density(site | elev, slope, precip, TWI, dist_to_navigable_water, dist_to_grassland)`）→ **可以在主线上直接校准**。
   - **非等距量**（依赖水系拓扑、海岸距离、走廊中介中心性、降水梯度方向的量）→ 只能在评估进程里、在未扰动基底上标定其**函数形式**，然后把 `f(covariates) → rate` 搬到主线。**搬运的是函数形式，不是拟合的空间场**，每次搬运在参数登记表留痕。
5. **自主性必须被测量并预注册接受带**：20 维预注册宏观描述向量，按基底实例 × 参数抽样 × 种子做嵌套方差分解，`Autonomy_k = (σ²_seed + σ²_{seed×basemap}) / Var(M_k)`，并配 `R²_geo`（用 {高程, 坡度, 降水, 距通航水体, 距草原生态带, 纬度带} 的样本外预测力）。骨架层允许 `Autonomy ≥ 0.10`、`R²_geo ≤ 0.80`；中层要求 `Autonomy ≥ 0.50`、`R²_geo ≤ 0.50`。

### 为什么

两份简报给出了相反的结论，而它们争的其实是不同的东西：

- `china-eastasia-geography-archaeology` §3.0：**必须用真实地形**，因为校准资源在合成大陆上全部失效——"放弃真实地形 = 放弃校准集"；且合成地形的算法偏见会以不可见的方式污染涌现结论。
- `east-asia-climate-environment` §11.2：**必须扰动**，因为一比一真实地形会诱导"这里应该出现关中"这类思维。

`critique/mandate-contradictions` F1 支持扰动，理由是硬的：距草原距离是农业格帝国密度的最强预测因子，与农业持续时间、高程三者解释 42% 方差；消掉草原效应后 R² 从 0.65 掉到 0.17（Turchin et al. 2013）。**在真实东亚地图上宣布"世界自己演化出了统一农耕帝国和北方游牧对手"，信息量接近零。**

但 F1 没有解决 `china-geography` 的反对意见：扰动之后那 51,074 个遗址点还怎么用？如果答案是"用不了"，F1 就是在用"放弃校准集"换"自主性"。

**等变类分析是这个冲突的解**：镜像与旋转是球面等距同构，一切只依赖协变量的统计量在它们下面精确不变。`china-geography` 要的"统计与拓扑性质 + 全套校准资源"通过等距不变量保留下来；`east-asia-climate` 要的"实例被打乱、没人能预期关中"通过扰动实现。

**不用纯合成大陆的理由**：合成大陆最大的隐患不是"不像"，而是"你不知道它哪里不像"。"盆地—走廊—平原"这类拓扑（一条 900 km 的单线走廊连接两个大生态区）是一个低概率构型，随机生成极难自发产生。

### 替代方案

| 方案 | 为什么不采纳 |
|---|---|
| 一比一真实东亚做主线 | 无 holdout；宏观骨架高概率复演；"这个世界拥有自己的历史"无法被保卫也无法被检验 |
| 纯程序生成大陆 | 校准集全部失效；生成算法偏见不可见 |
| 每 tick 扰动 | 破坏地理的时间连续性，路径依赖失去物理锚点 |
| 只做去名不做几何扰动 | 挡住了 LLM 的语义泄漏，挡不住地理决定论——最强的那条通道还开着 |

### 仍是待验证假设

- **最大的残余风险：如果实测发现绝大多数有用的校准量都是非等距的，这个和解就退化了。** 而这很可能发生——河网拓扑、走廊中介中心性、距草原距离恰恰是最强预测因子那一类，而它们全部是非等距的（河网重连、走廊剪断、降水梯度旋转都会改变它们）。**行动：Phase 0 结束前必须做一次清点，把打算用的校准量逐条标注等距/非等距并公布比例；若非等距占比 > 50%，本 ADR 必须回到人裁决，在"要校准"与"要自主性"之间真的二选一。**
- 全部接受带数字（0.10 / 0.80 / 0.50 / 0.50）是 **D 级**，需在玩具世界标定。
- 自主性的方差分解改写（原建议是条件熵比，在 N=200 下不可估计）是**本项目原创，无来源**。
- 非等距量的"函数形式可搬运、空间场不可搬运"这条界线在实践中是否清晰可判，未验证。
- 扰动强度与"世界还像不像东亚"之间的权衡没有客观标准。

## 决定 B：世界边界零外部通量

### 决定了什么

1. **窗口必须画得足够大，使整条温带草原/牧业生态带及其与农耕带的接触面完整地在世界之内**，其人口、畜群、机动性、技术全部内生模拟。窗口准入判据：包含草原带完整跨度且外加 ≥500 km 缓冲；包含所有与陆地核心区相连的海岸线与第一列近海群岛链；边界处通行成本必须自然地高，若不得不切在低成本通道上，该通道必须被显式记为"世界的裂口"并在报告中列出。
2. **窗口外是吸收边界，默认外部通量恒为 0。** 越界迁出的人口记为永久损失；没有任何东西从窗口外进来。
3. `world_external_flux` 接口**在生产线编译期关闭**（feature flag off，代码里连符号都不存在）。启用它的运行永久带 `exogenous_flux_on` 标记，且不得用于任何关于自主性的主张、任何世界史叙述、任何小说素材。

**这与 `critique/mandate-contradictions` 决定 5 的建议默认值相反**——该红队建议"有限世界 + 显式的低频泊松外部通量接口"。

### 为什么

**理由一（决定性）**：如果窗口边界切在草原带里，"北方压力"就变成一条从窗口外流进来的泊松流，其到达率是我们写的一个 D 级参数。于是纲领里最重要的宏观格局就是**我们手动注入的**。该红队自己在决定 5 里写了这句话——"若做成外生流，我们等于手动注入了真实历史最重要的那个变量"——本决定把这句话当作否决理由，而不是当作可接受的代价。

**理由二**：非零默认值烤不回来。一个非零到达率会静默控制最有后果的东西（新作物、新病原、新军事技术）的出现时刻，它是一个无法标定的 D 级数字，下游影响会被路径依赖放大三千年。设成 0 之后世界的贫瘠是**可读的**——如果世界从没长出金属冶炼，那是一个结果，不是一次缺席的进口。而且**这个决定在诚实的方向上可逆**：你随时可以打开它并测量差异；你没法把一个已经烤进三千年历史的到达率取出来。

**理由三**：外部通量接口在结构上与反剧情树禁用清单里的"兜底重生"同形——它是一个"当世界内部没有产生我们期待的东西时，从外面送一个进来"的通道。它的正当工程借口（"真实东亚不是封闭的"）是真的，但这个借口同样适用于剧情树。

### 代价（必须签字）

**这是代价最大的一条裁决。**

小麦、大麦、绵羊、山羊、黄牛、马、青铜与铁的冶炼技术，在真实历史上都是从窗口外传入东亚的。零通量意味着**这些东西必须在窗口内被独立发明，否则永远不存在。我们的世界很可能没有马。** 没有马意味着没有骑射；没有骑射意味着草原压力的形态与真实历史完全不同。

**这不是 bug，是这次裁决买到的东西。** 如果我们注入马，"草原骑兵帝国"就是我们放进去的。如果不注入，世界要么自己驯化出某种大型可骑乘动物（由 Taxon 注册表的抽样决定），要么发展出完全不同的北方接触带动力学——后者正是纲领第 1 条与第 7 条要的东西。

推论：**"这个世界里有没有可驯化的大型役畜"是一次抽样的结果，不是一个设定。** 这个 bit 会解释后续三千年历史的很大一部分方差，因此它必须作为一等的世界属性出现在报告首页。

同时失去：一切依赖"传入时间"的考古锚点在主线上不可用，只能在评估进程里用。

### 替代方案

| 方案 | 为什么不采纳 |
|---|---|
| 低频泊松外部通量（红队建议） | 见理由一：等于手动注入真实历史最重要的变量 |
| "幽灵边缘"：边界外一圈降级模拟带 | 不是外生注入（好），但它产生不了新驯化物或新技术（没有历史深度、没有个体、没有信息网络），付出复杂度却没换到代价缓解 |
| 窗口扩到整个亚欧非 | 格数到 10⁶ 量级，格扫预算超支一个数量级；且把项目从"以东亚为舞台"变成"以旧大陆为舞台"，超出纲领 |

### 仍是待验证假设

- 指示性窗口（约 65°E–150°E、15°N–58°N，H3 res 5 约 1.4×10⁵ 格，按陆比 0.6 约 8.4×10⁴ 陆格）中，**陆比 0.6 是拍的数，必须实测**。
- 500 km 缓冲这个数字是 **D 级**。
- 扰动算子中的"走廊剪断/新开"可能改变裂口位置，因此扰动后必须自动重新检查窗口准入判据；**作废率必须报告**（作废率高说明扰动算子太强）。这条检查的可行性未验证。
- **退路必须现在写下来**：若牧业机制在 Phase 1 做不出来，唯一诚实的退路是**把世界缩回农业带并声明"本世界没有草原压力"**，而不是偷偷打开外部通量接口。
- 零通量对"世界能否长出足够复杂的社会"的影响未知。这是一个真实的风险：世界可能因为缺少关键驯化物而永远停在低复杂度，而我们无法区分"这是真实的生态约束"与"我们把窗口画错了"。
