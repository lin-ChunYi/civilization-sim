# ADR-0001：把"AI 不能直接决定客观结果"重写为"测度归规则，分布归 LLM"

- **状态**：提议（等待人类签字）
- **日期**：2026-09-10
- **取代**：原始纲领第 5 条的字面表述
- **相关**：`docs/CONSTITUTION.md` P5、P9；`docs/spec/spec-llm-boundary.md`；`docs/DECISIONS.md` A25、§5.5

## 决定了什么

1. **规则拥有每一个概率测度与每一次状态转移。** LLM 对世界状态 schema 每个字段的写权限恒为空集。它的输出只能是两样东西：(a) 规则生成的**有限选择集上的一个分布** `p_LLM`（采样由我方 CBRNG 完成，**不是让它挑一个**）；(b) 不参与任何数值计算的**标签文本**。

   *为什么是分布不是选择*：单点选择是三重损失——反事实 abduction 失效（无法回答"同样局面下它有多大概率不这么做"）、注入的熵不可观测、污染指标只能单边。有了分布，污染量就是 `D_KL(p_LLM ‖ π)`，可计量、可进预算。这一条修正了本 ADR 初稿的"选择归 LLM"。

1b. **默认档是 `surrogate mode`（LLM 全关），所有带因果主张的正式实验只在这一档运行。** LLM 只允许出现在三个受限位置：**(P1)** 运行期分布提供者；**(P2)** 离线策略编译器（产出可审阅、可 diff、带 hash 的策略片段，运行期执行确定性策略函数）；**(P3)** 作者层渲染器与**假设提出器**——它可以提出"也许是 X 导致的"，但写入因果图的是消融的实测结果，不是它的话，所以它在这里可以猜错一百次而不污染任何东西。

2. **删除"AI 负责解释"这一职责。** LLM 对因果图的写权限恒为零，CI 断言 `causal_purity = 0`。**同时禁止 LLM 充当合理性裁判**——判官与生成者共享同一套先验，这个裁判的检出力是负的：它会系统性放行那些符合 LLM 先验（也就是最像真实历史）的输出。若用作辅助筛查，必须先在金丝雀集上标定，且只能生成待人工检查的问题清单，永远不能删除或修改任何东西。

3. **把"AI 负责文化创造"降级为 verbalization。** 命名权收回给世界内的音系/构词/音变引擎（`name` 字段类型为 `EntityRef` 而非 `string`）；教义、制度、神话是结构化对象，每条禁令必须指向真实状态变量，每个起源神话槽位必须填入真实 `event_id`；LLM 只负责把结构口语化。

4. **"不作为"是规则侧默认路径，不是选项之一。** 没有触发器触发 → 什么都不发生 → 不调用 LLM。触发器只能引用物理量/经济量/信息量，禁止引用叙事节拍变量（"距上次大事件已 N 年"）。

5. **设立 LLM 影响力比特预算**：`narrative_bits_per_century = Σ −log2 π(a*)`，与规则 RNG 注入熵作比。越界只有两种合法处置——承认规则先验错了去改规则，或强制从 π 采样。

6. **架构硬约束**：世界在 LLM 完全关闭时必须能独立跑完三千年。

## 为什么

原文"AI 不能直接决定客观结果，例如 AI 可以决定发动战争，但战争胜负必须由规则计算"**在代码里不可判定**——战争爆发本身就是一个客观结果。这条边界实际保护的只有 `P(结果 | 战争发生)`，完全放弃了 `P(战争发生)`。而决定一部历史长什么样的主要是后者。

四条独立的失败通道：

**基率污染**。LLM 被问"你要不要打"时，答案不是从结构条件下的真实风险率 λ 采样，而是从"这个局面写成故事好不好看"采样。事件基率 = 咨询频率 × p(行动)，与世界状态无关，只与工程预算和提示词措辞有关。p 只要比 λ 高 20%，三千年累积下来就是一个完全不同的文明。**而每一场战争都会通过审计**：有前置资源缺口、有完整因果链、胜负由规则算。污染不在任何一条因果链里，它在因果链的数量里。

**解释权即事后合理化**。Turpin et al. 2023（arXiv:2305.04388, NeurIPS 2023）实证：仅重排选项顺序注入偏置就使 BIG-Bench Hard 13 个任务准确率掉 36%，而模型的 chain-of-thought 从不提及真正起作用的因素，反而给出一套自洽的别的理由。如果解释在裁决之后生成，模型已看到结果，必然构造通向该结果的叙事——**这在定义上就是合理化**，与"可追溯"背道而驰。

**文化创造是最大的真实历史泄漏通道**。LLM 关于"东亚季风河谷农业君主制的正当性叙事"的条件分布，其众数就是真实中国思想史。要求它为王权编一套天授正当性，"天命"会以极高概率自发出现，连带革命/德/礼的整套语义网络。这不是模型偷偷抄，这就是它学到的东西。一旦这些进入世界，"不需要出现真实历史上的制度"就作废了——我们复刻的恰恰是真实历史最核心的观念史层，只换了国号。

**间接通道**：文化 → 偏好权重/合法性/协调成本/通婚继承规则/禁忌 → 行为 → 制度 → 客观结果。"这个宗教禁止春季屠宰耕牛"是一句文本，同时是一个生产函数修改。只要下游有任何一段代码把文本解释成参数，AI 就在决定客观结果——**而写状态的是那段解释代码不是 LLM，所以"LLM 对世界状态写权限为空"的检查全部通过。**

## 有哪些替代方案

| 方案 | 为什么不采纳 |
|---|---|
| **保留原文，靠代码评审把关** | 污染只在分布层可见，单个事件层面每次审计都能通过。评审看不见它。 |
| **让 LLM 决定但事后用规则校验合理性** | 校验只能拒绝不可行的动作，无法纠正基率。而基率才是问题。 |
| **调低温度 / 加"不要戏剧化"的提示词** | 温度改变的是同一个分布的采样锐度，而问题是分布本身错了（众数错、方差错、尾部缺失）。提示词措辞本身就是先验来源。 |
| **LLM 完全退出，纯规则模拟** | 会失去人物级判断、文化内容、世界内叙事这些难以公式化的部分。**但这条作为退路被保留**——见下。 |
| **用 LLM 蒸馏出决策策略，运行期只执行策略** | 部分采纳（作为降低成本与恢复确定性的手段），但不能完全替代——策略的适用边界本身需要判断。 |

## 第二轮红队推翻了本 ADR 初稿的两条设计

`research/critique/llm-storytelling.md` 的第二轮（R2）明确标注"推翻 R1"，推翻的是本 ADR 初稿依赖的两个东西。已采纳：

**F6：LLM-off 孪生线不是有效对照，`event_rate_ratio` 建在一个坏分母上。** 两个独立的致命缺陷——(a) 这是一个路径依赖、混沌的系统（纲领第 3 条明确要求它是），两条线在分叉后几十年就进入不同状态。LLM-off 那条线可能压根没形成国家，它的战争频率当然低，但这不说明 LLM-on 被污染了。`f_on / f_off` 在分叉几百年后测的是"两个世界有多不同"，而且方向性错误是确定的：任何让世界更复杂的机制都会同时抬高几乎所有事件率。(b) 控制组是我们自己写的，可以被拟合——**有人会去调默认策略，直到比值落进阈值**，此后指标永远绿灯，而两条线可以同时是错的。

  **替代**：把比较从世界级降到**决策点级**——在同一条 LLM-on 运行里，每个决策点同时算 `π` 与 `p_LLM`，直接测 `D_KL(p_LLM ‖ π)`。这是配对比较，不受世界发散影响，样本量等于决策次数，功效高得多（这是 off-policy evaluation 的标准做法）。再加**第三条腿：外部经验校准**——决策点级比较只能告诉我们"LLM 和我们的规则谁更极端"，不能告诉我们谁对；要回答后者必须有世界之外的锚（Seshat 的战争起始率、政体存续时长分布、权力交接方式分布等分布级目标）。孪生线保留但降级：只用于空反事实的噪声地板，以及分叉后 50 年内的短窗口对比。

**F10：「LLM 输出永不回流为 LLM 输入」这条硬约束不可实现。** 只要 agent 之间存在自然语言通道（谈判、说服、传教、谣言），文本就必然回流。**正确形式是：回流的必须是结构化对象，不是文本。** 本 ADR 与宪法 P5 已按此表述修正。

**另外，F7 提出了一个本 ADR 完全没有覆盖的更深问题**——`π` 的作者是我们。已写成宪法 P5b，见那里。

**已知缺口**：`llm-storytelling.md` 的 R2 版本自称有 26 条发现，但磁盘上的文件在 F9 处被会话额度中断截断，F10–F26 只在正文中被引用而没有原文。第一轮（R1）的 14 条完整结构化结果保存在工作流 journal 中。**F10–F26 需要补跑**，见 `docs/OPEN-QUESTIONS.md`。

## 哪些部分仍是待验证假设

0. **`p_LLM` 的校准性尚未验证。** 让模型输出一个分布，不等于那个分布是校准的。必须检验：`p_LLM` 的熵是否长期低于 `H(π)` 的一半（坍缩），以及在已知答案的情境上它的分布与经验频率是否一致。

1. **"有意义但不主导"的中间带是否存在，尚未验证。** 必须做三支线对照：A=真 LLM，B=从同一候选集均匀随机抽，C=冻结的蒸馏策略表。若 A 与 B 的宏观分布 KS 距离要么接近 0（LLM 是昂贵装饰）要么很大（LLM 是剧情源），中间带在实证上就是空的，本 ADR 的整个架构假设落空。**退路已写进宪法 P5：接受 LLM 完全退出因果链、只在作者层工作。**

2. **比特预算的可接受阈值是 D 级。** `narrative_bits_per_century` 的健康区间没有任何文献依据，必须在玩具世界上标定。

3. **`event_rate_ratio ∈ [0.8, 1.25]` 与 `budget_sensitivity ≈ 0` 的具体阈值是 D 级。**

4. **音系引擎能否真的产出"读起来不像汉语"的专名，未验证。** 需要困惑度下界检验（用真实汉语古典语料训练字符级 n-gram，对生成专名算困惑度，设硬下界）与史学家盲测（20 个世界国号混 20 个真实年号，我们要的结果是"能明确指认哪些不是中国的"）。

5. **"LLM 偏好戏剧性"这一条方向性存疑。** `research/briefs/llm-agent-social-simulation.md` §8 明确指出：两轮检索没有找到 LLM"偏好戏剧性"的任何直接实证；能找到的证据（typicality bias、sycophancy、叙事同质化）指向的是**趋同与平淡**。真实风险更可能是"所有王朝写成同一个王朝"而非"编出精彩宫斗"。本 ADR 的防御对两个方向都有效，但**我们不应把"LLM 爱编戏"当作已确立的事实来引用**。

6. **文化能作用的有限数值通道清单（建议 ≤12 条）尚未定稿**，见 `docs/spec/spec-llm-boundary.md`。
