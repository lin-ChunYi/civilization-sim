**状态**：v1.0（Phase 0 产出，待人类签字）
**性质**：本文件是项目的最高约束。任何设计文档、代码、实验、对外表述与其冲突时，以本文件为准。
**修改规则**：本文件的每一条修改都必须记录 ADR（`docs/adr/`），说明改了什么、为什么、依据是什么、作废了哪些既有结论。**修改第 2 章的任何一条 = 全部已跑历史线作废。**

原始纲领存档在 [`MANDATE.md`](MANDATE.md)，**不修改**。本文件是它经过 22 份学科研究简报与 7 个视角红队审查之后的可执行重写稿。凡本文件与原始纲领字面冲突之处，第 6 章逐条列出了改写理由。

## 0. 这个项目是什么，不是什么

**是**：一个以东亚地理的统计与拓扑性质为舞台的自主文明模拟系统。它的产物是一个可查询、可重放、可分叉、可做反事实实验的历史数据库，以及一套能说明"这段历史为什么可信"的证据。

**不是**：
- 不是中国历史的复刻或改编。
- 不是历史游戏。没有玩家，没有难度曲线，没有戏剧节奏调度器。
- 不是"用 LLM 生成一部编年史"。LLM 生成的文本永远不是世界事实。
- 不是一个必然会成功的项目。第 5 章预先写下了它失败时的样子。

**成功的定义**（改写自原始纲领，见 §6.13）：不是"能解释一个荒诞事件为什么发生"，而是**"对任意重大事件，我们能计算它的完整读取集闭包、能用同种子干预重放测出每条声称前因的实际因果贡献、并且至少发现并报告过一类我们原以为是原因、实测不是原因的东西。"**

理由：一个手写的剧情树在"能解释"这个标准上会拿满分——因为它的解释是作者亲手写的，一定最完整、最自洽、最好看。真正涌现的因果必然含混、多因、说不清主次。**解释的可得性与机制真实性几乎无关，甚至负相关。**（依据：`critique/pseudo-simulation` F1；Epstein 2023 "generative sufficiency is a necessary but not sufficient condition for explanation"）

## 1. 互斥声明（必须签字）

本项目的目标里存在三组数学上互斥的追求。它们不能同时最大化。以下是我们的取舍，**先写下来，就不会在半年后为了让数字好看而偷偷伪造**。

### 互斥 1：真实东亚地图 ⊥ 这个世界自己的历史 ⊥ 真实历史作校准集

三者不可兼得。距草原距离是农业格帝国密度的最强预测因子（与农业持续时间、高程三者解释 42% 方差；消掉草原效应后 R² 从 0.65 掉到 0.17）。用真实东亚地形并正确实现地理机制，"北方农牧带高频出现大型政体""南北二元""走廊决定政治边界"几乎是地图的函数。

**我们放弃的**：宏观格局会和真实东亚很不一样这个期待。
**我们保留的**：中层历史（具体政体边界、政体寿命、制度组合、宗教内容、语言分化树、人物与家族）与真实东亚不同。
**执行方式**：正式主线跑一次性创生扰动基底；真实基底只进物理隔离的评估进程；校准量必须是扰动算子等变类下的不变量。见 `docs/spec/spec-world-state.md` §8。
**禁止**：在自主性数字难看时修改地图或机制以提高它。那是把伪造引入项目的最典型路径，且它会打着"增强自主性"的旗号。

### 互斥 2：允许荒诞 ⊥ 完整因果链 ⊥ 涌现

要求任何重大事件都可追溯，等价于要求任何结果都由已存在的机制生成，即世界能产生的结果集合 = 机制库在组合下的闭包。在这个框架里"更荒诞"只有两个来源：数值尾部（同一批机制的极端实现）与组合新颖（机制以前所未有的方式挂接）。

**我们放弃的**："荒诞 = 罕见数值"这个读法。
**我们保留的**：荒诞 = 机制组合的新颖度，参考分布是世界自己此前的历史。
**执行方式**：`absurdity(e) = −log P(该事件所涉机制组合 | 此前历史中的机制共现分布)`；工程投资从"扩大分布尾部"转向"机制的可组合性"。验收指标是"新颖组合率随时间不饱和"。
**禁止**：荒诞度成为运行时变量。内核里不得存在任何计算"这个结果有多罕见"并据此调整概率的代码。

### 互斥 3：强路径依赖 ⊥ 单条反事实结论

路径依赖的可测定义就是"单点扰动后世界状态距离随时间发散而非收敛"。若路径依赖强，同一干预跑 N 次得到 N 个互不相似的世界，单条分叉线上任何"因为 X 没发生所以 Y 没发生"都是无信息的；若单条分叉线的反事实结论稳定，说明路径依赖弱。

**我们放弃的**：单条反事实历史线作为结论。
**我们保留的**：集合级反事实——N≥50 条干预支线 vs N 条空干预支线在预注册量上的分布差、效应量、功效分析。
**执行方式**：每条反事实结论必须附带空干预噪声地板与反事实有效期 `T_half`；单条支线只能作插图并强制打"非结论"水印。
**禁止**：任何没有安慰剂对照的反事实结论进入因果库。

### 互斥 4（附加）：验证的严谨 ⊥ 项目的速度

认真做验证会让项目慢 3–10 倍，验证算力吃掉一半以上预算。

**我们的选择**：付这个代价。算力四方分账（模拟 : 验证 : 因果 : LLM），验证不得被挤成零。
**如果将来不愿付**：诚实的做法是把项目目标降级为"生成有内部一致性的历史文本"——这是一个正当且有价值的目标——但不能一边宣称是可验证的文明模拟，一边只做文本目标的验收。

## 2. 不可协商的原则

每条都写成"可机械执行的形式"与"它禁止了什么"。只有可以被 CI 检查或被实验证伪的条款才写进本章；愿望写在别处。

### P1 涌现：范畴由观察层检测，不由内核存储

内核一等对象只有：**物质与能量存量、人、位置、关系边、信息副本**。不存在 `Polity`、`Settlement`、`Dynasty`、`Class`、`Religion` 这些类型；"国家""宗教""王朝""阶级"只存在于 (a) 观察层的模式检测器、(b) agent 持有的信念命题。

**可执行形式**：
- 原语准入规则：一个内核原语只有在定义不引用任何制度、且全部参数是物理量/信息量/关系边时才被允许（"征税"不合格；"以暴力威胁索取资源转移"合格）。
- 类型抹除测试：把所有 composite 标签替换为随机 UUID 后用同一 `(state, seed, proposal_log)` 重跑，轨迹必须逐位相同。任何读取标签的内核路径都会导致发散。
- 构建期单向依赖检查：内核不得 import 观察层。
- 阶跃探测：对每个宏观判定量做变点检测，范畴出现处不得是超过前驱波动 kσ 的单 tick 跳变。

**禁止**：`enum PolityStage`、`enum Class`、`tech_tree.yaml`、`legitimacy`/`stability`/`prosperity` 这类无微观所指的宏观标量字段、任何以宏观指标为条件的触发器（`if PSI>0.8: trigger_rebellion()`）、任何以真实地名或区域名为键的常量字典。

### P2 因果：测量得到，不是声明得到

因果不是状态变量。世界里没有一个字段叫"原因"。

**可执行形式**：
- 因果边只能由运行时数据流自动采集（读取集）或由干预重放测量得到；代码作者手工声明的原因只能存于独立字段并标注为"待检验假设"。
- 作弊检测器：`declared_causes(e) \ read_set_closure(e)` 必须为空，CI 强制。
- 因果边强制带类型：`mechanical` / `local_analytic` / `intervention_tested` / `statistical` / `narrative`。`narrative` 边不得作为任何其他边的父节点。
- 因果边强制区分：`caused_by_fact(X)` / `caused_by_belief(agent, X', t)` / `caused_by_absence_of_information`。
- 因果图住在观察层，内核与 agent 对它零可见性，CI 强制。

**禁止**：LLM 对因果图有任何写权限（`causal_purity = 0` 是硬门）；手写 `emit_event()` 命名事件；`parent_event_id` 式的单前驱链结构；在 `N_eff` 远大于 k 时显示 top-k 原因列表。

**必须承认做不到的**（写进产品界面，不是藏在附录）：没有唯一真原因；因果视界之外不可归因；只有被内核评估过的机会能成为缺席因；穿过 LLM 账本区的路径只有下界估计；慢变量干预的答案取决于我们如何设想它不发生；过度决定的事件报告"无原因"是正确答案。

### P3 路径依赖：只走离散、有名字、可枚举、会消亡的通道

**可执行形式**：路径依赖的载体是有生命周期的对象（制度、传统、仇恨、技术传统），具备显式的诞生条件、维持成本、衰减或被替代条件、显式承载者。任一政体身上活跃对象数设硬上限，超出必须挤出并记录"被挤出"事件。优先把路径依赖锚定在有独立物理约束的环境状态上（土壤深度、林线、河道、盐碱化、灌溉工程存量）。

**禁止**：连续浮点修正值的无界累加（这是 Paradox 式大战略游戏"看似历史其实是数值噪音"的成因）；制度只增不减（制度默认退化，只在竞争压力下被维持）。

**必须报告**：分叉发散率 λ（同种子单点扰动后 200 年的世界状态距离），它是路径依赖的验收证据，也是因果视界的度量。

### P4 信息边界：类型系统强制，不是提示词约束

**可执行形式**：
- agent 决策函数只接受 `Perception`；`Perception` 只能由运输过程构造；agent 决策模块不得 import 世界状态模块（CI 二值检验）。
- 信息是被运输的物质对象：有位置、载体、传播速度、失真概率、遗忘率。
- 因果隔离测试：对地理/网络完全隔离的孤岛做任意干预，远方大陆 100 年内必须逐位相同。这一条同时是信息边界唯一可机械执行的定义，也一次抓住 id 重编号、迭代顺序、浮点归约、索引重建、LLM 账本错位五类静默致命伤。
- 必须统计"因信息缺失导致的决策失误占比"。它为 0 说明信息边界是假的。

**必须承认**：LLM 的世界知识在权重里，View 投影管不到。第 4 条对 LLM agent 不可完全执行，只能靠"把不知道变成选择集约束"间接实现——选择集由规则从本世界已有的知识库生成，agent 想不出集合外的东西。知识泄漏率是监控指标而非拦截门。

### P5 测度归规则，分布归 LLM，采样归我们的 PRNG

**这是原始纲领第 5 条的重写。原文"AI 不能直接决定客观结果"不可判定——战争爆发本身就是一个客观结果。**

**可执行形式**：
- 规则拥有每一个概率测度与每一次状态转移。LLM 对世界状态 schema 每个字段的写权限恒为空集。
- **LLM 输出的是选择集上的一个分布 `p_LLM`，不是一次选择。** 采样由我方 CBRNG 完成。理由：单点选择是三重损失——反事实 abduction 失效（无法回答"同样的局面下它有多大概率不这么做"）、注入的熵不可观测、污染指标只能单边。有了分布，污染量就是 `D_KL(p_LLM ‖ π)`，可计量、可进预算。
- **默认档是 `surrogate mode`（LLM 全关）。所有带因果主张的正式实验只在这一档运行。** LLM-on 产生质感，LLM-off 做科学。
- **污染的度量在决策点级，不在世界级。** 在同一条 LLM-on 的运行里，每个决策点同时算出 `π` 与 `p_LLM`，直接测 `D_KL(p_LLM ‖ π)`。**不得用 LLM-off 孪生线的事件率作为长期污染指标的分母**——两条线在分叉后几十年就进入不同状态，`f_on / f_off` 测的是"两个世界有多不同"而不是"LLM 注入了多少偏置"；而且控制组是我们自己写的，有人会去调默认策略直到比值落进阈值，从此指标永远绿灯而两条线可以同时是错的。孪生线降级为两个用途：空反事实的噪声地板，以及分叉后短窗口（约 50 年、尚未结构性发散）的分布对比。
- **控制组冻结纪律**：默认策略一旦用于任何污染指标，其参数即进入版本冻结；任何修改必须开新的指标基线并说明理由。
- LLM 只允许出现在三个受限位置：**(P1) 运行期分布提供者**（在规则给定的选择集上输出经校准的 `p_LLM`，四元组进 ledger，`D_KL` 计预算，配额封顶）；**(P2) 离线策略编译器**（产出可审阅、可 diff、带 hash 的策略片段，运行期执行的是确定性策略函数）；**(P3) 作者层渲染器与假设提出器**（把结构对象渲染成文本，永不回流；提出可被消融检验的因果假设——**写入因果图的是消融的实测结果，不是 LLM 的话**，所以它在这里可以猜错一百次而不污染任何东西）。
- "不作为"是规则侧默认路径，不是选项之一：没有触发器触发 → 什么都不发生 → 不调用 LLM。
- LLM 影响力比特预算：`narrative_bits_per_century = Σ −log2 π(a*)`，与规则 RNG 注入熵作比，设硬预算。越界只有两种合法处置——承认规则先验错了去改规则，或强制从 π 采样。
- **文化文本置换不变性检验**：把一条历史线的全部文化文本换成另一条世界线的文本（参数一字不改），从 t=0 重放，世界事实层必须逐位相同。这是"AI 不决定客观结果"唯一可机械执行的定义，成本只是一次重放，且不能被调参绕过。

**四项永久禁止**：命名（`name` 类型为 `EntityRef` 而非 `string`）、教义与文化内容的**数值部分**、因果图写入（`causal_purity` = LLM 撰写的因果节点与边数量，**恒等于 0**，CI 断言）、**合理性裁判**。

最后一项需要解释：让 LLM 判断"这段历史合不合理"看起来很自然，但判官与生成者共享同一套先验，**这个裁判的检出力是负的**——它会系统性放行那些符合 LLM 先验的（也就是最像真实历史的）输出。若一定要用作辅助筛查，必须先在金丝雀集上标定，**并禁止它做任何筛除动作**：它只能生成待人工检查的问题清单，永远不能删除或修改任何东西。

**另外禁止**：LLM 决定事件是否发生、决定任何数值、发明新的动作类型或制度、生成会被后续 tick 读取的结构化内容。

### P5b `π` 的作者是我们——比 LLM 编故事更难发现的那个问题

把污染定义成 `D_KL(p_LLM ‖ π)` 之后，还剩一个更深的漏洞：**如果 `π` 本身是被编排的呢？**

一个手工调出来的 `π`——让继承危机在王朝第三代高发、让边境冲突在饥荒后两年高发、让宗教运动在瘟疫后高发——每一条都"听起来很有历史感"，每一条都是从真实历史（或我们对历史的印象）里抄来的叙事节拍。此时 `D_KL = 0`，**全部污染指标满分通过，而这个世界是被完全编排的**。我们只是把剧作家从 LLM 换成了自己，并顺手取消了唯一能测出这件事的仪表。

这比 LLM 编故事更难发现：我们的偏置在代码里，代码看起来像物理；`π` 本身没有参照物；我们会把自己写的规则的输出当作"世界的自然行为"来验收。

**可执行形式**：
- **参数-目标比**：`P` = 所有风险率函数与先验函数里的自由参数总数，`T` = 有独立外部经验目标的校准目标数。**`P / T > 3` 即判定模型不可证伪。这个数字必须出现在每一份模型文档的第一页。**
- **参数溯源审计**：每个参数标注 `justification_class ∈ {外部数据拟合, 理论推导, 量纲/守恒约束, 未校准(默认值), 叙事}`。**`叙事` 类的允许数量是 0**；`未校准` 的比例是模型成熟度的直接读数。
- **`π` 必须被拟合，不能被撰写**：有外部数据的量（战争起始率、政体存续、城市规模分布、迁徙速率）一律对数据拟合；没有数据的量一律用最大熵/无信息先验，**而不是"我们觉得合理的值"**。
- **禁止在触发器与先验里引用叙事节拍变量**："距上次大事件已 N 年"、"这个王朝已经三代了"、"这个文明太平稳了"——这些是伪装成工程条件的剧情树。
- **改动动机审计**：git blame 每一次参数改动，commit message 里出现"这样跑出来更像历史"即为违规实例。
- **调 `π` 的人与看叙事的人必须分离。**

**退路条款**：如果三支线对照（真 LLM / 从同一候选集均匀随机 / 冻结蒸馏策略）测出"有意义但不主导"的中间带在实证上是空的——即改变 LLM 的接线方式只能在"完全无影响"和"完全主导"之间跳变——则接受更保守的定位：**LLM 完全退出因果链，只在作者层工作**。这条退路现在就写下来，不是失败，是预案。

### P6 随机性：计数器寻址，不是状态迭代

**可执行形式**：
- counter-based RNG，key = `(world_seed, stream_id, tick, 内容寻址的实体 id, 静态槽位 id)`；流按机制封闭注册。
- 实体 id 必须是内容/血缘派生哈希，**任何全局自增计数器都是构建期错误**。
- 一切离散抽样用 Gumbel-max，禁止逆变换采样——不同的区间排列给出相同的观测分布与干预分布、不同的反事实，且这个依赖不可用数据检验。
- 世界状态一律定点整数，内核禁用浮点。1 ULP 差异在约 60 步后放大到 O(1)，而我们要跑 3000 步。
- 每个抽样点必须能重算出 `(分布族, 参数, 分位 u, 阈值)`。凡内核评估过概率但未触发的抽样点都是一等公民节点（近失账本）。

**禁止**：全局有状态 PRNG；用可变量做种子；遍历哈希容器；无确定性 tiebreaker 的 argmax/排序；重放时重新调用 LLM（oracle miss 必须是致命错误）。

### P7 荒诞：组合新颖度，且审查门槛对称

见互斥 2。补充：**审查必须对称化**。因果链审计按 `significance(e)` 分层随机抽样，与稀奇程度无关，每批次至少 50% 是"寻常"事件。

理由：不对称的证据门槛是一台把输出分布推回真实历史的保守棘轮，同时把审查注意力精确导向作弊最不可能藏身的地方——隐藏剧情树的产物一定落在"寻常"那一侧，永远不触发对荒诞的审查。原文第 7 条按字面实现就是一台自动化的确认偏误机。

### P8 真实历史是校准集，且校准集必须与验收集分离

**可执行形式**：
- 预注册的模式电池：每条含陈述、方向性/区间（**禁止点值**）、口径三元组（阈值/定义/估计方法）、证据等级、来源、功效分析、归属（校准集 or 封存验收集）。哈希提交。
- 模式预算账本：每条模式被"看过"N 次以上自动降级为校准集并永久移出验收集。
- 验收集只用序数/方向性判据。点值判据几乎总能被拟合。
- 功效不足的判据不得进入验收集——它不是弱判据，是零判据，留着比删掉更危险，因为它会一直显示绿色。
- 争议量只进观察集：政体寿命分布形状有四个互相矛盾的已发表答案；任何 C 级判据一律不进验收集。
- 缺失数据必须区分 `absent` / `unknown`。（Whitehouse et al. 2019 Nature 因把 61% 的 unknown 重编码为"不存在"而于 2021 年撤稿。）

**禁止**：把幂律当正面证据（任何把平均活动维持在界限内的动力系统统计上等价于 SOC 分支过程，因此我们一定会免费得到幂律）；用 log-log OLS 拟合重尾分布；把"能产生 X"当验收标准（等结局性使任何机制都会通过；正确的问法是"我们能产生 X 而不能产生 not-X 吗"）。

### P9 四层分离：机械事实 / 因果分析 / 世界内叙事 / 作者层

原始纲领只分两层。实际需要四层。

- **L1 机械事实**：状态、转移、抽样点分布与分位、读取集闭包、近失集合。唯一可称"世界事实"的一层，可逐位校验，无语义。
- **L2 因果分析**：干预实测效应量、PN/PS、必然性剖面、因果视界、`N_eff`。**这是我们的历史学，带 `analyzer_version`，可被推翻。** 对世界内 agent 永久不可见，由进程/类型系统强制。
- **L3 世界内叙事**：物质痕迹、意图性记录、流通信念、世界内史学。世界内不存在自然语言——史学的世界内表示是命题图，文本只是按需渲染的视图。
- **L4 作者层**：LLM 写给我们看的旁白。默认不出现在因果链查询结果里，视觉上必须不可混淆。

**可执行形式**：跨层写入禁止并 CI 强制；查询必须显式指定层；`belief_groundedness = 1.0` 是硬门（任何影响决策的信念，其 provenance 链必须能追到真实 event_id）；**可知性上界不可超越检验**——世界内史学家对任一历史命题的正确率不得高于 `U(t)`（用存活语料能达到的理论上限），超过即证明有泄漏。

### P10 模拟与文学创作分离，且这条约束现在就生效

原始纲领第 10 条只覆盖"未来写小说时"，没有覆盖"现在看输出时"。这个缺口现在补上。

**必须提前接受的事实**：**模拟层的输出会是枯燥的。枯燥是正确性的证据，不是缺陷。** 前期跑出来的历史会像一份电子表格：数字、结构化事件、生成的音节名，没有史诗感。团队第一次看到这种输出时会有强烈冲动"就让 LLM 稍微润色一下因果说明吧"——那就是墙被推倒的时刻，而且它会发生在一个所有人都觉得无害的下午。

**可执行形式**：渲染层与模拟层彻底分离；世界事实数据库对渲染层**只读**，用文件权限/类型系统/进程边界保证，不靠自律。渲染层可以任性（最强的模型、最自由的写法），因为它不写回世界、可以随时重跑、可以有多个互相矛盾的版本。

**选择即抽样**：将来从世界史里挑一段写小说，必须记录选择规则与被拒绝的段落数。这是"文学不污染模拟"唯一可核查的形式，成本为零。

## 3. 反剧情树宪章

隐藏剧情树的危险不在于我们会故意写它，而在于**每一种引入它的方式在代码里都看起来像工程卫生**。

### 3.1 禁用清单（lint 规则，可 grep）

| 形态 | 它的正当借口 | 为什么禁止 |
|---|---|---|
| `clamp` / `clip` / `max(0,x)` | 防止发散 | 制造隐式吸引子并污染均值；危机期触发率会比平时高一个数量级 |
| 份额归一化 | 概率要归一 | 隐藏了绝对水平本该变化 |
| 拒绝采样 `while not valid(state): resample()` | 保证状态合法 | 这是对结果的条件化 |
| 世界初始化重生成 `while arable < θ: regen_map()` | 保证世界可玩 | 我们只在"文明可能发生"的世界里采样 |
| 自适应速率控制器 | 稳定性 | 字面意义的 PID = 字面意义的剧情树 |
| 灭绝兜底 `if pop < 10: respawn()` | 防止世界死掉 | 取消了灭绝这个合法结局 |
| 事件冷却时间 | 防止事件扎堆 | 节奏设计 = 叙事 |
| 存在性保证 `ensure_at_least_one_polity()` | 防止空世界 | 把结论写死 |
| 隐式求解器 | 数值稳定 | 静默阻尼掉本该发生的崩溃振荡 |
| 占位实现返回"合理近似值" | 子系统还没做完 | 占位实现从不被删除，它们会成为世界的物理定律 |

**未达证据等级门槛的子系统，其对外接口必须返回"不存在/无效应"，而不是返回一个看起来合理的近似值。**

**例外程序**：确实必须保留的，每一处带 `# GATED(reason=, evidence=, ticket=, review=)` 注释，CI 统计 GATED 数量，**只允许下降不允许上升**。每次 clamp 触发写 `invariant_violation(var, cell, tick, magnitude)`；触发率超 ε 视为机制缺陷（模型在该区域外推失败），必须改机制，不得加 clamp。提供 `--no-clamp` 模式并定期跑，允许世界真的崩溃，崩溃率作为报告指标。

### 3.2 人类回路防线

**代码层的全部措施对这条通道完全免疫。** 涌现认证、消融测试、空模型对照、参数活性测试、读取集追踪——全部在单次运行内部生效，没有一个能看见"我们跑了 400 次只留了 5 次"。

| 措施 | 内容 |
|---|---|
| **运行登记表** | 每次超过 100 模拟年的运行，无论结果，自动写入不可删除的表（kernel_version, param_hash, world_seed, 终止原因, 宏观量摘要, 是否被人查看）。删除需显式提交记录。 |
| **预注册抽样规则** | 将来作为"这个世界的历史"公开的那次运行，其 `world_seed` 由事先声明的、与结果无关的规则决定（如 `seed = sha256(kernel_version ‖ "canonical")`）。允许因技术故障重跑，**不允许因不好看重跑**，重跑必须留痕。 |
| **失败率公布制度** | P(灭绝)、P(5000 年无国家)、P(永久停滞) 是必须公布的指标。200 个种子上灭绝率恰为 0 是可疑的。 |
| **无聊运行必须被展示** | 任何成果汇报必须同时给出该内核版本全部运行的分布图，并标出被展示那次的分位数。 |
| **参数改动分类账** | 每次改动标记为 `bug` / `evidence`（附引文）/ `aesthetics`（结果不好看）。CI 公开 aesthetics 计数。**被 aesthetics 改过 ≥2 次的参数，其下游宏观现象永久标注为"非涌现（拟合产物）"。** |
| **参数冻结时点** | Phase 1 结束冻结参数集。此后声称涌现必须零新增零重调参数（prediction vs postdiction）。 |
| **形态多样性账本** | 记录每一次为通过判据而做的参数改动，定期报告"我们为了通过判据放弃了多少形态多样性"。 |

### 3.3 二值检验优先于统计检验

**凡是能做成二值结构检验的，就不要做成统计检验——统计判据能被调参绕过，结构检验不能。**

必须在写第一个机制之前跑通的地基测试：
- **零干预测试**：把某值改成它原本的值，要求逐位相同。
- **因果隔离测试**：对地理/网络完全隔离的孤岛做任意干预，远方大陆 100 年内逐位相同。
- **类型抹除测试**：composite 标签换随机 UUID 后逐位相同。
- **容器逆序遍历测试**：逐位相同。
- **线程数不变性**：1/4/16 线程逐位相同。
- **依赖检查**：内核不 import 观察层；agent 决策模块不 import 世界状态模块。
- **poison-build 阳性对照**：故意注入违规代码，上述测试必须失败。（一个从未失败过的测试等于没有测试。）

## 4. 算力宪法

**预算单位不是"跑完一次三千年"，而是"单次墙钟 × 集合规模"。** 反事实、平行世界、涌现认证、参数标定每一项都是 50–5000 倍乘数。按"能跑完一次"设计出来的系统只能拿 3 个种子做结论——**算力不足不是让项目变慢，是让它失去证伪能力。**

**必须在 Phase 1 第一页写死三个数**：目标硬件、`T_run` 上限、`N_ensemble`。其他一切由它们反推。

**四方分账**：模拟 : 验证 : 因果分析 : LLM。三者不得互相挪用；验证算力不得低于总预算的规定下限。因果分析算力不得与验证算力共用同一笔。

**硬约束**：
- 自由参数硬配额（建议 12–15）。每个参数必须标注 `source: <简报/DOI>` 或 `free: true`，CI 检查 free 计数。
- 每类实体硬上限（聚落、具名人物、组织、活跃个体、社会网络边）。没有上限的实体会在第 1500 年吃掉全部预算。
- 复杂度契约表 + log-log 斜率回归测试（1×/2×/4× 实体数，斜率 > 1.2 则失败）。
- **仓库里必须始终存在一个能在笔记本上 60 秒内跑完 3000 模拟年、输出因果图、并通过 bit 级重放测试的 `main`。任何一周内它跑不起来，该周其他工作全部暂停。**
- 单次长跑时长必须小于机制变更的预期间隔。若"一次长跑 30 天而我们平均 5 天改一次机制"，当前架构在方法学上不可能产出一条可信历史线——这个数字必须尽早算出来。
- `kernel_version_hash` 写进每个 tick。机制变更 ⇒ 该世界作废、从 t=0 重跑。只有观察层与渲染层允许热更新。

**LLM 的位置**：永不在 tick 关键路径上（decide 相位读上一 tick 的 View，Intent 在下一 tick 的 resolve 消费）；批处理单位是"同一 tick 序号 × 全体种子"；每条世界线调用总数写死配额。这个配额同时是成本控制和污染控制——**事件密度跟着调用预算走，两者是同一个旋钮。**

**架构硬约束**：**世界在 LLM 完全不可用时必须能独立跑完三千年。** 任何在 HEADLESS 模式下会导致模拟无法推进的依赖都是架构缺陷。

## 5. 失败的定义

一个没有拒绝域的判据体系不是判据而是修辞。以下条件在跑第一个长世界之前签字冻结。**具体数字大部分是 D 级待标定，但"事先写下来"这个动作本身才是关键。**

### 5.1 预注册拒绝条件（出现即判定内核错误）

1. 200 个种子的政体寿命变异系数 < 0.3（路径依赖被磨掉了）
2. 灭绝率恰为 0（存在兜底逻辑）
3. 事件聚类簇数在 t=1000 后不再增长（原语层已封顶）
4. 摘要覆盖率 `C_7` 中位数 > 0.9（存在解析捷径，非涌现）
5. 四检测器的政体归属 Fleiss' κ > 0.95（政治空间被做成了 Civilization 的地图）
6. `causal_purity ≠ 0`（LLM 写进了因果图）
7. `belief_groundedness < 1.0`（存在凭空发明的信念）
8. `budget_sensitivity` 显著非零（历史是预算写的，不是世界写的）
9. 同种子重放两次不逐位相同
10. 因果隔离测试失败
11. top-significance 事件中非政治类别占比 < 40%（显著性函数有偏）
12. 隔离度 × 时间 → 文化距离的回归斜率不显著为正（LLM 是吸引子，物理世界的分化被抹平了）

### 5.2 我们最可能以什么方式失败（排序）

1. **人类回路的梯度下降**：反复调参到"像样"，跑 400 个种子只展示好看的 5 个。代码层全部防御对此免疫。
2. **验证被无限期推迟**：算力不够 → "这次先不跑全套电池，赶下个里程碑" → 出现第二次 → 永远不补。
3. **范围没有底**：仓库里有 40 篇设计文档、一个精美的本体论、和 0 个能跑到底的 `main`。（Ultima Ratio Regum 的作者有学术训练、极度勤奋、目标高度重合，他失败于范围没有底：15 年，0.11 版本 66 篇更新，目标仅是"第一次包含一条完整谜题线"。）
4. **外生输入的影子**：把真实古气候序列注入的兴衰节律当成自己机制的涌现成果。（Artificial Anasazi 的教训：零 agent 行为的纯外生承载力模型误差只高 10–50%，两模型最优参数完全相同，原文称该 ABM"只起了平滑函数的作用"。）
5. **LLM 的不可见先验导航**：世界沿"游群→部落→酋邦→国家→帝国"的教科书序列演化，同时每一步都有完整因果链。它的症状是**世界过于合理**。
6. **静默的确定性丧失**：实体 id 重编号 / 浮点归约顺序 / 容器迭代顺序，任一都会让"抑制一次生育，100 年后世界完全不同"看起来像路径依赖的胜利。这类 bug 会在 18 个月后才被发现。
7. **因果链的自欺**：我们一定做得出一条看起来很好的因果链，且没有机制能让我们发现它是假的。

### 5.3 合法的结果

以下都不构成失败，**必须在纲领层面明确**：

- **世界什么都不发生，是一个合法的科学结果。** 真实世界里"什么都没发生"本身就是最常见的结果：到 500 BCE 有农业的地区，23% 到 1500 年仍无宏观国家；农业到国家的平均时滞约 2000 年。
- 跑 5000 年不出现文字/常备军/中心财政，且这不算失败——验收集必须包含至少一条"允许缺席"的判据。
- 世界灭绝。史前人群的局部灭绝在考古上是常态。
- **原始纲领第 24 段的"最终希望"清单（形成自己的国家、民族、制度、宗教、文化、技术、历史人物）不是验收条件，而是被测量的输出。** 一个在 200 个种子上从未产生国家、但每个种子的停滞都能追溯到具体资源/信息/协调约束的世界，是一个成功的 Phase 1。

## 7. 引用与证据纪律

**全项目统一的证据等级**：
- **A** = 多个独立实证来源支持，且有可用的量化参数或范围
- **B** = 学界有理论共识或机制被广泛接受，但量化弱、参数需自行选择
- **C** = 存在实质争议、仅单一来源、或结论被后续研究挑战
- **D** = 无来源，属于我们为了让模拟能跑而做的假设

**规则**：
1. 每个参数、每个概率函数、每个分布在运行时都携带 `(evidence_level, source)` 元数据。
2. 定期报告"重大事件中由 D 级分布生成的比例"。若 80% 的重大事件来自我们自己发明的分布，这个世界是我们的发明加一层随机涂装——这不必然是失败，但必须写在首页而不是藏在附录。
3. 任何 D 级分布的**形状**（不只是参数）必须做敏感性分析：把指数换成对数正态、把幂律换成截断幂律，看宏观结论是否翻转。
4. C 级判据一律不进验收集。
5. 一个以"可追溯"为原则的项目，其调研材料本身也必须遵守这条原则：研究笔记必须分级（一手/二手/推论），引文必须核验（见 `research/README.md`）。
