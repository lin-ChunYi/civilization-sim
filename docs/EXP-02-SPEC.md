## 1. 新增的那一个机制

**每格再生量的年际波动。定位是受控的资源波动实验，不是气候模型**——它不试图表示降水、温度、季风或任何真实过程，只提供一个可调的、空间独立的资源扰动源。

```
类型       SIGMA_M 必须是**严格整数**。`make_world()` 先查类型再查范围：
           非 int（含 float、str、None、complex）=> TypeError
           bool（是 int 的子类，True 会被当成 1）=> TypeError
           —— 浮点会让 stock 整个变成 float，而守恒误差是 0.0，守恒检验抓不到

合法范围   SIGMA_M ∈ [0, 1000]（千分之一）。越界 => ValueError。
           0    = 无波动，退化为 EXP-01
           1000 = 乘数可低至 0（该年该格完全不再生）

寻址       u1 = rng(world_seed, S_CLIM=5, tick, cell, 0) mod (SIGMA_M + 1)
           u2 = rng(world_seed, S_CLIM=5, tick, cell, 1) mod (SIGMA_M + 1)
           —— 按 (tick, cell) 坐标寻址，与遍历顺序、与调用次数无关

分布       z = u1 − u2
           两个独立同分布离散均匀之差 ⇒ **离散三角分布**，支撑 [−SIGMA_M, +SIGMA_M]，众数 0，对称
           SIGMA_M=0 时 u1=u2=0 ⇒ z≡0

取整       regen_eff = regen(cell) × (1000 + z) // 1000     整数除法，向下取整
           SIGMA_M=0 时 regen × 1000 // 1000 = regen，**严格恒等，无取整损失**
```

改动范围：相位 1 加上述逻辑，新增一条 RNG 流与四个资源账计数。**其余规则、地图、种子、参数全部不动。**

不做：不扩大地图（仍 64 格）、不接 LLM、不改人口/迁移/分裂等既有机制、不加任何社会机制。

## 2. 与冻结基线的关系

**退化恒等**：`SIGMA_M = 0` 时，EXP-02 必须逐位复现基线状态。判定用**基线自己的哈希函数**——测试按路径加载冻结的 `exp01/verify.py`，用 `base.state_hash()` 同时作用于基线状态与 EXP-02 状态。**不把基线改成能通过的样子**；`exp01/` 本轮零改动。

这条检验有双重作用：它既验证"新机制在关闭时不改变任何东西"，也验证"这份从基线复制过来的代码没有偷偷漂移"。

**身份分开记录**：EXP-02 新增了 `SIGMA_M` 与 `S_CLIM` 流，参数指纹必然改变，因此 `run_id` 与基线**必须不同**——这是正确行为，不是失败。相等的是 `state_hash`（基线口径），不同的是 `run_id`。C7 同时断言这两件事。

`cellrev`（资源格遍历顺序）归入 `TRAVERSAL_POISONS`，不进运行身份；`climseq`（按调用序寻址）归入 `SEMANTIC_POISONS`，进运行身份。

## 4. 实测结果

运行环境：Python 3，无依赖。`SIGMA_M ∈ {0, 100, 200, 400, 800}`，种子 `[0, 12345, 777, 4242, 99, 31337, 2026]`，每次 300 年。

### 4.1 正确性

```
cd exp02 && python3 run_tests.py   ->  必过项 11/11 通过，退出码 0（约 36 秒）
```

双向验证过退出码：故意让 C1 失败 → `exit=1`；故意让 C11 失败 → `exit=1`；全部通过 → `exit=0`。完整输出见 `exp02/TESTS.txt`。

几处值得单独记：
- **C7 逐步退化恒等**：7 个种子各逐 tick 比对 300 步，全部相同；`run_id` 全部与基线不同。（原先只比末状态，现已固化为逐步回归。）
- **C11 类型校验**：`100.0` 与 `100.5` 此前会被接受并让 `stock` 变成 float，而守恒误差是 `0.0`——这是一个守恒检验结构上抓不到的缺陷。
- **C6 资源格逆序**：5 档 × 7 种子全部一致。这条是新增的——`revorder` 确实管不到资源格。
- **C10**：健康版正序与逆序得到同一个 `(tick,cell)→z` 映射；`poison-climate-seq` 下 **144/144 个 (tick,cell) 全部错配**。
- **C9**：7 个种子全部满足前提且通过，正对照全部有效。

### 4.3 B1：本配置与本样本未支持

```
SIGMA_M=0    误判 30 / 迁移 1947 = 1.54%
SIGMA_M=100  误判 26 / 迁移 1960 = 1.33%
SIGMA_M=200  误判 28 / 迁移 1916 = 1.46%
SIGMA_M=400  误判 19 / 迁移 1891 = 1.00%
SIGMA_M=800  误判 13 / 迁移 1400 = 0.93%
```

**误判率没有随 `SIGMA_M` 上升；总体方向反而是下降的（1.54% → 0.93%），中间还不单调。**

按预先说好的处置：**不调参去把曲线做出来，也不就此宣布找到了另一个原因。** B1 是待检验假说，这次的读数是它在这个配置与这个样本下不成立。

同时记下两条与之相伴、但**不构成解释**的测量事实，它们只是下一步该去分开检验的候选方向：

- **入账/计划 总体下降但并非单调**：memory 臂 `0.3427 → 0.3323 → 0.3266 → 0.3271 → 0.2963`，**200 档到 400 档略有回升**（0.3266 → 0.3271）；omniscient 臂 `0.3327 → 0.3433 → 0.3355 → 0.3081 → 0.2811`，0 档到 100 档也有一次回升。两端相比是下降的，但中间的非单调说明这里不是一条干净的趋势。
  一个可能的机械原因是 `min(cap, stock + regen_eff)` 的上截断对正负扰动不对称——高 z 的年份溢出被丢掉，低 z 的年份无法补回。**这只是候选机制，本轮没有单独设计实验去检验它，也不能解释中间的回升。**
- **迁移次数与人口随 SIGMA_M 下降**（迁移 1947 → 1400，人口 5202 → 4359）。误判率的分母因此变小。分子分母同时在动，所以"误判率下降"本身还不能被读成"信息变得更不重要"。

**不能从这次结果得出的结论**（写在这里以免日后被误引）：不能说"信息边界不重要"，不能说"波动没有影响"，不能说"上截断是原因"。能说的只有：在 64 格地图、这套规则、这 5 个档位、这 7 个种子下，误判率没有随波动上升。

## 5. 读数须知与限制

1. **全知对照臂的误判恒为 0，有一部分来自选择规则本身。** 误判的定义是"搬去的格子事后看并不更好"，而全知臂直接读当年真值，按定义几乎不可能选错。**不要把这个 0 当成长期福利收益。** 两臂的福利要看缺粮、人口、群体数——而这三项在两臂之间互有高低，没有稳定方向。
2. **"被容量挡"是"计划"的大头**（约 66%–72%）。格子很快涨到 `cap`，此后多数再生量根本没进入世界。任何关于资源总量的说法都必须先看 `计划/名义` 与 `入账/计划` 两列，**不能把资源总量的变化全部解释成信息效应**。
3. **迁移为 0 时误判率记"不可计算(分母0)"**，不记 0%。本轮的 70 次运行里没有出现分母为 0 的情况，但口径已经定死。
4. **`SIGMA_M=0` 档是退化档**，与冻结基线一致（由 C7 判定，不由这张表判定）。
5. EXP-01 的全部已知限制在 EXP-02 里**原样继承且未修**：迁移储存损失结构性恒为零、默认样本无灭绝、饱和由分裂规则的几何造成、均衡食物比与 LTP 的 0.668 有已量化偏差、8/9 假设为 D 级。
6. 仍然**未验证**：跨版本存档兼容、人口学标定、跨架构一致、多线程确定性。
