# EXP-02 方案（待批准）

**基线**：EXP-01 @ `20da486a4fc12cf51db70c98e5d69f66a90996fe`，冻结不改。
**范围**：**只加一个机制**。不扩大地图、不接 LLM、不加社会机制、不启动研究、不修 EXP-01 的已知限制。

---

## 一、新增的那一个机制

**每格再生量的年际波动。**

```
regen_eff(cell, tick) = regen(cell) × (1000 + z) / 1000
  其中 z = 由 CBRNG 按 (world_seed, stream=climate, tick, cell, 0) 寻址取出，
          落在 [−SIGMA_M, +SIGMA_M] 的整数（三角分布，整数实现）
新参数只有一个：SIGMA_M（千分之一为单位）。SIGMA_M = 0 时该项退化为恒等。
```

改动范围：相位 1（regen）一行，加一个参数、一条 RNG 流。其余规则、地图、种子、参数全部不动。

## 二、它要回答什么问题

**信息边界在什么条件下开始有后果？**

这不是一个想加点内容的选题，是 EXP-01 实测出来的缺口。基线里信息滞后 4.5 年、看起来"信息边界在起作用"，但事后看错的迁移只有 30/1947 = **1.5%**。原因已经查清并写在 `EXP-01-SPEC §7.2 缺陷 4`：格子的存量总是朝 `cap` 单调恢复，所以**过时的信息在方向上通常仍然对**，滞后几乎不产生代价。

后果很具体：**如果不先解决这个，之后任何决策机制都会在一个"信息几乎免费且几乎准确"的世界里被验收**，我们会得到"信息边界工作正常"的结论，而它其实什么都没约束。波动是让滞后真正产生代价的最小改动——资源变化快于侦察频率时，记忆才会失真。

**为什么不是"储存被他人取走"（强制转移）**：那个机制更有意思，也是通往制度的那条路，但它的动机是野心不是测量。而且它会在一个信息不起作用的世界里被验收——决策有没有意义，取决于信息有没有意义。顺序应该反过来。它留给 EXP-03。

## 三、怎样与 EXP-01 对照

对照设计的核心是一条**退化恒等式**：

> **`SIGMA_M = 0` 时，EXP-02 必须逐位复现 EXP-01 基线的 `state_hash` 轨迹。**

这把"我没弄坏别的东西"变成一个二值检验，而不是一句保证。跑法是同一套种子 `[0, 12345, 777, 4242, 99, 31337, 2026]`、同一张地图、同一组参数。

一处必须说清的细节：**`run_id` 会改变，这是正确行为**。新增了 `SIGMA_M` 与 climate 流，参数指纹必然变，所以 EXP-02 与 EXP-01 是两次不同的运行。相等的是 `state_hash`，不是 `run_id`。测试要显式断言这两件事同时成立，否则就是把"运行身份"和"状态摘要"又混回去了。

然后扫 `SIGMA_M ∈ {0, 100, 200, 400, 800}`（即 0 / ±0.1 / ±0.2 / ±0.4 / ±0.8），同种子集合，看响应。

## 四、验收标准

**必过（二值）**

| # | 判据 |
|---|---|
| A1 | `SIGMA_M = 0` 时，7 个种子 × 300 年的 `state_hash` 与基线**逐位相同**；同时 `run_id` 与基线**不同** |
| A2 | T1–T8 在每个 `SIGMA_M` 档位下全部仍然通过 |
| A3 | 守恒误差在每个档位下恒为 0（波动改的是 inflow，必须如实进账本） |
| A4 | 新注入 `poison-climate-seq`（气候用按调用序推进的流，而不是按 `(tick, cell)` 坐标寻址）**必须打破 T3 区块隔离与 T6 逆序不变性** |
| A5 | 必过项失败 ⇒ 退出码非零 |

**观察（预注册方向，不预注册数值）**

| # | 观察 |
|---|---|
| B1 | 事后看错的迁移比例随 `SIGMA_M` **单调上升**。方向预注册；**不预注册任何目标数值，也不调参去追** |
| B2 | `poison-omniscient` 的效应量随 `SIGMA_M` 增大（信息优势变值钱） |
| B3 | 报告 regret、迁移次数、人口、群体数对 `SIGMA_M` 的完整响应曲线 |

**如果 B1 不成立**——即加了波动，误判率仍然不动——那是一个**有价值的否定结果**，说明代价不在"信息过时"而在别处（例如 1.25 倍的增益门槛把边缘决策全挡掉了）。**这种情况下不调参数去把曲线做出来**，而是把否定结果记录下来，重新判断信息边界该怎么做。

## 五、明确不做

不扩大地图（仍是 64 格）、不接 LLM、不加任何社会机制（无胁迫、无交换、无组织）、不改人口学曲线、不修迁移损失恒为零、不动灭绝、不做跨版本存档、不做标定、不换语言。

## 六、工作量与产出

改动约 30 行（一个参数 + 一条 RNG 流 + regen 一行 + 一个 poison 开关），测试新增 A1/A4 两项与一个档位扫描。产出：`exp01/` 之外新建 `exp02/`，基线代码不动；一页实测结果附在本文件末尾。
