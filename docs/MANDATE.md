# civilization-sim — 项目原始纲领（用户原文，2026-09-09）

这个项目的目标不是复刻真实中国历史，也不是制作一个按照预设剧情运行的历史游戏，而是建立一个"以中国及周边东亚地理环境为舞台的自主文明模拟系统"。

我们希望从文明形成之前开始模拟，让人口、聚落、资源、地理、气候、技术、经济、贸易、战争、政治制度、社会阶层、宗教、文化、思想、人物以及偶然事件相互作用，使文明能够持续演化数千年甚至更久。

真实中国历史只能作为研究、建模和合理性校准的参考，绝不能作为剧情模板。模拟中不需要出现真实历史上的夏商周、秦汉、三国、唐宋等朝代，也不要求出现真实历史人物、真实战争或真实制度。这个世界应该拥有自己的历史。

核心原则是：可以离奇，可以荒诞，可以产生现实历史中从未出现过的文明形态，但不能无缘无故。任何重大历史事件都必须能够追溯其形成过程。例如战争、国家形成与灭亡、革命、宗教诞生、制度改革、技术突破、民族迁徙、经济危机、思想运动等，都不能因为"这样更有戏剧性"而发生，而应该由此前已经存在的地理条件、资源约束、人口变化、经济利益、社会结构、制度、文化、人物动机、信息条件和偶然事件共同推动。

我们尤其重视：

1. 涌现（Emergence）：不预先规定文明必须经历哪些阶段。国家、君主制、官僚体系、宗教、文字、货币、市场、帝国等都应该尽可能由更基础的机制演化出来，而不是按照固定科技树依次解锁。
2. 因果链（Causality）：每一个重大事件必须保存可追溯的原因。几百年以后，我们仍然应该能够询问"为什么这个国家会灭亡？"并一路追溯到更早的结构性变化和具体事件。
3. 历史路径依赖（Path Dependence）：曾经发生的小事件可以长期改变未来。文化、制度、仇恨、联盟、技术传统和社会习惯应该拥有历史连续性，而不是每个 tick 重新开始。
4. 信息边界（Information Horizon）：世界中的人物和组织只能根据自己当时合理能够获得的信息行动。模拟器拥有全局状态，但 Agent 不能拥有上帝视角。
5. 规则与 AI 分离：AI 可以负责人物和组织的判断、计划、解释、文化创造等难以公式化的部分，但 AI 不能直接决定客观结果。例如 AI 可以决定发动战争，但战争胜负必须由世界模拟规则根据军力、经济、后勤、地形、士气、技术、将领能力和随机因素等计算。
6. 受约束的随机性：世界允许灾害、疾病、事故、死亡、发现等偶然事件，但随机事件必须受到环境和概率条件约束，并记录随机种子，以便重放和进行反事实实验。
7. 允许荒诞，但要求更强解释：越违反常识、越罕见的历史结果，越需要强大的前置条件和完整的演化过程。不要因为结果奇怪就禁止它，也不要因为结果有趣就允许它。
8. 真实历史是校准集，不是答案：后续我们会研究考古学、历史学、经济史、人口史、气候史、政治学、社会学、Agent-Based Modeling、复杂系统等资料，用真实文明检验我们的机制是否至少能够产生合理的社会现象。但虚拟文明没有义务重复真实历史。
9. 世界事实与历史叙事分离：模拟器保存"实际上发生了什么"。世界内部的人类只能知道其中一部分，并且可能误解、遗忘、神话化甚至篡改历史。因此未来可以同时存在真实历史、官方历史、民间传说、宗教叙事和后世历史学研究。
10. 模拟与文学创作分离：首先让世界真实运行并形成历史数据库。未来如果根据其中某段历史写小说，小说只能在既有世界事实的约束下进行文学重建，不能为了剧情修改已经发生的历史。

最终希望系统能做到：从早期人类聚落开始自主运行数千年；形成完全属于自己的国家、民族、制度、宗教、文化、技术和历史人物；可以查看任意时代的世界状态；可以查询任何重大事件的因果链；可以查看人物、家族、组织和国家的历史；可以保存任意历史节点并建立平行世界；可以进行"如果当时没有发生某件事"的反事实实验；可以让世界中的历史学家研究他们自己的历史；最终可以从真实模拟产生的历史中选择某个时代、事件或人物，生成历史书、传记或长篇小说。

这是长期研究型项目，不追求尽快堆出大量代码。

## Phase 0 的关键待答问题
- 世界最底层必须有哪些状态？
- 哪些变化应该由数学/规则系统决定？
- 哪些问题适合交给 LLM Agent？
- 哪些事情绝对不能让 LLM 直接决定？
- 如何产生真正的涌现，而不是隐藏的剧情树？
- 如何保存因果关系？
- 如何验证一个重大历史事件在逻辑上成立？
- 如何处理我们无法获得准确历史参数的问题？
- 如何防止模型为了戏剧性制造事件？
- 如何衡量一个模拟世界是否"合理但不必真实"？
- 如何让数千年的模拟在计算成本上可行？
- 如何设计不同时间尺度和不同粒度的人口/人物模拟？
- 如何保证未来可以重放、分叉和比较不同历史线？

## Phase 0 的成功标准
不是"写出了多少代码"，而是是否已经建立了一套足够严谨的基础，使未来发生一个荒诞事件时，可以解释它为什么发生，而不是只能回答"因为 AI 生成了它"。
