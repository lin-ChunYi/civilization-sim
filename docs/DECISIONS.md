## 0. 这份文件是什么

7 份红队审查各自末尾都有「必须先做的决定」与「Phase 0 必须产出」两节。**计数口径**：一条 = 一个可裁决的决定，或一件可交付的产出。五份有显式清单的审查合计 **120 条**（`mandate-contradictions` 20+12、`computational-feasibility` 12+8、`emergence-verifiability` 16+12、`causality-bookkeeping` 13+3、`prior-art-postmortem` 14+10）；`pseudo-simulation` 与 `llm-storytelling` 没有清单节，其对应内容散落在各 F/S 节的「判别测试 / 替代设计」里，按同一口径提取得 **24 + 20 = 44 条**。**合计 164 条，去重归并后 80 条**，压缩比约 2:1。重复最严重的五个主题是：确定性与重放（7 份里 6 份提）、算力预算（5 份）、因果记录方式（5 份）、地图/气候基底（4 份）、LLM 边界（5 份）。

**这份表的唯一用途**：让"某个决定被默认掉了"这件事变得不可能发生。`mandate-contradictions §0` 的判决是——"在没有裁决规则的地方，实现者会按最容易写出来的那一种默认，于是纲领会以一种没人签字同意的方式被逐条改写"。这张表就是签字页。

`为什么不可事后补` / `建议默认值`（含**禁止**子句 —— 一个不禁止任何东西的设计等于没有设计）/ `依据` / `被否决的替代方案` / `待验证假设` / `裁决人`。

`裁决人` 只有两个值：
- **人** = 这是一个价值取舍或不可归约的口味问题，必须由项目所有者书面签字，不能由跑数据决定；
- **证据** = 一旦某个基准/实测跑出来，答案就唯一确定，不需要人拍板（本表标出该由哪个实验决定）。

### A1 · 目标硬件 + 单次长跑墙钟上限 `T_run` + 集合规模 `N_ensemble`

- **为什么不可事后补**: 它是所有其他数字的父节点。tick 率、网格分辨率、实体上限、LOD 预算、LLM 配额、验证算力全部由它反推。事后改它，等于全部已标定参数同时失效。更致命的是失败方式：`computational-feasibility F1` 给出完整链条 —— 没人写下 `N_ensemble` → 每个子系统按"跑一次花得起吗"判断 → 单跑涨到 8–24 小时（演示时完全可接受，无人报警）→ 需要验证时 200 种子 × 12 小时没人等得起 → 种子降到 3–5 → **唯一能做的事变成"看这 3 条里哪条好看"**，即 `pseudo-simulation` 判定为代码审查完全无效的 L4 失效。
- **建议默认值**: 8 台 16 核工作站；`N_ensemble = 200`；`T_run ≤ 1 小时`（不含 LLM）。**禁止**：任何子系统 owner 以"这一项在一次长跑里花得起"为由申请预算；超支必须从别人那里买。**禁止**在 CI 之外估算 `T_run` —— 每次提交在缩小地图上跑标定基准，外推超预算即构建失败。
- **依据**: `computational-feasibility F1`、§1（预算链条的第一性原理）、§8（1.2 s/tick = 3.6×10⁹ 周期 @3 GHz 的分配表）；`prior-art-postmortem 致命3`、§4.1、§1.10（Songs of Syx 的个体级尺度参照）；`emergence-verifiability F15`（一次消融矩阵 = 10,500 次长跑；Stonedahl & Wilensky 一次对抗式敏感性搜索 45,000 次运行、5 次搜索约 2,500 CPU 小时）。
- **被否决的替代方案**: (a) "先做对再优化"——被 `prior-art-postmortem §1.16`（AI Town 第一个被牺牲的就是记忆深度）与 §1.9（URR 15 年 0.11 版）否决；(b) 先定本体论再定预算——`prior-art-postmortem §1.10/致命3` 明写"先定预算，再定本体论"；(c) 云上按需扩容当作预算——它把 `N_ensemble` 变成一个每次都要重新申请的东西，实践中等于 3。
- **待验证假设**: 全部三个数字都是 D 级。`computational-feasibility §9` 自述预算表 12 行百分比"是我拍的"，价值只在"总和必须是 100%"这个约束。**必须由 `computational-feasibility §7 第 1 条` 的空壳内核基准（null kernel）替换**，两周可完成。
- **裁决人**: **人**（买不买机器是资源承诺）。数字本身由证据（空壳内核基准）确定。

### A2 · 确定性策略：定点整数 / 确定性树归约 / 放弃 bit-exact

- **为什么不可事后补**: 它决定每一个状态字段的物理表示。事后从 float 改 int64 定点 = 重写状态层 + 重新标定所有参数 + 全部历史作废。
- **建议默认值**: **(a) 定点整数**。所有守恒量与状态量（kcal、人口、粮储、兵力、货币）用 `int64/int32` + 声明标度；浮点只允许出现在诊断输出与不进入下一 tick 的中间量。**禁止**：内核中任何 `f32/f64` 字段；`-ffast-math`；依赖 BLAS 版本的归约；线程数影响结果。CI 从第一次提交起跑：线程数不变性（1/4/16 逐位相同）、容器逆序遍历不变性、跨机器不变性、从快照重放逐位相等。
- **依据**: `computational-feasibility F2`（本机实测：顺序 15848104.404159734 vs numpy 成对 15848104.40415974，相对差 ≈1.2e-16；logistic map r=3.9 下 1 ULP 约 60 步放大到 O(1)，而我们要跑 3,000 步）；`abm-methodology §830`（跨版本/跨机器/并行化漂移已被列为失真方式，但未给量级）；`causality-bookkeeping F7`（浮点归约顺序是使反事实静默失效的五类陷阱之一）；[已裁决 spec D5]。
- **被否决的替代方案**: (b) 确定性树归约 + 编译器约束 —— 靠纪律维持，任何一次依赖升级都可能静默破坏；(c) 放弃 bit-exact，把第 6 条降级为"重采样" —— 诚实但会同时废掉纲领的"平行世界"与"反事实"两个能力，且 `causality-bookkeeping §7.1` 的重算架构（唯一真相源）以比特级确定性为硬前提，选 (c) 等于同时否决 A19 的默认值。
- **待验证假设**: 定点标度的设计（除法精度、溢出边界）无先例；`computational-feasibility §7 第 5 条` 要求先在玩具世界实测"1 ULP 扰动的发散时间"——如果实测发散时间是 60 年，则**任何跨越 60 年以上的单线因果解释都必须改在集合层陈述**。这条实验同时是 A19、B6 的输入。
- **裁决人**: **证据**（1 ULP 发散时间实验 + 空壳内核基准的定点/浮点性能比）。

### A3 · 内核实现语言与"Python 不得进热路径"纪律

- **为什么不可事后补**: 一旦有 1 万行 Python 内核，重写成本超过项目本身。且 Python 的哈希容器迭代顺序、浮点行为、GIL 下的并行策略会把 A2/A6 的确定性契约变成靠纪律维持。
- **建议默认值**: 内核用编译型语言或全数组向量化实现；Python 只做编排、分析、可视化。**禁止**：任何逐 tick 调用的 Python 回调；任何在热路径上依赖 dict/set 迭代顺序的代码。
- **依据**: `computational-feasibility §6 第 3 条`、F4（每 tick 固定开销 5–50 ms 对"20 个子系统 + 事件日志 + Python 编排层"是乐观估计；日 tick 在做任何物理之前就已花光 1 小时预算的 1.5–15 倍）。
- **被否决的替代方案**: 纯 Python + numba/JIT —— 未被红队直接讨论，但它把确定性契约交给了 JIT 版本，与 A2 的 (b) 同类风险［本表原创，无来源，D 级］。
- **待验证假设**: 每 tick 固定开销 0.05–50 ms 的区间是 `computational-feasibility §9` 自报的 D 级假设。
- **裁决人**: **人**（团队技能栈约束）。

### A4 · 随机数体系：CBRNG + 流注册表 + Gumbel-max 采样

- **为什么不可事后补**: 纲领第 6 条的措辞（"记录随机种子"，单数）会诱导实现者写一个全局有状态 PRNG。在有状态 PRNG 下，"删掉一个事件"会重排此后**所有**抽样序列 —— 那不是最小干预，那是换了一个世界。事后更换 RNG 体系 = 全部历史与全部反事实结论作废。
- **建议默认值**: counter-based RNG（Threefry/Philox 类），`key = H(world_seed, stream_id)`，`counter = (tick, entity_id, purpose_id, draw_index)`；流按机制封闭注册（气候、疾病、生育、战斗结算、发现、LLM 采样…）。一切离散抽样用 **Gumbel-max**，Gumbel 分量按候选项的**内容哈希**寻址，禁止逆变换采样。**禁止**：全局有状态 PRNG；任何未注册的流；任何以"下一个随机数"为语义的 API。
- **依据**: `mandate-contradictions F5`/决定 9；`abm-methodology M4/M14`（该简报明确指出这是纲领第 6 条"唯一干净的实现路径"）；`provenance-replay-counterfactual M2`；`causality-bookkeeping F5`（CBRNG 下"什么都不改"的干预产生逐位相同输出，所以安慰剂必须是"同 tick、同机制类、可比位置上换一个抽样点翻转"）；Gumbel-max 用于反事实 abduction：`provenance-replay-counterfactual §2.7`（Oberst & Sontag，A 级）、`llm-storytelling §2`；[已裁决 spec D9/D10]。
- **被否决的替代方案**: 每实体一个独立有状态 RNG —— 在 A5 的 id 规则不稳时同样失效，且分叉后无法保证两条线的抽样序列可比。
- **待验证假设**: "Gumbel 分量按内容哈希寻址"是 `spec-world-state` 自报的原创 D 级；候选集变化时的行为需在玩具世界验证。
- **裁决人**: **证据**（因果隔离测试 + 零干预测试通过即成立）。

### A5 · 实体 id 生成规则（内容/血缘派生哈希）

- **为什么不可事后补**: 这是全表里最隐蔽、代价最高的一条。若 id 由全局自增计数器分配：抑制远洋小岛上的一次生育 → 全局计数器少加 1 → 此后每个新生者拿到不同 id → 每个人的 CBRNG counter 全变 → 三年内整个大陆全变。**我们会观察到"抑制一次生育，100 年后世界完全不同"，并把它写成路径依赖的证据。** 这个 bug 与真实路径依赖在任何宏观观测量上都不可区分，且 `causality-bookkeeping F7` 判断它"会在 18 个月后才被发现"。
- **建议默认值**: `child_id = H(mother_id, father_id, birth_tick, birth_order_within_mother)`；`site_id = H(cell_id, founding_tick, founder_lineage_id)`；BLAKE3-128 或同类。**禁止**：任何全局自增计数器（构建期错误，不是运行期警告）；任何以插入顺序为语义的容器 id。两个 CI 门禁测试必须在写第一个机制之前跑通：**零干预测试**（把某值改成它原本的值，输出逐位相同）与**因果隔离测试**（对地理/网络上完全隔离的孤岛 A 做任意干预，远方 B 在 100 年内逐位相同）。
- **依据**: `causality-bookkeeping F7`（含同类陷阱清单：容器迭代顺序、浮点归约、空间索引重建、LLM 账本序号错位）；[已裁决 spec D8]。
- **被否决的替代方案**: UUIDv4 —— 不可重放；(branch_root_id, local_id) 复合 id（`mandate-contradictions` 决定 10 的备选）—— 解决了分叉后的冲突，但没解决同一条线内的重编号问题。
- **待验证假设**: 血缘派生哈希的碰撞概率与性能开销未实测。
- **裁决人**: **证据**（因果隔离测试是二值的）。

### A6 · tick 内相位顺序规范与版本化

- **为什么不可事后补**: 顺序是一个隐藏参数，而且是一等重要的参数。Kehoe 2016 用形式化方法证明《Growing Artificial Societies》出版 20 年后仍不可无歧义重实现，三大原因之一就是"书里没有说规则以什么顺序应用"。事后改顺序 = 所有历史线语义改变，且改变不可见。
- **建议默认值**: 相位顺序显式版本化为 `PHASE_ORDER_V1`，是 spec 的一等公民；改变它要走和改变模型一样的评审流程。**禁止**：依赖哈希容器迭代顺序；任何"顺便在这里也更新一下"的跨相位写入。CI 放"逆序遍历、输出逐位相同"的测试。
- **依据**: `mandate-contradictions` 决定 19（转引 `abm-methodology`，Kehoe 2016 arXiv:1505.06012v3，简报标注读到全文）；`emergence-verifiability §6 第 16 条`（并引 Epstein 2002 civil violence 模型：Mesa 实现的注释写明公式里的取整"不在 PNAS 原文中，但没有它就不可能复现"）；`computational-feasibility S6`（多速率下还多出一个"相位"自由度：第 Y 年的收成在疫病结算之前还是之后，给出不同死亡率）；[已裁决 spec D7]。
- **被否决的替代方案**: 事件驱动的乱序执行 + 幂等性假设 —— 与 A2 的确定性契约不兼容。
- **待验证假设**: 无（这是纯纪律条款）。
- **裁决人**: **人**（顺序本身是建模选择，不能由性能决定）。

### A7 · 主时钟、合法 tick 率集合、子时钟配额表

- **为什么不可事后补**: 一切速率、预算、LOD、事件密度都以 tick 计价；事后改 tick 会让所有已标定参数同时失效。且不整除的速率会产生拍频，使宏观周期变成 tick 表的产物 —— 对一个要研究长周期的项目是致命伪影。
- **建议默认值**: 主时钟 = **1 年**，唯一合法主时钟；合法年内细分 {1,2,4,12}；合法慢周期 {1,5,25,100}；Strang 对称分裂（半步 A - 整步 B - 半步 A）。所有概率以**年危险率**存储。更细的时间必须是**事件局部、有界、有配额**的子时钟，配额表进 Phase 0 文档（哪个子系统可开、最大步数、最大空间范围、并发实例上限）。**禁止**：全局月 tick 与日 tick（永远）；不整除的速率；无配额的子时钟；强耦合量跨速率分裂（人口 ↔ 食物比 E ↔ 疫病死亡必须在同一速率上联立）。
- **依据**: `computational-feasibility F4`（日 tick 的杀手不是格点物理而是每 tick 固定开销：5 ms/tick × 1.1×10⁶ 步 = 1.5 h，50 ms → 15.2 h；而 5 场并发战争 × 180 天 × 10⁴ ops = 9×10⁶ ops/年可忽略）、S6（算子分裂误差正比于对易子，**在饥荒+疫病+战争同时发生的崩溃期最大，即我们最需要精度的地方**）；`mandate-contradictions` 决定 1；`china-eastasia-geography-archaeology §9.1`（气候慢时钟 100 年 / 社会快时钟 1–5 年，自报 D 级）；[已裁决 spec D7]。
- **被否决的替代方案**: 可变步长/自适应时钟 —— 步长会跟着"有事发生"走，即 `pseudo-simulation S8` 的 LOD 剧情通道的时间版本；季度作为独立主时钟 —— 被 `computational-feasibility F4` 的固定开销算术排除。
- **待验证假设**: "步长减半不变性"必须在**崩溃期窗口**上测（平稳期会通过）。这条没做之前，"历史是机制的函数"这句话未经检验。
- **裁决人**: **证据**（步长减半不变性测试）+ **人**（配额表的分配）。

### A8 · 空间：一张动态网格 + 分辨率　【冲突 3，详见 §5.3】

- **为什么不可事后补**: 格尺寸是所有空间机制的公共标定基准。`cliodynamics-secular-cycles` 明确警告缩小网格必须重新标定 δ_s（它按格数计）。且"几张网格"这个决定决定了是否存在逐 tick 执行的插值算子 —— 插值是一个有系统性偏置的算子，从粗到细会造出不存在的空间结构，下游子系统会把它当真实地理来响应。
- **建议默认值**: **单一动态网格 H3 res 5**（252.90 km²/格，边长 9.854 km，中心距约 17 km；东亚约 4.7 万格，含草原带的扩大窗口约 8.4×10⁴ 陆格）。1 km 只做一次性静态预计算，聚合时**保留分布摘要**（min/p10/p25/p50/p75/p90/max + 最大连通可耕斑块），不是只留均值。亚格子过程 = 冻结的位点集 + 图上的边，不参与逐 tick 遍历。**禁止**：第二张动态栅格；任何逐 tick 执行的重采样/降尺度算子；同一个量在两个子系统里有两个值。
- **本表对 spec D6 的补充（回退规则）**［本表原创，无来源，D 级］: 空壳内核基准若实测格扫超过 350 ms/tick，**唯一合法的调整方向是降到 H3 res 4（1,770.35 km²，约 2 万格），不得增加第二张网格、不得给"重要区域"加密**。后两者会分别复活 S3 的插值偏置与 S8 的 LOD 剧情通道。
- **依据**: `settlement-urbanization-spatial §4.6`（H3 官方分辨率表，已核验：res 4 = 1,770.35 km²/26.07 km/288,122 格；res 5 = 252.90/9.854/2,016,842；res 6 = 36.13/3.725/14,117,882）、§11.2（ORBIS 实测：牛车 12 km/天、挑夫 20、步行与驮兽 30 —— res 5 的中心距 17 km ≈ 载货运输的一天行程）；`computational-feasibility S3`（一张网格纪律 + 内存不是约束：1 km 全域每格 2 KB 也只要 24.6 GB）；`china-eastasia-geography-archaeology §3.1`（5–10 km，该简报 §9.1 自报"纯工程取舍"D 级）；[已裁决 spec D6]。
- **被否决的替代方案**: res 6（36 km²）—— 被算术排除（同窗口格数是 res 5 的 7.0 倍，气候+农业两项就吃光整个 tick 预算）；25 km/625 km²（`computational-feasibility S3` 的建议）—— 中心距 26 km 超出载货运输的一天行程，"相邻 = 一天可达"的语义锚失效，且把早期政体粒度的偏差再放大 2.5 倍；`settlement` M7 的 L1 动态加权 Voronoi —— 第二张动态空间划分，且需要 `Settlement` 一等实体（与 A15 冲突）。
- **待验证假设**: 陆比 0.6、周期/格估算全部 D 级；`settlement-urbanization-spatial §11.5 D` 自己指出 253 km²/格会**系统性低估早期政体数量、高估其平均规模**，而纲领要求"从文明形成之前开始"，最脆弱的恰是这一段 —— 这个偏差没有补救方案，只能声明。
- **裁决人**: **证据**（空壳内核基准）。

### A9 · 地图基底与 holdout 划分　【冲突 1，详见 §5.1】

- **为什么不可事后补**: 基底一旦冻结进 `basemap_hash`，换基底 = 全部历史作废。更重要的是：holdout 的划分决定了"我们的世界演化出了 X"这句话有没有信息量，而事后划 holdout 在方法学上无效（数据已经看过了）。
- **建议默认值**: 正式主线运行在 `T(真实骨架, world_seed)` —— 一次性创生扰动（镜像/旋转/河网局部重连/海平面偏移/走廊剪断或新开/降水梯度主轴旋转），创生时应用、结果冻结、内容哈希。未扰动的真实基底**只存在于物理隔离的评估进程**（不同 crate、不同进程、不同目录、只读挂载，内核零可见性，CI 强制）。**扰动算子必须声明等变类；校准量必须是该等变类下的不变量**：等距不变量（协变量条件统计量）可直接在主线校准；非等距量只能在评估进程标定**函数形式** `f(covariates) → rate`，搬到主线的是函数形式，不是空间场，且每次搬运在参数登记表留痕。**禁止**：主线基底出现任何真实地名/水名/山名/族名；任何以"区域名"为键的手工属性表；agent 视图或 LLM prompt 出现经纬度绝对值。
- **依据**: `mandate-contradictions F1`（Turchin et al. 2013：距草原距离是农业格帝国密度最强预测因子，与农业长期存在程度、高程共同解释 42% 方差；消掉草原效应 R² 从 0.65 掉到 0.17；Madge et al. 2019 复现：仅用人口密度基线 R²=0.75；Kapoor et al. 2024：无 holdout 导致走捷径与过拟合）；`china-eastasia-geography-archaeology §3.0`（51,074 遗址点、7,083 个 14C 年代、CHGIS、HYDE、CHELSA-TraCE21k 在合成大陆上全部失效）；`east-asia-climate-environment §11.2`；`pseudo-simulation F4`（地图置换套件：真实/镜像/程序生成同统计量/真实欧洲/真实中美洲，各 40 种子）；`prior-art-postmortem 取舍1`、§1.3；[已裁决 spec D11]。
- **被否决的替代方案**: (a) 一比一真实东亚做主线 —— 无 holdout，且诱导"这里应该出现关中"；(b) 纯合成大陆 —— 放弃全部校准资源，且"你不知道它哪里不像"（生成算法偏见以不可见方式污染涌现结论）；(c) 主线跑真实、只在事后声明"这是地理效应" —— 措辞纪律无法阻止参数调优朝真实历史走。
- **待验证假设**: **等变类和解的成立条件本身未验证**［本表原创，无来源，D 级］—— 如果实测发现绝大多数有用的校准量都是**非等距**的（河网拓扑、走廊中介中心性恰恰是最强预测因子那一类），这个和解就退化为"大部分校准要靠评估进程搬函数形式"，其可信度需要单独论证。建议 Phase 0 先做一次清点：把打算用的校准量逐条标注等距/非等距，比例写在这一条下面。若非等距量占比 > 50%，本条必须回到人裁决。
- **裁决人**: **人**（这是"我们要什么"的取舍，`mandate-contradictions §7 第 2 条` 要求它以《互斥声明》形式签字）。

### A10 · 气候来源：合成序列 vs 真实古气候序列

- **为什么不可事后补**: 气候序列不是边界条件，是**事件生成器**。若来自外部文件第 N 行，其原因是"文件这么写的"，纲领第 2 条在气候这条通道上永久失效，且所有平行世界共享同一条气候史（分岔空间被人为压缩）。事后换成合成 = 全部历史作废。
- **建议默认值**: **地理用真实（扰动后），气候用合成 —— 这个不对称是刻意的。** 生产世界的气候由 `G(seed, params)` 生成，参数从真实东亚古气候标定（事件基率与持续时间分布、温度/降水的世纪尺度振幅、空间相关长度与季风/西风反相结构、年际 CV 空间梯度）；缓变基线可取 CHELSA-TraCE21k 东亚窗口的**平滑低频包络**，不是逐年数值。真实古气候序列只出现在**孪生验证线**里，且永久标记 `calibration_only`，不得作为世界史来源。气候场**禁止落盘**（25 km × 12 月 × 3,000 年 × 2 变量 = 5.5 GB/线），必须用 CBRNG 按 `(tick, cell, purpose)` 现算。
- **依据**: `east-asia-climate-environment §11.1`（"地理是边界条件，气候序列是事件生成器"这个区分）、§11.2 方案 A、§11.3 取舍矩阵、§11.4（校准是分布匹配不是逐年匹配：功率谱、事件持续时间分布、空间范围分布、CV 空间梯度、洪水频次弹性、改道重现间隔、**崩溃间隔的分布形状**）；`pseudo-simulation F4`（真实序列里的干旱在时间上与真实王朝更替相关，喂进去之后任何机制都会"解释"王朝崩溃）；`computational-feasibility S5 第 5 条`。
- **被否决的替代方案**: 真实序列直接驱动主世界（`east-asia-climate` 方案 B）—— 五条代价：因果链断裂、反事实受污染、诱导历史匹配（"一旦知道 1637 年应该有大旱，我们会不自觉地调参数让那一年真的出乱子"）、平行世界不可能、**前文明期根本没有年分辨率真实序列**（所以方案 B 无论如何都要在早期退化成方案 A）。
- **待验证假设**: 合成生成器能否复现"崩溃间隔重尾"这个最重要的判据（`east-asia-climate-environment §11.4 第 7 条`：若产生近乎周期性的崩溃间隔，说明阈值把气候变成了节拍器 —— 这是失败信号）。
- **裁决人**: **人**（一句话就能定，但必须签字，因为"用真实序列"在演示上永远更诱人）。

### A11 · 世界边界与"世界外通量"接口　【红队之间对立，详见 §5.7】

- **为什么不可事后补**: 这条决定了**草原压力这个最强宏观驱动到底是内生的还是外生注入的**。而 `mandate-contradictions F1` 已经用 Turchin 2013 证明距草原距离是最强预测因子。事后从"外生流"改成"内生"= 整个北部动力学重写。
- **建议默认值（本表建议采纳 spec D12，与 `mandate-contradictions` 决定 5 相反）**: 草原/牧业生态带**整体在世界之内**；窗口外为吸收边界；`world_external_flux` 接口存在但**默认恒为 0 且在生产线编译期关闭**。**禁止**：以泊松流形式注入外来技术、病原、人群作为主线机制。
- **依据**: `mandate-contradictions` 决定 5（提出问题，并建议"有限世界 + 显式世界外通量接口，到达率由地理通道成本计算"）；`spec-world-state D12`（给出相反裁决，理由：若做成外生流，等于手动注入真实历史最重要的那个变量）；`mandate-contradictions F1`（草原效应的量化：消掉后 R² 0.65→0.17）。
- **被否决的替代方案**: `mandate-contradictions` 决定 5 的原建议（低频泊松流外部通量）—— 本表判断它把最强的一个宏观驱动变成一个我们手调的参数，与 A9 的自主性目标直接冲突；周期边界 —— 在真实地形骨架上无物理意义。
- **待验证假设**: 扩大窗口后的格数（约 8.4×10⁴ 陆格）与预算的关系是 D 级；把草原纳入世界内需要牧业生业系统在 t=0 就可表示，这是一个额外的机制负担，未评估。**本条是两份文件明确对立的地方，必须由人裁决，不许各自实现。**
- **裁决人**: **人**。

### A12 · t=0 初始条件包

- **为什么不可事后补**: 这是整个项目最大的一次假设注入，且它处在路径依赖的上游 —— `mandate-contradictions F12` 指出最高杠杆的时期恰好是证据最稀薄的时期（ArchaeoGlobe *Science* 2019：考古数据覆盖峰值在 2000 BP；粟驯化期跨 8300–4300 BC，在年 tick 上几乎没有任何约束）。
- **建议默认值**: t0 取"末次冰消之后"；初始人群按**纯环境适宜度函数 + 种子**播撒，**禁止读取任何遗址坐标**（遗址数据库只在评估进程使用）；初始知识集合除觅食外为空；**初始参数取分布不取点值，正式产物是集合而不是单一世界**。早期（建议前 2000 模拟年）**只允许 A/B 级证据支撑的机制生效**，其余机制的对外接口返回"不存在/无效应"，而不是返回一个看起来合理的近似值。终态方差中来自 t=0 抽样的份额是必填报告字段。
- **依据**: `mandate-contradictions` 决定 4、F12；`pseudo-simulation` G1/F4；`china-eastasia-geography-archaeology §3.0(c) 第 3 条`（初始播种只能用环境规则 + 随机种子）；[已裁决 spec §7]。
- **被否决的替代方案**: 把初始人群放在真实遗址点上 —— 直接把答案抄进初始条件；给早期机制填"看起来合理的近似值" —— 与 `pseudo-simulation C9`"未实现子系统必须返回不存在"冲突，且占位实现从不被删除，它们会成为世界的物理定律。
- **待验证假设**: "前 2000 年只允许 A/B 级机制"这个门槛的具体年数是 D 级；早期敏感性分析尚未做。
- **裁决人**: **人**。

### A13 · 单位体系 + 定点标度 + 每 tick 守恒审计

- **为什么不可事后补**: 单位混乱是历史数据的固有属性，不是可以事后清洗的噪声（亩有 10 种大小、清代银两 56 种地区标准）。标度一旦写进定点表示就是类型的一部分。
- **建议默认值**: 物质以 kg/g 干重、能量以 kcal、人以人年（或微人 µp）计；标定**优先用比率而非绝对值**（稻/麦单产比 ≈ 2.5–3.7、南北人口密度比），因为比率对历史单位混乱免疫。每 tick 对每种守恒量（人口、粮食、金属、马匹、财政）做全局收支闭合检查，容差为定点精度；**不平即构建失败**。每 tick 对每种共享资源做并发占用检验（同一片腹地不能被两个城市各自全量计入）。**禁止**：任何无声明标度的数值字段；把守恒违反降级为警告。
- **依据**: `mandate-contradictions` 决定 18（转引 `agriculture-carrying-capacity`）；`emergence-verifiability F12`（**逐事件检查在数学上抓不住并发违约**：每场战争单独通过后勤检查，但同一年三场合计超过全国盈余 —— 这不是"检查器可以更好"，而是"逐事件检查在数学上不可能做到"）、§7.1 L1（守恒闭合是"合理"里最硬、最便宜、最该先做的部分，**而纲领里一个字都没提到守恒律**）；[已裁决 spec D4]。
- **被否决的替代方案**: 抽样式守恒审计 —— 并发违约恰恰在危机期集中出现，抽样会系统性漏掉。
- **待验证假设**: 每 tick 全量守恒审计的开销未进 `computational-feasibility §8` 预算表。
- **裁决人**: **人**（单位选择）+ **证据**（审计开销）。

### A14 · 三值逻辑：存在 / 不存在 / 未知

- **为什么不可事后补**: 这是一个 schema 级区分。事后加，等于所有已存的"缺失"都不知道当初是哪一种。
- **建议默认值**: 世界事实层的"不存在"与记录层的"未知"是两个不同的值，在类型系统里不可互换。**禁止**：任何把缺失默认编码为 0 / false / 不存在的序列化；任何在统计中把 unknown 当 absent 的聚合函数（必须报告"全当 absent"与"全当 present"两个极端下的区间）。
- **依据**: `emergence-verifiability §6 第 10 条`、F8；`pseudo-simulation S6`（Whitehouse et al. 2019 *Nature* 568:226–229 已被撤稿，Retraction Note *Nature* 595:320, 2021；Beheim et al. 2021 *Nature* 595:E29–E34：Seshat 中道德化神灵数据 **61% 为缺失**，把缺失重编码为"不存在"时原结论成立，只用现存数据或标准插补时**结论反转**）；`prior-art-postmortem §1.5`、§4.10。
- **被否决的替代方案**: 用可空类型代替三值 —— null 在下游会被当成 0，这正是 Seshat 的失败模式。
- **待验证假设**: 无（这是已被一次撤稿事件验证过的教训）。
- **裁决人**: **证据**（Beheim 2021 已经给出答案）。

### A15 · 内核词汇表分层与原语准入规则

- **为什么不可事后补**: 一旦 `Polity` 是一个有 `territory/tax_rate/legitimacy/ruler` 字段的类，任何变大的社会形态**都会**被塞进 `Polity`，我们就永远观察不到"一个不是政体的大规模社会形态"——一个没有领土的、永久性的商贸离散社群，在我们的世界里连**存储的位置**都没有。事后删除一个一等类型 = 重写全部机制。
- **建议默认值**: 内核一等对象只有：个体、家户、地块/格、物质存量、关系边、信息副本（+ 内容寻址的物质/物种/配方注册表）。原语准入两条硬规则：(i) 定义**不引用任何制度**（"征税"不合格，"以暴力威胁索取资源转移"合格）；(ii) 全部参数是物理量、信息量或关系边。**禁止清单（可 grep）**：`Polity` / `Religion` / `Dynasty` / `Class` / `EventType` 枚举 / `legitimacy` / `stability` / `prosperity` / `morale` 之类无微观所指的宏观标量字段。配套三个二值检验：**类型删除测试**（物理删除 `Polity` 类，编译/运行不通过 ⇒ 政体是被假设的）、**类型抹除测试**（把所有 composite 标签替换为随机 UUID 后同 `(state, seed, ledger)` 重跑，轨迹必须逐位相同）、**内核不得 import 观测器**的构建期检查。
- **依据**: `pseudo-simulation S4/S5`（"国家应该是世界里的人头脑中的一个信念对象，而不是模拟器的一个数据结构"；`Dynasty` 是致命的，因为王朝是回溯性的史学建构）；`emergence-verifiability F5`（类型抹除测试，该文自标 [我的推断，无来源]）、7.2 D1/D2；`state-formation §9.a`（正确的"国家出现观测器"模板，AP1 已禁止 `enum PolityStage`）；`causality-bookkeeping F3 路A`（因果链的可读性需求会独立地、以"为了能解释"的名义把语义对象塞回内核 —— 这是即使防住了 S5 也还开着的门）；[已裁决 spec D1/D2]。
- **被否决的替代方案**: 保留一等类型但"约定不在内核读取" —— 字段不存在比"约定不使用"强；把标签放进配置文件/字符串比较 —— 类型抹除测试就是为了抓这一类间接实现。
- **待验证假设**: 取消 `Settlement`/`Polity` 之后，需要"这块地属于谁"的机制（田赋、征兵、封地）只能写成图上的可达集，其表达力是否够用未验证（`spec-world-state §4.3` 已签字接受这个代价）。
- **裁决人**: **人**。

### A16 · 决策主体本体：Actor 三段分离

- **为什么不可事后补**: 纲领把三件不同的事混成一个词"人物"。如果不在类型层分开，"个体 agent 在某一年上线"的阶段门就会被写进 LOD 调度器（A17），而它住在性能代码里，任何"机制层不得包含阶段枚举"的检查都抓不到。
- **建议默认值**: 三段分离写进类型系统 ——
  (1) **人口个体**（有年龄性别、会生会死）：t=0 起永远存在，用队列（cohort）表示，不是 agent；
  (2) **决策主体 Actor**（拥有资源、有效用、有受限信息视图、会做选择）：**t=0 起永远存在**，前农业期的默认 Actor 是家户/营群；这是唯一的一等决策接口，聚落/血统/组织/政体是 Actor 的组合与角色（AGR 范式）；
  (3) **历史人物**（被命名、被记住、被后世研究）：**当且仅当世界内出现能跨代承载专名的记录/记忆机制之后** —— 它不是模拟粒度选项，而是记录层的涌现产物。
  **禁止**：任何"person agent 在条件 X 下启用"的开关；任何以年份或政体存在与否为参数的本体切换。
- **依据**: `mandate-contradictions F4`/决定 6（Park 式全量 generative agent：10⁵ agent 推进 10 步 = 5×A100×2 天，外推 3000 步 = 5×A100×600 天，所以"每人一个 LLM agent"在任何预算下都不成立，LOD 是**强制**的）；`abm-methodology §2.16`（AGR 范式）；[部分已裁决 spec D2]。
- **被否决的替代方案**: 统一的 `Agent` 类 + 活跃标志位 —— 活跃条件就是隐藏阶段门；只在"文明形成后"引入 Actor —— 直接违反纲领第 1 条。
- **待验证假设**: 家户作为 t=0 默认 Actor 的效用函数形式无文献支持。
- **裁决人**: **人**。

### A17 · LOD 提升/降级规则与活跃个体预算

- **为什么不可事后补**: LOD 分配规则是一条**在机制层面制造主角、且不留代码痕迹**的正反馈：个体层有方差、有世系灭绝、有尾部事件，队列层数学上不可能有；一旦某地被 promote，它就获得更高的方差和更多尾部事件，于是它更显得重要，于是继续被 promote。
- **建议默认值**: 提升函数**只读结构量**（控制的劳动/粮食份额分位、网络中介中心性、是否占据一个被制度定义的职位、组织层级数、人口规模）；**禁止读取年份、禁止读取"是否存在国家"、禁止读取任何全局阶段标志、禁止读取任何重要性/戏剧性/事件密度变量**（写成 lint：LOD 调度器模块不许 import 事件系统）。活跃个体预算 `B` 见下方冲突。降级时残余影响写回队列、状态归档进事件图而非丢弃。**加 1% 随机提升对照组**（唯一能测出提升偏差的办法）。**LOD 不变性检验（二值）**：随机提升一个子集，宏观分布的移动必须落在噪声地板内。
- **数值冲突**: `mandate-contradictions` 决定 7 建议 `B = 10⁴`（引 `abm-methodology M11`，该简报自标 D 级量级猜测）；`computational-feasibility T2` 按 1 小时预算反推 `B = 3×10⁴`；`population-dynamics §807` 估计现代引擎上限约 10⁵。**本表建议取 3×10⁴**，理由是它是唯一从预算反推出来的数（其余两个是量级猜测），并绑定到 A1 的空壳内核基准。
- **依据**: `mandate-contradictions F4`；`computational-feasibility S1`（`abm-methodology §4.8` 明确写：多层级 ABM 的 aggregation/disaggregation "综述指出 Zoom 范式有信息损失，但未给出可用的误差界或守恒律形式"）、T2（**已知方向的选择性偏置**：精英被个体化、平民被聚合，于是所有"个体性"现象都发生在精英身上，而"精英过度生产"恰是 Turchin 框架的核心机制 —— 我们把观测能力集中在了它的一侧）；`pseudo-simulation S8`（判别测试：LOD 不变性 + 随机 LOD 对照）；`population-dynamics §3.11/§14`（"队列不能灭绝"）。
- **被否决的替代方案**: 按"有意思程度"分配 LOD 预算 —— 这就是剧情通道；全量个体化 —— 被算力排除。
- **待验证假设**: `population-dynamics §3.11` 的守恒不变量（纯队列投影 vs 提升为个体再跑再聚合，200 年窗口内 Monte Carlo 误差内一致）**必须做成从第一天起在 CI 里跑的回归测试**，目前未做。
- **裁决人**: **证据**（LOD 不变性检验 + 空壳内核基准）+ **人**（B 的最终取值是预算承诺）。

### A18 · 事件的地位：内核无 `Event`，事后提名 + 语义无关重大性

- **为什么不可事后补**: 若内核有 `emit_event()`，因果图的形状 = 我们注意力的形状 = 我们的历史观，且这是一个完美闭环的偏见（我们认为重要的事才被记录成原因，然后我们回头发现历史确实是被这些事推动的）。事后改成"检测出来的事件"= 全部因果库作废。
- **建议默认值**: 内核只写状态，不命名事件。"事件" = 状态轨迹上的显著变化，由变点检测器在状态通道上**事后**识别，输出一个**无名对象**（状态差分 + 读取集闭包）。**提名可以延迟发生** —— 一次边境小冲突可以在 80 年后被提名（这解开了三级留档的死结：不需要在事件发生时预判它未来是否重要）。通道集必须由状态 schema **机械导出**，手工添加的通道进登记表并计入自由度。**禁止**：`enum EventType`；`found_state()` / `start_religion()` / `reform_bureaucracy()` 这类历史层级的效果函数动词；任何手写 `emit_event()`。
- **依据**: `pseudo-simulation S4`（含自我批评："在哪些状态通道上做变点检测这个选择，就是新的枚举，只是从内核挪到了观察层"——好处是它不再影响世界演化）；`causality-bookkeeping S3`（事件由下游影响自动提名；提名器必须可替换、可版本化，且至少同时跑两个不同提名器并比较重叠度）、F2(a)（三级留档的死结）、§6 第 7 条（重大性的语义无关定义：`重要性(τ) = E[d(世界_有τ, 世界_无τ)]` 在若干未来时点上的加权和，或信息论版本的互信息）；`emergence-verifiability F4`（`impact(e)` = 同种子重放、在 e 处翻转抽样、测 T ∈ {50,200,500} 年后世界状态向量的距离；**乐观冻结 + 延迟裁剪**）；`mandate-contradictions F7`（纲领第 9 行的事件清单是历史教科书章节目录，9 项全是政治—思想类）。
- **被否决的替代方案**: 事件类型枚举 + 触发条件 —— 是剧情树节点的定义；由 LLM 判断"这件事重要吗" —— 循环性（`abm-methodology AP9`）；由人事后指定 —— "每个重大事件都有因果链"变成永真命题。
- **待验证假设**: 变点检测器的通道集是否够宽；两个提名器的重叠度未知（低重叠本身是一个值得报告的发现）。
- **裁决人**: **人**（这是一个本体论承诺）。

### A19 · 因果架构：重算 vs 写入级 provenance　【冲突 2，详见 §5.2】

- **为什么不可事后补**: 存储布局与真相源数量。写入级 provenance 有两个写路径，两库会漂移，而因果库的错误极难发现（它长什么样都"说得通"）。事后从写入级改成重算 = 全部因果结论作废。
- **建议默认值（三层合成，见 §5.2）**: **主干采用重算架构**（唯一真相源 = 状态 + 种子；`world_seed` + 配置哈希 + 内核版本哈希 + LLM 冻结账本 + 内容寻址快照，约 30 GB/跑）；**常开一层有界读取集指纹**（≤64 项 `(entity_kind, entity_id, field_id)` 变量级三元组 + tick + rule_id + rng_key + llm_call_id，常数大小）；**全量 taint 追踪只在 `--audit` 短世界（500 年）开启**。作弊检测器 `declared_causes(e) \ read_set_closure(e)` 必须为空，CI 强制。**禁止**：任何由代码作者手工声明的 `cause_list` 进入因果库主表（只能作为待检验假设存在于独立字段并在展示时标注）；把 PROV-DM 当作因果模型使用。
- **依据**: `causality-bookkeeping F2`（写入级存储量推导：10⁵ 个体 × 20 写/tick + 1.1×10⁵ 格 × 30 变量/tick ≈ 5.3×10⁶ 写/年；3000 年 ≈ 1.6×10¹⁰ 写；平均 3 父 × 44 B ≈ **700 GB/跑**，加索引 1–3 TB，× 50 种子 = 50–300 TB；且写入记账**在原理上不能表示缺席因**）、§7.1（三条路的对照表）、§9（**W3C PROV-DM 规范原文本次会话核验**："PROV does not attempt to specify the conditions under which derivations exist"；`wasInfluencedBy` 是 dependency 不是 causation —— 这直接修正了 `abm-methodology §2.19` 的表述）；`pseudo-simulation F3`（自报的因果链等于伪造；读取集追踪；开销估计 2–10×，该文自述"我的工程估计，未做基准"）；`computational-feasibility F3`（祖先闭包 b^d 组合爆炸；格点级全量 PROV 图 = 2.16×10¹⁰ 事件 × 4 边 = 8.64×10¹⁰ 边，**超 Neo4j aligned/standard 格式 2³⁵ 上限 3 倍**，官方文档已核验；剪枝规则就是解释）；`prior-art-postmortem 致命2`/§1.8（Caves of Qud：先生成事件、事后合理化，证明"读起来有因果的历史"可以廉价生产）。
- **被否决的替代方案**: 写入级全量 provenance 闭包（存储不可行 + 认识论无价值）；事后从轨迹拟合（观察性推断，混杂无法控制，非遍历下样本不独立）。
- **待验证假设**: taint tracking 开销 2–20× 是 `causality-bookkeeping §9` 标注的 [记忆，未核实]，**必须以我们自己的实测替代**；重算架构的硬前提是 A2 的比特级确定性 —— 如果 A2 选了"放弃 bit-exact"，本条默认值自动失效。
- **裁决人**: **证据**（taint 开销实测 + 存储实测）。

### A20 · 抽样点记账规范 + 近失账本

- **为什么不可事后补**: 事后看每件事都有原因、每条链都完整 —— 这在数学上是必然的，因为我们只保留了实现了的那一条轨迹。丢失的是每个抽样点上的**分布**：那个点当时可能是 p=0.97 还是 p=0.03，实现之后在记录里长得一模一样。不在架构里保证可重算，"本来有 30% 概率走向另一条路"永远无法表达，**必然性错觉是默认结果**。
- **建议默认值**: 每个抽样点必须能重算出三样东西：分布族与参数、抽到的分位 `u`、触发阈值。在 CBRNG 下 `u` 是计数器的纯函数（免费），分布参数是状态的纯函数（重算即得），所以边际存储成本为零 —— 前提是 A19 的重算架构。**近失账本（near-miss ledger）**：凡是内核评估过概率但没有触发的抽样点，都是因果图的一等公民节点 `(site_id, tick, 分布参数, 分位 u, 阈值)`，按需重建、不落盘。**禁止**：任何不经注册抽样点直接消费随机数的代码路径。
- **依据**: `causality-bookkeeping F6`（必然性剖面 `p̂(Δ)`：从事件前 Δ ∈ {10,50,200,500} 年分叉、重采样非焦点流，该事件在 100 条平行线中出现的频率；"兴国之亡 · 必然性剖面：10 年前 96/100 · 50 年前 71/100 · 200 年前 23/100 · 500 年前 4/100" —— 这一行字比任何叙事免责声明都更能杀死必然性错觉）、F2 替代设计 2（近失账本回答"为什么没有改革"：提案在 t=1240/1263/1288 三次被评估，触发概率 0.11/0.19/0.07）；`pseudo-simulation S7`（记录种子让抽签结果可复现，但剧情树不住在骰子里，住在分布的形状里；**确定性重放对剧情树同样成立，而且剧情树是最可重放的系统**）。
- **被否决的替代方案**: 只记录抽样结果 —— 使 F6 的必然性剖面与 F2 的缺席因表示都不可能。
- **待验证假设**: 近失账本的**已声明局限**：只有"内核评估过的机会"能成为缺席因；世界里根本没有建模的可能性（"他们没有发明 X，因为我们的技术空间里没有 X"）永远不会出现在因果链里 —— **不可修补，只能在每份报告页脚常驻声明**。另见 `causality-bookkeeping T3`：近失账本把概率参数变成一个我们能直接盯着看、并且有强烈动机去调的东西，这是一条**未解决的残余风险**。
- **裁决人**: **证据**（重算成本实测）。

### A21 · 慢变量注册表与 `Channel` 节点类型

- **为什么不可事后补**: 因果模型如果只有一种节点（离散事件），慢变量就只有两条路：把它离散成事件（`if gini > 0.65: emit("土地兼并危机")` —— 每一条因果链的终点都会停在一个我们亲手写下的数字上，而且这个语义对象会被下游机制引用，在结构上与手写剧情树无法区分），或者根本无法表示。
- **建议默认值**: 因果模型有**两种**节点：`Event(id, tick, site, 分布参数, u)` 与 `Channel(id, variable, [t0,t1], 轨迹摘要)`。**Channel 不需要阈值，它由变量本身与时间窗定义。** 慢变量注册表是 Phase 0 交付物（哪些量算结构性慢变量、时间尺度多少），**允许事后追加** —— 而事后追加只有在重算架构下才可能（这是支持 A19 的又一条独立理由）。**禁止**：任何 `if 慢变量 > 常数 then 语义事件` 的内核代码；任何以人类历史学概念命名的内核符号（`LAND_CONCENTRATION_CRISIS_THRESHOLD`、`FISCAL_COLLAPSE_GINI`）—— 静态检查。
- **依据**: `causality-bookkeeping F3`（含对 Channel 干预的四种算子与修复规则的偏置声明）。
- **被否决的替代方案**: 只做事件节点 + 阈值离散化（路 A）；只做 Channel 不做干预量化（无法回答"它有多重要"）。
- **待验证假设**: 慢变量注册表的初版内容尚不存在；四种干预算子给出不一致答案时**没有裁决办法**（`causality-bookkeeping T4`：只能说"取决于你如何设想它不发生"）。
- **裁决人**: **人**（注册哪些量是建模判断）。

### A22 · 分层 schema L0/L1/L2/L3 与因果图归属层

- **为什么不可事后补**: 因果图是一个全局的、跨 agent 的、上帝视角的对象。如果它在内核状态里，任何能读内核的代码都有一条通往上帝视角的捷径，**而这条捷径逃得过"agent 模块不得 import 世界状态"的静态检查**（它 import 的是因果图，不是状态）。最可能的犯案现场：世界内史学家的实现、以及提示词构造器。
- **建议默认值**: 四层，跨层写入禁止，CI 强制 ——
  **L0/L1 机械事实**（状态、转移、抽样点、读取集闭包、近失集合）：可逐位重放校验，无语义、不可读、不带权重；
  **L2 因果分析**（干预实测效应量、PN/PS、必然性剖面、视界、`N_eff`）：这是**我们的历史学**，有方法、有版本、有误差棒、可被推翻；**对世内 agent 永久不可见，由进程/类型系统强制**（CI：任何 agent prompt 构造路径若能到达 L2 命名空间，编译失败）；
  **L3 世内叙事**（官方史、民间传说、宗教叙事、世内史学）；
  **作者层**（我们的解释、小说、可视化、LLM 旁白）：`author_narration` 单独存储，因果链查询默认不返回。
  **禁止**：把因果图放进"世界事实"层；`narrative` 类型的边作为任何其他边的父节点；世内史学家读 L2 或 L0。
- **依据**: `causality-bookkeeping S4`（三层模型 + 第 9 条应改为"只有 L1 是世界事实；L2 与 L3 是同一类东西——对事实的解释——区别只在于 L2 的工具更好、信息更全"；若把 L2 当事实，第 10 条会把小说锁死在我们的因果分析上并抹掉不确定性，**比自由发挥更失真**）；`mandate-contradictions F8`/决定 13（**可知性上界不可超越检验**：世内史学家对任一历史命题的正确率不得高于 `U(t)`，超过即证明有泄漏，CI 失败）；`pseudo-simulation S2`（三层存储强制分离：`world_fact` / `in_world_belief` / `author_narration`）、S13；`emergence-verifiability C7`（矛盾总表第 7 行：因果图属于哪一层）。
- **被否决的替代方案**: 纲领第 9 条的两层（世界事实 / 世内叙事）—— "我们的解释"是第四层，它一定会存在，不给它位置它就会混进前两层。
- **待验证假设**: `D(t) − U(t)` 分解（史学水平 vs 史料条件）来自 `writing-records-memory M13`，简报自标 D 级设计。
- **裁决人**: **人**。

### A23 · 文本的地位：世界内不存在自然语言

- **为什么不可事后补**: 文本是唯一不能压缩成状态量的对象，且它是一条**从背后穿透 AI 边界**的回路：LLM 虚构 → 世界内信念 → 决策 → 世界事实。成本上，后世史学要读前世史学，LLM 调用量随 `记录存量 × 世纪` **超线性**增长。
- **建议默认值**: 世界内一切"文本"是结构对象（命题图 `Claim`、教义结构体、`Recipe`）的**渲染视图**；渲染只在世界外查询时按需发生，产物写入作者层，**永不回流为模拟输入**（类型级约束 + 序列化边界强制）。**禁止**：任何以字符串为语义载体的世界状态字段；任何把渲染文本重新解析为参数的代码（`interpret_doctrine(text) -> Dict[str, float]` —— **看到这个函数签名就已经中了**）。
- **依据**: `mandate-contradictions F6`/决定 14（命题图 schema：指涉的世界事实 id 或 null(纯虚构)、失真算子链、载体群体、声望、存活副本数、依据的 Claim 集合；校准锚点：手稿存活率 7%（普通抄本）/20%（高端抄本）、集体记忆对在位者之前 8–9 位前任呈大致线性遗忘、名人声望峰值后半衰期 73 年）、F3（`interpret_doctrine` 的症状）；`llm-storytelling F3`（教义不是文本，是结构化对象）；`writing-records-memory` L4 层。
- **被否决的替代方案**: 存文本但"约定不解析" —— 只要下游有任何一段代码把文本解释成参数（人手写的映射表或又一次 LLM 调用），AI 就已经在决定客观结果，而这条通道不会被"AI 不能写世界状态"的检查抓住。
- **待验证假设**: 命题图能否承载"宗教教义"这类内容的表达力未验证。
- **裁决人**: **人**。

### A24 · 命名与语言系统：音系引擎 + `EntityRef` + 音译表

- **为什么不可事后补**: 专名是最强的真实历史泄漏通道。而且它有一层 `llm-storytelling F3` 才发现的书写层泄漏：**即使名字由世界内音系引擎生成，渲染成汉字的那一刻语义就回来了** —— 把 `/tavix/` 写成"塔维"是中性的，写成"天维"就把"天"的整套语义送了进去。
- **建议默认值**: Phase 0 交付世界内音系生成引擎（音位库、音节结构、音位配列约束、构词形态、随时间演化的规则音变）。名字从这里用世界 RNG 采样。**LLM 在任何 name 字段只能填 `EntityRef`，不能填字符串**（schema 级类型约束）。世界内专名的规范形式是音位串（中性拉丁转写）；汉字渲染是可选展示层，用**固定的音节→汉字表**（一次性人工选定语义最中性的字），**不允许模型逐个挑字** —— 这张音译表是 Phase 0 交付物。**禁止**：代码、注释、测试数据中出现任何真实历史专名（lint 强制）。
- **依据**: `llm-storytelling F3`（含"结构指纹可识别性探针"：把去掉全部专名的世界状态摘要喂给干净模型问"这最像哪个政体"，若能高置信说出"秦"或"商"，去专名化根本没用；困惑度下界检验用**字符级 n-gram** 而非神经嵌入）；`mandate-contradictions` 决定 16；`pseudo-simulation S2.3`（专名审计：与真实汉语历史术语表的命中率必须趋近于零）；`prior-art-postmortem §1.15`（去名词化测试**可能直接否决"LLM 做在线决策"的整个方案，所以必须早做**）、§4.12。
- **被否决的替代方案**: LLM 起名 + 事后黑名单过滤 —— 黑名单挡不住构词法与文体（`llm-storytelling F3` 列举："玄/昭/靖/烈/大宁/永昌"是真实汉语年号的构词法，不是这个世界的构词法）。
- **待验证假设**: 附带好处（语言谱系、同源词、借词层次成为规则自然产出的真实路径依赖）未验证；音系引擎的工作量未估。
- **裁决人**: **人**。

### A25 · LLM 边界形态：输出**分布**而非选择　【冲突 5，详见 §5.5】

- **为什么不可事后补**: 这决定了 ledger 的 schema 与反事实的可识别性。若 LLM 只输出一个选择：(a) Gumbel-max abduction 无法进行，**每个 LLM 决策点在反事实里都是一个识别洞**，而实现者会静默跳过它们；(b) 熵不可观测，Ozkan 式分布坍缩检不出来；(c) 污染指标单边 —— 一个永远选众数的 LLM 得分 0 比特，看起来最清白，实际最坏。事后改 schema = 全部 ledger 作废。
- **建议默认值**: 三段式 —— **规则**生成选择集 `A(state)` 与先验 `π(·|state)`；**LLM** 输出该集合上的概率分布 `p_LLM(·|view)`（verbalized sampling 形态）；**我们的 CBRNG** 从 `p_LLM` 采样。ledger 记录 `(view_hash, model_id, p_LLM, rng_counter, a*)` 四元组。`不作为` 必须永远在选择集里，且在绝大多数局面下先验最大。**禁止**：把"要不要发生"问给 LLM（风险率由规则算，掷中之后才唤醒 LLM）；LLM 创造新候选项；LLM 对世界状态的任何写权限（恒为空集）；意图 schema 含连续量与绝对时间。
- **依据**: `llm-storytelling §2`（六项收益表 + 代价：`p_LLM` 是自报概率不是校准概率，Verbalized Sampling 论文自己报告矫枉过正 SD-ratio 0.4–0.56 → 1.26–1.37，**没有校准的 `p_LLM` 只是换了个形状的偏置**）、F1（`事件基率 = 咨询频率 × p`，两个因子都与世界状态无关；**基率是提示词措辞的函数，不是世界的函数**）、F5；`mandate-contradictions F3`（第 5 条建议改写：AI 的输出只能是两类 —— 规则给定有限选择集上的一次选择，或不参与任何数值计算的标签文本）；`emergence-verifiability F2`（`step(state, rng_stream, proposal_log)` 对三个输入是纯的）。
- **被否决的替代方案**: "LLM 只从选择集里挑一个"（`llm-storytelling` R1 自己的旧方案，被 R2 明确推翻）；LLM 自由生成意图；LLM 直接裁决结果（纲领已禁）。
- **待验证假设**: `p_LLM` 的校准可行性（校准曲线是 Phase 0 交付物，尚不存在）；当前 Anthropic 前沿模型已移除 `temperature/top_p/top_k` 且无 `seed`（厂商文档，B 级）—— 这使得"让模型显式给出概率"成为唯一可行的分布获取途径。
- **裁决人**: **人**。

### A26 · LLM 确定性契约：内容寻址账本 + 权重冻结 + model pin

- **为什么不可事后补**: **一旦第一条正式历史线用托管 API 跑出来，它就永久失去了可反事实性。** 且模型版本会静默漂移（GPT-4 质数判定 84%→51%）。
- **建议默认值**: 所有 LLM 调用经 `llm_call(prompt, params) -> output`，key = `hash(model_id, model_revision, prompt, decoding_params)`，value 写入与存档同级的 artifact store。**重放模式下缓存未命中必须抛错**，不许静默重新调用（除非显式 `--allow-new-llm-calls`）。存档记录 artifact store 的 content hash；两个存档若 hash 不同，**禁止直接比较**。凡是写入世界状态路径的模型，**必须本地部署、权重冻结**，`model_id + weights_hash` 进世界线身份。**禁止**：托管前沿 API 出现在正式主线；重放时重新调用模型（那在语义上是"开一条新分支"，必须显式标记 `regenerated_branch`，且禁止与原分支做反事实对比）。
- **依据**: `prior-art-postmortem 致命1`/§4.3；`emergence-verifiability F2`（Ouyang et al.：即使贪心解码，零匹配输出比例 CodeContests 75.76% / APPS 51.00% / HumanEval 47.56%；Generative Agents 官方 repo 的 `replay` 端点回放的是已保存的世界状态轨迹，不是 LLM 调用的重放，README 自述"primarily intended for debugging"）；`llm-storytelling F4 第一层`（"重放已解决，不必再争论"）；`computational-feasibility T4`（一次模型升级 = 所有旧世界线冻结为只读文物，不能与新世界线做对照实验 —— **这决定了什么时候可以升级模型**）。
- **被否决的替代方案**: temperature=0 求确定性 —— 被 Ouyang 的实测否决；只记录 prompt/output 不记录权重哈希 —— 无法区分"世界不同"与"模型不同"。
- **待验证假设**: 本地部署开放权重模型的每 token 摊薄成本未核实（`computational-feasibility §9` 列为 Phase 1 待补检索）。
- **裁决人**: **人**（这是一笔基础设施支出承诺）。

### A27 · 可重算核 / 冻结账本区的边界

- **为什么不可事后补**: 这条边界决定了**哪些因果结论是完整的、哪些永久带星号**。做反事实时两个选项都错：复用账本 ⇒ 干预"下了一场大旱"之后君主做了完全相同的决定 ⇒ **系统性低估一切通过人的认知起作用的因果路径**；重新调用 ⇒ 差异里混进模型版本差异且无法分离。因为选项 A 更便宜、更"可复现"，我们一定会默认用它。
- **建议默认值**: Phase 0 划死这条线。可重算核里的决策必须由**确定性纯函数**产生（可以是从 LLM 蒸馏出来的小模型/查表/规则）；LLM 只在账本区。**星号必须是机器可读的**：任何因果路径若穿过账本区，报告显示"此路径穿过 N 个不可重算决策点，其因果贡献为下界估计"。**必须做一次"通道封闭偏差"实测**：对一小批事件同时用复用账本与重新调用（固定模型版本、固定采样种子、多次求均值）各跑一遍，测两者效应量之差。**禁止**：带因果主张的实验运行在账本区未标注的模式下。
- **依据**: `causality-bookkeeping S5`（含长期方向：把"人的判断"移进可重算核 —— LLM 只用于**离线**生成决策策略的结构，运行期由确定性策略函数执行；这与第 5 条字面不冲突，但把它移到了编译期）、§6 第 4 条；`llm-storytelling F4 替代设计 2`（双通道：带因果主张的实验一律在 `surrogate mode` 下运行；**世界在 LLM 完全不可用时必须能自己跑完三千年**，这条应作为架构硬约束写进纲领）。
- **被否决的替代方案**: 全部决策走 LLM（因果结论全部带星号，等于没有因果结论）；全部决策走规则（纲领第 5 条落空，且丢掉 LLM 作为搜索器的价值）。
- **待验证假设**: "通道封闭偏差"的量级未知（`causality-bookkeeping S5`："如果它很大（我猜很大），那么第 5 条与第 2 条的冲突不是理论问题，是必须在纲领层面裁决的问题"）。
- **裁决人**: **人**。

### A28 · 存储 / 快照 / 分叉模型与留存策略

- **为什么不可事后补**: "保存任意历史节点并建立平行世界"要求持久化数据结构（写时复制），不是"每隔 100 年存一个全量快照"。选错 = 重写整个状态层。而且失败方式是静默的：磁盘先满 → 有人开始删旧世界线 → "平行世界比较"这件事悄悄从项目里消失，**不会有任何一次会议讨论过要不要放弃它**。
- **建议默认值**: **不存轨迹，存配方**。世界线身份 = `(world_seed, code_hash, param_hash, llm_ledger_hash, weights_hash)`；轨迹按需重算。事件溯源 + 内容寻址的持久数据结构 + 写时复制分叉；快照 = 不可变根指针，每 50 年 + 每个提名点。唯一**必须**持久化的是不可重算的东西（LLM ledger，3×10⁴ 次 × 1.5 KB ≈ 45 MB/线）+ 年度聚合缓存。参考线全量 ≈ 28 GB，其余 199 条各留年度聚合 1.2 GB → **200 条集合 ≈ 267 GB**（装得进一块盘）。**禁止**：气候场落盘（5.5 GB/线 @25 km，34.6 GB/线 @10 km）；保存非参考世界线的完整轨迹。
- **依据**: `computational-feasibility S5`（HAMT/CoW 让**分叉那一瞬间**是 O(1)，但分叉之后每 tick 写入的新节点数量与主线一样多：250 MB 状态 × 10% 年变动 × 3000 年 = 73 GB/线，× 20 分叉 × 200 种子 = 14.3 TB）、§6 第 8 条；`causality-bookkeeping §7.1`（重算架构 ~30 GB/跑，比写入级低 1–2 个数量级）、§6 第 6 条；`mandate-contradictions` 决定 10；`prior-art-postmortem §4.13`。
- **被否决的替代方案**: 定期全量快照 —— 无法"保存任意节点"；把"结构共享 O(1) 分叉"理解为"分叉不占空间" —— 系统性低估了 1–2 个数量级。
- **待验证假设**: 状态本体大小 250 MB、年变动率 10%、每格 512 B / 每个体 200 B 全部是 D 级（`computational-feasibility §9` 明确列出）。
- **裁决人**: **证据**（空壳内核基准的快照吞吐与增量实测）。

### A29 · 干预代数与反事实语义

- **为什么不可事后补**: "改状态后重放"与"改事件后重放"语义完全不同，且决定存档格式。而且干预必须修复不变量 —— 把地权分布钉在 t0 的值上，那 120 年里实际发生的每一笔土地交易的地要放到哪里去？**每一个修复规则都是一个建模选择，并且它会把偏置直接注入因果结论**（"多余的土地按原比例分配给所有家户"这个修复，等于在反事实世界里偷偷执行了一次土地改革）。
- **建议默认值**: 干预代数至少包含：`flip(抽样点)` / `suppress(事件) + 修复规则` / `clamp(慢变量, 值) + 修复规则` / `detrend` / `shuffle_time` / `resample_process` / `branch(分叉点, 新种子集)`。每一种都有**合法性检查器**（干预后世界是否仍满足人口/物质/土地守恒与所有不变量）与**修复规则的偏置声明**（必须报告修复所搬运的物质/人口量，例如"本次干预人为消灭了 4.2% 的耕地"）。对慢变量的四种干预**必须四种都跑并同时报告四个答案**；四者不一致时正确结论是"该慢变量的因果作用取决于我们如何设想它不发生"——这是诚实结论，不是 bug。**禁止**：任何不声明修复规则的干预；用"换种子"冒充"do-干预"（前者得到同分布的另一个世界，后者在同一世界里改一个事实，回答不同的问题）。
- **依据**: `causality-bookkeeping F3 路B`、§6 第 3 条、C4、T4；`mandate-contradictions F5`；`prior-art-postmortem §4.8`；`emergence-verifiability F2 第 4 条`（反事实只允许 `seed 分流` 与 `state 编辑` 两种，差异必须分开报告）。
- **被否决的替代方案**: 只支持事件抑制 —— 慢变量（土地兼并、识字率漂移）永远无法被反事实检验，于是"我们能回答为什么这场叛乱爆发，但答不上为什么这个社会变得这么脆弱"。
- **待验证假设**: 修复规则的偏置方向可声明但不可消除。
- **裁决人**: **人**。

### A30 · 事件读取集的格式与最大长度

- **为什么不可事后补**: 事后无法补回没记的读取集。这是 `computational-feasibility F3` 与 `abm-methodology` 都明确点名的"必须在写第一行代码之前定死"的条目。
- **建议默认值**: 每个事件只存**固定长度 ≤64 项**的读取集：读了哪些**变量** `(entity_kind, entity_id, field_id)` 三元组，不是哪些**事实实例**；加 `tick`、`rule_id`、`rng_key`、`llm_call_id`。这是常数大小，可以对全部实体级事件开启。**格点级转移一定不进日志。** 分层记录按 A18 的重大性度量 + 闭包深度截断（如 200 模拟年）。**禁止**：无界读取集；把 provenance 边写成实例级指针。
- **依据**: `computational-feasibility F3 替代设计 1`、§6 第 7 条；`pseudo-simulation F3`（读取集追踪的成本缓解：分层记录 + 深度截断 + 独立 `--audit` 全量短世界）；`emergence-verifiability §6 第 15 条`（所有判据必须能从压缩的事件日志计算，不能依赖全状态转储 —— 这是一个必须在写第一行代码前定的存储格式决定）。
- **被否决的替代方案**: 实例级完整 PROV 闭包（Neo4j 上限 + page cache 退化为随机磁盘 IO）。
- **待验证假设**: 64 项这个上限是 `computational-feasibility` 的工程判断，未验证是否够用。
- **裁决人**: **证据**（`--audit` 短世界里统计真实读取集长度分布）。

### A31 · 信息边界的载体实现 + 因果隔离测试

- **为什么不可事后补**: 计算 agent 视野的那段代码是全世界最适合埋剧情的地方。典型实现"把相关信息推送给相关 agent"—— "相关"由事件系统定义时，信息就会在剧情需要它到达的时候到达，**而它会通过第 4 条的审查，因为它看起来像在实现信息边界**。事后改成"运输的物质对象"= 重写全部决策路径。
- **建议默认值**: 信息是**被运输的物质对象**：一个信息副本有位置、载体、传播速度、失真概率、遗忘率；Agent 只能读取与自己共位的副本。类型层面禁止全局查询：agent 决策函数签名只接受 `Perception`，`Perception` 只能由运输过程构造。**CI 静态检查：agent 决策模块不得 import 世界状态模块。** 记忆状态必须有固定上限表示（≤ K 条带时间戳与来源的 `Claim`，超出按显式遗忘规则挤出，**且遗忘本身是被记录的历史事件**）。**信息光锥检查**（硬失败）：事件 e 的决策者 d 引用的每个命题 f，必须在 d 的信念库中且注入路径可追溯到一条实际传播链，累计传播时间 ≤ t − t(f)。**禁止**：任何"推送给相关 agent"的实现；无上限增长的记忆系统（"记忆无限增长然后靠检索凑合"的系统在第 200 模拟年就会停摆）。
- **依据**: `pseudo-simulation S9`（**最硬的症状**：如果历史上从来没有一次因为"关键人物不知道某事"而导致的重大后果，信息边界就是假的；`因信息缺失导致的决策失误占比` 必须是被统计、被公布的指标）；`emergence-verifiability F17`（信息光锥检查 + **反事实盲测**：把 prompt 中的真实事实随机替换为等概率假事实，若决策分布不变说明没泄漏；该文自标 [我的推断，无来源]）；`causality-bookkeeping F7 第 2 条`（**因果隔离测试给了信息边界一个机械可执行的定义**：如果 A 的事件在物理上无法影响 B，那么 B 的任何 agent 的任何决策都不得依赖 A 的状态，而这一点现在可以被逐位验证）；`prior-art-postmortem 结构性2`、§1.14/§1.16（AI Town README：`NUM_MEMORIES_TO_SEARCH` 设为 1 以避免变慢 —— 真实工程里第一个被牺牲的就是记忆深度）。
- **被否决的替代方案**: 检索时过滤（"prompt 里少放几段文本"）—— 对世界动力学没有任何影响，只影响 LLM 措辞。
- **待验证假设**: 信息传播速度表（B13）尚不存在；`settlement-urbanization-spatial §4.3` 的 ORBIS 运输速度表是起点。
- **裁决人**: **人**。

### A32 · 路径依赖的承载方式：离散命名对象，禁裸浮点修正值

- **为什么不可事后补**: 为让历史"留下痕迹"，最自然的实现是给实体挂不断累加的修正值。3000 年后单个政体身上有数百个来源的浮点累加，**形式上完全可追溯，实质上完全不可解释**，且最终数值由浮点加法顺序决定。事后改 = 全部路径依赖机制重写。
- **建议默认值**: 制度/传统/仇恨/技术传统都是**有生命周期的离散对象**：显式的诞生条件、维持成本、衰减或被替代条件、显式的承载者（哪些人/哪个机构在维持它）。任何时刻一个实体身上活跃的这类对象设**硬上限**（`prior-art-postmortem §1.12` 建议 ≤32），超出必须挤出并记录被挤出事件。**优先把路径依赖锚定在有独立物理约束的环境状态上**（土壤深度、林线、河道、盐碱化、灌溉工程存量），而不是锚定在政体身上的抽象修正值。**禁止（lint）**：任何名为 `stability` / `legitimacy` / `prosperity` 的裸浮点全局修正值字段；任何无生命周期的累加量。
- **依据**: `prior-art-postmortem §1.12`（Paradox 病：一个省份的产出由三十个来源的修正值加总时，"为什么这里富"的答案是"因为 +5%、+3%、−2%、+11%…"；恶性反馈：修正值越多设计师越难预测结果，就越倾向于加脚本事件"确保历史大致对"）、§1.4（MedLand：把历史写进环境状态是路径依赖最干净的实现方式）、结构性1、§4.6；`pseudo-simulation S5`（`legitimacy` 是最坏的字段：一个没有微观所指的宏观变量，一定会被拿去当触发器）；[部分已裁决 spec §2.4 黑名单]。
- **被否决的替代方案**: 连续修正值 + 衰减 —— 仍然是浮点累加，只是慢一点。
- **待验证假设**: ≤32 这个上限无来源。
- **裁决人**: **人**。

### A33 · canon / lab 单向阀（数据模型级）

- **为什么不可事后补**: 分叉 + 反事实 + "选择某个时代写小说" **合起来是一个搜索算法**：分叉 = 扩展节点，反事实 = 定向扰动，选择 = 评分函数（而这个评分函数是人类审美，训练自真实历史与文学）。这条通道对 L1–L3 的全部防御**完全免疫**：涌现认证、消融、空模型对照、参数活性、读取集追踪，全部在单次运行内部生效，没有一个能看见"我们跑了 400 次、分了 60 次叉、只留了 1 条"。必须是数据模型的硬约束，不是一条纪律。
- **建议默认值**: canon 与 lab 在**存储层物理分离**。canon 的种子由**事先声明的、与结果无关的规则**决定（例如 `seed_k = sha256(kernel_version ‖ "canonical" ‖ k)`，k = 0..N−1），先定种子再跑，跑出什么算什么；允许因技术故障重跑，**不允许因不好看重跑**，重跑必须留痕。**单向阀**：lab 可以从 canon 任意分叉，**但任何实验分支永远不能成为 canon** —— lab 分支带不可移除的 `lineage_class=lab` 标记，出版工具拒绝读取。
- **本表的一处修正**［本表原创，无来源，D 级］: `pseudo-simulation F5` 把 canon 写成"append-only 的**单一线**"，这与 `mandate-contradictions F12`（早期取分布不取点值，正式产物是**集合**）冲突。本表建议：**canon 是一个集合**（种子集由上述规则机械生成），单向阀约束的是"不许从 lab 提拔"，不是"只能有一条线"。
- **依据**: `pseudo-simulation F5`（含 story sifting 的文献证据：Kreminski 等人的 *Winnow* AIIDE 2021、《Select the Unexpected: A Statistical Heuristic for Story Sifting》ICIDS 2022、*Authoring for Story Sifters* 2022 —— 该领域的共识是"模拟本身不产出故事，故事是被一个独立筛选器从日志里挑出来的，而它的默认启发式就是选出意外的"）；`mandate-contradictions F12`。
- **被否决的替代方案**: 只靠流程纪律（"我们不会挑好看的"）—— 这是唯一无法被任何度量抓住的失效模式（`pseudo-simulation` 的 K7 金丝雀专门用来证明这一点）。
- **待验证假设**: 无。
- **裁决人**: **人**。

**B1 · `significance/impact` 的阈值、分级留档预算与降采样率落盘**
- 不可事后补的部分已在 A18；这里定的是**数值**。建议默认：`significance = f(Δ人口, Δ迁移量, Δ死亡率, Δ产出, Δ制度参数) × 持续时间 × 空间范围 × 受影响人口`，与事件类型**完全解耦**；阈值以上全量记录，以下按概率采样**并把采样率落盘**；每 tick 因果记录预算固定（建议 ≤ 状态字节数的 5%），超预算降采样并记录降采样率。**禁止**：按事件类型枚举定义重大性；不落盘采样率（那等于覆盖率不可知）。
- 依据：`mandate-contradictions` 决定 11、C11、F7；`emergence-verifiability F4`（`impact` 的计算发生在事件之后，所以冻结策略必须是**乐观冻结 + 延迟裁剪**）；`causality-bookkeeping §6 第 7 条`。
- 被否决：纲领第 9 行的事件清单当枚举用（那是历史教科书章节目录，9 项全政治—思想类，没有一项是疫病、饥荒、水患、生育制度或农业产出）。
- 待验证：`mandate-contradictions F7` 建议的预注册门槛"top-significance 事件中非政治类别占比 ≥ 40%"是该文自报的拍脑袋数字（D 级），方向性判断才是重点。
- 裁决人：证据（阈值由分布定，占比门槛由人签字）。

**B2 · 预注册模式电池 v0**
- 每条模式含七字段：陈述、方向性或区间、**口径三元组**（阈值/定义/估计方法）、证据等级、数据来源、功效分析结果、归属（校准集 or 封存验收集）。文件哈希后提交，改动需记录理由。通过规则也必须预注册（例如"A 级判据零失败 + B 级判据通过 ≥ k/n"），并对 p 值做 FDR 控制。**禁止**：C 级判据进验收集；无功效分析的判据进验收集（**功效不足的判据不是"弱判据"，它是零判据，留着比删掉更危险**——它会一直显示绿色）。
- 依据：`emergence-verifiability F1`（Larooij & Törnberg 2025 综述：35 篇 LLM 社会模拟研究中 **15 篇完全依赖主观评估**）、F13、F16、§7.1 的可用/不可用判据表；`abm-methodology §2.4`（POM，Grimm et al. 2005 *Science* 310:987–991；**POM 没有给出"多少条模式才够"的量化标准**）。
- 被否决：事后辩论式验收（"这个结果看起来挺合理的"）。
- 待验证：判据数量与阈值全部需要在玩具世界与诱饵世界上标定后才有意义。
- 裁决人：人。

**B3 · 参考集合（三个空模型）的定义与版本**
- 荒诞度与解释力都相对它度量。建议默认：(a) 纯地理/气候驱动的承载力模型（零 agent 行为）；(b) 打乱地理邻接后的同机制模型；(c) 全部机制开启但决策替换为随机基线。**禁止**：用真实人类历史当参考分布（读法 A —— 那把真实历史变回软性剧情模板）；用本次运行自身当参考分布（读法 B —— 一个从头到尾都是神权政体的世界里神权政体永远不罕见，且它奖励单调性，世界越贫乏越容易通过）。
- 依据：`emergence-verifiability F3`；`pseudo-simulation S1(b)`（"罕见/违反常识"只能相对参考分布定义，而我们唯一拥有的参考分布就是真实人类历史，**因此第 7 条在技术上只能被实现为"与真实历史的偏离度"**）。

**B4 · 诱饵世界 W1–W3 + 剧情树金丝雀 K1–K7**
- **这是 Phase 0 的第一交付物之一**：故意造假，看能不能抓住自己。W1 剧情树世界（触发器生成国家/宗教/货币）、W2 纯外生驱动世界（宏观节律由外生气候注入，agent 决策随机）、W3 纯噪声世界（机制骨架保留，因果耦合切断）。金丝雀 K1 脚本王朝 / K2 PID 人口控制器 / K3 拟合空模型 / K4 事件表 + 冷却 / K5 LLM 编剧 / K6 存在性兜底 / K7 策展（内核干净但只保留前 5% 的运行）。**验收规则**：任何检测器若对它负责的金丝雀检出率为 0，**删除它，不要发布它**；报告每个金丝雀被几个检测器抓住（只被 1 个覆盖 = 单点故障）；**K7 必须在表里**，因为它证明唯一能抓住人类回路的东西是流程留痕，不是任何度量。金丝雀套件是**回归测试**，每次内核大改后重跑。
- 依据：`pseudo-simulation F6`（`complex-systems-emergence §7.18` 自承"**没有任何文献做过'剧情树能否骗过涌现度量'的研究**"；同时 §3 指出多个判据有严重伪阳性 —— 隐藏剧情树会给出极低的 `T`，因为剧情树里的宏观变量确实不由微观决定）；`emergence-verifiability F6`（判据标定报告：**任何在 W1 上不失败的判据，不得进入验收集**）。
- 被否决：只做正向验收（"全部检查通过"这句话在没有阳性对照时没有信息量，而我们会在看到"全部通过"时停止怀疑）。
- 待验证：金丝雀内核是玩具规模的，不需要跑 5000 年 —— 成本低是它必须现在做的理由。
- 裁决人：证据（检出率矩阵）。

**B5 · 荒诞度的三分口径　【冲突 4，详见 §5.4】**
- 建议默认（三个量各司其职，都不进内核）：`surprise_bits(e) = −log₂ P(e | 参考集合)` 作为**事件层**"这需要解释多少"；**机制组合新颖度** `−log P(机制组合 | 历史共现分布)` 作为**项目层**能力指标（新颖组合率随时间不饱和）；**必然性剖面 `p̂(Δ)`** 作为单事件"强解释"的操作化（荒诞不是靠叙事解释的，是靠剖面证明的）。**红线**：这三个量任何一个都不得被内核读取，不得进入任何决定"是否允许"的代码路径（lint）；审查抽样必须按 `significance` 分层随机、与稀奇程度无关，每批含 ≥50% 的"寻常"事件。
- 依据：`emergence-verifiability F3`；`mandate-contradictions F2`；`causality-bookkeeping F6`、C5；`pseudo-simulation S1`；`prior-art-postmortem 结构性4`/§1.11。
- 被否决：把第 7 条实现成运行时门槛（保守棘轮 + 显式剧情控制）；单侧人工评审门槛（**第 7 条是一台自动化的确认偏误机**：剧情树的产物一定落在"寻常"那一侧，永远不会触发第 7 条的审查）。
- 待验证：`explanation_bits` 需要逐前因重放，覆盖率必然很低，必须公布。
- 裁决人：人。

**B6 · 反事实契约**
- 建议默认：反事实的合法输出只有三种形态，写进查询接口的类型 —— (1) **集合级**：N≥50 条干预支线 vs N 条**空干预**支线，在 K 个预注册量上的分布差 + 效应量 + 功效分析；(2) **反事实有效期 `T_half`**（干预效应信噪比降到 1 的时间），超过 `T_half` 的推断**在界面上被拒绝渲染**；(3) 单条支线只能作为插图，强制打"非结论"水印。**安慰剂对照强制化**：没有零分布的反事实结果不得进入因果库；安慰剂 = 同 tick、同机制类、可比空间位置上随机选另一个抽样点做同类型翻转，重复约 100 次。**功效预注册**：跑之前算出需要多少次重放；超预算则该问题标记为"算力不可回答"，**而不是用小 N 硬答**。
- 依据：`causality-bookkeeping F5`（**在任何有正反馈与离散决策的系统里，任意一次单点扰动都会在足够长时间后产生宏观差异** —— 翻转"关键将领病死"与翻转"东南渔村多生一个孩子"都会让 200 年后世界大不同；没有第二个实验，第一个实验毫无意义。功效算术：0.30→0.45 需每臂 163 次、两臂 326；0.30→0.35 需每臂 1376、共 2752；一个原因 ≈163 CPU 小时，20 个候选原因 ≈3,260 CPU 小时 ≈136 CPU 天；**一次严肃的因果回答在 5,000–10,000 CPU 小时量级**）；`mandate-contradictions F5`；`llm-storytelling F4`（空反事实检验必须成为常设指标；`效应量/噪声地板 < 3` 的结论无效）。
- 被否决：单条分叉线当反事实结论（强路径依赖下无信息）；N=1 或 N=5 下结论。
- 待验证：`causality-bookkeeping §10` 自述成本数字依赖"一次完整长跑 = 10 CPU 小时"这个自编基准，绝对数字不可引用，数量级结论（因果分析比模拟本身贵）把握较高。
- 裁决人：人（"哪些为什么值得回答"是有偏的人为选择，必须留痕）。

**B7 · 归因报告规范**
- 建议默认：每个因果查询返回**三元报告**而不是一个排序 —— `N_eff` 与归因熵（**`N_eff > 10k` 时 UI 必须拒绝显示 top-k 列表**，改为"此事件不存在少数主因"）；每个候选原因的 **(PN, PS) 二维散点**（不合成一维）；**最小充分前因集的枚举 + 过度决定度 `OD(e)`**（`OD ≥ 3` 时"此事过度决定"作为主答案显示在 top-k 之前）。候选原因集必须机械生成并预注册。公理选择必须写在报告上（"本排序采用 Shapley；若改用 PN 排序，第 1 与第 4 位互换"）。**把"链"这个词从设计文档里删掉**，改称归因报告/因果场。**禁止**：`parent_event_id` 单指针数据结构；百分比加总到 100% 的展示（那是效率公理的产物，不是世界的性质）；跨 `evidence_kind` 的排序与百分比合并。
- 依据：`causality-bookkeeping F4`（留一法在过度决定下全部返回零；Shapley 的效率公理强制把效应分解干净、对称公理抹掉时间顺序；PN 与 PS 对同一原因经常给出相反排名且**这个问题没有客观答案**；Halpern–Pearl 实际因果的判定复杂度标注为 [记忆，未核实]，方向性结论"非多项式时间可判定且随定义版本变化"够用）、S2（`mechanical` / `local_analytic` / `intervention_tested` / `statistical` / `narrative` 五种 `evidence_kind`）、S7。
- 被否决：给出唯一的"主因排序"（数学上做不到；能做到的是把主观性从隐藏权重挪到公开的公理选择上）。
- 待验证：`causality-bookkeeping §10 第 3 条` 自述"`N_eff` 会不会真到 10⁴ 量级我不知道，这是我的直觉，**这是本文最容易被证否的一条，我希望它被证否**"——应列为 Phase 1 第一批测量。
- 裁决人：人。

**B8 · 共享分叉集合网格与必然性剖面参数**
- 建议默认：在时间 × 空间上铺一张分叉点网格（例如每 50 年 × 每个主要区域一个分叉点），每个分叉点跑 N=100 条平行线。**同一批集合同时产出四样东西** —— 必然性剖面、安慰剂零分布、因果视界 `H_Y`、事件的自动提名。这是整个因果基础设施**唯一的规模化路径**。
- 依据：`causality-bookkeeping §7.3`、F6 第 4 点。
- 被否决：围绕"事件图"建基础设施（按事件而非按分叉点分摊成本，贵 1–2 个数量级）。
- 待验证：`causality-bookkeeping §10 第 4 条` 自述网格参数"完全是我拍的"，正确密度取决于实测视界长度，是一个鸡生蛋问题（先粗测视界 → 定网格 → 精测）。
- 裁决人：证据。

**B9 · LLM 调用配额、批处理单位、tick 内位置**
- 建议默认：**LLM 永远不在 tick 的关键路径上** —— `decide` 相位读**上一 tick** 的 View，产出的 Intent 在**下一 tick** 的 `resolve` 里消费（1 年滞后，本身就是合理的信息传递延迟）。**批处理单位 = 「同一 tick 序号 × 全体种子」**，200 条世界线锁步推进，每批 2,000 次调用 —— 这是唯一能同时拿到 50% Batch 折扣和可接受墙钟的结构（**集合反而比单跑更划算**）。每条世界线 LLM 调用总数写死配额（建议 ≤3×10⁴，即每 tick ≤10 次），超配额直接走规则先验，**不排队不降级模型**。调用预算**按世纪封顶且与模拟年份无关**。
- 依据：`computational-feasibility F5`（价格表：纲领字面读法 1,000 具名人物 × 每月 1 次 × 3,000 年 = 3.6×10⁷ 次调用 = Haiku 4.5 $44,910 / Sonnet 5 $89,820 / Opus 5 $224,550 **每条线**，× 200 = $9M–$45M；本文配额方案 $37–$187/线；**真正的瓶颈是墙钟**：逐 tick 阻塞发批、每批周转 60 s = 50 小时/线，5 分钟 = 250 小时/线；且"用 Batch 省钱"与"每 tick 等 LLM 回话"互斥）；`mandate-contradictions F6`（世内史学在模拟期的 LLM 预算份额 = 0，否则第 24 行会在 Phase 3 静默吃掉整个预算）；`llm-storytelling F1`（**配额同时是成本控制和污染控制，两者是同一个旋钮**）。
- 被否决：每个具名人物每月一次调用；tick 内阻塞等待。
- 待验证：`computational-feasibility §7 第 4 条` 要求用 `count_tokens` 实测一次真实 View prompt 的 token 数（10 分钟能做完，能把整个 LLM 预算从 D 级变 A 级）；Batch 50% 与 prompt caching 0.1× **在这个工作负载里很难同时拿到**（5 分钟 TTL 在批处理返回前就过期），需用 `usage.cache_read_input_tokens` 实测验证。
- 裁决人：证据。

**B10 · `p_LLM` 校准曲线 + `D_KL` 预算 + 熵监控**
- 建议默认：`p_LLM` 必须先在**有真值的小场景**上做一次校准（温度式重标定 `p^(1/T)` 归一化），**校准曲线本身是 Phase 0 交付物**。污染量 = `D_KL(p_LLM ‖ π)`，两侧都罚，每世纪 `Σ D_KL` 设上限；超限只有两个合法处置：承认 `π` 错了（去改规则），或强制按 `π` 采样。**不允许第三种处置（"这次就算了"）**。同时监控 `H(p_LLM)`：长期低于 `H(π)` 的一半 = 坍缩；长期高于 `H(π)` = 矫枉过正。**禁止**：用调温度当作多样性解药（**温度改变的是同一个分布的采样锐度；坍缩是分布本身错了**，调高温度只会在错误的分布上采到更多噪声）。
- 依据：`llm-storytelling §2`（六项收益表 + 代价声明）、F5、F9；证据基础见 `llm-storytelling §0` 的七行表（Ozkan 2026 C 级：85% 场景坍缩、约 80% persona 选同一选项；Verbalized Sampling A 级：标注者 51.6–60.8% 偏好典型回答；Doshi & Hauser 2024 *Science Advances* A 级：AI 辅助的故事彼此更相似；Kirk et al. A 级：RLHF 显著降低多样性；Bisbee et al. A 级；Sharma et al. A 级；OASIS A 级）。
- 被否决：单点选择 + `−log₂ π(a*)` 单边指标（一个永远选众数的 LLM 得 0 比特，看起来完全清白）。
- 待验证：自报概率的可校准性；Verbalized Sampling 报告了矫枉过正（SD-ratio 0.4–0.56 → 1.26–1.37）。
- 裁决人：证据。

**B11 · 自由参数配额 + 溯源标注 + P/T 比**
- 建议默认：自由参数**硬配额 12–15 个**；每个参数在配置里标注 `source: <简报/文献 DOI>` 或 `free: true`，`free: true` 的数量由 CI 检查、超过即构建失败。另加 `justification_class ∈ {外部数据拟合, 理论推导, 量纲/守恒约束, 未校准(默认值), 叙事}` —— **`叙事` 这一类的允许数量是 0**；`未校准` 的比例是模型成熟度的直接读数。**参数-目标比 `P/T`**（自由参数总数 / 有独立外部经验目标的校准目标数）**必须出现在每份模型文档的第一页；`P/T > 3` 即该模型不可证伪**。
- 依据：`computational-feasibility S2`（Sobol 一阶+总效应 N=1024：d=10 → 22,528 次、d=30 → 63,488 次；`T_run=1h` + 8 台机 = 5,760 次/月，**一个月的标定预算最多支撑 d≈10**；而纲领列了 15+ 子系统 × 每个 3 个待标定参数 = 45 维，45 维在这个预算下无法标定，于是参数只能手调，**而手调就是写剧情**）、§6 第 10 条；`llm-storytelling F7`（P/T 比与 `justification_class` 是该文原创）；`pseudo-simulation S6 判别测试4`（自由度审计：公开 `参数数 / 有效约束数`，以及每个宏观模式是否消耗了新的自由参数）。
- 被否决：无上限的参数集（Turchin 2013 用 12 个参数拟合宏观模式得 R²=0.65，而"累积帝国密度 vs 历史人口密度"的朴素基线达 0.75 —— 在欠定区间里"模型复现了模式 X"携带的信息量接近零）。
- 待验证：12–15 是从 Sobol 次数反推的量级，不是文献值。
- 裁决人：人。

**B12 · 每类实体硬上限 + 复杂度契约表**
- 建议默认：聚落 ≤5,000、具名人物 ≤3×10⁴、组织 ≤2,000、社会网络边 ≤3×10⁶、活跃个体 ≤3×10⁴（与 A17 一致）。**复杂度契约表**：每个子系统一行，写明代价是哪个实体计数的什么函数、截断半径/top-k、超出时如何退化。**任何超线性项必须带一个显式常数上限，而且这个上限必须是世界内可解释的量，不是魔数**（例如贸易半径 = 该运输方式在可接受成本内能到达的距离；ORBIS 成本表：驴驮 0.028、大车 0.035、河运下行 0.0034 denarii/kg/km —— 差 10 倍的成本比直接给出 10 倍的合理半径比）。CI 加复杂度回归测试：1×/2×/4× 实体数各跑 50 tick，拟合 log-log 斜率，>1.2 即失败。
- 依据：`computational-feasibility S4`（聚落对数二次增长：5,000 聚落月度全对贸易 = 4.5×10¹¹ ops，超预算 3 个数量级；**关键在于这个失败是延迟触发的** —— 世界跑到第 800 年、聚落从 300 涨到 3,000 时每 tick 时间涨 100 倍，而开发期只跑 200 年的原型永远看不到它）、§6 第 11 条。
- 被否决：无上限增长 + "以后再优化"。
- 待验证：全部上限是按预算反推的 D 级数字。
- 裁决人：证据（log-log 斜率回归测试）。

**B13 · 信息传播速度表**
- 建议默认：按地形 × 技术 × 制度给出传播速度与通行成本图，起点用 `settlement-urbanization-spatial §4.3` 的 ORBIS 运输速度表（牛车 12 km/天、挑夫 20、步行与驮兽 30）。**这是 A31 信息光锥检查的前提；没有它，纲领第 4 条只是一句愿望。**
- 依据：`emergence-verifiability F17`/§6 第 12 条/§8 第 9 条；`settlement-urbanization-spatial §4.3`。
- 被否决：统一常速传播。
- 待验证：前工业信息传播（相对于货物运输）的速度倍率无直接来源。
- 裁决人：证据。

**B14 · 效用分解 schema + `irrationality_bits`**
- 建议默认：对每个 agent 发起的动作，用 agent 在 `t⁻` 的信念状态重算 `U(a) = Σ w_i·u_i(a|belief)`；候选集必须包含"什么都不做"与 ≥k 个可行替代；`irrationality_bits(e) = −log₂ P_softmax(a_chosen | U, τ)`。判据是**分布性的**，不是逐事件硬失败：残差全局分布必须稳定，且**不能被单个事件类型长期占据尾部**（若"战争"事件的残差系统性高于其他类型，说明 LLM 在战争上编故事 —— 这是"为戏剧性制造事件"的可观测指纹）。**关键工程约束**：效用分解必须在动作被裁决**之前**落盘并哈希（commit-before-resolve），事后不得修改；权重 `w_i` 必须是 agent 的持久状态、有世界内来源（家族、教育、经历），**不能每次由 LLM 现编，否则整个检查是循环的**。
- 依据：`emergence-verifiability F11`；`llm-storytelling F2 替代设计 2`。
- 被否决：逐事件硬失败（那会把 agent 变成最优化器，而 Madge et al. 证明**贪心决策使 R² 从 0.66 掉到 0.22–0.39 并抹平草原的因果效应** —— 让 agent 更"聪明"让宏观历史更不真实）。
- 待验证：可接受带必须**事先声明**（`pseudo-simulation S2` 建议：在 8 个声明的宏观量上 KS 距离落在 [0.05, 0.25]；事后再定就是拟合）。
- 裁决人：人。

**B15 · 机制数量上限 `|M|`**
- 建议默认：`|M| ≤ 20`（消融成本 ∝ `|M|`：(|M|+1) 臂 × N=50 种子 × 10 个 NROY 参数点 = 10,500 次完整长跑）。这条约束会反过来强迫机制取舍，这是好事。
- 依据：`emergence-verifiability F15 第 3 条`（引 Turchin 自己的警告："大型复杂模型往往结构不稳定，一个参数的小变化会导致动力学大变"，主张 "a spectrum of models, each simple enough"）；`causality-bookkeeping S9 第 3 条`（协变量数量作为受监控的复杂度预算 —— 这是同一件事的另一面）。
- 被否决：无上限机制库。
- 待验证：20 无来源。
- 裁决人：人。

**B16 · 事件日志的压缩格式**
- 建议默认：所有判据必须能从压缩的事件日志计算，不能依赖全状态转储。格式与 A30 的读取集格式一起定。
- 依据：`emergence-verifiability §6 第 15 条`。
- 被否决：判据依赖全状态转储（那使涌现认证的 50 种子 × 消融矩阵在存储上不可行）。
- 待验证：哪些判据真的能从日志算，需要逐条检查。
- 裁决人：证据。

**B17 · 灭绝/停滞合法性 + 吸收态失败判据 + 失败率公布**
- 建议默认：**允许**灭绝与永久停滞；预注册灭绝率的目标区间；**禁止任何形式的兜底重生**（`ensure_at_least_one_polity()`、`if pop < 10: respawn_band()` 进 lint 黑名单）。定义吸收态检测（人口全灭、单一政体统一全图后再无变化、所有政体规模冻结、事件率趋零）——**没有这个，我们永远不知道自己在改进还是在漂移**。`P(灭绝)`、`P(5000 年无国家)`、`P(永久停滞)` 是必须公布的指标；**一个在 200 个种子上灭绝率恰为 0 的世界是可疑的**。
- 依据：`mandate-contradictions` 决定 17；`pseudo-simulation F5 第 5 条`、S3（存在性保证）；`prior-art-postmortem §4.11`。
- 被否决：保证世界"能跑下去"的兜底机制（它看起来像工程卫生，实际是把结论写死）。
- 待验证：灭绝率的目标区间无来源；相关实证锚点是 `state-formation §8 AP3`（Turchin 2022：500 BCE 已有农业的地区 **23% 到 1500 年仍无宏观国家**，农业到国家平均时滞**约 2000 年**）—— 这条支持"200 个种子里 190 个停在采集群"可能是**正确结果**而不是 bug。
- 裁决人：人。

**B18 · 校准靶的形状 + 东亚 holdout 的范围**
- 建议默认：校准对象必须是**分布形状与关系**（寿命分布形状与变异系数、冲突规模谱指数、聚落标度指数、危险率是否随年龄上升），不是中国的具体数值。验收标准：真实历史的宏观指标应落在我们模拟集合的 **5%–95% 分位之间，而不是等于中位数**。结构性统计只做**单边排除**（rank-size 只在 α ∉ [0.4, 1.8] 时报警，**α → 1 永远不是目标**）；任何 α 必须与口径三元组（截断阈值、聚落定义、估计方法）一起报告。**东亚 holdout**：参数只在美索不达米亚、中美洲、安第斯、西非、地中海等区域的比较数据上校准，东亚只作测试集；东亚特有参数（水稻、黄土、季风）显式列为"东亚专用参数"，单独计入自由度预算、单独标注下游结论。
- 依据：`pseudo-simulation S6`（含三层失败机制与四个判别测试：东亚 holdout、对应词典覆盖率、盲测排序、自由度审计）；`emergence-verifiability F10`（**幂律是免费的**：Marković & Gros 2014 *Physics Reports* 536:41–74 —— 任何把平均活动水平恒稳维持在界限内的动力系统统计等价于 SOC 分支过程；**有些幂律要求是错的**：Clauset/Shalizi/Newman 2009 重分析 24 个数据集，7 个被明确排除**其中包括财富**，对数正态在 23/24 个中未被排除；**有些指数是内生的**：Cederman et al. 2011 论证战争规模指数随动员制度变迁而变；Cottineau 2017 MetaZipf 1,962 个指数估计，均值 1.025、sd 0.282、**40% 变异来自技术选择**；Altaweel 2015 的直觉反例：帝国统一期 rank-size 反而更凸 0.69 vs 碎片期 0.58）、F16（政体寿命分布**四个互相矛盾的结论**：Arbesman 2011 指数 τ≈220；Scheffer 2023 *PNAS* 饱和危险函数、众数约 200；Ciliberti 2025 指数 τ=298 KS p=0.71；Lu et al. 2021 幂律；Wand 2024 指出"年轻国家更稳"很可能是幸存者偏差 —— **连"帝国寿命分布是什么形状"这个最基础的问题学界都没有共识**）；`prior-art-postmortem §1.5`。
- 被否决：点值校准靶（"政体寿命 τ ∈ [200, 320]"—— 那是校准一场学术争论的某一方）；要求财富分布服从幂律（**要求它违背这个领域最好的经验分析**）。
- 待验证：holdout 的代价（东亚特有参数无法从别处校准）必须显式承担。
- 裁决人：人。

**B19 · 事件本体的最小区分**
- 建议默认：`政权更替`（统治集团更换，制度延续）/ `国家解体`（中央权威消失，制度部分保留）/ `社会崩溃`（人口、城市化、文字、分层同时下降）三者在观察层必须可分。**不做这个区分，"为什么这个国家灭亡"在语义上是三个不同的问题。**
- 依据：`emergence-verifiability §6 第 11 条`（引 `cliodynamics-secular-cycles AP-11` / Scheffer et al. 2023：晚青铜时代克里特的终结带来人口、宫殿体系与文字的消失，而中国的很多朝代更替"基本上只是统治精英的替换"）。
- 被否决：单一的"灭亡"事件类型。
- 待验证：这三类在我们的观察层用什么可测量区分，未定。
- 裁决人：人。

**B20 · 世内史学：命题图 schema + `D(t)`/`U(t)` + 模拟期 LLM 预算 = 0**
- 建议默认：史学的世界内表示是**命题图**（`Claim = {id, 指涉的世界事实 id 或 null(纯虚构), 失真算子链[遗忘/夸大/张冠李戴/合并/道德化/责任转移/年代望远], 载体群体, 声望, 存活副本数, 首次出现 tick, 依据的 Claim 集合}`）；史学家 = **规则 agent**，在命题图上执行外部批判/内部批判/来源独立性检验。史学水平 = `D(t) − U(t)`（实际重建度 − 可知性上界），**这个分解让"这个文明的历史学家是笨，还是史料真的没了"变成可计算的问题**。世内史学在模拟期的 LLM 预算份额 = **0**。**世内史学家的错误率是一等指标，必须被测量并公布**（准确率/遗漏率/虚构率/归因错误率，按"事件距今年数"与"信息传播距离"分层）；**准确率过高是失败信号**（95% 准确率的史官说明它在直接读数据库）。**禁止**：在任何工程判断中把世内叙事当作证据；验收报告里出现世内史书引文而不并列给出对应 `world_fact` 差异。
- 依据：`mandate-contradictions F6`、F8（可知性上界不可超越检验）；`pseudo-simulation S13`（**一个不连贯的世界，只要配一个足够好的世界内史官，看起来就是连贯的** —— 它让我们丧失了发现自己内核有病的能力）；`writing-records-memory M13` 与 §2 的校准锚点。
- 被否决：世内史学产出自然语言文本（成本随记录存量 × 世纪超线性增长，且从背后穿透 AI 边界）。
- 待验证：`U(t)` 的计算方法（"在存活语料下任何完美推理者能恢复的上限"）是简报的 D 级设计。
- 裁决人：人。

**B21 · 文化的数值通道白名单 + 文本置换不变性检验**
- 建议默认：`CultureObject = { params: Vector[float]（由规则从结构状态计算，LLM 只读不写）, labels: Text（由 LLM 填，任何代码不得据此计算数值）, label_provenance: LLMCallRef }`。规则层预定义**有限数量的数值通道（建议 ≤12）**：内群偏好强度、时间贴现率、对权威的服从、协调成本折减、通婚半径、继承分割度、外群接触意愿、劳动季节性约束、储蓄倾向、暴力正当化阈值、知识传承保真度、创新接受度；取值由规则从结构状态（生业方式、亲属结构、资源波动性、外群接触频率、人口密度）计算。**决定性的二值检验 —— 文化文本置换不变性**：取一条已跑完的历史线，把所有 `labels` 替换成**另一条世界线**的文本（params 一字不改），从 t=0 重放，**世界事实层必须逐位相同**。不相同 ⇒ 存在文本→事实通道 ⇒ CI 失败。
- 依据：`mandate-contradictions F3`（该文自述这是它最有价值也完全原创的一条，D 级；**它是"AI 不决定客观结果"这句话唯一可机械执行的定义**，成本是一次重放）；`llm-storytelling F3 第 4 条`（教义 = 结构化对象，每条禁令必须指向一个真实的世界状态变量，每个起源神话槽位必须填入一个真实记录在案的 `event_id`）；`pseudo-simulation S2`。
- 被否决：LLM 自由创作文化内容（"这个宗教禁止在春季屠宰耕牛"是一句文本，同时是一个生产函数修改）。
- 待验证：12 条通道是否够用；`labels` 与 `params` 长期不一致时的表现未验证。
- 裁决人：人。

**B22 · 玩具世界 + 已知答案标定世界 + 缩小版端到端里程碑**
- 建议默认：三个不同的小世界，用途不能混 —— (1) **CI 级玩具世界**（小地图、300–500 年、简化机制，全套判据能在每次提交上跑完）；(2) **已知答案标定世界**（**里面必须有一个我们亲手植入的、已知的真因果结构**：A 是真因、B 是精心构造的强相关伪因、C 是过度决定的第二充分因；因果分析器必须找到 A、拒绝 B、报告 C 的过度决定，**做不到就不许用在真世界上**）；(3) **缩小版端到端里程碑**（一个流域、300 年、全部机制、200 个种子，成本几分钟）—— 它能在写东亚和三千年之前暴露**每一个**已知失败模式：LOD 偏置、二次项、分裂误差、浮点不确定性、闭包爆炸、LLM 用量结构。
- 依据：`emergence-verifiability F15 第 2 条`；`causality-bookkeeping §6 第 13 条`（"**没有一个已知答案的标定世界，我们永远不知道自己的因果分析器是不是在编** —— 这是本文认为最重要的一条缺口"）；`computational-feasibility §7 第 8 条`（"纲领说'不追求尽快堆出大量代码'，但没说先做什么。**这就是先做的东西**"）。
- 被否决：直接在全尺度上验证。
- 待验证：无。
- 裁决人：人。

**B23 · 零模型套件与机制准入门槛**
- 建议默认：至少四个常设对照组 —— (1) 纯资源承载力模型（无 agent）；(2) agent 决策随机化；(3) agent 决策替换为单步贪心最优；(4) 文化/制度/记忆状态全部冻结。**任何新机制的合并请求必须附带"本机制相对全部四个零模型的增益"报告；增益不显著则不合并。** 这条比任何"与真实历史相似度"指标都重要，**因为相似度可以靠调常数买到，而对零模型的增益不行**。
- 依据：`prior-art-postmortem 致命4`/§1.1（Janssen 2009 *JASSS* 12(4)13：Artificial Anasazi 的拟合成功来自两个承载力参数——Harvest Adjustment 1.0→0.56（正文写 0.6，表 4 为 0.56）、Harvest Variance→0.4；**纯外生承载力模型（零 agent 行为）的相对误差只高 10%(L1)–50%(L2)**；原话 "The agent-based model acted as a smoothing function for the irregular carrying capacity levels"；且模型**根本无法再现这段历史唯一真正需要解释的事** —— 山谷在 1300 年前后被彻底放弃）；`emergence-verifiability F6 W2`；`pseudo-simulation F6 K3`。
- 被否决：只与真实历史比对。
- 待验证："增益显著"的统计判据未定。
- 裁决人：证据。

**B24 · 目标方差 / 路径依赖强度的预注册水平**
- 建议默认：把**输出方差本身**列为一个必须匹配的量，而不是要被消灭的东西。Phase 0 必须声明目标方差水平（例如"政体最大规模在 t=3000 的种子间变异系数 ≥ 0.6"）。**分叉发散测试**：同种子重放、只翻转一次抽样，测 200 年后世界状态距离，要求**距离随时间发散而非收敛**，把发散率 `λ`（及 `computational-feasibility F3` 的"发散锥"增速）作为一等报告指标。**禁止**：以"数值稳定"为名的均值回复、平滑、缩小随机项（每一次降方差都在削弱路径依赖）。
- 依据：`pseudo-simulation S10`（强路径依赖 = 种子间方差大 = 与任何校准靶都"不显著不符"也"不显著符合"；当校准做不动时最省事的修法是降低方差）；`emergence-verifiability F9`（Stonedahl & Wilensky：**30 次重复时 GA 参数显著优于 Janssen 参数 p<0.01；改用 100 次重复后结论反转** —— 重复次数可以决定结论的方向；且 ±10% 参数邻域内同一个模型既能产出人口爆炸，也能产出公元 994 年归零的缓慢灭绝）；`causality-bookkeeping F1`。
- 被否决：把方差当噪声消除。
- 待验证：目标 CV 值无来源。
- 裁决人：人。

**B25 · 算力三方分账比例　【三份红队给出三个不同数字，详见 §5.6】**
- 冲突原文：`mandate-contradictions` 决定 20 建议 **模拟 : 验证 : LLM = 5 : 4 : 1**；`emergence-verifiability F15` 建议**验证 ≥ 50%**；`causality-bookkeeping T5` 指出因果分析必须**单独第三方分账**（且明确说"不能与验证共用同一笔预算"），三方分账后真正用于跑世界的算力**可能只剩 20–30%**。
- 建议默认（本表）：**模拟 30% : 验证 35% : 因果 25% : LLM 10%**［本表原创，无来源，D 级 —— 它取 `causality-bookkeeping T5` 的"模拟只剩 20–30%"作为约束，把 `mandate-contradictions` 缺失的因果一档补上，并保留 `emergence-verifiability` 的"验证不得被挤成零"］。**禁止**：任何未分账的"从公共池子里借"。
- 依据：上述三条 + `emergence-verifiability F15`（**验证算力会是模拟算力的一到两个数量级**；实际后果是验证会被"以后补"，然后永远不补）。
- 被否决：不分账（默认结果是验证与因果都归零）。
- 待验证：三个比例全部 D 级；只有"总和 = 100%"这个约束是硬的。
- 裁决人：人。

**B26 · 快表/慢表分离与季度一致率**
- 建议默认：秒级返回的"快表"因果结论与干预实测的"慢表"结论**在类型上不同**，快表每条必须显示"未经干预验证"标记，UI 视觉差异必须显著到无法忽略。**强制抽样对比**：每季度随机抽 10 个快表结论跑完整协议，报告一致率；低于阈值（建议 60% 的 top-3 重叠）快表必须停用。把纲领第 24 行的"随时可查"改成"任何重大事件都可以被**排队**进行因果分析，分析是一个有成本、有排期、有结论版本的过程"。
- 依据：`causality-bookkeeping S6`（预计算启发式会覆盖 99.9% 的查询，**因此成为我们、未来的读者、小说、世内史学家训练数据实际接触到的"因果"**，且从未与严肃分析系统比对过）。
- 被否决：只有快表；或只有慢表（后者会导致 UI 无法使用，然后有人偷偷加快表）。
- 待验证：60% 无来源。
- 裁决人：人。

**B27 · 内核版本与长跑的绑定 + 单次长跑时长上限**
- 建议默认：`kernel_version_hash`（机制代码 + 参数集的内容哈希）写进**每个 tick**；**机制变更 ⇒ 该世界作废，必须从 t=0 重跑**；只有观察层与渲染层允许热更新（并同样记录版本）。内核变更分级：`纯性能`（要求位相同，自动验证，重算债务为零）/ `参数`（债务 = 受影响结论集）/ `机制`（全部债务）。**Phase 0 必须算出一个数**：内核变更的预期间隔 × 长跑耗时 → 单次长跑时长上限。**如果算出来"一次长跑要 30 天，而我们平均 5 天改一次机制"，那么当前架构在方法学上不可能产出一条可信的历史线 —— 这个结论越早知道越好。**
- 依据：`mandate-contradictions F9`/决定 15（可观察症状：`git log` 里有大量 `fix: 修正饥荒判定` 这类提交，其时间戳落在某条长跑的运行区间内）；`causality-bookkeeping S1`（三年后因果库里躺着来自 40 个不同内核版本的结论，互相引用，没人知道哪些还有效；**它比一个明显的 bug 更有害，因为库看起来是完整的**）。
- 被否决：长跑期间热更新机制（"物理定律会变的世界"，且这条历史线在语义上不是一个世界）。
- 待验证：内核变更频率只能靠历史估计。
- 裁决人：证据（这个数是算出来的）。

**B28 · LOD 一致性测试与两条极端对照线**
- 建议默认：定义聚合函数 `A(x)`，把 `A(step_fine(x)) ≈ step_coarse(A(x))`（给定容差）写成**单元测试，作为 LOD 合并的硬门槛**。跑两条对照世界线（小地图上可行）：**永不 promote** 与 **全程全 promote**；两者的宏观差异就是 LOD 机制注入世界的力的大小，**这个数字必须公开报告在每次长跑结果里，和随机种子放在一起**。若它大于种子间方差，那么我们的历史主要是 LOD 调度器写的。
- 依据：`prior-art-postmortem 结构性6`/§1.7（DF 病：worldgen 阶段与实时阶段是两套模型，世界在切换点"撒谎"——**这个测试的存在与否，决定了这个项目是"多尺度模拟"还是"两个互相撒谎的模拟"**）；`computational-feasibility S1 第 3 条`；`pseudo-simulation S8 判别测试1`。
- 被否决："历史生成阶段 + 详细模拟阶段"的两阶段模型。
- 待验证：容差取值；`abm-methodology §4.8` 明确说 aggregation/disaggregation 的误差界"是本项目必须自己做实验确定的量"。
- 裁决人：证据。

## 3. C 档 —— 治理与流程（随时可加，但越早越好）

**C 档的共同性质**：它们不改变代码能做什么，只改变**我们能否发现自己做错了**。`pseudo-simulation §1` 的判据表说明：L4（人类回路）与 L5（目标反噬）是唯二能让一个彻底干净的内核产出彻底虚假历史的机制，而**它们只能靠流程留痕抓住，任何度量都抓不住**。所以 C 档不是"锦上添花"，是唯一防线。

**C1 · 《纲领 v2》带裁决的重写稿 + 一页纸《互斥声明》签字**
把纲领第 3、5、6、7、9 行/条按 §5 的裁决逐条改写，每条下面写明"这条否决了哪一种实现"。《互斥声明》把三组互斥（真实地图 ⊥ 自己的历史 ⊥ 校准集；允许荒诞 ⊥ 完整因果链 ⊥ 涌现；强路径依赖 ⊥ 单条反事实）写下来并签字，说明每组里放弃了什么。依据：`mandate-contradictions §0/§7 第 1–2 条`（**这是防止半年后"为了让世界更有自己的历史"去动地图/动机制的唯一制度性保障**）。裁决人：人。

**C2 · 运行登记表与 canon 治理流程**
每一次超过 100 模拟年的运行，无论结果，自动写入不可删除的表 `(kernel_version, param_hash, world_seed, lineage_class, 终止原因, 宏观量摘要, 是否被人查看过)`；删除条目需显式提交记录。**无聊运行必须被展示**：任何对内/对外汇报必须同时给出该内核版本**全部运行的分布图**，并标出被展示那一次所处的分位数（"这是 87 号世界，它在'最大政体规模'上处于 P97"比一段精彩叙事诚实得多）。依据：`pseudo-simulation F5 第 3–5 条`（K7 金丝雀证明：**唯一能抓住 L4 的东西是流程留痕**）。裁决人：人。

**C3 · 参数改动分类账 + 参数冻结点 + 回滚测试**
每个自由参数带 `change_log`，每次改动必须归入 `bug` / `evidence`（须附引文）/ `aesthetics`（结果不好看）三类之一；CI 公开 `aesthetics` 改动的数量与涉及参数。**任何被 `aesthetics` 改过 ≥2 次的参数，其下游一切宏观现象在文档中永久标注为"非涌现（拟合产物）"。** Phase 1 末冻结参数集合与取值，此后"我们的世界涌现出了 Z"只有在没有新增或重调任何参数的前提下才成立（prediction vs postdiction）。**回滚测试**：一次性回滚全部 `aesthetics` 改动重跑，宏观形态若崩塌，我们就知道了那部分形态的真实作者是谁。依据：`pseudo-simulation F2`（这条通道"与手写剧情树在信息论上等价 —— 只是换成了一条更慢、更贵、留不下痕迹的梯度下降通道，梯度信号是'我们知道历史上应该有国家'"）；`llm-storytelling F7`（改动动机审计：git blame 每一次参数改动，看 commit message 里有没有"这样跑出来更像历史"）。裁决人：人。

**C4 · 《反剧情树宪章》：lint 黑名单 + GATED 注释 + clamp 记账 + `--no-clamp`**
把九类目标导向调节机制变成 grep 模式与 lint 规则：clamp、归一化、拒绝采样、世界重生成、自适应速率（**字面意义的 PID = 字面意义的剧情树**）、灭绝兜底、冷却时间（**这是节奏设计 = 叙事**）、存在性保证、隐式积分（**静默阻尼掉本该发生的崩溃振荡**）。每一处必须带审批注释 `# GATED(reason=, evidence=, ticket=, review=)`，CI 统计 GATED 数量、**只允许下降不允许上升**。clamp 必须记账（`invariant_violation(var, cell, tick, magnitude)`），触发率超 ε 视为**机制缺陷**，必须改机制不得加 clamp。提供 `--no-clamp` 模式并定期跑。**矩位移测试**进 CI：任何被声明为"方差/噪声幅度"的参数，改变它时被调制量的**均值**不得显著移动。依据：`pseudo-simulation S3`（实证支撑：Stonedahl & Wilensky 2010 在 Artificial Anasazi 里发现的两个 bug 都属这一类，且**在一个被广泛引用、被多次复现的已发表模型里存活了十年**——`quality = random-normal(0,1)*σ + 1.0` 后 `if quality<0 → 0` 这个纯 clamp 导致增大方差的同时抬高均值，使所有"波动性 vs 平均水平"的结论为伪；`HarvestVarianceYear` 声明后从未被引用）；`emergence-verifiability §8 第 12 条`。裁决人：人。

**C5 · CI 红线：只允许断言不变量，永远不允许断言宏观结果**
允许的断言：守恒律、确定性（同种子逐位相同）、调度顺序无关性、`GATED` 计数不上升、读取集差集为空、类型删除测试通过、金丝雀检出率不下降。**宏观结果只能进仪表盘，不能进红/绿测试。** 依据：`pseudo-simulation S11`（"assert 到 t=2000 至少存在一个人口 > 10000 的政体"这类断言一旦进 CI 就变成世界必须满足的定律，并由机器每天强制执行；**它比手写剧情树更糟**：它不在内核里，任何"内核无硬编码"的审查都看不见它；它把"结果不对"自动转化为红色失败，从而把人手梯度下降**自动化、日常化、并赋予道德正当性**）。裁决人：人。

**C6 · 密封清单测试（现在就做，成本几乎为零）**
团队每人写下他们能想到的全部"这个世界可能发生的事件种类"，合并去重，**加密封存**，Phase 2 前不得查看。跑完长世界后对检测到的事件做无监督聚类，然后开封，统计有多少簇**无法**用清单里的任何词描述。**如果是 0，我们的世界没有产生任何我们想不到的东西。** 配套**词表增长测试**：每 500 模拟年聚类一次，记录簇数 `K(t)`；`K(500)=40` 而 `K(5000)=41` ⇒ 原语层已封顶。依据：`pseudo-simulation S4 判别测试 1/2`（建议最低及格线 15%，该文自标"我编的数字，D 级"）；`mandate-contradictions F2`。裁决人：人。

**C7 · 证据分级与引用规范 + D 级概率质量占比公布**
每个概率函数与分布携带元数据 `(evidence_level ∈ {A,B,C,D}, source)`。定期报告**重大事件中由 D 级分布生成的比例**；若 80% 的重大事件来自 D 级分布，这个世界是我们的发明加一层随机涂装 —— 这不必然是失败，但**必须写在首页，不是藏在附录**。任何 D 级分布的**形状**（不只是参数）必须做敏感性分析（指数换对数正态、幂律换截断幂律，看宏观结论是否翻转）。研究笔记本身也遵守这条（`prior-art-postmortem §0`：一个以"可追溯"为核心原则的项目，其研究阶段的每一条结论也必须带来源等级标注）。依据：`pseudo-simulation S7`；`prior-art-postmortem §0/§5 第 10 条`。裁决人：人。

**C8 · 负空间清单：我们承认做不到 / 无法验证什么**
两份清单。**(a) 不模拟什么**（个体级农业操作、语言音系的声学细节、单兵战术、城市内部结构、格内 1–3 km 尺度的聚落互动、季节内过程……）——`prior-art-postmortem §1.9` 的教训：**没有负空间的范围定义等于没有范围**（URR 15 年 0.11 版）。**(b) 无法验证什么**（语言分化树形状、思想运动的扩散、宗教内容的演化、政体寿命分布形状……）——这些量只能进观察集，**这份清单的长度是项目诚实度的直接指标**。另加因果侧的诚实清单（`causality-bookkeeping §8` 的 8 条：给不出唯一真正原因；视界之外无法归因；只有被内核评估过的机会能成为缺席因；穿过账本区的路径只有下界估计；慢变量干预答案取决于我们如何设想它不发生；因果结论是我们的历史学不是世界事实；过度决定的事件没有主因；一年只能严肃回答几十个"为什么"）。依据：`prior-art-postmortem §5 第 8 条`；`emergence-verifiability §8 第 10 条`；`causality-bookkeeping §8`；`spec-world-state §4.5`。裁决人：人。

**C9 · 措辞纪律与 `R²_geo` 仪表盘**
每一条宏观结论必须附带 `R²_geo`（仅用 `{距草原距离, 高程, 距大河距离, 年降水}` 的 GBM 能预测多少）。预注册上限（建议政体密度类结论 `R²_geo ≤ 0.5`，D 级待标定）。超限时该结论**只能表述为"我们复现了地理效应"，不得表述为"我们的世界演化出了 X"**。**这是一条措辞纪律，成本为零，效果最大。** 依据：`mandate-contradictions F1 第 3 条`、F10（**必须现在就接受**：在固定地理 + 校准过的机制下，跨种子的宏观骨架大概率高度一致，自主性主要体现在中层；如果半年后有人发现"我们的世界宏观上还是像中国"，最省事的反应是去动机制或动地图**让它不像**——那是把伪造引入项目的最典型路径，而且它会打着"增强自主性"的旗号）；`prior-art-postmortem 取舍1`。裁决人：人。

**C10 · 角色分离与评审对称化**
调 `π`（规则先验、风险率函数）的人与看叙事的人必须是不同的人。因果链审计按 `significance` 分层随机抽样，与稀奇程度无关，每批必须包含 ≥50% 的"寻常"事件。依据：`llm-storytelling F7 第 4 条`；`pseudo-simulation S1 第 2 条`（否则"事件审计日志里有 200 条关于奇怪事件的详细讨论，和 3 条关于'又一个王朝在 250 年后崩溃了'的讨论"）。裁决人：人。

**C11 · 研究简报物理隔离 + 渲染期 prompt lint**
`research/` 目录对运行时代码**不可见**（不同 package、CI 断言、依赖检查）；简报用来写规则，不能用来写 prompt。构建期断言：`grep` 渲染后的 prompt，命中 `research/briefs/` 里任何长度 ≥8 字的连续片段即构建失败。**lint 必须在渲染期做，不是模板期** —— 污染是变量插值进来的。黑名单内容：真实朝代名、天命/科举/封建等制度词、现代政治词、真实地名、**绝对年份、时代标签**（"青铜时代""轴心时代"会召回整条教科书时间线；技术必须用能力向量描述："本地已掌握含锡合金铸造，未掌握块炼铁"）。依据：`llm-storytelling F8`（**最危险的一条：研究简报回流** —— 项目已有 22 份、约 2.7 MB 真实历史简报，只要其中任何一段进入运行时 prompt，这个世界就读到了自己的未来；而"有人为了让 agent 更懂农业，把 `agriculture-carrying-capacity.md` 的片段塞进 system prompt"**不会觉得自己在破坏项目**）；`prior-art-postmortem §5 第 7 条`。裁决人：人。

**C12 · 重算债务仪表盘 + 因果结论元数据 + 跨版本比较禁令**
每条因果结论强制携带 `(kernel_hash, config_hash, seed_set, analyzer_version, N, CI, placebo_baseline_id)`，缺任一字段不得写入。**UI 层硬拒绝跨 `kernel_hash` 的比较与聚合**（报错而不是警告）。**"重算债务"仪表盘**：多少条结论的 kernel_hash 落后于当前 HEAD、按重要性排序、重算需要多少 CPU 小时 —— **这个数字应该出现在每次里程碑评审的第一页**。依据：`causality-bookkeeping S1`。裁决人：人。

**C13 · 形态多样性账本**
记录每一次"为通过判据而做的参数改动"，定期报告"我们为了通过判据放弃了多少形态多样性"。验收集里**必须包含至少一条"允许缺席"的判据**（例如"在 ≥10% 的种子中，5000 年内不出现文字/常备军/中心财政，且这不算失败"）；若实际比例为 0%，说明世界被判据挤压成了单一形态 —— 这本身应当报警。依据：`emergence-verifiability F14`（**这是最严重的一种，因为它以严谨之名运作**：我们能拿到经验散布的量全都是关于城市、战争、财政、政体规模的，于是任何不产生这些量的文明形态会被判据系统性判低分，团队会调参把世界推回"有城、有战、有税"的形态 —— **这就是一条隐形科技树，而且是我们以严谨之名亲手装上去的**；且 `state-formation §9.a` 的六个"前置条件"里协调收益、人口密度、粮食可储存性三条都有反证据）、F18。裁决人：人。

**C14 · 判据治理元规则**
预注册文件格式与哈希提交流程；校准集 / **封存验收集**的划分；**模式预算账本**（记录每条模式被"看过"多少次，看过 N 次以上自动降级为校准集、永久移出验收集）；**开封即作废**（封存的验收集只在预注册的里程碑开封一次，开封后进入校准集）；FDR 控制；**以及一条元规则 —— 判据失败时，谁有权改机制、谁有权改判据、改判据后必须重跑哪些历史结论。** 验收集只用序数/方向性判据（点值判据几乎总能被拟合）。依据：`emergence-verifiability F13`（**POM 的三个标准用途里就包括逆向参数化，也就是明确把模式当训练信号；那么同一批模式在数学上不可能同时充当验收信号** —— 纲领没有区分这两种用途）、§6 第 5 条。裁决人：人。

**C15 · 因果链盲测 + 前瞻性因果预注册与校准**
**(a) 盲测（图灵测试）**：取 20 个重大事件，每个准备两份归因报告 —— (A) 干预实测产出、(B) 让 LLM 只看事件摘要与时间线编一份；三名团队成员盲判。**若判别准确率不显著高于 50%，说明我们的因果链没有超出叙事，全部投入白费。** Phase 1 结束目标 ≥80%。**(b) 前瞻性校准**：跑干预之前分析器必须先输出预测（效应量 + 区间），跑完打分；累积几十次后检验校准性（当它说 PN=0.7 时，是不是约 70% 的情形里去掉该因结果就不发生）。**一个不能被校准检验的因果引擎与一个似真叙事生成器不可区分。** 依据：`causality-bookkeeping §7.5`（该文自述盲测"我没见过先例，是我为这个项目现造的"，并自己指出可能的失效模式：评审看多了会学会认风格特征而不是认因果内容；缓解 = 轮换评审、统一表述格式、加入"两份都是真的"与"两份都是编的"对照组。**但它仍是唯一直接测量"我们是不是在自欺"的操作**）。裁决人：人。

**C16 · 端到端管道不许断**
从 Phase 0 起，仓库里必须**始终存在一个能在 60 秒内跑完 3000 模拟年并通过重放测试的 `main`**（故意愚蠢的 spike：只有高程 + 单一作物 + 人口 + 迁徙 + 一种冲突，零 LLM，输出因果图）。任何一周内如果这个 `main` 跑不起来，该周的其他工作全部暂停。此后每一个机制都必须"插进这条已经能跑的管道"，而不是先设计完再实现。依据：`prior-art-postmortem 取舍2`/§1.9/§5 第 1 条（URR：15 年、单人、目标高度重合、作者极其胜任 —— 仍然停在 0.11；**纲领第 26 行"不追求尽快堆出大量代码"在语义上正确，在工程上是 URR 的墓志铭**）；`computational-feasibility C5`（**Phase 0 的从容不是"慢慢写代码"，而是"在写代码前把这七件事定死"**）。裁决人：人。

**C17 · 世内史学准确率上界的常态公布**
`D(t)`、`U(t)`、`D(t) − U(t)`、虚构率、归因错误率按"距今年数"与"传播距离"分层公布；**准确率过高触发泄漏调查**（可知性上界不可超越检验失败 ⇒ CI 失败）。依据：`mandate-contradictions F8 第 3 条`；`pseudo-simulation S13 第 1–2 条`。裁决人：证据。

**C18 · 选择即抽样：小说方向的三道闸门 + 选择规则留痕**
三个压力点各设闸：**人物因果权重**（把"个体决策对政体寿命方差的贡献份额"做成被测量的输出，预注册一个带，建议 10–30%，D 级待标定）；**事件密度**（是**输出**不是参数；"无事发生"必须显式占概率质量；密度随时间的曲线进预注册）；**身份连续性**（归属可争议性测试：多个独立检测器对"这是不是同一个政体/家族"的 Fleiss' κ **不得接近 1**，边界必须有模糊带）。将来从世界史里挑一段写小说，**必须记录选择规则与被拒绝的段落数** —— 这条成本为零，但它是"文学不污染模拟"这句话唯一的可核查形式。依据：`mandate-contradictions F11/F7 第 5 条`（证据支持第一行不是无害的美学选择：Madge et al. 2019 把决策规则改成贪心，R² 从 0.66 掉到 0.22–0.39 并抹平草原的因果效应 —— **给人物加戏 = 改变世界的宏观动力学**）；`pseudo-simulation S5 判别测试2`。裁决人：人。

**C19 · 红队文档完整性缺口（本表在核对时发现的事实问题）**
`research/critique/llm-storytelling.md` 磁盘上只写到 **F9**（354 行），但该文 §0 自称"下面是 **26 条发现**"，且 §1 的通道清单与 F1–F9 的正文明确引用了 **F10、F11、F12、F15、F17、F18、F19、F22、F23** 九条本表读不到的发现（另有 `causality-bookkeeping F6` 引用了该文的 **F13**）。这意味着本登记表在以下主题上**只有引用没有原文**：agent 之间的自然语言通道（F10）、校验失败后的重试/回落路径（F11）、选项顺序/批处理/prompt 缓存等实现细节（F12）、拒答与软化（F15）、世界内叙事→信念→决策的回流（F17）、**人读 LLM 叙事后回去调规则参数（F18）**、黑名单本身的脆弱性（F19）、"无事发生"的概率质量（F22）、意图 schema 里的时机（F23）。**行动**：补齐该文档或明确标注为未完成；在补齐之前，凡引用 F10–F26 的地方必须标注"原文缺失"。本表中受影响的条目：A25（F22 的"不作为"先验）、B9（F12 的实现细节通道）、C3（F18 的人回路）、C11（F19 的黑名单脆弱性）。裁决人：人。

## 5. 红队之间的实质冲突（原样列出 + 裁决建议）

**读法**：每条给出双方原文主张与各自的证据强度、为什么这是实质冲突而不是措辞差异、本表的裁决建议与理由、**这个裁决要付的代价**、以及**如果裁错了最早会在哪里看出来**。凡属本表自己的综合，标注原创。

### 5.1 冲突 1 —— 地图基底：真实东亚 vs 扰动基底

| 方 | 主张 | 核心论据 | 自报强度 |
|---|---|---|---|
| `china-eastasia-geography-archaeology §3.0` | **用真实东亚地形做几何基底**，不要纯合成大陆；配"真实基底 + 扰动族"，`baseline` 是**唯一允许看真实考古数据的世界**，`variant_*` 用于证明机制不是被地形硬编码 | 校准资源在合成大陆上**全部失效**：51,074 个新石器—早期铁器遗址点、7,083 个 14C 年代、CHGIS、HYDE 3.4/3.5、CHELSA-TraCE21k。"**放弃真实地形 = 放弃校准集**"。且合成大陆的隐患不是"不像"而是"你不知道它哪里不像" | 数据条目 A；结论 D |
| `east-asia-climate-environment §11.2` | **真实地理骨架 + 一次性创生扰动**（镜像/旋转/河网局部重连/去名）作为主线 | "**为什么不用一比一真实地形：因为它会诱导'这里应该出现关中'这类思维**，而且真实地名会污染叙事层" | D |
| `mandate-contradictions F1` | **正式主线跑扰动基底；未扰动真实基底只在物理隔离的评估进程里出现** | 三重身份不可兼得 = 无 holdout + 宏观骨架高概率复演。Turchin 2013：距草原距离是最强预测因子，三因子解释 42% 方差，消掉草原效应 R² 0.65→0.17；Madge 2019：人口密度基线 R²=0.75；Kapoor 2024：无 holdout 导致走捷径 | 转引，简报标注已核验 |
| `pseudo-simulation F4` | 不裁决基底，但要求**地图置换套件**（真实 / 东西镜像 / 程序生成同统计量 / 真实欧洲 / 真实中美洲，各 40 种子）作为常规实验 | Anasazi 被注入的不是剧情，是**舞台** | D（协议）；Janssen 证据 A |
| `prior-art-postmortem 取舍1` | 接受地理会把结果推回真实历史，但**必须提前决定它算什么**，并用三大陆消融把"地理层校准成功"与"机制正确"分开 | Turchin 2013 用地理 + 一条扩散规则解释 65% 方差 | 一手 |

**为什么这是实质冲突**：两篇简报对"正式历史线跑在哪张图上"给出了**相反的操作指令**，而纲领第 3 行的字面读法（"以中国及周边东亚地理环境为舞台"）支持前者。这不是措辞问题，因为两种做法产出的是不同的 `basemap_hash`，事后不可转换。

**裁决建议**: 采纳 `mandate-contradictions F1` + `spec-world-state D11` 的**等变类补丁** —— 主线跑 `T(真实骨架, world_seed)`，真实基底只进物理隔离的评估进程；**扰动算子必须声明等变类，校准量必须是该等变类下的不变量**；等距不变量（`density(site | elev, slope, precip, TWI, dist_to_navigable_water, dist_to_grassland)` 这类只依赖协变量、不依赖绝对坐标的统计量）可直接在主线校准；非等距量只能在评估进程标定**函数形式**再搬到主线，每次搬运留痕。配 `pseudo-simulation F4` 的地图置换套件作为验收。

**理由**: 两方争的其实不是同一个东西 —— 一个要**统计结构**（校准可行性），一个要**实例不可预期**（自主性）。等变类划分把校准量切成两半，让两个诉求各自落地。

**代价**: (a) 非等距量的校准要多走一道搬运手续，且搬运的每一步都是一次可能的污染；(b) 主线上不能直接做"模拟聚落分布 vs 真实遗址点分布"的空间比对（只能做协变量条件分布的比对）；(c) 扰动算子本身是一组我们选的参数，它有自己的偏置，没人检查过。

**残余风险（本表原创的判断，D 级）**: **如果实测发现绝大多数有用的校准量都是非等距的，这个和解就退化了。** 而这很可能发生 —— 河网拓扑、走廊中介中心性、距草原距离恰恰是最强预测因子那一类，而它们全部是非等距的（河网重连、走廊剪断、降水梯度旋转都会改变它们）。**行动**：Phase 0 先做一次清点，把打算用的校准量逐条标注等距/非等距并公布比例；**若非等距占比 > 50%，本条必须回到人裁决，在"要校准"与"要自主性"之间真的二选一。**

**裁错了最早在哪看出来**: 跨 200 个种子，"农牧分界线位置"的空间方差极小、政体重心几乎重合；或者反过来 —— 校准工作在第一次尝试时就发现"我们想用的锚点一个都搬不过来"。

**裁决人**: **人**（写进《互斥声明》签字）。

### 5.2 冲突 2 —— 因果记录：写入级 provenance vs 重算架构

| 方 | 主张 | 核心论据 |
|---|---|---|
| `pseudo-simulation F3` | **读取集追踪**：世界状态的所有读取经受控访问器，每个决策点记录 `read_set`；事件因果闭包 = 从写入集沿 `read_set` 反向传递闭包。作弊检测器 `declared_causes(e) \ read_set_closure(e)` 必须为空 | "保存"是存储动作不是测量动作；默认实现是自报，而**剧情树的自报质量最高**（手写规则知道自己的触发条件，真正的涌现过程不知道自己为什么发生）。成本自估 2–10×，"我的工程估计，未做基准" |
| `causality-bookkeeping F2` | **放弃写入级 provenance，改为"不保存因果，保存可重算性"** | 存储：1.6×10¹⁰ 次写 × 44 B ≈ **700 GB/跑**，加索引 1–3 TB，×50 种子 = 50–300 TB；重算架构 ≈30 GB/跑。认识论：读取集**过近似**（短路求值里被读但不影响结果的变量会被记成原因）且**欠近似**（"没有被读的东西可以是原因"——**一个基于写入记账的因果图在原理上不能表示"什么没有发生"，而"什么没有发生"是历史解释的主干**） |
| `computational-feasibility F3` | **有界读取集（≤64 项，变量级三元组）+ 干预式重放归因** | 祖先闭包 `b^d` 组合爆炸；格点级全量 PROV = 8.64×10¹⁰ 条边，**超 Neo4j aligned 格式 2³⁵ 上限 3 倍**（官方文档已核验），且 1–4 TB 的图进不了 page cache，多跳遍历退化为随机磁盘 IO；剪枝规则就是解释 |

**为什么这是实质冲突**：`pseudo-simulation F3` 明确要求"每一个重大事件必须保存**由运行时数据流测量得到的**读取集闭包"（闭包，不是指纹），而 `causality-bookkeeping F2` 明确说这条路"同时是存储不可行的和认识论上无价值的"。两者对同一个字段给出相反的存/不存指令。

**裁决建议（三层合成，本表原创的分配方案，D 级）**:
1. **主干 = 重算架构**（`causality-bookkeeping §7`）：唯一真相源 = 状态 + 种子；因果是从它派生的，不是与它并存的第二个库（这同时消灭了 `causality-bookkeeping S8` 的"两库漂移"问题）。
2. **常开一层有界读取集指纹**（`computational-feasibility F3`）：≤64 项 `(entity_kind, entity_id, field_id)` **变量级**三元组 + tick + rule_id + rng_key + llm_call_id，常数大小，对全部实体级事件开启，格点级不进。
3. **全量 taint 追踪只在 `--audit` 短世界（500 年）开启**（`pseudo-simulation F3` 的成本缓解建议），用于跑作弊检测器 `declared_causes \ read_set_closure = ∅`。
4. **保留 `pseudo-simulation F3` 的核心禁令**（这条与重算架构完全不冲突）：**任何由代码作者手工声明的原因只能作为"待检验的假设"存在于独立字段，并在展示时明确标注为假设。**
5. **保留 `causality-bookkeeping F2` 的近失账本**（缺席因），它在重算架构下存储成本为零。

**理由**: 三方的核心诉求两两不冲突 —— pseudo 要的是"禁止自报"，causality 要的是"不落盘闭包"，comp 要的是"常数大小的廉价指纹"。真正被三方共同否决的只有一个东西：**写入级全量 provenance 闭包**。

**代价（必须签字）**: `causality-bookkeeping T1` 已明码标价 —— 没有即时因果查询；调试期看不到"这个数为什么变了"；新人上手更难；**回答一个"为什么"要花小时到 CPU-天**（一次严肃回答 5,000–10,000 CPU 小时，一年只能认真回答个位数到几十个）。

**硬前提**: 重算架构要求比特级确定性（A2/A4/A5）。**如果 A2 选了"放弃 bit-exact"，本裁决自动失效，必须回到写入级 provenance，并同时接受它的存储与认识论代价。** 这两条决定是绑在一起的。

**裁错了最早在哪看出来**: 存储监控在第一次 1000 年长跑时爆掉，团队的反应是"先关掉细粒度 provenance"，之后再也没打开过；或者：因果查询在演示里是秒级返回的。

**裁决人**: **证据**（taint 开销实测 + 存储实测 + 1 ULP 发散时间）。

### 5.3 冲突 3 —— 空间分辨率：H3 res 5（4.7 万格） vs 25 km（19,200 格） vs 5–10 km

| 方 | 主张 | 论据 | 自报强度 |
|---|---|---|---|
| `settlement-urbanization-spatial §4.6/§11` | **H3 res 5**：252.90 km²/格、边长 9.854 km、中心距约 17 km、东亚约 4.7 万格；四层表示（六边形栅格 + 动态加权 Voronoi 地块 + 多式联运图 + 政治连续场） | **分辨率不是任意的美学选择，它应该等于系统里最基本的交互半径**：ORBIS 实测牛车 12 km/天、挑夫 20、步行与驮兽 30，17 km 中心距 ≈ 载货运输的一天行程；res 6（36 km²）需 33 万格，res 7 需 230 万格 | 分辨率表 A（H3 官方）；四层方案 D |
| `computational-feasibility S3` | **一张网格**，主格 25 km 六边形（19,200 格）承载所有动态状态；1 km 只做静态预计算并**保留分布摘要**；亚格子 = 格内 N 个位点的随机过程 | 内存不是约束（1 km 全域 2 KB/格 = 24.6 GB，装得下）；约束是**每 tick 遍历次数**与**插值误差** —— 插值是每 tick 执行的、有系统性偏置的算子，从粗到细会造出不存在的空间结构 | 内存表 A；主格选择 D |
| `china-eastasia-geography-archaeology §3.1` | 主格 **5–10 km 六边形** | 无独立论据 | §9.1 自报"纯工程取舍"，**D** |

**为什么这是实质冲突**：三个值相差 7 倍与 25 倍；`cliodynamics-secular-cycles` 明确警告缩小网格必须重新标定 δ_s（它按格数计），所以这不是可以事后调的旋钮。

**裁决建议**: **H3 res 5 + `computational-feasibility` 的"一张网格"纪律 + 它的亚格子方案；拒绝 5–10 km；拒绝 25 km；拒绝第二层动态 Voronoi。**（与 `spec-world-state D6` 一致。）

**理由（算术优先，语义其次）**:
- res 6 被**算术**排除：同窗口格数是 res 5 的 7.0 倍；按 1.2 s/tick 预算，气候 + 农业两项在 res 6 下就吃光整个 tick。
- 5–10 km 被**证据缺失**排除：其来源简报自己标注为"纯工程取舍、D 级、无文献支持"，这里没有需要保护的证据。
- 25 km 被**语义**排除：中心距 26 km 超出载货运输的一天行程，"相邻 = 一天可达"的物理含义丢失，基层市场区在这个格上不可表示；且 253 km²/格已经会系统性低估早期政体数量（`settlement-urbanization-spatial §11.5 D`），625 km² 让这个偏差再放大 2.5 倍，而**最脆弱的恰恰是纲领要求的"文明形成之前"那一段**。

**本表补充的回退规则**［本表原创，无来源，D 级］: 空壳内核基准若实测格扫超过 350 ms/tick，**唯一合法的调整方向是降到 res 4（1,770 km²，约 2 万格）**，不得增加第二张网格、不得给"重要区域"加密 —— 后两者分别复活插值偏置（S3）与 LOD 剧情通道（S8）。

**代价（必须写进 README，不得事后惊讶）**: 永久放弃格内空间结构的动态演化、1.5–3 km 尺度的聚落互动（该尺度有实证：克里特青铜时代 PCF 的聚落间抑制距离）、城市内部结构、腹地作为**面**的表示（只剩图上的可达集）。**这三类现象不得作为涌现结论被引用。**

**裁错了最早在哪看出来**: 同一个量（例如"这一格的农业适宜度"）在两个子系统里算出不同的值；聚落分布在网格边界上出现人工纹理；把主格换一档，宏观结论变了。

**裁决人**: **证据**（空壳内核基准）。

### 5.4 冲突 4 —— 荒诞度的定义：`surprise_bits` 不等式 vs 机制组合新颖度

| 方 | 主张 | 论据 |
|---|---|---|
| `emergence-verifiability F3` | `surprise_bits(e) = −log₂ P(e \| 参考集合)`；`explanation_bits(e) = log₂[P(e\|完整前因)/P(e\|参考集合)]`；**原则 7 的可执行版本：`explanation_bits ≥ surprise_bits − τ`**。参考集合由三个空模型构成 | "罕见"的两种自然读法都自毁：相对真实历史 ⇒ 真实历史成了先验；相对模拟自身 ⇒ 自洽的荒诞世界永不荒诞且奖励单调性。Clauset 2018：1945 年后的"长和平"与之前的大暴力期**都不能与平稳过程的涨落区分**，还需 100–140 年才显著 —— 一次实现里的"罕见"根本不可估 |
| `mandate-contradictions F2` | 荒诞度 = **机制组合的新颖度** `−log P(机制组合 \| 此前历史中的机制共现分布)`；投资方向从"扩大分布尾部"转向"机制的可组合性"；验收指标 = **新颖组合率随时间不饱和** | 第 2 条已经把结果空间封顶：世界能产生的结果 = 机制库在组合下的闭包。"更荒诞"只有两种来源：数值尾部 (i) 与组合新颖 (ii)；**第 7 条的措辞指向 (i)，而"现实历史中从未出现过的文明形态"只能来自 (ii)**。组合口径的参考分布是世界自己的历史，正好绕开 F3 的"缺参考分布"问题 |
| `causality-bookkeeping F6/C5` | 用**必然性剖面 `p̂(Δ)`** 定义"强解释"：`p̂(Δ)` 在较大 Δ 上仍显著高于同类事件基率 = 强前置条件 | **荒诞 = 低概率 = 多个小概率巧合的合取 = 归因最分散、最不像"强前置条件"** ⇒ 第 7 条在最需要它的地方最难满足，会诱导我们**给荒诞事件补写解释**（剧情树回流入口） |
| `pseudo-simulation S1` | 荒诞度**绝不可以是运行时变量**；审查对称化；第 7 条改写为**叙述规范**而非接受标准 | 不对称审查 = 定向选择压，把输出分布系统性推回真实历史；**第 7 条是一台自动化的确认偏误机**（剧情树的产物一定落在"寻常"那一侧，永远不会触发审查） |

**为什么这是实质冲突**：`emergence-verifiability F3` 的 `surprise_bits` 需要一个**外部参考集合**；`mandate-contradictions F2` 明确说组合口径的价值恰恰在于**不需要外部参考分布**。两者对"参考系是什么"给出相反答案，而参考系决定了这个量算出来是什么。

**裁决建议（三分口径，本表原创的分工，D 级）**: **三个量测的是三个不同的东西，全部保留，各自限定用途，互不替代**：

| 量 | 测什么 | 用途 | 严禁 |
|---|---|---|---|
| `surprise_bits`（相对三空模型） | **事件层**："这件事需要多少解释" | 只进归因报告，配 `explanation_bits ≥ surprise_bits − τ` 作为**报告项**（不是门槛） | 进内核；作为"是否允许"的输入 |
| **机制组合新颖度** | **项目层**："我们的世界会不会平庸" | 唯一能测"结果空间是否封顶"的量；`新颖组合率不饱和` 进验收集 | 用调大方差来刷分（它刷不动，这正是选它的理由） |
| **必然性剖面 `p̂(Δ)`** | **单事件**："本来有多大概率不这样" | 取代"因果链的丰满度"作为"强解释"的操作化 | 用叙事长度冒充剖面 |

**共同红线（采纳 `pseudo-simulation S1`）**: 这三个量**任何一个都不得被内核读取**，不得进入任何决定"是否允许"的代码路径（lint 强制）；审查抽样按 `significance` 分层随机，与稀奇程度无关，每批含 ≥50% 的寻常事件。第 7 条改写为叙述规范：**罕见结果与寻常结果适用同一套因果验收标准；区别只在于罕见结果对外展示时需要更长的叙述篇幅，因为读者缺少先验 —— 篇幅要求不等于证据要求。**

**理由**: 把三个量强行合成一个数会同时丢掉三件事（事件层的解释义务、项目层的能力诊断、单事件的偶然性刻画）。而它们各自的失效模式已经被各自的作者写清楚了，分开用就不会互相掩盖。

**代价**: `explanation_bits` 需要逐前因重放（B6 的功效算术：一个原因 163 次/臂），所以不等式只能对少数事件执行，**覆盖率必须公布**；组合新颖度依赖"机制"这个单位的划分，而划分是我们做的。

**裁错了最早在哪看出来**: 世界里最"离奇"的事件全是数值极端，没有一个是结构新颖 —— 我们能用现有词汇给每一个制度命名；机制共现矩阵在 t=1000 之后不再出现新的非零格；或者团队讨论里出现"这个世界太平淡了，要不要加点事件"（**这句话本身就是症状**）。

**裁决人**: **人**。

### 5.5 冲突 5 —— LLM 的定位：受约束参与决策 vs 完全退出因果链

| 方 | 主张 | 论据 |
|---|---|---|
| `llm-storytelling §2/F1/F5` | **受约束参与**：规则给选择集与先验 `π` → LLM 输出**分布** `p_LLM` → 我们的 PRNG 采样。污染量 = `D_KL(p_LLM ‖ π)`，进预算 | 单点选择是三重损失（反事实 abduction 失效、熵不可观测、指标单边）；且这个形态让"AI 能不能决定 X"变成**可判定**：X 是测度或状态写入 ⇒ 永远不能；X 是在规则给定集合上给出分布 ⇒ 可以 |
| `prior-art-postmortem §1.14/致命3` | **完全退出在线决策**：LLM 降级为**离线策略编译器**，在少量代表性情境上生成可审阅的策略片段，运行期由规则引擎执行；调用量与"新情境类别数"挂钩而非"人物数 × 年数" | Generative Agents 实测尺度是 **25 agent × 2 模拟日**，与"数千年 + 一个大陆"隔 6–8 个数量级；且论文自报 agent "excessive cooperation, agreeing to requests even when they conflicted with their established interests" —— **一个由这种 agent 组成的世界不会有背叛、政变、清洗、宗教迫害、王朝倾覆，而纲领要的正是这些**；"添加看似合理但虚构的细节"是模型的默认行为 |
| `pseudo-simulation S2/S12` | LLM 只能在规则层已构造好的**有限离散候选集**上选择 + 产生 rationale；**不能创造新候选项、不能命名、不能生成会被后续 tick 读取的结构化内容**；**绝不能当合理性裁判**（判官与生成者共享先验，**这个裁判的检出力是负的**） | LLM 的两难：若对宏观历史**有**实质影响 ⇒ 它的先验就是剧情树且方法论上不可验证；若**没有** ⇒ 它是昂贵的装饰，其"解释"是纯粹的事后编造 |
| `causality-bookkeeping S5` | 划**可重算核 / 冻结账本区**的边界；长期方向是把"人的判断"移进可重算核（LLM 只在编译期） | 反事实时两个选项都错，且**默认会选便宜的那个**，于是因果结论**系统性偏向物质/结构原因，低估决策、信息、误解、性格的作用** |
| `mandate-contradictions F3` | **文本自由、参数不自由**：AI 的输出只能是 (a) 有限选择集上的一次选择，或 (b) 不参与任何数值计算的标签文本 | 文化 → 偏好权重/合法性/协调成本 → 行为 → 制度 → 客观结果；第 5 条只禁止了"**直接**决定"，而"直接"在代码里没有对应物 |
| `computational-feasibility F5` | LLM **永远不在 tick 关键路径上**；批处理单位 = tick × 全体种子；每线配额 ≤3×10⁴ | 逐 tick 阻塞 = 50–250 小时/线，**于是为了跑得动就把 LLM 关掉 —— 而这会让 LLM-on/LLM-off 对照永远做不成**，性能问题直接废掉检测污染的唯一测试 |

**为什么这是实质冲突**：`llm-storytelling` 要 LLM 在**运行期**提供分布（它认为这是唯一能让污染可测的形态）；`prior-art-postmortem` 要 LLM **完全离开运行期**（它认为在线决策在算力与偏置上都不成立）。两者对"运行期是否有 LLM 调用"给出相反答案。

**裁决建议（分层退出，本表原创的综合，D 级）**:
1. **默认档 = `surrogate mode`（LLM 全关）。所有带因果主张的正式实验只在这一档运行；架构硬约束：世界在 LLM 完全不可用时必须能自己跑完三千年。**（`llm-storytelling F4 替代设计 2`）
2. LLM 只允许出现在**三个受限位置**：
   - **(P1) 运行期分布提供者**：在规则给定的选择集上输出经校准的 `p_LLM`，由我方 CBRNG 采样，四元组进 ledger，`D_KL` 计预算，配额封顶（`llm-storytelling §2` + `computational-feasibility F5`）；
   - **(P2) 离线策略编译器**：产出可审阅、可 diff、带 hash 的策略片段，运行期执行的是**确定性策略函数**（`prior-art-postmortem §1.14` + `causality-bookkeeping S5` 的长期方向）；
   - **(P3) 作者层渲染器与假设提出器**：把结构对象渲染成文本（永不回流）；提出可被消融检验的因果假设（**写入因果图的是消融的实测结果，不是 LLM 的话** —— LLM 在这里是启发式搜索器，可以猜错一百次而不污染任何东西）。
3. **四项永久禁止**：命名（A24）、教义/文化内容的**数值部分**（B21）、因果图写入（`causal_purity` = LLM 撰写的因果节点与边数量 **恒等于 0**，CI 断言）、合理性裁判（若一定要用作辅助筛查，必须先在金丝雀集上标定，**并禁止它做任何筛除动作** —— 它只能生成待人工检查的问题清单，永远不能删除或修改任何东西）。

**理由**: "完全退出"会同时丢掉两样东西：纲领第 5 条的字面承诺，以及 LLM 作为**搜索器**的真实价值（在 10⁵ 个状态变量的世界里"该检查哪个因子"本身是巨大的搜索问题）。"不受约束参与"会同时破坏反事实可识别性与因果纯度。分层退出把"LLM 在不在因果链里"变成一个**可切换的开关**，而所有科学结论只在关闭档产生 —— 于是 `pseudo-simulation S2` 的两难被化解为一个工程配置，而不是一个必须回答的哲学问题。

**代价**: (a) 要写两套决策路径（LLM 与 surrogate），且必须保证两者的接口完全一致；(b) `causality-bookkeeping S5` 的"通道封闭偏差"仍然存在，只是被限制在 P1 里，且必须实测其量级；(c) 如果 surrogate 档跑出来的世界"不好看"，压力会全部压回"打开 LLM"——**这个压力必须被预期，并由 C1 的《互斥声明》挡住**。

**裁错了最早在哪看出来**: 预算弹性实验（同种子、把 LLM 调用预算翻倍再跑一次）显示事件密度跟着涨 ⇒ **事件密度是预算的函数，不是世界的函数**；或者：`p_LLM` 的熵长期低于 `H(π)` 的一半（坍缩）；或者：从来没有人跑过 surrogate 档的完整三千年。

**裁决人**: **人**。

### 5.6 冲突 6（本表发现）—— 算力三方分账：三份红队给出三个不兼容的数字

- `mandate-contradictions` 决定 20：**模拟 : 验证 : LLM = 5 : 4 : 1**，理由是"验证算力从来不进预算，不预先切分它一定会被挤成零"。
- `emergence-verifiability F15`：**验证预算必须被声明为总算力的固定下限，建议 ≥50%**，理由是一次消融矩阵 10,500 次长跑、一次对抗式敏感性分析 2,500 CPU 小时（而那是 80×120 格、700 年的 Artificial Anasazi）。
- `causality-bookkeeping T5`：因果分析必须与模拟、验证**三方分账**，且明确写"**两者不能共用同一笔预算**"；三方分账后真正用于跑世界的算力**可能只剩 20–30%**。

**冲突点**：`mandate` 的三分法里根本没有"因果分析"这一档（它把因果算力隐含在验证里），而 `causality` 明确说这两笔钱不能共用。若按 `mandate` 的 5:4:1 执行，因果分析会从验证的 40% 里挤，而 `emergence` 又要求验证本身 ≥50%。**三条同时满足是不可能的。**

**裁决建议**［本表原创，D 级］: **模拟 30% : 验证 35% : 因果 25% : LLM 10%**。取 `causality-bookkeeping T5` 的"模拟只剩 20–30%"作为硬约束，把缺失的因果档补上，保住 `emergence-verifiability F15` 的"验证不得为零"。**唯一硬的东西是"总和 = 100%"与"四档都非零"；具体比例是 D 级，第一次里程碑后按实测重新分配。**

**代价**: 我们的世界会比同等预算下的天真实现**小、慢、少**。这是纲领第 26 行"不追求尽快堆出大量代码"的算力版本，必须被明确接受。

**裁错了最早在哪看出来**: "这次先不跑全套电池，赶下个里程碑"出现第二次；消融矩阵的最后一次完整运行是三个月前；有人提议把 N 从 50 降到 10。

**裁决人**: **人**。

### 5.7 冲突 7（本表发现）—— 世界边界：外部通量接口 vs 草原内生

- `mandate-contradictions` 决定 5：有限世界 + **显式的"世界外通量"接口**，外来技术、病原、人群以低频泊松流进入，到达率由地理通道成本计算，参数冻结并公开。该文自己称这是"**纲领最大的一个未提及的结构性决定**"。
- `spec-world-state D12`：**草原/牧业生态带整体在世界之内**；窗口外为吸收边界；`world_external_flux` **默认恒为 0 且在生产线编译期关闭**。该规格明确说这是与 `mandate` 决定 5 **相反**的裁决。

**冲突点**：`mandate-contradictions F1` 自己已经证明距草原距离是帝国密度的最强预测因子（消掉草原效应 R² 0.65→0.17）。如果草原压力做成外生泊松流，我们等于**手动注入了真实历史最重要的那个变量**，并把它变成一个我们调的参数；如果做成内生，我们要在 t=0 就能表示牧业生业系统，且窗口必须扩大到包含整个草原带（格数从 4.7 万涨到约 14 万含海 / 8.4 万陆格）。

**裁决建议**: 采纳 `spec-world-state D12`（草原内生 + 外部通量默认 0 + 编译期关闭）。理由：把最强的宏观驱动做成外生注入，会让"我们的世界演化出了南北二元"这句话彻底失去信息量，而这正是 A9 想保住的东西。代价是扩大窗口的格数与牧业机制的额外负担，两者都进 A1 的预算。

**残余风险**: 若牧业机制在 Phase 1 做不出来，唯一诚实的退路是**把世界缩回农业带并声明"本世界没有草原压力"**，而不是偷偷打开外部通量接口。**这条退路必须现在写下来。**［本表原创，D 级］

**裁错了最早在哪看出来**: `world_external_flux` 在生产线里被打开过一次且没有留痕；或者：北部动力学的所有参数都标着 `free: true`。

**裁决人**: **人**（两份文件明确对立，不许各自实现）。

## 6. 本项目最可能以什么方式失败

**合并方式**：`prior-art-postmortem §6` 给了一份按概率排序的 10 条；其余 6 份没有给排序，但各自的"致命"节实际上都在描述一种终局。本节把它们合并成 14 条，按 **P(发生) × 不可恢复性 × 不可检测性** 排序 —— 这个乘法排序是本表的判断［本表原创，无来源，D 级］，与 `prior-art-postmortem §6` 的纯概率排序有三处差异，逐条注明。

**排序原则的三条**：
1. **不可检测性权重最高**。一个我们会发现的失败只是延期；一个我们不会发现的失败会让全部产出无效，而且我们会带着它继续投资几年。
2. **发生在早期的失败排前面**，因为路径依赖对我们自己的项目同样成立。
3. **"我们会庆祝它"的失败额外加权**。`prior-art-postmortem §6.6` 对 Sid 病的评语——"我们会把它当成最大的成功，这使它格外危险"——是本节的排序直觉来源。

- **最早症状**：项目里第一次出现"我们这次跑了 3 个种子"这类句子，**而没有人觉得不对**；敏感性分析被排进"以后做"且连续三个月还在"以后"。
- 对抗手段：A1、B25、C2（运行登记表把"跑了几次"变成不可隐藏的事实）。
- 差异说明：`prior-art-postmortem §6` 没有单列这一条（它把算力问题并进了"致命 3"）。本表提前它，因为它是 #3 与 #4 的**使能条件** —— 没有集合，人类回路的选择偏差就没有任何东西挡得住。

**#3 · L4 人类回路：调参与策展直到世界"像样"**
- 预测者：`pseudo-simulation F2/F5`（判据表里的 L4，明确标注"代码审查**不能**抓住，只能靠流程留痕"）、`prior-art-postmortem §6.3`（Anasazi 病）。
- 机制：成功清单要求国家出现 → 跑 200 个种子只有 2 个出现部落联盟 → 我们**无法区分**"机制错了"与"国家形成本来就极罕见极慢"（Turchin 2022：500 BCE 已有农业的地区 23% 到 1500 年仍无宏观国家，平均时滞约 2000 年）→ 开始调参，每次都有像样的局部理由 → 若干轮后国家出现了。**这个过程与手写剧情树在信息论上等价，只是换成一条更慢、更贵、留不下痕迹的梯度下降通道，梯度信号是"我们知道历史上应该有国家"。**
- **最早症状**：提交历史里出现第一条"调整 X 使国家形成时间更合理"；某几个参数被反复修改、幅度不大、方向一致；团队里出现"这一版世界终于像样了"。
- 对抗手段：C3（参数改动分类账 + 回滚测试）、C2（运行登记表 + 无聊运行必须被展示）、B4 的 K7 金丝雀（**它存在的唯一目的就是证明其余检测器对策展全部失效**）。

**#4 · L5 目标反噬：可读性被当成验收信号**
- 预测者：`pseudo-simulation F1`（判据表里的 L5，"完全没有出现在纲领与 21 篇简报里"）。
- 机制：Phase 0 的成功标准衡量的是**解释的可得性**，而它与机制的真实性几乎不相关甚至负相关。一条手写规则在因果库里留下三条干净、语义清晰的前因；一个真正涌现的崩溃，其原因是十万次微观读写的交叠，摘要出来必然含混。**于是验收时我们会系统性地偏好剧情树的输出。**
- **最早症状**：内部评审第一次出现"这个解释很漂亮""这条因果链很清楚"作为**褒奖**；因果链界面上几乎每个重大事件都恰好有 3–7 条整齐的原因；**从来没有一个重大事件的答案是"我们查过了，说不清楚"**。
- 对抗手段：把 `不可解释事件占比` 列为必须公布的一等指标并事先声明下界（`pseudo-simulation F1` 建议不低于 10%）；B7（`N_eff > 10k` 时 UI 拒绝显示 top-k）；C15（因果链盲测）。
- 差异说明：`prior-art-postmortem §6` 完全没有这一条。本表把它排在第 4，因为它污染的是**评价函数本身** —— 它会让前三条的所有对抗手段被善意地绕过。

**#5 · 重放与反事实静默失效**
- 预测者：`prior-art-postmortem §6.2`（该文排第 2，并指出"这条一旦发生就不可逆，所以期望损失最大"）、`computational-feasibility F2`、`causality-bookkeeping F7`、`llm-storytelling F4`、`emergence-verifiability F2`。
- 机制：四个独立入口 —— 浮点归约顺序（1 ULP → 60 步 → O(1)）、entity_id 自增计数器（抑制一次生育 → 全局重编号 → 三年内整个大陆全变）、容器迭代顺序、LLM 不可复现。**四者都伪装成路径依赖**，且在任何宏观观测量上与真实路径依赖不可区分。
- **最早症状**：**因果隔离测试从未被写**（这本身就是症状）；同一种子在 4 线程与 8 线程下跑出不同的国家数量；在同事机器上重放，第 200 年之后对不上；最隐蔽的形式 —— 做反事实时"什么都不改"的对照组也偏离了主线，而**人们会以为是自己改错了东西**。
- 对抗手段：A2、A4、A5（两个 CI 门禁测试必须在写第一个机制之前跑通）、A26。

**#6 · Anasazi 病：宏观曲线由 2–3 个全局系数决定，机制是装饰**
- 预测者：`prior-art-postmortem §6.3/§1.1`、`pseudo-simulation F6 K3`、`emergence-verifiability F6 W2`。
- 机制：Janssen 2009 的完整剧本 —— 拟合成功来自两个承载力参数（Harvest Adjustment 1.0→0.56、Harvest Variance→0.4），**纯外生承载力模型（零 agent 行为）的相对误差只高 10%–50%**，"the agent-based model acted as a smoothing function"；而且模型**根本无法再现这段历史唯一真正需要解释的事**（山谷被彻底放弃）。
- **最早症状**：第一次"校准"只需要改 2–3 个全局常数就能显著改善匹配度；零模型套件不在 CI 里；把 agent 决策全部替换成均匀随机、宏观曲线几乎不变（而没有人跑过这个对照）。
- 对抗手段：B23（四个零模型 + 机制准入门槛）、B4（W2 诱饵世界）。

**#7 · Qud 病：LLM 的事后合理化填满因果库，而我们毫无察觉**
- 预测者：`prior-art-postmortem §6.4/§1.8`、`llm-storytelling F2`、`pseudo-simulation F3`。
- 机制：Grinblat & Bucklew 2017 已经证明"读起来有因果的历史"可以用"**先生成事件、事后合理化**"廉价生产。因此"我们的系统能讲出一条因果链"对"我们的系统真的有因果"**零证据力**。而 Turpin et al. 2023 实证：注入偏置特征后模型答案会变，但它的 chain-of-thought **从不提及真正起作用的因素**，反而给出一套听上去很可信的别的理由（BIG-Bench Hard 13 个任务上准确率掉 36%，解释始终自洽）。
- **最早症状**：代码里出现 `event.causes[]` 由生成事件的那段代码顺手填写；出现 `interpret_doctrine(text) -> Dict[str, float]` 这类函数签名（**看到它就已经中了**）；因果字段里出现只在事件模板里存在、在世界状态里没有对应存储的概念（"民怨""气数"）。
- 对抗手段：A19（禁止自报，作弊检测器 CI 强制）、A22（`author_narration` 物理隔离 + 因果查询默认不返回）、A25（`causal_purity ≡ 0`）、C15（盲测）。

**#8 · 归因崩塌被误读为路径依赖**
- 预测者：`causality-bookkeeping F1/F5`（该文的头号发现）。
- 机制：路径依赖强 ⇒ 单点扰动响应饱和 ⇒ 对晚期事件做归因时**每一个早期抽样点都会显示"翻转它，e 就不发生了"** ⇒ 几十万个前因、重要性完全均匀 = **归因的完全崩塌**。而我们会把它解读成"路径依赖非常强，第 3 条实现了"。反过来若响应衰减到零，我们会解读成"因果链清清楚楚，第 2 条实现了"。**纲领没有任何判据能让我们说"这次不对"。**
- **最早症状**：反事实实验报告里**没有"安慰剂"这个词**；所有反事实的结论都是"是的，这件事很重要"（**零否定结果**）；从来没有人报告过"这个干预的效应在第 80 年后与随机扰动不可区分"。
- 对抗手段：B6（安慰剂强制化 + 噪声地板 + `T_half`）、B7（`N_eff`、`OD`、"不可归因"必须是常见答案）、B8（共享分叉集合同时产出视界）。

**#9 · 判据自欺：全绿报告，而没人知道它能不能区分真假**
- 预测者：`emergence-verifiability F6/F13/F14`、`pseudo-simulation F6`。
- 机制：三层叠加 —— (a) **判据从未在已知作弊上标定**（`complex-systems-emergence §7.18` 自承"没有任何文献做过'剧情树能否骗过涌现度量'的研究"，而判据 E1 的最严重伪阳性**正是剧情树**）；(b) **Goodhart 是必然而非风险**（POM 本身就是逆向参数化工具，同一批模式在数学上不可能同时充当训练信号与验收信号）；(c) **形态偏置**（能拿到经验散布的量全是关于城、战、税的，于是判据以严谨之名装上一条隐形科技树）。
- **最早症状**：验收报告上所有指标都是绿的，而**没有人能说出"如果我们真的作弊了，这一页会长什么样"**；有人提议加新判据时，讨论的是"这条听起来有道理吗"而不是"这条在诱饵世界上的伪阳性率是多少"；判据通过率随版本单调上升。
- 对抗手段：B4（诱饵世界 + 判据标定报告：**在 W1 上不失败的判据不得进验收集**）、C14（模式预算账本 + 开封即作废）、C13（形态多样性账本 + "允许缺席"判据）。

**#10 · Turchin 镜像病：地理复演被误读为机制成功**
- 预测者：`mandate-contradictions F1/F10`、`prior-art-postmortem §6.10/§1.3`、`pseudo-simulation F4`。
- 机制：只要用真实东亚地形且把"草原邻接—骑射技术—战争强度—制度选择压力"这条链实现对，"北方农牧接触带高频出现大型政体""南北二元""盆地—走廊拓扑决定政治边界"就**几乎是地图的函数**。我们会把它们写进演示，说"看，我们的世界自己演化出了帝国"——**这句话在字面上是真的，在信息量上等于"我们的世界正确实现了地理"**。
- **最早症状**：跨种子的农牧分界线位置几乎重合、政体重心的空间方差极小；`R²_geo` 从未被计算过；盲测中一个不知情的人能以远高于随机的准确率说"这是中国"。
- 对抗手段：A9（扰动基底 + 等变类）、C9（`R²_geo` 仪表盘 + 措辞纪律）、`pseudo-simulation F4` 的地图置换套件。
- 附带的二次伤害（`mandate-contradictions F10` 明确警告）：**发现"还是像中国"之后，最省事的反应是去动机制或动地图让它不像 —— 那是把伪造引入项目的最典型路径，而且它会打着"增强自主性"的旗号。**

**#11 · 均质化与"世界太平淡"：防御装反**
- 预测者：`llm-storytelling §0/F9`（该文推翻了纲领对威胁方向的预设）。
- 机制：纲领预设"LLM 会为了戏剧性编故事"，但**能找到的全部实证都指向相反方向**（七条独立证据：分布坍缩、typicality bias、集体多样性下降、RLHF 降低多样性、合成响应方差偏低、迎合、过度从众）。若按"防戏剧性"设计防御（抑制事件率、惩罚巧合、给尾部设上限），我们会**加剧**真正会发生的失败，同时对真正的污染毫无作用。叠加**递归去噪**：文化传承是"LLM 生成 → 下一代输入 → 再生成"，与模型崩溃的动力学结构完全一致（Shumailov et al.：**tails of the original content distribution disappear**）。
- **最早症状**：**隔离-分化检验**的回归斜率不显著为正（物理隔离没有增大文化距离）；文明间文化距离矩阵的总方差随时间下降；团队讨论里出现"这个世界太平淡了，要不要加点事件"。
- 对抗手段：B10（熵监控双向）、B21（文化 = 结构化基因组 + 数值通道白名单）、A23（切断文本递归回流）、B5（组合新颖度作为项目层能力指标）。

**#12 · Sid 病：制度名词搬运，被当成最大的成功**
- 预测者：`prior-art-postmortem §6.6/§1.15`、`pseudo-simulation S2/S5`、`llm-storytelling F3`。
- 机制：LLM 的训练语料里塞满了宪法、投票、税制。**当一个 LLM 世界"涌现"出与人类现代制度同名的东西时，最简约的解释是复读，不是演化。** 而 `llm-storytelling F3` 补上了更隐蔽的一层：即使名字由世界内引擎生成，**渲染成汉字的那一刻语义就回来了**。
- **最早症状**：世界里出现与人类制度同名的东西，而追溯其诞生事件时前置条件只有"某人提出了这个想法"；量化指标 —— "人类历史上不存在的制度组合"占比接近 0；结构指纹探针中一个干净模型能高置信地说出"秦"或"商"。
- 对抗手段：A24（命名权收回 + 音译表）、A15（原语准入 + 禁止制度类一等对象）、B21、C11（prompt 渲染期 lint）。

**#13 · 隐式 storyteller 藏在 LOD、`should_call_llm()`、信息推送与 CI 断言里**
- 预测者：`pseudo-simulation S8/S9/S11`、`prior-art-postmortem §6.7/§1.11`、`computational-feasibility S1`。
- 机制：四个藏身处，**全部看起来像工程卫生** —— (a) LOD 跟着"有意思"走，而分辨率会改变结果（个体层有方差与尾部事件，队列层数学上不可能有，于是这是一条正反馈，**在机制层面制造主角且不留代码痕迹**）；(b) `is_significant()` / `should_call_llm()` 的阈值被反复调整直到输出好看；(c) 信息在剧情需要它到达的时候到达（而它会通过第 4 条的审查）；(d) CI 上的宏观断言 —— **它把"结果不对"自动转化为红色失败，从而把人手梯度下降自动化、日常化、并赋予道德正当性**。
- **最早症状**：LOD 调度器 import 了事件系统；测试文件里出现以模拟年份为条件的期望值；重大事件在高 LOD 区域的密度显著高于人口/资源所能解释的水平。
- 对抗手段：A17（提升函数只读结构量 + lint）、B28（LOD 一致性 + 两条极端对照线）、A31（信息是被运输的物质对象）、C5（CI 只允许断言不变量）。

**#14 · Seshat 病 / 长跑期间改机制 / Paradox 病（三条并列的慢性病）**
- **Seshat 病**（`prior-art-postmortem §6.9`、`pseudo-simulation S6`）：校准集本身被"缺失 = 不存在"污染，我们把记录偏差学成历史规律。**最早症状**：状态库里没有三值逻辑（A14）。
- **长跑期间改机制**（`mandate-contradictions F9`）：物理定律会变的世界。**最早症状**：`git log` 里出现第一条 `fix:` 提交，其时间戳落在某条长跑的运行区间内；无法回答"这条历史线是用哪一版内核跑的"。
- **Paradox 病**（`prior-art-postmortem §6.5/§1.12`）：路径依赖退化成浮点修正值堆叠，"历史感" = 数值噪音；且有恶性反馈 —— 修正值越多设计师越难预测结果，就越倾向于加脚本事件"确保历史大致对"。**最早症状**：状态里出现第一个名为 `stability`/`legitimacy`/`prosperity` 的裸浮点字段。
- 对抗手段：A14、B27、C12、A32。

### 6.1 一句话总判断

七份审查在一件事上完全一致，值得原样保留 —— `prior-art-postmortem §6` 的收尾：

> 前人失败的共同模式不是想错了，而是**没有为自己的核心主张准备一个能证伪它的实验**。Anasazi 没有零模型，Qud 干脆放弃因果，Sid 没有区分涌现与复读，URR 没有范围的负空间。因此 Phase 0 的真正任务不是回答那 13 个待答问题，而是**为其中每一个问题写出对应的"如果我们错了，会在哪个指标上看出来"**。

这张登记表的 80 条里，超过一半（B 档与 C 档的绝大多数）的本质就是这件事的具体化：为每一条主张配一个能证伪它的观测。
