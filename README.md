# civilization-sim

一个以东亚地理的统计与拓扑性质为舞台的**自主文明模拟系统**。从前文明期开始，让人口、聚落、资源、气候、技术、经济、贸易、战争、制度、阶层、宗教、文化、人物与偶然事件相互作用，自主演化数千年。

产物不是一部小说，而是**一个可查询、可重放、可分叉、可做反事实实验的历史数据库**，以及一套能说明"这段历史为什么可信"的证据。

真实中国历史只作研究、建模与合理性校准的参考，**不作剧情模板**。这个世界拥有自己的历史。

## 原版 M1（已被取代，保留作参考）

不是"跑一个像样的世界"。M1 是**一个只有 6 个机制的内核，跑在三张小地图上，能通过全部二值结构检验，能在每一个对应的"毒药构建"上失败，并且用实测数字替换掉当前预算表里的每一个 D 级乘数**。

这个反直觉的次序来自验证规格：**先实现度量 → 再用假货把度量测一遍 → 然后才实现世界**。因为一条从未失败过的检验等于没有检验——未标定判据的证据量 ≤ 0。所以 M1 的真正交付物是那批毒药：把实体 id 改回全局自增计数器、在热路径插一个 `f64` 累加、插一行 `if label_of(cell)=="c:cluster" { forage_yield *= 1.05 }`、给产出加一个 `max(0,x)`——**毒药上不红的检验，删掉，不许辩护**。

日历：签字冲刺 1 周（四份各一页的规范文本）+ 实现 6–8 周。**如果第 3 周结束时 `main` 还跑不到 t=3000，砍机制，不砍里程碑。**

## 三句话概括这个项目的立场

**1. 涌现意味着内核里没有"国家"这个类型。**
内核只承认物质与能量存量、人、位置、关系边、信息副本。"国家""宗教""王朝""阶级"只存在于观察层的检测器和 agent 头脑中的信念里。一个内核原语只有在定义不引用任何制度时才被允许——"征税"不合格，"以暴力威胁索取资源转移"合格。

**2. 因果是测量出来的，不是声明出来的。**
世界里没有一个字段叫"原因"。因果边只能由运行时数据流自动采集或由干预重放测量得到；LLM 对因果图的写权限恒为零。代价是：一个"为什么"的严肃回答要花小时到 CPU-天，而且大部分"为什么"的正确答案是"在这个观测量的因果视界之外，不可归因"。

**3. 我们预先写下了自己会怎么失败。**
排在第一位的失败模式不是代码写错，而是**人类回路**：跑 400 个种子只展示好看的 5 个，反复调参到"像样"。代码层的全部防御——涌现认证、消融测试、空模型对照——对这条通道完全免疫。所以有运行登记表、预注册抽样规则、参数改动分类账。

## 一条已查实的教训

Artificial Anasazi 是这个领域最著名的 agent-based 历史模拟之一。Janssen 2009 的复现分析发现：**一个零 agent 行为的纯外生承载力空模型，误差只比原 ABM 高 10–50%，且两个模型的最优参数完全相同**——原文的结论是该 ABM"只起了平滑函数的作用"。它的拟合主要来自两个调节承载力的参数和一条外生降水序列。

这决定了本项目的一条内核级要求：**空模型支配测试与外生序列置换检验必须是内核的一部分，而不是事后分析。**

## 这个项目可能不成功

它有明确的、预先写下的失败条件（宪法 §5.1），也有明确的合法失败结果——**"世界什么都没发生"是一个合法的科学结果**。真实世界里这本来就是最常见的结果：到公元前 500 年已有农业的地区，23% 到公元 1500 年仍无宏观国家；从农业到国家的平均时滞约 2000 年。
