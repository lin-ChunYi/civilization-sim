# exp02/ —— 资源再生波动实验

由 `exp01/verify.py`（冻结基线 `20da486`）复制并**只加一个机制**：每格再生量的年际波动。
**这不是气候模型**，是一个受控的资源扰动源。规格见 [`../docs/EXP-02-SPEC.md`](../docs/EXP-02-SPEC.md)。

`exp01/` 只读，本轮零改动。基线对照读取冻结版本，不把基线改成能通过的样子。

```
verify2.py     引擎（基线复制 + 波动 + 资源账 + 两个新注入开关 + 两个定向场景）
run_tests.py   正确性测试 C1–C10。必过项失败 => 退出码 1
run_scan.py    观察扫描。只报告现象，不判定通过与否
TESTS.txt      正确性测试的完整输出（上次运行）
SCAN.txt       逐种子原始结果 + 汇总 + B1 判读（上次运行）
```

## 怎么跑

```bash
cd exp02
python3 run_tests.py ; echo "exit=$?"     # 正确性，必过项失败返回 1
python3 run_scan.py                       # 观察扫描，约 40 秒
```

无依赖，Python 3.9+。种子 `[0, 12345, 777, 4242, 99, 31337, 2026]`，`SIGMA_M ∈ {0,100,200,400,800}`。

## 这次得到了什么

**正确性 10/10 通过。** 其中三项是这轮新加的：

- **C6 资源格遍历逆序不变** —— 旧的 `revorder` 只改群体遍历，管不到资源格的随机数次序，所以必须单独测。
- **C7 退化恒等** —— `SIGMA_M=0` 时用**基线自己的哈希函数**判定，7 个种子逐位相同；同时 `run_id` 必须与基线不同（新参数进了指纹，这是正确行为）。这条同时也验证了"从基线复制的代码没有漂移"。
- **C10 坐标寻址** —— 健康版正序/逆序得到同一个 `(tick,cell)→z` 映射；`poison-climate-seq` 下 144/144 个 `(tick,cell)` 全部错配。

**核心假说没有成立。** 预注册的方向是"误判率随波动上升"，实测是 1.54% → 1.33% → 1.46% → 1.00% → 0.93%——总体下降，中间还不单调。按事先说好的处置：**不调参追曲线，也不宣布找到了另一个原因。**

## 不要拿它做什么

- 不要把全知对照臂的"误判 0%"当成福利收益——那一部分是选择规则的定义带来的。
- 不要把资源总量的变化全部解释成信息效应——"被容量挡"占了计划量的 66%–72%。
- 不要外推性能或参数；8/9 假设仍是 D 级，仍无外部标定目标。
- 不要认为 EXP-01 的已知限制被修了——迁移损失恒为零、默认样本无灭绝，全部原样继承。
