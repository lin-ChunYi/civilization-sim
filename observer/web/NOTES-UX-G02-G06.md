# 非阻塞 UX（G02 / G06）

记录于 G01_R1 返工，不在本轮改行为。

## G02 沙盘 / 顶栏
顶栏把原始参数串（SIGMA_M / MOVE_MORT_M / SHARE_M / AID_M / RECIP_M）和技术路径挤在 HUD 里，和「第几年 / 多少人 / 发生了什么」抢注意力。后续把参数收进可展开的技术条，HUD 只留回放年、人口、群体、事件、运行状态。

## G04 群体档案
回放第 124 年时 `loadBand` 仍展示完整终局轨迹（可含 125/131）。没有「截至当前回放年 / 全历史」模式，容易把未来迁徙当成当年已知。后续档案应明确两种范围，默认不要混用。

## G06 创建流程
「开启优先回助（1000）」在 AID_M=0 时仍没有援助预算，优先回助不会发生。不要暗改 AID_M。应明示依赖（优先回助需要 AID_M>0），或提供可见的成套预设（例如援助+回助一起开），由用户点选。
