# G02 两套视觉方案

同一套数据、同一 64 格邻接。区别在空间层次与群体符号，不只是换色。

## 主页面（沙盘棋子，默认 `/`）
- 布局：紧凑 HUD + **地图占视口主体** + 右侧卷宗/档案/口径标签轨。
- 群体：圆形棋子；缩放后才出现人口与名称。
- 格子：默认不贴满数字，悬停/放大才读资源。
- 选择：沙盘优先，方法学进「口径」。

## 实验室（指挥台，`/static/index.html?skin=console` 或 `/static/visual-lab.html`）
- 布局：三栏（卷宗 | 地图 | 档案），更像策略 HUD。
- 群体：菱形棋子、青冷描边。
- 不在终端默认页放切换按钮。

## 选择依据
主页面更解决「地图不在首屏 / 左栏方法学挤掉事件」的真实体验问题，放大后细节仍在。指挥台适合对照截图与桌面宽屏情报工作。

颜色只表示所选图层的相对量，**不是地形高度或山脉**。屏障列仍是不可通行格。
