# exp04/ —— 同格信息交换

由 `exp03/verify3.py`（冻结基线 `6b6af4f`）复制并**只加一个群体间互动机制**：
同一格上的参与群体交换各自对邻格的资源记忆。规格与结果见
[`../docs/EXP-04-SPEC.md`](../docs/EXP-04-SPEC.md)。

`exp01/`、`exp02/`、`exp03/` 都只读，本轮零改动。三条退化恒等式各自用对应基线**自己的**哈希判定。

```
verify4.py     引擎（EXP-03 复制 + 交换相位 + 信息账 + 交换记录 + 六个注入 + 定向场景）
run_tests.py   正确性 E1–E14。三态结果 PASS/FAIL/UNCOVERED；有 FAIL 则退出码 1
run_scan.py    112 次观察扫描（300 年）。只报告现象，不判定通过与否
TESTS.txt      正确性完整输出（上次运行）
SCAN.txt       112 行原始整数账 + 交换统计 + 结果读数 + 三个假说的原始数字
```

## 怎么跑

```bash
cd exp04
python3 run_tests.py ; echo "exit=$?"    # 约 25 秒
python3 run_scan.py                      # 约 9 秒，112 次运行 × 300 年
```

无依赖，Python 3.9+。种子 `[0,12345,777,4242,99,31337,2026]`，
`SIGMA_M ∈ {0,400}`，`MOVE_MORT_M ∈ {0,50}`，`SHARE_M ∈ {0,250,1000}`。

## 这次得到了什么

**正确性 15 通过 / 0 失败 / 0 未覆盖。** 六个注入全部实测会红；其中 `sharediag` 在长跑上空转，
挂到定向场景才承重。

**G2 成立**：信息确实变新了（平均陈旧度降到原来的 1/2 ～ 1/3）。
**G3 不为 0**：交换确实改变过迁移目标（四个组合里都有）。
**G1 与预想相反**：共享得越多，记忆臂的缺粮强度离全知臂**更远**，末人口更低。
这是一个**如实保留的否定读数**，不调参去追，也不给它编一个"看起来合理"的机制解释——
那需要专门的定向实验，本轮没有做。

## 结论边界

- 本实验**不检验**"信息共享是否有益"这个总体命题，只检验"新增同格信息交换如何改变
  这套固定规则下的人口、缺粮、迁移与信息新鲜度"。
- **交换记录是可核实的**：每条采纳都能在交换前快照里找到同源（值与时戳都对得上），
  来源与接收者当时同格。不用任何模型补编。
- 长跑与定向场景的分工照旧：长跑覆盖不到的路径（诊断回灌、决策改变）必须有定向场景，
  年数不够时如实记未覆盖。
