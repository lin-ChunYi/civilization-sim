# exp05/ —— 同格食物援助

由 `exp04/verify4.py`（已审阅版本 `68015cc`）复制并**只加一个机制**：同一格内，有余粮的群体
把一部分食物援助给当年缺粮的群体。规格与结果见 [`../docs/EXP-05-SPEC.md`](../docs/EXP-05-SPEC.md)。

**这是写死的援助规则，不是涌现**：本切片不宣称出现了合作、道德或制度。

`exp01/`～`exp04/` 都只读，本轮零改动。`AID_M=0` 逐 tick 复现 EXP-04（用它自己的哈希判定）。

```
verify5.py     引擎（EXP-04 复制 + 援助相位 + 援助账 + 逐笔记录 + 六个注入 + 定向场景）
run_tests.py   正确性 F1–F13。三态结果 PASS/FAIL/UNCOVERED；有 FAIL 则退出码 1
run_scan.py    42 次配对扫描（300 年）。只报告现象，不判定通过与否
TESTS.txt      正确性完整输出（上次运行）
SCAN.txt       42 行原始整数账 + 援助统计 + 结果读数 + 同种子配对比较
```

## 怎么跑

```bash
cd exp05
python3 run_tests.py ; echo "exit=$?"    # 约 25 秒
python3 run_scan.py                      # 约 4 秒，42 次运行 × 300 年
```

种子 `[0,12345,777,4242,99,31337,2026]`，`SIGMA_M ∈ {0,400}`，`MOVE_MORT_M=50`，
`SHARE_M=1000`，`AID_M ∈ {0,250,1000}`。

## 这次得到了什么

**正确性 13 通过 / 0 失败 / 0 未覆盖。** 六个注入全部实测会红，但其中四个只在**定向场景**里承重：
自然运行 200 年只有 17 笔援助，"供不应求"只出现 5 个 tick，按比例摊分 / 转赠 / 超预算这些路径
在长跑上基本不被走到。

**援助确实在发生**（7 种子 300 年：170–438 次活动、247–619 笔转移，覆盖参与格缺口的 20%–61%），
但**末人口与累计人年随 AID_M 上升而下降**，逐种子方向并不一致。
按事先约定，**"援助一定增加长期人口"不设为必过结论**，这个不符合预想的读数如实保留，
不调参、不制造灾荒去强行触发。本轮也**没有分离**援助的直接效果与它触发的连锁。

## 结论边界

- 不宣称涌现出合作、道德或制度；规则是写死的。
- 不能从这些读数说"援助有害"——直接效果与连锁效应没有分离。
- 逐笔记录可核实：谁给谁、哪一格、哪一年、多少 kcal，都来自模型自己的 `aid_log`。
