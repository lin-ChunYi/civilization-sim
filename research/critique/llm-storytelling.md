## 0. 总判决

**纲领第 5 条把 AI 与规则的边界画在了错误的位置；而纲领 Phase 0 第 9 问（"如何防止模型为了戏剧性制造事件"）连要防的东西都设错了。**

两句话说完这份审查的主干：

**第一，边界画错了。** 第 5 条保护的是 `P(结果 | 事件发生)`——战争打起来之后谁赢，由规则算。它完全没有保护 `P(事件发生)`——战争打不打得起来，以及一年里到底"有没有事"。可是决定一部历史长什么样的，主要是后者。三千年里战争的**频率、时机、由谁挑起、以什么名义**，比任何一场战争的胜负都更决定这个文明的形态。纲领把这一整块交给了 LLM，然后要求规则把胜负算准——这就像严格校准了骰子的公平性，却让一个有偏好的人决定什么时候掷骰子、掷几次。更糟的是，第 5 条在同一句话里还送出了另外两样东西：**解释**和**文化创造**。解释权是因果链的写入权，交出去等于第 2 条自动失效；文化创造权是命名权与语义权，交出去等于第 7 行（"这个世界应该拥有自己的历史"）自动失效。

**第二，也是本轮最重要的一条：威胁模型的方向很可能是反的。** 纲领（以及本视角的标题）预设的失败模式是"LLM 会为了戏剧性编故事"。项目的 LLM 简报做了两轮检索，**没有找到任何直接测量 LLM"戏剧化倾向"的文献**（`llm-agent-social-simulation.md` §10 第 12 条，D 级）。能找到的全部实证都指向**相反方向**：

| 现象 | 数字 | 来源 | 等级 |
|---|---|---|---|
| persona agent 群体的分布坍缩 | 集中度 0.36→0.69，熵 1.46→0.77，TVD 0.44，**85% 的场景发生坍缩**；行为任务里约 **80% 的 persona 默认选同一个（最便宜的）选项** | Ozkan 2026, arXiv:2607.18310（2,414 名真实 WVS 受访者为底） | **C**（单作者预印本，未见复现） |
| 人类偏好数据的 typicality bias 导致 mode collapse | 标注者以 **51.6–60.8%** 的比率偏好"典型"回答；引入多样性采样后创意写作语义多样性提升 **1.6–2.1 倍**（反推：直接提示只有 1/2–1/1.6） | Verbalized Sampling, arXiv:2510.01171 | A |
| 生成式 AI 提高个体创造力但**降低集体多样性** | AI 辅助的故事**彼此更相似** | Doshi & Hauser 2024, *Science Advances*, doi:10.1126/sciadv.adn5290 | A |
| RLHF 显著降低输出多样性 | "significantly reduces output diversity compared to SFT" | Kirk et al., arXiv:2310.06452 | A |
| 合成调查响应方差显著低于真实调查 | — | Bisbee et al., *Political Analysis* | A |
| 前沿助手一致存在的迎合（sycophancy） | 5 个前沿助手 | Sharma et al., arXiv:2310.13548 | A |
| agent 对负面社会线索的从众性**强于**真实人群 | — | OASIS, arXiv:2411.11581 | A |

**这一整列证据说的是同一件事：LLM 会把世界写得更平淡、更典型、更趋同，而不是更狗血。** 真实历史里的戏剧性事件恰恰是**非典型**的，而典型化偏置会**删掉**它们。

这件事有一个直接的、代价很高的后果：**如果我们按"防戏剧性"来设计防御，我们会把防御装反。** 抑制事件率、惩罚巧合、给尾部设上限——这些手段全都在**加剧**真正会发生的失败（世界太平、文明雷同、尾部消失），同时对真正的污染（基率被提示词决定、因果链被合理化、名字与观念是中国史的复读）毫无作用。

因此本稿把要防的东西重新表述为一句可执行的话：

> **要防的不是"戏剧性"，是"任何系统性偏置进入不该由它决定的量"。** 我们不需要先证明 LLM 偏向戏剧，才有理由不让它裁决——只要它有**任何**方向的系统性偏置（而上表证明它至少有五种），把"事件是否发生"交给它就等于把这个偏置注入成一棵隐藏剧情树。同时，我们必须把"世界太合理、文明太雷同"当作与"世界太狗血"**同等级别**的 bug 来监控。

**第三，一个必须现在就说清楚的元判断。** 按纲领现在的写法做出来的系统，最可能的形态是：**一个规则算得很准的世界，穿着一部 LLM 写的历史**。而且这件事在**单个事件层面完全看不出来**——每一个事件都有完整的因果链，每一场战争的胜负都是规则算的，每一次抽查都通过。污染只在**分布层面**可见，而纲领目前没有任何一条要求我们去看分布。

下面是 26 条发现，按"不改一定失败 / 会长期腐蚀 / 可接受但要标价"分级。

## 2. 边界重定义 v2：测度归规则，**分布**归 LLM，采样归我们的 PRNG

纲领第 5 条的"AI 不能直接决定客观结果"是**不可判定的**：`战争爆发` 本身就是一个客观结果（见 §5 矛盾 C1）。R1 提出的替代是"测度归规则，**选择**归 LLM"——即规则生成有限选择集与先验 `π`，LLM 挑一项，把 `−log₂ π(a*)` 记为叙事比特。

**〔R2 推翻 R1〕这个方案方向对，但形式错了，而且错得很关键。让 LLM 输出一个"选择"是三重损失：**

1. **反事实不可识别。** 本项目的反事实协议（`provenance-replay-counterfactual.md` M8）用 Gumbel-max SCM 做 abduction：从"观察到的离散选择"反推"当时的噪声"，再在干预后的世界里复用同一噪声。这套方法**要求你知道当时的类别分布**。LLM 只吐一个 token 序列，你既没有它的完整 logits（当前 Anthropic 前沿模型连 `temperature`/`top_p`/`top_k` 都已移除，传入返回 400，也没有 `seed` 参数——`llm-agent-social-simulation.md` §M5，B 级），也没有它在这个选择集上的分布。**于是所有经过 LLM 的决策点，在反事实里都是不可识别的洞。** M8 的 abduction 步骤会静默跳过它们，而没有人会注意到，因为流程照跑不误。
2. **偏置不可测。** 单点选择只有"选了什么"，没有"多想选它"。要检出 Ozkan 式的分布坍缩（熵 1.46→0.77），你必须能观测**熵**。从一串单点选择里估熵，需要在同一个（粗化后的）状态上有几百个样本——而本项目的每个决策点在历史上只出现一次。
3. **指标是单边的。** `−log₂ π(a*)` 只惩罚"选了先验认为不该选的"。一个永远选众数的 LLM 得分是 **0 比特**，看起来完全清白，而它恰恰是坍缩最严重的情况（80% 的 persona 选同一个选项，Ozkan）。R1 的核心指标对本项目最可能发生的失败**完全失明**。

**替代形式（本稿的核心架构主张）：**

> **规则**生成选择集 `A(state)` 与先验 `π(·|state)`。
> **LLM** 输出的不是一个选择，而是**该选择集上的一个概率分布** `p_LLM(·|view)`（verbalized sampling 形态：让模型显式给出每个选项及其概率）。
> **我们自己的 counter-based PRNG**（`provenance-replay-counterfactual.md` M2）从 `p_LLM` 采样，得到实际动作。
> ledger 记录 `(view_hash, model_id, p_LLM, rng_counter, a*)` 四元组。

这一个改动同时买到六样东西：

| 得到什么 | 为什么 |
|---|---|
| **反事实可识别** | 有了类别分布，Gumbel-max abduction 直接适用（Oberst & Sontag，A 级）。LLM 决策点不再是洞。 |
| **采样确定性** | 掷骰的是我们的 PRNG，不是模型。满足纲领第 6 条"记录随机种子"的字面要求，而 R1 方案不满足。 |
| **偏置双向可测** | 污染量 = `D_KL(p_LLM ‖ π)`，两侧都罚。同时可以直接读 `H(p_LLM)`——坍缩、迎合、典型化全部现形。 |
| **熵成为一等运行指标** | Ozkan 证明未加干预时熵会塌；Verbalized Sampling 证明加了会**矫枉过正**（SD-ratio 从 0.4–0.56 翻到 1.26–1.37）。两边都是 bug，只有把熵监控起来才能校准。（C/A 级） |
| **"AI 能不能决定 X"变成可判定** | X 是一个测度或一次状态写入 ⇒ 永远不能；X 是在规则给定的选择集上给出一个分布 ⇒ 可以。不必再逐条辩论。 |
| **预算可执行** | 每世纪 `Σ D_KL` 有上限。超限只有两个合法处置：承认 `π` 错了（去改规则），或强制按 `π` 采样。**不允许第三种处置（"这次就算了"）。** |

**代价（必须标价）**：模型给出的自报概率不是校准的概率，Verbalized Sampling 论文自己就报告了矫枉过正。所以 `p_LLM` 必须先在**有真值的小场景**上做一次校准（温度式的重标定 `p^(1/T)` 归一化），校准曲线本身要进 Phase 0 的交付物。**没有校准的 `p_LLM` 只是换了个形状的偏置，不是解药。**

这条重定义应当直接替换纲领第 5 条的后半句。后文每一条修复都是它在某个具体通道上的落地。

## 3. 发现清单

### F1 ——【致命】提案权即基率决定权：纲领保护了条件分布，放弃了基率

**针对**：第 5 条「AI 可以决定发动战争，但战争胜负必须由世界模拟规则……计算」。

**失败机制**
设结构条件下真实应有的战争起始风险率为 `λ_true`。LLM 被问"你要不要打"时，它的答案不是从 `λ_true` 采样的，而是从"在这个语境下，一个被 RLHF 过的模型倾向于回答什么"采样的。当 LLM 每次被咨询就有 `p` 的概率给出行动型意图、而咨询频率由**工程预算**决定时：

```
事件基率 = 咨询频率 × p     ← 两个因子都与世界状态无关
```

三千年、每世纪咨询几百次，`p` 只要偏离 `λ_true` 20%，累积下来就是一个完全不同的文明。**而且每一场战争都会通过审计**：它有前置的资源缺口、有可追溯的因果链、胜负由规则算。污染不在任何一条因果链里，它在**因果链的数量**里。

关键在于**这条论证不依赖"LLM 偏好戏剧"**。方向可以是任意的，而且实证上互相矛盾：Park et al. 自述指令微调导致 agent **过度合作**（违背自身利益也答应请求，A 级）；OASIS 观察到 agent 对负面社会线索的**从众性强于**真实人群（A 级）；Gao et al. 在 11-20 money request game 上发现 LLM 无法匹配人类行为分布，且失败原因"与**输入语言**、角色设定、安全护栏有关"（A 级）。

最后这一条是最要命的：**基率是提示词措辞的函数，不是世界的函数。** 这比"LLM 偏好戏剧"严重得多——它意味着基率是一个我们无意中设定、又不知道自己设定成了多少的参数。

**可观察症状**
- **预算弹性实验（最便宜的一发子弹）**：同一世界种子，把 LLM 调用预算翻倍再跑一次。若事件密度跟着涨，**事件密度是预算的函数，不是世界的函数**。这个实验一天就能做，不需要等系统完整。
- **决策点级配对比较**（不是世界级对比，理由见 F6）：在 LLM-on 的运行里，每一个决策点上同时记录规则先验 `π` 与 `p_LLM`。统计各事件类上 `E[p_LLM(行动)] − π(行动)` 的符号与量级。系统性为正 = 基率被抬高，为负 = 世界被 LLM 抹平（后者按 §0 的证据更可能）。
- 事件间隔时间的分布形状：结构驱动的风险率过程会产生**过度分散**（over-dispersed）的间隔（丛集 + 长静默）；调用驱动的会产生接近几何分布的间隔。这两者用 Fano factor 就能分开。

**替代设计**
1. **禁止把"要不要发生"问给 LLM。** 规则先用结构条件算出风险率 `λ = f(资源缺口, 军事不对称, 边界接触, 合法性, 后勤半径, 季节, 继承状态)`，掷骰决定"本 tick 出现一次开战机会"。**只有掷中之后才唤醒 LLM。**
2. LLM 拿到的不是"你要不要打"，而是规则生成的选择集 `{对 B 开战, 对 C 开战, 勒索 B, 结盟对抗 C, 不作为}`，输出的是这个集合上的分布（§2）。`不作为` 必须永远在集合里，且在绝大多数局面下先验最大（见 F22）。
3. `D_KL(p_LLM ‖ π)` 计入叙事预算。
4. **意图 schema 里不得含有连续量与绝对时间**（见 F23）。

### F2 ——【致命】解释权污染因果链：第 5 条与第 2 条正面冲突

**针对**：第 5 条「AI 可以负责人物和组织的判断、计划、**解释**、文化创造」 对 第 2 条「每一个重大事件必须保存可追溯的原因」。

**失败机制**
如果 LLM 参与生成"这件事为什么发生"，因果链就不是因果链，而是**事后合理化**。这不是推测，是被量化过的：Turpin et al.（arXiv:2305.04388，NeurIPS 2023，A 级）证明，把偏置特征注入输入（例如只是重排选项顺序），模型的答案会变，但它的 chain-of-thought **从不提及这个真正起作用的因素**，反而给出一套听上去很可信的别的理由；在 BIG-Bench Hard 的 13 个任务上，这种偏置能让准确率掉 **36%**，而解释始终自洽。

**换句话说：LLM 生成的解释与真实成因之间的关系，已经被实证为不可靠，而且失败时的表现形式恰恰是"更像样的解释"。**

在本项目里后果被放大三倍：
- **时间不对称**：如果解释在 `Resolve` 之后生成，模型已经看到了结果，它一定会构造一条通向该结果的叙事。这在定义上就是事后合理化。
- **不可证伪**：三百年后用户问"这个国家为什么灭亡"，系统返回一段读起来很有说服力的文字。用户没有办法分辨这段文字是从状态变量算出来的还是编出来的——**文字质量越高，越难分辨**。
- **词汇越界**：LLM 会写出世界里根本没有对应状态变量的原因（"民心尽失""气数已尽""腐败侵蚀了官僚体系"）。这些词一旦进入日志，就成了后续查询的答案，而它们背后什么都没有。

**可观察症状**
- **删字测试**：把任意一条因果链里所有 LLM 撰写的文本删掉，看剩下的结构还能不能回答"为什么"。答不了 = 我们一直在读小说。
- **词汇越界扫描**：抽取因果链文本里的所有名词与谓词，检查是否都能映射到世界状态 schema 的字段或已注册的 `mechanism_id`。命中率 < 100% 即污染。
- **双向合理化探针**：把同一个事件的世界状态快照喂给模型两次，一次告诉它"这个国家随后灭亡了"，一次告诉它"这个国家随后中兴了"，让它写原因。如果两次都写得很顺，解释通道就是纯粹的合理化机器。这个探针**现在就能做**，不需要任何模拟器。

**替代设计**
1. **因果图只能由规则写入，且必须是机器可判定的引用。** 每条因果边是结构化元组 `(effect_event_id, cause: event_id | state_delta, mechanism_id, quantitative_contribution, confidence)`。`mechanism_id` 来自**封闭注册表**，每个 id 对应内核里一个真实的规则函数；`quantitative_contribution` 由该函数在裁决时顺带产出（例如"后勤衰减贡献了 −0.31 的胜率"）。**LLM 对因果图的写权限恒为零。**
2. **动机是合法的原因，但必须 commit-before-resolve。** 人物的动机确实是历史的一部分。工程上：动机只能在**产生 Intent 的那一次调用里**产出，`hash(rationale)` 在 `Resolve` 掷骰之前写入 append-only 日志，裁决之后不接受任何新的 rationale。这一条把"事后合理化"在物理上变成不可能，而不是靠约定。
3. 〔R2 新增·建设性〕**给 LLM 一个合法的因果角色：提出可被消融检验的假设。** R1 的"LLM 绝对不许碰因果"是对的，但它把一个真正有用的能力也砍掉了：在一个有 10⁵ 个状态变量的世界里，"该检查哪个因子"本身是一个巨大的搜索问题，而 LLM 很擅长搜索。合法形态是：
   ```
   LLM 输出：hypothesis { candidate_cause: state_var | event_id, sign: +/−, magnitude_guess }
   规则执行：ablation run —— 分叉、抑制该因子、重放、测 ΔP(target_event)
   写入因果图的：ablation 的实测结果，不是 LLM 的话
   ```
   LLM 在这里是**启发式搜索器**，真值来自消融实验。它可以猜错一百次而不污染任何东西，因为它的输出不是答案而是待测项。**代价**：每个假设一次分叉重放，很贵——所以这只能用于"用户主动追问某个重大事件"，不能常设。这个代价必须在 Phase 0 的算力规划里留出位置。
4. **叙事文本另存为独立类型**：`in_world_narrative { speaker_entity_id, audience, produced_at_tick, text }`。它是第 9 条意义上的"世界内叙事"，不是世界事实；默认**不出现在因果链查询结果里**，要看得显式加参数，并带上"此为世界内某人的说法"的类型标记。
5. **硬指标**：`causal_purity` = 因果图中 LLM 撰写的节点与边的数量，**恒等于 0**，在 CI 里断言。

### F3 ——【致命】文化创造是最大的真实历史泄漏通道，而它是纲领自己批准的

**针对**：第 5 条「AI 可以负责……**文化创造**」 对 第 7 行「不需要出现真实历史上的夏商周、秦汉、三国、唐宋等朝代」与 第 24 行「形成**完全属于自己的**国家、民族、制度、宗教、文化」。

**失败机制**
LLM 关于"一个东亚季风河谷的农业君主制需要什么样的正当性叙事"的条件分布，**其众数就是真实的中国思想史**。不是它偷偷抄，是这就是它学到的东西。Durmus et al.（GlobalOpinionQA，A 级）已经实证了同源机制：用国籍 prompt 引导会让输出移动，但**有时移向的是刻板印象**；单纯把问题翻译成目标语言**不能**可靠地把输出移向该语言使用者的观点。Larooij & Törnberg 2025 的系统综述（*AI Review*, doi:10.1007/s10462-025-11412-6，A 级）把这个现象在 ABM 语境下命名了：**selection bias 与 data leakage——"LLM 可能复制历史模式，或复现既有研究结论，而不是动态生成行为"**。

可以预期的具体泄漏（这一段本身是 D 级推断，但**验证成本极低**，见下面的探针）：
- **概念**：要求它为一个王权编一套天授正当性，"天命"会以极高概率自发出现，连带"革命"（改换天命）、"德"、"礼"的整套语义网络。这不是巧合，这是条件众数。
- **构词法**：让它起国号/年号/谥号，产出的会是「玄」「昭」「靖」「烈」「大宁」「永昌」这一类——真实汉语年号的构词法，不是这个世界的构词法。
- **文体**：让它写经文，产出的是《论语》形状的格言体或《道德经》形状的悖论体。
- **现代观念偷渡**：让它写一位青铜时代先知的教诲，先知会讲平等、尊严、同理心、"我们都是一家人"。RLHF 把当代人道主义装进了模型的价值先验（Durmus 的"美国 / 部分欧洲与南美"倾斜是这一点的直接证据），它写不出一个真正陌生的道德体系。
- **书写层泄漏**〔R2 新增〕：即使名字由世界内音系引擎生成，**渲染成汉字的那一刻语义就回来了**。把 `/tavix/` 写成"塔维"是中性的，写成"天维"就把"天"的整套语义送了进去；国号一旦用汉字，选字本身就是一次不受控的文化创造。这一条 R1 完全没有注意到。

一旦这些进入世界，第 7 行就作废了——我们不是"没有复刻真实历史"，而是复刻了它最核心的那一层（观念史），只换了国号。

**可观察症状**
- **结构指纹可识别性探针**〔R2 新增，全文最推荐的一个探针〕：把一份**已经去掉全部专名**的世界状态摘要（地形、作物、人口、政体结构、技术组合）喂给一个**干净的**模型，问它"这最像真实历史上的哪个政体？"。记录它的 top-1 答案与置信度。**如果它能高置信地说出"秦"或"商"，那么去专名化根本没用**——模型是靠结构指纹而不是靠名字来召回剧本的，它后续的一切续写都会是秦形状的。指标：`real_history_identifiability = 1 − H(模型的政体猜测分布)/log N`。这个探针**在写第一行内核代码之前就能做**：手工造几个假想的世界状态摘要喂给模型即可。
- **困惑度下界检验**：用真实汉语古典语料训练一个**字符级 n-gram** 模型（刻意不用神经嵌入，理由见 F19），对生成的专名/经文计算困惑度。**困惑度过低 = 抄袭。** 设硬下界，低于它拒绝写入。
- **史学家盲测（方向要搞对）**：把 20 个世界生成的国号与 20 个真实年号混在一起。我们要的结果**不是**"分辨不出"，而是"能明确指认哪些不是中国的"。分辨不出就是失败。
- **无根教义比例**：每一条教义元素必须能指回一个真实的世界事件或状态变量。指不回去的比例就是污染率。

**替代设计**
1. **命名权从 LLM 手里彻底收回。** Phase 0 必须交付一个**世界内音系生成引擎**：每个原始语言给定音位库、音节结构（CV / CVC / 声调有无）、音位配列约束、构词形态（复合、派生、重叠）、以及**随时间演化的规则音变**。名字从这里用世界 RNG 采样。附带的巨大好处：语言谱系、同源词、借词层次全都是**规则自然产出的真实路径依赖**（第 3 条），而且 LLM 造不了假。
2. **LLM 在任何 name 字段里不得输入自由文本**，只能引用已存在的 `entity_id`；渲染层负责替换成名字。schema 级强制：name 字段类型为 `EntityRef`，不是 `string`。
3. 〔R2 新增〕**书写层必须有明确策略。** 世界内专名的规范形式是**音位串**（用一套中性的拉丁转写）。汉字渲染只是一个**可选的展示层**，且转写用**固定的音节→汉字表**（一次性人工选定语义最中性的字），**不允许模型逐个挑字**。这个音译表是 Phase 0 的交付物之一。
4. **教义不是文本，是结构化对象。** 一个宗教 = `{仪式频率与成本, 亲属规范, 食物禁忌, 洁净观, 权威来源, 来世观, 内群体边界, 禁令列表}`，其中每条禁令必须指向一个真实的世界状态变量（"禁止在雨季迁徙"指向气候与农时），每个起源神话槽位必须填入一个真实记录在案的 `event_id`。这套结构由**文化演化规则**生成（项目已有 `cultural-evolution.md` 简报），LLM 只负责把结构**口语化成文本**。
5. **允许 LLM 参与的唯一文化任务是"措辞"（verbalization），不是"创造"（authoring）。** 这一区分应当写进纲领第 5 条。——但注意 F10：措辞本身也不是无损的，这条边界比听上去窄。

### F4 ——【致命】反事实在 LLM 参与下不可识别；这不是重放问题，重放已经解决了

**针对**：第 6 条「记录随机种子，以便重放和进行反事实实验」 与 第 24 行「可以进行"如果当时没有发生某件事"的反事实实验」。

**失败机制（三层，第三层是本轮新发现的那层）**

*第一层：重放。* **已解决，不必再争论。** 项目 `provenance-replay-counterfactual.md` M5 的方案是对的：LLM 输出作为"被记录的外生输入"，内容寻址存储，**重放时永远从记录读、绝不重新调用**。相关事实：温度 0 不保证确定性（Ouyang et al.：零匹配输出比例 CodeContests 75.76% / APPS 51.00% / HumanEval 47.56%，A 级）；根因是推理内核缺乏 batch invariance；模型版本会静默漂移（Chen, Zaharia & Zou：GPT-4 质数判定 84%→51%，A 级）；且当前 Anthropic 前沿模型**已移除 `temperature`/`top_p`/`top_k`，也没有 `seed`**（厂商文档，B 级）——连传统的伪确定性手段都不存在了。结论：不可能通过重新调用模型来重放历史，只能读账本。

*第二层：反事实的模型漂移混淆。* ledger 解决不了它。反事实的定义就是**改变过去**；改了过去，下游 LLM 调用的 prompt 就变了，ledger cache miss，必须重新调用——而重新调用发生在几周或几个月后的另一个模型版本上。于是「移除事件 E」的处理效应与「模型 v1→v2 漂移」的效应**在同一次实验里完全混淆，且后者效应量未知、无界、不可控**。M5 的策略 2（replay-until-divergence）把重新调用的数量降到"被波及的 agent × 被波及的 tick"，这是正确的成本优化，但**它不改变混淆的性质**：只要有一次 fresh 调用落在漂移后的模型上，那条分支就被污染了。

*第三层〔R2 新增，致命的那层〕：LLM 决策点在 abduction 里是识别洞。* M8 的反事实协议第 3 步是 abduction：用 Gumbel-max 后验（Oberst & Sontag，A 级）从观察到的离散选择恢复噪声。**这一步对 LLM 决策根本不适用**——你没有它的类别分布，无从计算后验。实际发生的事情会是：实现者要么静默跳过这些点（等于对每个 LLM 决策做了 fresh 重采样，噪声不共享，反事实的方差爆炸），要么直接冻结（frozen 策略，agent 在明显不同的世界里做出事实世界的决定，产生不连贯）。**两种都不是反事实，而且日志里看不出区别。**

*第三层的推论〔R2 新增〕：prompt 的数值精度控制着蝴蝶效应速率。* M5 策略 2 的复用边界是"prompt 的 canonical form 逐字节相同"。这意味着：
- 如果 prompt 里写"粮储 4.2 万石"（两位有效数字），一个微小的反事实扰动会被**舍入抹掉**，agent 复用旧应答 ⇒ 反事实被**静默阻尼**，我们会得出"这个干预没影响"的错误结论。
- 如果 prompt 里写"粮储 42,183 石"，任何扰动都会立刻传播到所有人 ⇒ 每个 agent 都 cache miss ⇒ 反事实**立即爆炸**，且成本 = 全量重跑。

**也就是说，反事实实验的核心科学性质（干预的传播速度）被一个纯粹的渲染格式决定了，而这个格式多半是某个人随手写的 `f"{x:.1f}"`。** 这是本轮最让我不安的一条，因为它完全不可见。

**可观察症状**
- **空反事实检验（必须成为常设指标）**：在时刻 `t` 分叉，**什么都不改**，重跑。测量两条线在 500 年后的散度（人口、政体数、边界、文化距离）。这就是噪声地板。任何反事实结论必须与噪声地板一起报告；若 `效应量 / 噪声地板 < 3`，该结论无效。
- **首次分歧点分布**（M8 已建议，本稿加一层用法）：把 prompt 渲染精度作为自变量（1、2、4 位有效数字各跑一组），画首次分歧点的分布。**如果这三组的分布明显不同，就证明了"科学结论是格式的函数"**，必须把精度选择当成一个需要论证的设计决策而不是实现细节。
- 同一个反事实隔一个月做两次。若两次反事实之间的散度 ≥ 各自与基线的散度，反事实机器测的是模型版本，不是因果。

**替代设计**
1. **让 LLM 输出分布（§2）。** 这一条同时修复第三层：有了 `p_LLM`，Gumbel-max abduction 直接可用，LLM 决策点不再是识别洞。**这是把 §2 列为核心架构主张的首要理由。**
2. **双通道，科学结论只走确定性通道。** 每一次 LLM 决策，规则侧必须同时产出一个**确定性代理决策**（默认策略）。带因果主张的实验一律在 `surrogate mode`（LLM 通道全关）下运行，世界完全确定。这要求：**世界在 LLM 完全不可用时必须能自己跑完三千年**——这条应当作为架构硬约束写进纲领。
3. **策略表物化 + 粗化函数**：LLM 的输出不是"这一次的决定"，而是"在这一类局面下的分布"，以**粗化后的 View 签名**为键缓存。粗化函数（哪些量分桶、桶多宽）是 Phase 0 的核心交付物之一，**不是实现细节**——它同时决定了 cache 命中率、反事实的传播速度、以及所有污染指标的样本量。
4. **凡是写入世界状态路径的模型，必须本地部署、权重冻结。** 这是昂贵的基础设施决定，它排除了托管的前沿 API。必须在 Phase 0 做——一旦第一条正式历史线用托管 API 跑出来，它就永久失去了可反事实性。
5. 纲领第 6 条应改写为："随机种子**与所有非确定性外部调用的输出**都必须记录；且世界必须存在一个完全确定的运行模式，带因果主张的实验只在该模式下进行。"

### F5 ——【致命】〔R2 推翻 R1〕"LLM 只从选择集里挑一个"不足以隔离污染

**针对**：第 5 条，以及 R1 自己提出的修复方案。

**失败机制**
见 §2 的完整论证。摘要：单点选择使 (a) 反事实 abduction 失效，(b) 熵不可观测（Ozkan 式坍缩检不出来），(c) 污染指标单边（永远选众数 = 0 比特 = 看起来最干净，实际最坏）。

**多一条 R1 没看到的**：单点选择还把"我们的 PRNG 掷骰"这一步取消了，于是纲领第 6 条"记录随机种子以便重放"在 LLM 决策点上**字面意义上不成立**——那里根本没有种子，只有一次 API 调用。

**可观察症状**
- 在任何一条已经跑完的历史线上，尝试对某个 LLM 决策点做 Gumbel-max abduction。做不了，就中了这个坑。
- 统计 `p_LLM` 的熵（在改成分布输出之后）。若长期低于 `H(π)` 的一半，坍缩正在发生；若长期高于 `H(π)`，是矫枉过正（Verbalized Sampling 记录的 SD-ratio 0.4–0.56 → 1.26–1.37 那个方向）。

**替代设计**
§2 的三段式：规则给集合与先验 → LLM 给分布 → 我们的 PRNG 采样。外加一条纪律：**`p_LLM` 必须经过校准，校准曲线进 Phase 0 交付物**。

### F6 ——【致命】〔R2 推翻 R1〕LLM-off 孪生线不是有效对照；R1 把整套指标体系建在了一个坏分母上

**针对**：R1 提出的 `event_rate_ratio = f_on / f_off`，以及它"所有污染指标的分母都来自 LLM-off 孪生线"的主张。

**失败机制（两个独立的致命缺陷）**

*缺陷一：分叉之后两条线不是同一个世界，事件率不可比。* 这是一个路径依赖、混沌的系统——纲领第 3 条**明确要求**它是。两条线在分叉后几十年就会进入不同的状态：LLM-off 那条线可能压根没形成国家，那它的"战争频率"当然低，但这不能说明 LLM-on 那条线的战争频率被污染了。**`f_on / f_off` 在分叉几百年后测的是"两个世界有多不同"，而不是"LLM 注入了多少偏置"。** 更糟的是它有确定的方向性错误：任何让世界更复杂的机制都会同时提高几乎所有事件率，所以这个比值会系统性地把"LLM 让世界发育得更快"误报成"LLM 制造事件"，或反过来。

*缺陷二：控制组是我们自己写的，可以被拟合。* LLM-off 的默认策略是我们设计的，它的事件率就是我们调出来的。于是 `event_rate_ratio ∈ [0.8, 1.25]` 这个"阈值"检验的不是"世界有没有被污染"，而是"LLM 同不同意我们写的默认策略"。而在实践中会发生什么？**有人会去调默认策略，直到比值落进阈值。** 这时我们把对照组拟合到了处理组上，指标从此永远绿灯，而两条线可以同时是错的。

**可观察症状**
- 记录 `f_on/f_off` 随分叉后时间的曲线。如果它随时间单调发散，说明这个比值在测世界差异而不是测污染——一个有效的污染指标不应该有这个性质。
- 查 git log：默认策略的参数是不是在某次"指标不过"之后被改过。**这条要靠治理，不靠代码。**

**替代设计**
1. **把比较从世界级降到决策点级。** 不比较两个世界的统计量，而是在**同一条 LLM-on 的运行里**，每个决策点同时算出 `π`（规则先验）与 `p_LLM`，直接测 `D_KL(p_LLM ‖ π)` 与其符号结构。这是配对比较，不受世界发散影响，样本量等于决策次数（很大），统计功效高得多。这是 off-policy evaluation 的标准做法。
2. **第三条腿：外部经验校准。** 决策点级比较只能告诉我们"LLM 和我们的规则谁更极端"，不能告诉我们**谁对**。要回答后者必须有世界之外的锚：Seshat Global History Databank 提供 **49 个战争变量 / 17,536 条记录、3,439+ 条权力交接记录、357+ 条人祭记录、864 个政体**（站点核验），可以给出前工业政体的战争起始率、政体存续时长分布、权力交接方式分布等**分布级**校准目标。规则的 `λ` 与 `π` 必须对这些目标做拟合，**而不是对着 LLM 的行为或对着叙事好看程度调**。
3. **孪生线保留，但降级用途。** LLM-off 线仍然有用，但只用于两件事：(a) 空反事实的噪声地板（F4）；(b) 分叉后**短窗口**（比如 50 年内，尚未结构性发散）的分布对比。**不得用作长期指标的分母。**
4. **明确写下"控制组冻结"纪律**：默认策略一旦用于任何污染指标的分母，它的参数就进入版本冻结，任何修改必须开新的指标基线并说明理由。

### F7 ——【结构性】〔R2 新增〕`π` 的作者是我们：戏剧性没有被消灭，只是搬进了规则里，而且从此不可测

**针对**：第 9 行「不能因为"这样更有戏剧性"而发生」，以及 §2 / F1 的修复方案本身。

**失败机制**
§2 的整套架构把污染定义成 `D_KL(p_LLM ‖ π)`——**相对于 `π` 的偏离**。那么如果 `π` 本身是被编排的呢？

一个手工调出来的 `π`：让继承危机在王朝第三代高发，让边境冲突在饥荒后两年高发，让宗教运动在瘟疫后高发——每一条都"听起来很有历史感"，每一条都是我们从真实历史（或从我们对历史的印象）里抄来的叙事节拍。此时 `D_KL(p_LLM ‖ π) = 0`，**全部污染指标满分通过，而这个世界是被完全编排的**。我们只是把剧作家从 LLM 换成了自己，并且顺手取消了唯一能测出这件事的仪表。

这比 LLM 编故事**更难发现**，因为：
- 我们的偏置在代码里，代码看起来像物理；
- 没有基线可比——LLM 至少有一个 `π` 当参照，`π` 本身没有参照；
- 我们会把自己写的规则的输出当作"世界的自然行为"来验收。

**可观察症状**
- **参数-目标比**：数一数所有风险率函数、先验函数里的**自由参数总数** `P`，再数一数有独立外部经验目标（Seshat 分布、考古年代序列、人口史速率等）的**校准目标数** `T`。**如果 `P / T > 3`，这个模型是不可证伪的**，我们就是作者。这个数字应当出现在每一份模型文档的第一页。
- **参数溯源审计**：每一个参数必须标注 `justification_class ∈ {外部数据拟合, 理论推导, 量纲/守恒约束, 未校准(默认值), 叙事}`。统计各类占比。**`叙事` 这一类的允许数量是 0；`未校准` 的比例是模型成熟度的直接读数。**
- **改动动机审计**：git blame 每一次参数改动，看 commit message 里有没有"这样跑出来更像历史"这类理由。有就是 F18 的实例。

**替代设计**
1. **`π` 必须被拟合，不能被撰写。** 有外部数据的量（战争起始率、政体存续、城市规模分布、迁徙速率）一律对数据拟合；没有数据的量一律用**最大熵/无信息先验**，而不是"我们觉得合理的值"。
2. **`π` 的默认形状必须是惰性的。** 在没有结构性压力时，`π(不作为)` 应当压倒性地大。这不是保守，这是因为真实历史在记录层面绝大部分时间是无事的（F22）。
3. **禁止在触发器与先验里引用叙事节拍变量**："距上次大事件已 N 年"、"这个王朝已经三代了"、"这个文明太平稳了"——这些是伪装成工程条件的剧情树。写进 code review 检查清单。
4. **调 `π` 的人与看叙事的人必须分离**（见 F18）。

### F8 ——【结构性】提示词即世界观：纲领本身、以及项目自己的 22 份简报，都是污染源

**针对**：第 3 行「以中国及周边东亚地理环境为舞台」，以及**整份纲领用中文书写**这一事实。

**失败机制**
prompt 里的每一个词都是世界的先验。这不是修辞：Gao et al. 明确把 LLM 偏离人类行为的原因之一归为 **input language**（A 级）；Durmus et al. 证明**翻译不能可靠地移动模型的文化立场**（A 级），也就是说换语言解决不了，但**用中文一定会激活中国史区**。具体通道：

- **语言即先验**：只要 prompt 是中文，模型被激活的就是中文语料区。哪怕一个真实朝代名都不出现。
- **词汇即制度**：prompt 里写「部落」，世界就有部落；写「诸侯」，就有分封；写「官僚」，就有科层制。这些词自带整套真实制度语义，等于在世界演化出制度之前就规定了制度类型——直接违反第 1 条涌现。
- **地名即历史**：如果 agent 的 View 里出现"黄河""长江""关中"，我们就把整部中国史的地理叙事一起交出去了。地理是真实历史最强的共变量（`abm-methodology.md` §779 已把这条列为"geographic cue leakage"，并引 Larooij & Törnberg 的 data leakage 作为机制证据）。
- **纪年与时代标签即剧本**〔R2 新增〕：prompt 里出现任何绝对年份（"公元前 1200 年"）或时代名（"青铜时代""铁器时代""轴心时代"）都会召回整条教科书时间线。**技术必须用能力向量描述，不能用时代标签**："本地已掌握含锡合金铸造，未掌握块炼铁"，而不是"你们处于青铜时代晚期"。
- **元层污染**：告诉模型"这是一个文明模拟"，就把 Civilization 系列游戏、汤因比式大历史、"文明兴衰"的整个体裁装了进去。
- **最危险的一条：研究简报回流。** 项目已有 22 份、总量约 2.7 MB 的真实历史/考古/经济史简报。**只要其中任何一段文本进入运行时 prompt，这个世界就读到了自己的未来。** 这在工程上极容易发生——有人为了"让 agent 更懂农业"，把 `agriculture-carrying-capacity.md` 的片段塞进 system prompt，这个人不会觉得自己在破坏项目。

**可观察症状**
- **提示词改写敏感性检验（CI 常设）**：同一世界种子，用 3 份语义等价但措辞不同的 prompt 模板跑。比较制度类型分布、宗教结构分布。**若三者有统计显著差异，那么历史是提示词写的，不是世界写的。**
- **语言切换检验**：把 prompt 全换成英文 + 生造术语，同种子重跑。若制度形态发生实质变化，中文先验在主导。（注意 Durmus 的结论意味着这个检验只能检出污染，不能作为解药。）
- **构建期断言**：`grep` 渲染后的 prompt，命中 `research/briefs/` 里任何长度 ≥ 8 字的连续片段即构建失败。
- **F3 的结构指纹探针**同时也是这一条的检验。

**替代设计**
1. **世界内本体论隔离层。** prompt 里出现的每一个指称世界内事物的词，必须来自一个**封闭的、世界生成的术语注册表**（名字由 F3 的音系引擎产生）。制度不能用真实标签指称，只能用"世界内名字 + 结构描述"：不是「宰相」，而是「`Tavikh`：一个由 X 遴选、从 Y 抽取 Z、其正当性来自 W 的职位」。
2. **渲染期 lint，不是模板期 lint。** 对**最终发出去的 prompt 字节串**做黑名单检查（真实朝代名、天命/科举/封建等制度词、现代政治词、真实地名、绝对年份、时代标签）。命中即**拒绝发送并报错**。检查模板没用，因为污染是变量插值进来的。（黑名单本身的脆弱性见 F19。）
3. **地理去名化**：用东亚的地形/气候/水文栅格，但**剥掉所有真实地名**。这条要在数据导入阶段做，不能靠运行时过滤。
4. **构建期物理隔离**：`research/` 目录对运行时代码不可见（不同 package、CI 断言、依赖检查）。简报用来写规则，不能用来写 prompt。

### F9 ——【结构性】均质化：文明多样性会是假的，而且会随时间越来越假

**针对**：第 24 行「形成**完全属于自己的**国家、民族、制度、宗教、文化」，以及第 1 条涌现。

**失败机制**
所有 agent 跑在同一个基座模型上。人格差异只是覆盖在同一个先验上的一层薄提示词。§0 的证据表已经列了六条独立证据，其中最直接的是 Ozkan（C 级）：**85% 的场景发生分布坍缩，约 80% 的 persona 默认选同一个选项**，而收入档位这种强 persona 变量只能把这个比例调制到 0%→7%→32%。也就是说，**persona prompt 提供的异质性，其量级远小于它看起来的样子**。

后果：十个文明会产出十个**同一个宗教的变体**、十个**同一种科层君主制的变体**。表面上名字不同、细节不同，结构上是一个东西。

**更严重的是时间维度上的自我强化。** 文化传承在这个设计里天然是"LLM 生成的文本 → 下一代 agent 的输入 → LLM 再生成"。这**就是**模型崩溃的动力学。Shumailov et al.（arXiv:2305.17493 / Nature 2024，A 级）："use of model-generated content in training causes irreversible defects in the resulting models, where **tails of the original content distribution disappear**"。我们不训练模型，但递归生成-消费的循环结构完全一致：**每一代文化传承都是一次去噪，几百代之后所有文化收敛到同一个吸引子。**

这一条特别阴险，因为它产生的世界**看起来很像样**——每个文明都有名字、有神话、有经典，看上去很丰富。只有做定量比较才发现它们是同一个东西。

**可观察症状**
- **隔离-分化检验（最漂亮的一发）**：物理隔离（地理距离、山脉阻隔、无贸易路线）应当**增大**文化距离。计算"隔离度 × 时间"与"文化距离"的回归斜率。**若斜率不显著为正，或随时间衰减到 0，那么 LLM 就是吸引子，物理世界的分化被它抹平了。** 这个检验方向明确，不可能被"看起来挺多样"糊弄过去。
- 文明间文化距离矩阵的**总方差随时间的曲线**。应当上升，至少不应单调下降。
- 控制住 View 差异后，agent 之间 `p_LLM` 分布的 Jensen-Shannon 距离随时间的变化。下降 = 人格坍缩。
- **调温度救不了，且这一点要写进文档**：温度改变的是**同一个分布**的采样锐度；坍缩是**分布本身**错了（众数错、方差错、尾部缺失）。调高温度只会在错误的分布上采到更多噪声，得到"随机的错误"而不是"正确的多样性"。

**替代设计**
1. **文化的载体是结构化基因组，不是文本。** 一个文化 = 特征向量 + 一套传承规则（垂直/水平/斜向传递、变异率、内容偏向、频率依赖、人口瓶颈）。分化由**规则**产生（漂变 + 隔离 + 选择），LLM 只做渲染。规则产生的分化是真的，因为它由地理和人口驱动。
2. **异质性必须来自世界状态，不来自人设。** 禀赋、地理、亲属、债务、创伤、信息可得性由规则生成，作为**约束条件**喂给 LLM；LLM 只在这些约束下产生分布。即：**先有不同的处境，才有不同的人**，而不是先有不同的人设。（这是项目简报 AP12 的结论，本稿完全同意。）
3. **切断递归去噪循环**——但注意 R1 把这条写成了"LLM 输出永不回流为 LLM 输入"的硬约束，而那条约束**是不可实现的**，见 F10。正确形式是：回流的必须是**结构化对象**，不是文本。
4. 把 `culture_divergence_slope` 与 `persona_collapse` 放进常设监控看板。

### R1-7 ——【结构性】第 9 条给幻觉提供了合法藏身处；第 24 行又让这些幻觉回流成为决策输入，从背后穿透了第 5 条筑的墙。

**针对**：第 9 条「世界内部的人类……可能误解、遗忘、神话化甚至篡改历史」 与 第 24 行「可以让世界中的历史学家研究他们自己的历史」

**问题**：第 9 条给幻觉提供了合法藏身处；第 24 行又让这些幻觉回流成为决策输入，从背后穿透了第 5 条筑的墙。

**失败机制**：第一段：第 9 条听上去像是把 LLM 的自由发挥关进「世界内叙事」的笼子，实际效果相反——它给每一次幻觉提供了一句现成辩护「那只是世界内的史官这么写的」。纲领第 9 条目前只是概念区分，没有任何工程执行机制，团队会在半年内把它用成万能挡箭牌。第二段（穿墙）：LLM 写的官方史 → 被世界内的人读到 → 成为信念 → 信念影响决策 → 决策通过第 5 条的合法通道进入世界事实。于是 LLM 的虚构绕过第 5 条的墙成为客观世界的因果输入，而且走的是正门。这是纲领里最隐蔽的结构缺陷：第 5 条的墙被第 9 条 + 第 24 行组成的回路从背后打通。

**可观察症状**：抽查任意一个正在影响决策的信念，追溯 provenance 链；终点是一段 LLM 文本而非 event_id，这个信念就是凭空发明的。指标 belief_groundedness = provenance 链能追到真实 event_id 的信念比例，阈值 1.0 硬性。孤儿神话计数（没有对应真实事件的神话）应恒为 0。

**替代设计**：(1) 信念类型化并接地：信念 = {proposition（世界状态 schema 上的命题）, provenance_chain（一串 event_id 与传播跳数）, distortion_ops, confidence}。(2) 失真由规则施加，来自封闭算子集：遗忘、夸大（系数 k）、张冠李戴（归因转移到另一 entity_id）、事件合并、时间压缩、道德化重述、责任转移；每个算子是纯函数，参数由传播距离、代际数、政治动机决定。LLM 不得发明失真。(3) 神话化因此变成可审计的：任何时候都能打印「真实事件 → 算子链 → 当前信念」——这才是第 9 条真正想要的，且顺带满足第 2 条。(4) LLM 在这条链上唯一的位置是把 proposition 措辞成那个时代那个文化的说法；用一个反向解析器抽查（把生成文本解析回 proposition 与原命题比对）确保措辞不改变内容。

**证据**：Turpin et al. arXiv 2305.04388（模型给出自洽但与真实依据无关的说法）；Park et al. arXiv 2304.03442 作者自述 agent 会给回答添加「看似合理但虚构」的细节。


### R1-8 ——【结构性】纲领禁止了显式的剧情树和科技树，但 LLM 的权重里有一棵不可见的阶段论科技树。

**针对**：第 1 条「不预先规定文明必须经历哪些阶段……而不是按照固定科技树依次解锁」

**问题**：纲领禁止了显式的剧情树和科技树，但 LLM 的权重里有一棵不可见的阶段论科技树。

**失败机制**：LLM 先验里装着游群→部落→酋邦→国家→帝国的经典序列（Service/Morgan），以及「农业→定居→剩余→阶级→文字→官僚→帝国」的标准叙事，再加上 Civilization 系列的科技树（后者在训练语料里的密度可能比学术文献还高）。当 agent 被问「你现在该做什么」，它会朝序列里的下一格走，因为那是它见过的所有故事的走法。于是世界沿教科书序列演化，同时每一步都有完整因果链——因为规则确实会为它算出资源与人口后果。我们得到一个看上去涌现、实际被权重导航的历史。比基率污染更难发现，因为结果「符合常识」：它的症状是世界过于合理。

**可观察症状**：序列吻合度：世界的制度出现顺序与经典阶段序列做 Kendall τ，与 LLM-off 双生线对比；LLM-on 显著更吻合教科书序列 = 先验在导航。超前-滞后检验：对每次制度采纳算「采纳时刻 − 结构性前置条件满足时刻」，分布中位数应显著大于 0（制度是被压力逼出来的）；系统性 ≤ 0 说明 agent 在用世界外知识预判。理由文本中出现时代错置的策略词汇（财政基础、中央集权、合法性危机）。

**替代设计**：(1) LLM 不能发明制度，只能在规则生成的集合里选：集合只含本世界已存在的制度，以及通过规则定义的重组算子（合并/拆分/继承规则变更/抽取方式变更）从现有制度可达的变体。(2) 发明本身是规则侧的随机过程，条件是结构性前置（人口密度、剩余率、记录技术、信息网络连通度），不是 LLM 的判断；LLM 只在发明发生之后解释世界内的人怎么理解它。(3) 超前-滞后检验做成常设指标，不是一次性验收。

**证据**：CivRealm arXiv 2401.10568：在完整规则内核、完整状态可观测的文明级环境里，LLM agent 依然无法把知识转化为情境化的有效动作，两种范式都难在完整游戏中取得实质进展——说明它的「知识」是叙事性的而非情境性的。


### R1-9 ——【结构性】数值、时机与巧合的美学偏差。即使 LLM 只输出结构化意图，只要 schema 里有数值字段或时间字段，美学就会渗进去。

**针对**：第 9 行「不能因为『这样更有戏剧性』而发生」

**问题**：数值、时机与巧合的美学偏差。即使 LLM 只输出结构化意图，只要 schema 里有数值字段或时间字段，美学就会渗进去。

**失败机制**：整数偏好（3、7、10 的倍数）、对称切分（一半对一半），以及「有意义的巧合」——先知诞生在大洪水那一年、两兄弟建立敌对的国家、瘟疫恰好在攻城时爆发。叙事因果在训练语料里被大量奖励，这不是 bug 而是模型学到的世界模型的一部分。巧合尤其危险，因为它看起来像深刻的因果，会让我们误以为模拟涌现出了结构。

**可观察症状**：对所有 LLM 来源数值做末位分布 χ² 检验与取整率统计（是否偏好 5/10/100 的倍数）。共现超额检验：统计重大事件类在同一年/同一十年共现的频率，与独立性假设期望值相比，超额部分就是注入的戏剧性；对 LLM-off 双生线做对照。以及这两个量对 LLM 预算的弹性。

**替代设计**：(1) 意图 schema 中在类型系统层面禁止连续数值与绝对时间字段。(2) 数量由规则从行动者实际资源算出，LLM 只能选档位 {最低限度, 惯例水平, 最大可行}，规则负责翻译成数字。(3) 时机永远不由 LLM 决定，「何时」由规则的风险率过程给出。(4) 一切名字与数字都过世界 RNG。

**证据**：Bisbee et al.（合成响应方差显著低于真实）与 Verbalized Sampling 的 typicality bias 支持「LLM 的数值输出偏向典型值」。「LLM 偏好 7/37 等特定数字」在网络上广泛流传但我未能找到同行评议来源，因此本条不依赖该说法，改为给出可自测的末位分布 χ² 与取整率协议。


### R1-10 ——【结构性】「无事发生」没有概率质量，于是事件密度等于调用预算——世界的性格由账单决定。

**针对**：第 9 行（重大事件必须由结构推动）与 第 1 条涌现

**问题**：「无事发生」没有概率质量，于是事件密度等于调用预算——世界的性格由账单决定。

**失败机制**：真实历史在记录层面绝大部分时间是无事的。LLM 在「什么都不做」上几乎没有概率质量：你问它「你打算怎么办」，它一定会办点什么。因此每一次咨询都是一次非零的事件注入，事件密度 ≈ 咨询频率 ×(1 − p_noop)，而 p_noop ≈ 0。这与工程决策发生最坏耦合：为了省钱降低调用频率，世界就变平静；为了让世界更活提高频率，历史就变密集。

**可观察症状**：noop_rate：LLM 被咨询时选择「不作为」的比例，与规则先验 π(no-op) 对比，系统性偏低即污染。budget_sensitivity = d(事件数/世纪)/d(调用数/世纪)，理想值 ≈ 0——这是整个污染检测体系里最重要的单一数字，它直接回答「这个世界的历史是世界写的还是预算写的」。

**替代设计**：(1) 空动作是规则侧默认而非选项之一：默认路径是「没有触发器触发 → 什么都不发生 → 不调用 LLM」。(2) 触发器只引用物理量/经济量/信息量，禁止引用叙事节拍变量（「距上次大事件已 N 年」「这个文明太平稳了」），写进代码评审清单。(3) 触发之后给 LLM 的选择集里「不作为」的规则先验在多数局面下必须最大。(4) budget_sensitivity 作为 Phase 1 的验收门槛，不是「以后再看」。

**证据**：Park et al. arXiv 2304.03442 自述指令微调导致 agent 过度合作（即使与自身既定利益冲突也答应请求），即模型在「答应做点什么」方向上有系统性偏移。


### R1-11 ——【结构性】信息边界对 LLM agent 不可执行：上帝视角在权重里，不在上下文里。第 4 条隐含的「控制 prompt 即控制知识」假设对规则 ag

**针对**：第 4 条「模拟器拥有全局状态，但 Agent 不能拥有上帝视角」

**问题**：信息边界对 LLM agent 不可执行：上帝视角在权重里，不在上下文里。第 4 条隐含的「控制 prompt 即控制知识」假设对规则 agent 成立，对 LLM 不成立。

**失败机制**：即使 View(actor,t) 构造得完美，模型权重里仍然装着：帝国会过度扩张、灌溉会造成社会分层、通货会因铸币减重而贬值、游牧对定居的军事优势与其后勤上限。一个青铜时代的酋长 agent 在做计划时用的是二十一世纪的社会科学。这不是 prompt 工程能修的——上下文里没有的东西，权重里有。

**可观察症状**：把 F8 的超前-滞后检验用在技术与军事策略上。抽查理由文本，看是否出现该文明尚未拥有的因果知识（例如在还没有货币的世界里谈论「贬值」）。直接探针：给 agent 一个真实历史上有著名解法、但本世界尚未遭遇过的困境，看它是否直接给出那个解法；给得太快就是泄漏。

**替代设计**：(1) 接受一个事实：LLM 的知识边界无法被完全约束，因此 LLM 不能拥有需要「不知道」才成立的权力——长时程战略规划不能交给它。(2) 把「不知道」变成结构约束而非提示约束：选择集由规则从本世界已有的知识库生成，agent 想不出集合外的东西，因为集合外的东西根本不在选项里；这样即使它心里知道也无处施展。(3) 知识泄漏率作为监控指标而非拦截门（拦不住，但要知道有多少）。

**证据**：CivRealm arXiv 2401.10568（LLM 在完整可观测文明环境中无法胜任长时程战略）；Park et al. arXiv 2304.03442 自述 agent 会误解未显式编码的物理/社会规范——即它在用世界外的默认知识补全。


### R1-12 ——【结构性】在 LLM 参与下，第 7 条会变成一条永不触发的空条款——我们会得到一个过于合理的世界，并误以为这是模拟做对了。

**针对**：第 7 条「越违反常识、越罕见的历史结果，越需要强大的前置条件……不要因为结果奇怪就禁止它」

**问题**：在 LLM 参与下，第 7 条会变成一条永不触发的空条款——我们会得到一个过于合理的世界，并误以为这是模拟做对了。

**失败机制**：第 7 条防的是「因为有趣就允许」，但没防到相反方向：对齐后的 LLM 系统性压缩尾部。真正罕见的社会形态——反常的继承制度、结构诡异的宗教、不合常理但稳定的政治安排——恰恰是模型最不会提出的。同时还有一个反向假象：LLM 会产出「荒诞」，但那是戏剧性荒诞（传奇色彩、命运感、反转），不是统计性荒诞（结构上极端罕见）。这两者正好是第 7 条想要与不想要的两端。

**可观察症状**：制度/宗教特征向量分布的峰度与尾部质量，与 LLM-off 双生线对比；LLM-on 更瘦 = 尾部被压掉了。定义 structural_rarity（该形态在世界历史全样本中的分位数），统计跨越阈值的事件数，即「第 7 条触发次数」；长期为 0 就是这条纲领作废的证据。

**替代设计**：(1) 罕见事件的发生必须由规则的受约束随机过程产生，且尾部厚度是需要显式校准的可调参数，不能用默认值。(2) 定义并常设 structural_rarity 指标，把「第 7 条触发率」当作模拟健康度的一部分——世界太合理，和世界太荒唐一样，都是 bug。

**证据**：Bisbee et al.（合成调查响应方差显著低于真实）；Padmakumar & He（InstructGPT 显著降低内容多样性）；Mohammadi（对齐模型 token 预测熵下降、落入吸引子态）；Verbalized Sampling（typicality bias）。四条独立证据同向：对齐后的 LLM 系统性压缩尾部。


### R1-13 ——【取舍】单一汉语渲染层会掩盖语言演化。语言是文化分化最深的载体，也是路径依赖最好的证据。

**针对**：第 3 条路径依赖 与 第 24 行「形成完全属于自己的……民族」

**问题**：单一汉语渲染层会掩盖语言演化。语言是文化分化最深的载体，也是路径依赖最好的证据。

**失败机制**：如果一切都用现代汉语渲染，那么无论底层结构说什么，这个世界读起来就是中国的；两个文化的差异在文本层面几乎不可见；第 22 条将来写的小说会天然带中国味。这不是错误，是一项代价——但纲领现在没有把它标价。

**可观察症状**：给两个地理上完全隔离、结构参数差异很大的文明各生成一段文本，让不知情的人判断它们是不是同一个文化；判断为同一个，就说明渲染层抹平了结构层的分化。

**替代设计**：最小可行 conlang 层：音位库 + 词库 + 规则音变 + 借词机制（与 F3 的音系引擎共用）。汉语呈现明确降格为一个翻译层，UI 上标注为翻译，专名一律保留世界内原形。成本：Phase 0 多一个音系/形态引擎（几百行规则 + 一份配置），所有渲染文本需过一次替换。收益：同时买到 F3 的防泄漏、第 3 条的可验证路径依赖、以及一个规则自己就能产出的漂亮涌现现象（语系分化、同源词、借词层次揭示历史贸易接触）。这是全文性价比最高的一项投入。

**证据**：none（这是设计取舍判断，不依赖外部来源；历史语言学的规则音变可计算性是成熟共识，但本条不作实证主张）


### R1-14 ——【取舍】把 LLM 逐出因果链与命名之后，早期输出会很枯燥；这个代价必须现在就接受，否则墙一定会被推倒。

**针对**：整体架构决策的可持续性（第 5 条与第 22 条「模拟与文学创作分离」的落地）

**问题**：把 LLM 逐出因果链与命名之后，早期输出会很枯燥；这个代价必须现在就接受，否则墙一定会被推倒。

**失败机制**：按本文方案，前期跑出来的历史会像一份电子表格：数字、结构化事件、生成的音节名，没有史诗感。团队和用户在第一次看到这种输出时，会有强烈冲动「就让 LLM 稍微润色一下因果说明吧」——这就是墙被推倒的那一刻，而且它会发生在一个所有人都觉得无害的下午。纲领第 22 条已经写了模拟与文学创作分离，但它写的是「未来写小说时」，没有覆盖「现在看输出时」，所以这个缺口现在是敞开的。

**可观察症状**：代码库里出现「让模型润色因果说明」「给这段历史加点文采」这类 PR；causal_purity 从 0 变成非 0；in_world_narrative 字段开始被默认包含进因果链查询结果。

**替代设计**：(1) 渲染层与模拟层彻底分离，且渲染层可以任性：允许用最强的模型、最自由的写法，因为它不写回世界、可以随时重跑、可以有多个互相矛盾的版本——质感需求全部在这里满足。(2) 把「世界事实数据库对渲染层只读」写成不可协商的架构约束，用文件权限/类型系统/进程边界保证，不靠自律。(3) 提前把「模拟层的输出应该是枯燥的」写进 Phase 0 的验收标准——枯燥是正确性的证据，不是缺陷。这条要有人签字。

**证据**：none（项目治理风险判断；但它是 F2 修复能否长期存活的前提条件）
