## 0. 一句话判决

**纲领把"伪模拟"当成一个代码问题（不要把结果写死），但在这个项目里，伪模拟主要是一个流程问题和选择问题：内核可以一行硬编码都没有，而最终被我们称为"这个世界的历史"的那段东西，仍然是被我们调出来、挑出来、并且被终极目标（写小说）反向塑造出来的。**

纲领用十条原则严密防守了"世界里发生了什么"，**没有任何一条约束"我们如何选择和对待世界发生的事"**。而这恰恰是唯一一条代码审查、涌现度量、消融实验全都看不见的通道。

第二重问题叠加在上面：纲领的 Phase 0 成功标准（"能解释一个荒诞事件为什么发生"）与终极目标（"生成历史书、传记或长篇小说"）**都在奖励可读性**，而可读性与真实涌现是负相关的。Artificial Anasazi 之所以能被抓住，是因为它有一条考古人口曲线可以对照；纲领第 8 条主动放弃了那条曲线，却保留了"结果必须像样"的隐含要求。这是比 Anasazi 更差的处境，不是更好的。

## 1. 判据：伪模拟的五个层级

越往下越难发现，也越难靠技术手段防守。

| 层级 | 形态 | 例子 | 代码审查能否抓住 |
|---|---|---|---|
| L1 显式脚本 | `if cond: spawn_dynasty()` | 事件表、阶段枚举、效果函数库 | 能，静态检查 |
| L2 隐式调节器 | clamp、归一化、拒绝采样、自适应速率、兜底重生 | `max(0,x)`、`ensure_at_least_one_polity()` | 能，但必须先知道要 grep 什么 |
| L3 参数拟合 | 把结果写进参数，而不是写进规则 | Anasazi 的 Harvest Adjustment 1.0 → 0.56 | 只能靠空模型对照 + 自由度审计 |
| **L4 人类回路** | 反复调参直到世界"像样"；跑 400 个种子只展示好看的那个 | 无代码痕迹 | **不能。只能靠流程留痕** |
| **L5 目标反噬** | 终极产物的需求（可解释、可写成小说）反向塑造内核设计与验收标准 | "这条因果链很清楚" 被当成褒奖 | **不能。它污染的是评价函数本身** |

**纲领与 21 篇简报的全部防御集中在 L1–L3。L4 只在个别简报里被侧面提到，L5 完全没有出现过。而 L4 与 L5 是唯二能让一个彻底干净的内核产出彻底虚假的历史的机制。** 这是本审查的主线。

## 2. 致命问题（不改就一定失败）

### F1. Phase 0 的成功标准会给隐藏剧情树发满分

**针对**：纲领最后一段 —— "使未来发生一个荒诞事件时，**可以解释它为什么发生**"。

**失败机制**：这个标准衡量的是**解释的可得性**，而解释的可得性与机制的真实性几乎不相关，甚至负相关。一条手写规则 `if (旱灾3年 && 精英超产 && 边境压力) -> 王朝崩溃`，在因果库里留下三条干净、语义清晰、可向前追溯的前因；一个真正涌现的崩溃，其原因是十万次微观读写的交叠，摘要出来必然含混、多因、说不清主次。**于是验收时我们会系统性地偏好剧情树的输出。** 纲领第 2 条"一路追溯到更早的结构性变化"这个要求本身，只有在因果关系被人为整理过时才容易满足。

**可观察症状**：
- 因果链界面上几乎每个重大事件都恰好有 3–7 条整齐的原因，读起来像教科书段落总结。
- 内部评审出现"这个解释很漂亮""这条因果链很清楚"。**"清楚"应该是警报，不是褒奖。**
- 从来没有一个重大事件的答案是"我们查过了，说不清楚"。

**判别测试（摘要覆盖率双侧诊断）**：对每个重大事件 `e`，同种子重放 + 逐个消融声称前因，测"前 k 条前因解释了多少概率质量" `C_k(e)`。
- 多数重大事件 `C_7 > 0.9` → 存在解析捷径 → 按 Bedau 的弱涌现定义它**不是**涌现的。
- `C_7 < 0.1` → 我们没有解释力，只有一堆数据。
- 健康区间必须在 Phase 0 **事先**声明（我的建议是中位数 0.3–0.6，这是我编的数字，D 级，须在玩具世界标定）。

**替代设计（改写成功标准）**：

> Phase 0 成功 = 我们有能力对任意重大事件：(a) 机械地算出它的读取集闭包（F3）；(b) 用同种子干预重放测出每条声称前因的真实因果贡献；(c) **发现并报告至少一类我们原以为是原因、实际不是原因的东西**；(d) **对一个可测量的事件比例，诚实地输出"原因不可恢复"**。

(d) 是本轮新增的、比旧稿更强的一条。真实历史里大量事件的成因是不可恢复的；一个**每一件事都有答案**的因果库，其完备性本身就是"原因是被作者写上去的"的证据。建议把 `不可解释事件占比` 列为一个必须公布的一等指标，并**事先声明它的下界**（例如不得低于 10%）。一套不能推翻自己的解释系统，不是模拟系统。

**证据**：Epstein —— "Merely to generate is not necessarily to explain (at least not well)"；生成充分性是解释的必要非充分条件（`abm-methodology.md` §8.7，`[全文]` 已核验）。

### F2. "最终希望"是一份结果清单，它会通过人手变成剧情树

**针对**：第 24 段 —— "**形成完全属于自己的国家、民族、制度、宗教、文化、技术和历史人物**"；以及第 5 段 "使文明能够**持续演化数千年甚至更久**"。

**失败机制**：这是一组**对输出的硬要求**，不是对机制的要求。它与第 1 条（不预设阶段）字面不冲突，工程上必然冲突：

1. 我们写好一套自认为诚实的机制，跑 200 个种子、5000 年。
2. 结果：190 个种子停在几千人的采集群，8 个灭绝，2 个出现了持续 40 年的部落联盟。
3. 我们**无法**区分：(a) 机制错了；(b) 国家形成本来就极罕见、极慢 —— Turchin et al. 2022 的实证是：500 BCE 已有农业的地区，**23% 到 1500 年仍无宏观国家**，农业到国家平均时滞**约 2000 年**（`state-formation.md` §8 AP3，已核验）。
4. 但成功清单要求国家出现。于是开始调参。每次调整都有一个像样的局部理由（"贡赋可征取性系数偏低"、"模仿学习速率不合理"）。
5. 若干轮后国家出现了。**这个过程与手写剧情树在信息论上等价 —— 只是换成了一条更慢、更贵、留不下痕迹的梯度下降通道，梯度信号是"我们知道历史上应该有国家"。**

这正是 Anasazi 的完整剧本。Janssen 2009 §4.7 与 Table 4：Harvest Adjustment Level 从原始 1.0 被校准到 **0.56**（正文写 "reduced to 0.6"，表 4 为 0.56），Harvest Variance 校准到 0.4；唯一的理由是这样人口曲线才对。而 §4.10：**纯外生承载力模型（零 agent 行为）的相对误差只高 10%（L1）到 50%（L2）**；§5.1 的原话是 **"The agent-based model acted as a smoothing function for the irregular carrying capacity levels."**（本轮直接抓取 jasss.org/12/4/13.html 核验）。

**可观察症状**：
- 提交历史里出现一串 "调整 X 使国家形成时间更合理"、"降低 Y 避免早期崩溃"。
- 某几个参数被反复修改，幅度不大、方向一致。
- 团队里出现"这一版世界终于像样了"。
- 最硬的症状：**把这几个参数改回初始值，宏观历史形态整体消失** —— 那不是涌现，是拟合。

**判别测试（三件套，缺一不可）**：
1. **参数改动分类账**。每个自由参数带 `change_log`，每次改动必须归入 `bug`（实现错误）/ `evidence`（新的一手文献，须附引文）/ `aesthetics`（结果不好看）三类之一。CI 公开 `aesthetics` 改动的数量与涉及的参数。**任何被 `aesthetics` 改过 ≥2 次的参数，其下游一切宏观现象在文档中永久标注为"非涌现（拟合产物）"。**
2. **参数冻结点**。Phase 1 末冻结参数集合与取值。此后"我们的世界涌现出了 Z"这句话，只有在**没有新增或重调任何参数**的前提下才成立（prediction vs postdiction）。
3. **回滚测试**。一次性回滚全部 `aesthetics` 改动，重跑。宏观形态若崩塌，我们就知道了那部分形态的真实作者是谁。

**替代设计（纲领文本层）**：

> 国家、民族、宗教、王朝的出现频率、时滞与形态多样性，是本系统的**被测量输出**，不是验收条件。验收条件是：这些量在多种子集合上有明确分布，且该分布能被机制消融解释。
> **一个在 200 个种子上从未产生国家的世界，如果每个种子的停滞都能被追溯到具体的资源/信息/协调约束，那是一次成功的 Phase 1，不是失败的 Phase 1。**

### F3. 第 2 条没有规定因果由谁计算 —— 自报的因果链等于伪造

**针对**：第 2 条 —— "每一个重大事件必须**保存**可追溯的原因"。

**失败机制**："保存"是存储动作，不是测量动作。默认实现是：产生事件的那段代码顺手把它**认为**的原因写进 `event.causes[]`。这是**自报**。自报因果有一个致命性质：**剧情树的自报质量最高** —— 手写规则知道自己的触发条件，能一字不差写下来；真正的涌现过程不知道自己为什么发生。

更隐蔽的一层：`cultural-evolution.md` M13 与 `abm-methodology.md` §2.19（PROV-DM / SIMPROV）给出的 provenance 方案**全部是作者标注式的**（`log_provenance(x, "innovation", ...)`）。它们记录的是"我们声称的来源"，不是"真实的来源"。`complex-systems-emergence.md` M6 已意识到 `σ(e)` 可以被"给脚本事件也挂一堆结构性前因字段"刷高，但它的对策是"用重放测"，而对每个事件的每条前因做重放，在数千年尺度上不可承受。

**可观察症状**：
- `event.causes[]` 的平均长度在不同事件类型间高度一致（模板产物）。
- 因果字段里出现只在事件模板里存在、在世界状态里没有对应存储的概念（"民怨"、"气数"）。
- 删掉某条声称的前因后重放，事件照常发生，而没人发现 —— 因为没人做这个测试。

**判别测试（读取集追踪，本文最核心的工程建议）**：不要让事件声明原因，让运行时**测量**它。
- 世界状态的所有读取经过受控访问器（Rust `StateRef` / Python `__getitem__` 包装 / 编译期 effect 类型）。
- 每个 tick 内，为每个决策点（任何消费随机数或产生写入的计算）记录它实际读取了哪些状态单元 —— 即 `read_set`。
- 事件 `e` 的因果闭包 = 从 `e` 的写入集出发，沿 `read_set` 反向传递闭包，到时间窗口边界为止。
- **作弊检测器**：`declared_causes(e) \ read_set_closure(e)` —— 声称了但根本没被读过的前因。CI 强制此差集为空。反向差集 `read_set_closure(e) \ declared_causes(e)` 才是我们真正学到东西的地方。

**成本与缓解**：最坏情况 2–10× 运行时开销与巨大存储（我的工程估计，未做基准）。缓解：按 `significance(e)` 分层记录 + 闭包深度截断（如 200 模拟年）+ 独立的 `--audit` 全量短世界（500 年）。

**纲领改写**：

> 每一个重大事件必须保存**由运行时数据流测量得到的**读取集闭包；任何由代码作者手工声明的原因，只能作为**待检验的假设**存储在独立字段，并在展示时明确标注为假设。

### F4. 真实东亚地理是本项目最大的一次外生注入，纲领完全没有防守

**针对**：第 3 段 —— "以**中国及周边东亚地理环境**为舞台"。

**失败机制**：纲领严密防守了"历史剧情"，完全没有防守"历史舞台"。而 Anasazi 的教训里被注入的不是剧情，正是舞台：逐年 PDSI 序列进去，人口曲线出来，中间那层 agent 只起了平滑函数的作用。

我们的风险比它大一个量级，因为会注入两样东西：

1. **真实地形**。华北平原 + 黄土高原 + 长江流域 + 400mm 等降水线 + 蒙古高原界面，这套几何本身就是"农耕统一帝国 vs 北方游牧压力"这个宏观格局的强预测器。用这张图当舞台，然后宣布"世界自己演化出了周期性统一的农耕帝国和北方游牧对手"—— 这句话的信息量接近零。
2. **真实古气候序列**（如果我们用它）。真实序列里的干旱事件在时间上与真实王朝更替相关。喂进去之后，**任何**机制都会"解释"王朝崩溃。我们会得到一部跑在真实中国气候上的、把名字换掉的中国历史小说。`east-asia-climate-environment.md` 自己已经写下这条风险（§"诱导历史匹配"："一旦知道 1637 年应该有大旱，我们会不自觉地调参数让那一年真的出乱子"）。

**可观察症状**：
- 不同种子的政权边界反复落在同样几条地形线上（这本身可能是对的，但如果**在所有种子上**都一样，说明地理是唯一起作用的东西）。
- 统一/分裂的时点在种子间高度对齐 → 它挂在外生序列的谱结构上。
- 只用 `{纬度, 高程, 距草原距离}` 三个变量就能以 `R² > 0.8` 预测重大事件（`complex-systems-emergence.md` M6 的捷径检验）。

**判别测试（地图置换套件）**：同内核、同参数，跑五组各 40 个种子 —— (a) 真实东亚；(b) 东西镜像东亚；(c) 程序生成地图，边际统计量（高程分布、河网密度、纬度带、海岸线分形维、可耕地比例）与东亚匹配；(d) 真实欧洲；(e) 真实中美洲。比较宏观历史的**分布**（政体数、最大政体规模时序、统一间隔、寿命分布形状、技术扩散半径）。
- (a) 与 (c) 的差异必须能被我们**事先声明**的几个地理特征量解释。若 (a) 明显"更成功"，说明已对真实地图过拟合。若 (a)–(e) 几乎无差别，说明地理根本没在工作，宏观格局来自别处。

**判别测试（气候来源的纲领级要求）**：

> **生产世界（我们将来要说"这是这个世界自己的历史"的那个世界）的气候驱动必须是合成序列**：统计性质（方差、自相关、极端事件重现期、准周期强度）取自古气候研究，具体实现由 `world_seed` 生成。真实古气候序列**只能**出现在验证运行中，作为 surrogate 集合的一个样本，且那些运行永久标记 `calibration_only`，不得作为世界史来源。

纲领里完全没有这条，而它决定了最终产出的那段历史到底属不属于那个世界。

### F5. 分叉 + 反事实 + 写小说 = 一次由我们的审美引导的束搜索

**针对**：第 24 段同时要求 —— "可以保存任意历史节点并建立平行世界；可以进行'如果当时没有发生某件事'的反事实实验……最终可以从真实模拟产生的历史中**选择**某个时代、事件或人物，生成历史书、传记或长篇小说"。

**失败机制**：这三条单独看都是好设计，**合起来是一个搜索算法**：

- 分叉 = 扩展节点；
- 反事实 = 定向扰动；
- "选择某个时代/事件/人物写小说" = 评分函数，而这个评分函数是人类审美，训练自真实历史与文学。

于是流程会自然演化成：跑一批 → 挑有意思的 → 从有意思的地方分叉 → 再挑 → …… 最后取出一条链。**这是一次 beam search，其产物在信息论上等价于人手写的剧情，只是搜索代价高了几个数量级，而且我们会真心相信它是涌现的**（因为每一步都确实是模拟器跑出来的）。

这条通道对 L1–L3 的全部防御**完全免疫**：涌现认证、消融、空模型对照、参数活性、读取集追踪，全部在单次运行内部生效，没有一个能看见"我们跑了 400 次、分了 60 次叉、只留了 1 条"。

**证据（本轮新增）**：在交互式叙事研究里，"从模拟日志里挑出故事"是一个有专门名字的成熟子领域：**story sifting**。Kreminski 等人为此做了专用语言（*Winnow: A Domain-Specific Language for Incremental Story Sifting*, AIIDE 2021）、专用启发式（**《Select the Unexpected: A Statistical Heuristic for Story Sifting》**, ICIDS 2022）、以及关于其作者身份问题的专文（*Authoring for Story Sifters*, 2022）。〔书目与 PDF URL 本轮直接抓取 mkremins.github.io/publications 核验；因 PDF 使用 XeTeX CID 字体且本机无 pdftotext，**未能提取逐字引文**，故此处只引用题名与出版事实。〕**这个领域的共识是：模拟本身不产出故事，故事是被一个独立的筛选器从日志里挑出来的；而它的默认启发式，按论文题名，就是"选出意外的"。** 我们计划中的最终产物，在设计上就是模拟输出分布的极端尾部样本。把尾部样本称作"这个世界的历史"，除非同时给出分布，否则是对读者（和对我们自己）的误导。

**可观察症状**：
- 有一个被反复引用的"主世界"，其他运行没人提。
- 分叉总是从精彩时刻分叉，从来没人从"公元 1200 年那个什么都没发生的世纪"分叉。
- 团队无法回答"我们一共跑过多少个世界？多少个在 1000 年内灭绝？"

**替代设计（正史/实验室的单向阀，本文最重要的流程建议）**：

1. **正史谱系（canon）与实验谱系（lab）在存储层物理分离。** canon 是 append-only 的单一线：种子由**事先声明的、与结果无关的规则**决定（例如 `seed = sha256(kernel_version || "canonical")` 前 64 位），先定种子再跑，跑出什么算什么。允许因技术故障重跑，不允许因不好看重跑，重跑必须留痕。
2. **单向阀**：实验谱系可以从 canon 任意分叉，**但任何实验分支永远不能成为 canon**。反事实是用来回答问题的，不是用来搜索历史的。这条必须是数据模型的硬约束（lab 分支带不可移除的 `lineage_class=lab` 标记，出版工具拒绝读取），而不是一条纪律。
3. **运行登记表（run registry）**：每一次超过 100 模拟年的运行，无论结果，自动写入不可删除的表 `(kernel_version, param_hash, world_seed, lineage_class, 终止原因, 宏观量摘要, 是否被人查看过)`。删除条目需显式提交记录。
4. **无聊运行必须被展示**：任何对内/对外汇报，必须同时给出该内核版本**全部运行的分布图**，并标出被展示那一次所处的分位数。"这是 87 号世界，它在'最大政体规模'上处于 P97"比一段精彩叙事诚实得多。
5. **失败率是必须公布的指标**：`P(灭绝)`、`P(5000 年无国家)`、`P(永久停滞)`。**一个在 200 个种子上灭绝率恰为 0 的世界是可疑的。**

### F6. 我们的全部反作弊检测器，从未在"已知作弊"上验证过

**针对**：Phase 0 待答问题 "如何产生真正的涌现，而不是隐藏的剧情树？"

**失败机制**：纲领与简报提出了一整套判据（涌现认证、`σ(e)` 可追溯性、`T(X→Y|E)`、`Ψ`、幂律、空模型支配、外生序列置换……）。**没有任何一条被验证过具有检出力。** `complex-systems-emergence.md` §7.18 自己承认："**没有任何文献做过'剧情树能否骗过涌现度量'的研究**"，并把它列为纯推测。同时 §3 又指出多个判据有严重伪阳性（例如"隐藏剧情树会给出极低的 `T`，因为剧情树里的宏观变量确实不由微观决定 —— 它由脚本决定"）。

一套没有阳性对照的检测系统，其"全部检查通过"这句话没有信息量。而我们会在看到"全部通过"时停止怀疑 —— 这是最危险的时刻。

**可观察症状**：验收报告上所有指标都是绿的，而没有人能说出"如果我们真的作弊了，这一页会长什么样"。

**判别测试（剧情树金丝雀套件 —— 本文认为的 Phase 0 第一交付物）**：**故意造假，看能不能抓住自己。**

构造 N 个**已知有病**的内核变体（每个都是真实、能跑、看起来合理的实现），跑同样的实验套件，记录每个检测器对每个金丝雀的**检出率与检出所需的样本量**：

| 金丝雀 | 植入的作弊 | 应当被谁抓住 |
|---|---|---|
| K1 脚本王朝 | 政体年龄 > Gamma(μ=280) 抽样值 → 触发崩溃 | 词汇表检查、读取集闭包、`C_k` 覆盖率 |
| K2 PID 人口 | 一个把总人口拉回目标走廊的控制器，伪装成"迁移压力" | clamp 记账、矩位移测试、方差诊断 |
| K3 拟合空模型 | 用外生气候直接解析产出人口与政体规模，agent 只做平滑 | 空模型支配测试、外生序列置换 |
| K4 事件表 | 一张 40 条的事件表 + 冷却时间 + 权重调度 | 词表增长测试 `K(t)`、密封清单测试 |
| K5 LLM 编剧 | 让 LLM 直接决定"这里该发生一场叛乱" | 三支线对照（真 LLM / 随机 / 冻结策略表） |
| K6 存在性兜底 | `ensure_at_least_one_polity()` + 灭绝重生 | 灭绝率诊断、GATED 清单、`--no-clamp` |
| K7 策展 | 内核干净，但只保留分布前 5% 的运行 | **运行登记表 —— 其余检测器全部失效** |

**验收规则**：
- **任何检测器，若对它所负责的金丝雀检出率为 0，就删除它，不要发布它。** 一个通不过阳性对照的指标，出现在验收报告上只会制造虚假安全感。
- 报告"每个金丝雀被几个检测器抓住"。只被 1 个检测器覆盖的作弊类型 = 单点故障。
- **K7 必须在表里**，因为它证明了一件事：**唯一能抓住 L4 的东西是流程留痕，不是任何度量。**
- 金丝雀套件是**回归测试**：每次内核大改后重跑，防止检测器在重构中悄悄失效。

**这件事必须在 Phase 0 做，因为它决定了度量层的 API，而且成本低：金丝雀内核是玩具规模的，不需要跑 5000 年。** `complex-systems-emergence.md` §9 已经建议"先实现度量，再实现世界"；本文追加的是：**先实现度量，再用假货把度量测一遍，然后才实现世界。**

## 3. 结构性问题（会长期腐蚀质量）

### S1. 第 7 条的不对称门槛，是一台把世界推回真实历史的棘轮

**针对**：第 7 条 —— "越违反常识、越罕见的历史结果，**越需要强大的前置条件和完整的演化过程**"。

**失败机制（两层）**：

**(a) 不对称审查 = 定向选择压。** 罕见结果 → 高门槛 → 更容易被判"证据不足" → 我们去改机制 → 该类结果频率下降；寻常结果 → 低门槛 → 无人审查 → 保留。输出分布被系统性推向真实历史，与第 8 条直接相反。

**(b) 更深的问题：荒诞度无法被独立定义。** "罕见""违反常识"只能相对于一个参考分布定义。而我们**唯一拥有的**参考分布就是真实人类历史。因此第 7 条在技术上只能被实现为"**与真实历史的偏离度**"，也就是说：**它字面上就是一个把世界拉回真实历史的损失函数**，尽管它被写成了一条保护荒诞的原则。

第三重伤害：它把审查注意力精确导向了作弊最不可能藏身的地方。隐藏剧情树最可能产出什么？产出符合我们预期的东西 —— 因为它是我们写的。剧情树的产物一定落在"寻常"那一侧，**永远不会触发第 7 条的审查。第 7 条是一台自动化的确认偏误机。**

**可观察症状**：事件审计日志里有 200 条关于奇怪事件的详细讨论，和 3 条关于"又一个王朝在 250 年后崩溃了"的讨论。

**替代设计**：
1. **荒诞度绝不可以是运行时变量**。内核中不得存在任何计算"这个结果有多反常"并据此调整概率的代码。进禁用清单（S3）。
2. **审查对称化**：因果链审计按 `significance(e)` 分层随机抽样，与稀奇程度无关；每批必须包含 ≥50% 的"寻常"事件。
3. **第 7 条改写为叙述规范，而非接受标准**：
   > 罕见结果与寻常结果适用**同一套**因果验收程序。区别只在于：罕见结果对外展示时需要更长的叙述篇幅，因为读者缺少先验。**篇幅要求不等于证据要求。**

### S2. 第 5 条授权 AI 做"文化创造"，这与第 1 条冲突，并且会污染因果库

**针对**：第 5 条 —— "AI 可以负责人物和组织的判断、计划、**解释**、**文化创造**"；对照第 1 条 —— "宗教、文字…都应该尽可能由更基础的机制演化出来"。

**失败机制（两条）**：

**(a) 文化创造 = 直接注入训练分布。** LLM 的先验是"当代美式互联网文化 + 教科书式中国印象"。`llm-agent-social-simulation.md` §6.3 明确指出：**目前没有针对东亚/中国历史语境的 LLM 偏差评测**，我们对这件事零量化依据。一旦 LLM 自由命名与创作，会立刻产出可识别的汉语文化专名。**这不是风味问题**：宗教教义、政治口号、亲属称谓在后续 tick 里会成为决策输入，因此它们是承载因果的对象。让 LLM 写它们，等于让人类历史从一扇无人看守的侧门进入内核。

**(b) LLM 的"解释"会冒充原因存进因果库。** 纲领第 9 条只区分两层：世界事实 / 世界内人类的叙事。但 LLM 生成的 rationale 是**第三层**：模拟器外部作者对已发生计算的事后合理化。它既不是世界事实，也不是世界内某人的信念 —— 它是我们的旁白。若它与真实前因存进同一个字段、同一个库、同一套 UI，三百年后有人查"为什么这个国家会灭亡"，读到的将是一段由语言模型编的、听起来极有说服力的故事。**这直接摧毁第 2 条。**

**LLM 的两难（纲领假设中间地带存在，但没有论证）**：
- 若 LLM 输出对宏观历史**有**实质影响 → 它的先验就是剧情树，且这条通道方法论上不可验证（Larooij & Törnberg：使用 LLM"可能**加剧**而不是缓解 ABM 的验证挑战"；生成式 ABM"占据一个含混的方法论空间"，`[页面]` 已核验）。
- 若**没有**实质影响 → 它是昂贵的装饰，产出的"解释"是纯粹的事后编造。

**判别测试**：
1. **三层存储强制分离**：`world_fact`（只有内核能写）/ `in_world_belief`（世界内 agent 持有的信息副本，带位置、来源、失真史）/ `author_narration`（LLM 旁白）。不同表、不同 schema、不同读接口。UI 上 `author_narration` 必须视觉上不可混淆。**因果链查询默认不返回 `author_narration`。**
2. **LLM 宏观影响度测量**：同内核同种子集跑三支线 —— (A) 正常 LLM；(B) LLM 换成从同一候选集均匀随机抽；(C) LLM 换成一张冻结的策略表。比较宏观分布。B ≈ A → LLM 是装饰（可以接受，但必须**书面承认**，且不得再宣称"人物的判断塑造了历史"）；B 与 A 差异巨大 → LLM 是剧情生成器。**可接受带必须在 Phase 0 事先声明**（例如在 8 个声明的宏观量上 KS 距离落在 [0.05, 0.25]）。事后再定就是拟合。
3. **专名审计**：世界内生成的全部专名与一份真实汉语历史术语表做匹配，命中率必须趋近于零。

**替代设计**：把"文化创造"降级 ——

> LLM 只能在**规则层已经构造好的、有限的、离散的候选集**上做选择，并为该选择产生一段自然语言 rationale。它**不能**创造新候选项，不能命名，不能生成会被后续 tick 读取的结构化内容。世界内的文字、专名、称谓、教义命题由规则层的语言演化系统（词表 + 音变 + 构词 + 语义漂移）产生；LLM 只做润色，且润色结果只写入 `author_narration`。

### S3. 纲领没有禁止目标导向的调节机制 —— 这是最大的空白

**针对**：全文。纲领禁止了"为戏剧性而发生的事件"，**没有禁止"为了让世界能跑下去而存在的机制"**。前者显眼，后者看起来像工程卫生。

| 形态 | 长什么样 | 借口 | 实际做了什么 |
|---|---|---|---|
| clamp | `max(0,x)`、`clip(morale,0,1)` | 防止发散 | 制造隐式吸引子；**并且污染均值** |
| 归一化 | 份额强制求和为 1 | 概率必须归一 | 隐藏了"绝对水平本该变化" |
| 拒绝采样 | `while not valid(s): resample()` | 保证状态合法 | 对结果做过滤 = 条件化 |
| 世界重生成 | `while arable < θ: regen_map()` | 保证世界可玩 | 只在"文明可能发生"的世界里采样 |
| 自适应速率 | 控制器把变量拉回区间 | 数值稳定 | 字面意义的 PID = 字面意义的剧情树 |
| 灭绝兜底 | `if pop < 10: respawn_band()` | 避免空世界 | 取消了灭绝这个结局 |
| 冷却时间 | `event.cooldown = 50y` | 避免刷屏 | 这是节奏设计 = 叙事 |
| 存在性保证 | `ensure_at_least_one_polity()` | 后续模块需要 | 直接把结论写死 |
| 隐式积分 | 半隐式/全隐式求解器 | 大步长稳定 | 静默阻尼掉本该发生的崩溃振荡 |

**实证支撑（不是假想）**：Stonedahl & Wilensky 2010 在 Artificial Anasazi 里发现的两个 bug 都属这一类，且**在一个被广泛引用、被多次复现的已发表模型里存活了十年**：`quality = random-normal(0,1)*harvestVarianceLocation + 1.0` 后跟 `if quality < 0 → 0` —— 一个纯 clamp，导致**增大"方差参数"的同时抬高了均值**，所有关于"波动性 vs 平均水平"的结论因此为伪；以及 `HarvestVarianceYear` 初始化后从未被引用（死参数）。（`abm-methodology.md` §8 AP5/AP6，`[全文]` 已核验。）

**可观察症状**：危机期 clamp 触发率比平时高一个数量级；文明"神秘地"总能挺过灾难；灭绝从未发生。

**替代设计**：
1. **《反剧情树宪章》**：把上表变成 grep 模式与 lint 规则。
2. **每一处必须带审批注释** `# GATED(reason=, evidence=, ticket=, review=)`。CI 统计 GATED 数量，**只允许下降不允许上升**。
3. **clamp 必须记账**：每次触发写 `invariant_violation(var, cell, tick, magnitude)`。触发率超过 ε 视为**机制缺陷**（模型在该区域外推失败），必须改机制，不得加 clamp。
4. **提供 `--no-clamp` 模式**并定期跑，允许世界真的崩溃/发散，把崩溃率作为报告指标。
5. **矩位移测试**进 CI：任何被声明为"方差/噪声幅度"的参数，改变它时被调制量的**均值**不得显著移动。

### S4. 事件类型枚举给世界的可能性封顶，而纲领第 9 段已经写好了那份枚举

**针对**：第 9 段 —— "例如战争、国家形成与灭亡、革命、宗教诞生、制度改革、技术突破、民族迁徙、经济危机、思想运动等"。

**失败机制**：这句话读起来像举例，实现起来是 `enum EventType`。一旦有了枚举，每个成员都需要触发条件与效果函数，而 `(类型, 触发, 效果)` 就是剧情树节点的定义。于是：世界能发生的"事情的种类"被我们的想象力封顶，而我们的想象力被真实历史训练过；第 7 条的"荒诞"退化为**枚举成员的罕见组合**（组合空间很大，但**新种类数为零**）；即使不叫 `EventType`，只要效果函数库里有 `found_state()`、`start_religion()`、`reform_bureaucracy()` 这样的动词，字母表仍然是历史层级的，封顶依旧。

**可观察症状**：跑完 5000 年，事件类型频率表里没有一个类型是我们没写过的；世界里"最奇怪的事"能用我们自己的一句话说清楚；世界内的历史学家永远造不出一个我们没造过的词。

**替代设计（事件是被检测出来的，不是被触发的）**：
1. **内核里不存在 `Event` 类型**。内核只有：实体、物质存量、空间、关系边（义务/债务/亲属/效忠）、暴力冲突的物理解算、信息副本的传播与失真。
2. **"事件" = 状态轨迹上的显著变化**，由变点检测器在状态通道上**事后**识别，输出一个**无名对象**（状态差分 + 读取集闭包）。
3. **命名只发生在事后的两个地方**：(a) 世界内的人给它命名（进 `in_world_belief`）；(b) 我们的分析工具做**无监督聚类**，簇数与簇形是被测量的输出。

**原语准入规则**：一个内核原语只有同时满足两条才被允许 —— (i) 定义**不引用任何制度**（"征税"不合格，因为它预设政体；"以暴力威胁索取资源转移"合格）；(ii) 全部参数是物理量、信息量或关系边。

**判别测试 1（密封清单测试）**：**Phase 0 就做，成本几乎为零。** 团队每人写下他们能想到的全部"这个世界可能发生的事件种类"，合并去重，**加密封存**，Phase 2 前不得查看。跑完长世界后对检测到的事件做无监督聚类，然后开封，统计有多少簇**无法**用清单里的任何词描述。**如果是 0，我们的世界没有产生任何我们想不到的东西 —— 项目在这一维度上失败了。** 建议最低及格线 15%（我编的数字，D 级）。

**判别测试 2（词表增长测试）**：每 500 模拟年聚类一次，记录簇数 `K(t)`。真涌现的世界 `K(t)` 应持续增长（可放缓，不应饱和）。`K(500)=40` 而 `K(5000)=41` → 原语层已封顶。

**本方案自身的漏洞（必须一起说清楚）**：**"在哪些状态通道上做变点检测"这个选择，就是新的枚举，只是从内核挪到了观察层。** 好处是它不再影响世界的演化（观察不改变被观察者）；坏处是我们能"发现"的东西仍受限于通道集。**缓解**：通道集必须由状态 schema **机械导出**（每个状态字段自动成为一个通道，加上一组机械构造的组合通道），禁止手工挑选；手工添加的通道必须在登记表里单独列出并计入自由度。

### S5. 分类即剧本：把国家/宗教/王朝做成内核一等对象，等于预设它们必须出现

**针对**：第 5 段与第 24 段把"国家、政治制度、宗教、社会阶层、民族"并列为被模拟对象；第 9 段把"革命"列为事件类型。

**失败机制**：`state-formation.md` §8 AP1 已正确禁止 `enum PolityStage`。但危险不止于阶段枚举，而在于**类型的存在性预设**：
- 如果 `Polity` 是一个类（有 `territory`、`tax_rate`、`legitimacy`、`ruler` 字段），任何变大的社会形态**都会**被塞进 `Polity`，我们就永远观察不到"一个不是政体的大规模社会形态"。一个没有领土的、永久性的商贸离散社群，在我们的世界里连**存储的位置**都没有 —— 不是因为它不可能，而是因为没有字段。
- `legitimacy` 是最坏的字段：一个没有微观所指的宏观变量。它一定会被拿去当触发器（`legitimacy < 0.3 → rebellion`），这正是 `complex-systems-emergence.md` §8.8 判定的剧情树，而且是最容易通过代码审查的那一种。
- **`Dynasty` 是致命的**：王朝是一个**回溯性的史学建构**，不是本体论对象。若 `Dynasty` 是内核对象，王朝更替就是内核事件，王朝周期就被保证了 —— 然后我们会为此庆祝。

**纲领第 9 条的适用范围太窄**：它把"世界事实 vs 叙事"只用在**历史记载**上，没有用在**社会范畴**上。但"国家""宗教""王朝"本身就是范畴化的产物，和官修史书一样是叙事对象。

**替代设计（一句话）**：**"国家"应该是世界里的人头脑中的一个信念对象，而不是模拟器的一个数据结构。**
- 内核一等对象只有：个体、家户、地块、物质存量、关系边、信息副本。
- "政体/宗教/王朝/革命"存在于两处：分析层的**模式检测器**，以及 agent 持有的**信念**（"我们是 X 的臣民"是一条有位置、有来源、有衰减率的信息）。
- 这样国家的崩溃才有机械意义：那条信念不再被共享、不再被行动所依据。

**判别测试 1（类型删除测试）**：从内核**物理删除** `Polity` 类。编译/运行不通过 → 政体是被假设的，不是涌现的。**这是二值的、无法狡辩的结构性检验，比任何统计判据都干净。**

**判别测试 2（归属可争议性测试）**：真涌现的政体，边界必须是**有争议的**。用四个独立检测器判定每个地块归属：贡赋流向、军事响应半径、效忠信念多数派、婚姻网络社群。要求对相当一部分地块，四者**不一致**。**如果地图上每个格子恰好属于一个国家、边界是清晰的多边形，我们做的是 Civilization 的地图，不是历史。** 指标：`边界模糊带面积/总面积`，以及四检测器的 Fleiss' κ —— **κ 接近 1 是坏消息**。

### S6. 校准的反噬：用中国做校准集，会通过校准目标的选择把朝代周期编码进内核

**针对**：第 8 条 —— "用真实文明检验我们的机制是否至少能够产生合理的社会现象"。

**失败机制（三层，一层比一层隐蔽）**：
1. **校准目标的选择本身就是拟合。** 若把"政体寿命 ~250–300 年"列为校准靶，我们已经把王朝周期写进了验收条件，此后一切调参都朝这个方向走。`cliodynamics-secular-cycles.md` §3.0 处理了写法 A/B/C（不要 `age` 字段、不要顶层 ODE、不要 PSI 触发器），但没处理**第四种写法**：不写周期，只把周期设为验收目标，让调参回路去实现它。这是 F2 的领域特化版。
2. **自由度 vs 约束数严重失衡。** 这个规模的系统会有数百到数千个自由参数，POM 模式清单撑死几十条。在这个欠定区间里，"模型复现了模式 X"携带的信息量接近零。Turchin 2013 用 12 个参数拟合宏观模式得 `R²=0.65`，而"累积帝国密度 vs 历史人口密度"的朴素基线达 **0.75**（Madge et al. 2019，经简报核验）。
3. **评判者与校准集是同一个东西 —— 我们。** 我们的"合理"感来自中国史。第 8 条的"合理但不必真实"在实践中会退化为"看起来像中国历史但细节不同"。

**证据（本轮新增，且是最直接的一个）**：**校准数据的编码选择可以单独决定结论，且这已经在本领域最高规格的期刊上发生过。** Whitehouse et al. 2019 *Nature* 568:226–229 "Complex societies precede moralizing gods throughout world history" —— **该文已被撤稿**（Retraction Notice, *Nature* 595:320, 2021, DOI 10.1038/s41586-021-03656-3）。撤稿源于 Beheim et al. 2021 *Nature* 595:E29–E34（DOI 10.1038/s41586-021-03655-4）"Treatment of missing data determined conclusions regarding moralizing gods"：Seshat 中道德化神灵数据 **61% 为缺失值**，把缺失重编码为"不存在"时原结论成立，**只用现存数据或标准插补方法时结论反转**。〔撤稿事实与书目本轮经 Europe PMC API 直接查询核验；61% 与"结论反转"的措辞转引自 `state-formation.md` §7 与 `religion-formation-spread.md` §3，均已在简报中核验。〕

**这个案例对我们的意义有两层**：(i) 我们打算用来校准的那一类数据库，其编码约定足以翻转结论 —— 因此"我们的模拟匹配了 Seshat 的模式"这句话的证据强度远低于直觉；(ii) 更贴身的一层：**"缺失"与"不存在"混同**是本项目会犯的同一个错误。我们的世界事实库如果不把三值逻辑（存在/不存在/未知）作为一等公民，几千年后我们自己的分析会产生同样的系统性偏误，而且没人能发现，因为我们既是数据生产者又是数据分析者。

**判别测试 1（东亚 holdout —— 本文最强的方法论建议）**：

> **把东亚整体从参数校准中排除。** 参数只在美索不达米亚、中美洲、安第斯、西非、地中海等区域的比较数据上校准。东亚只作**测试集**：用冻结的参数在东亚地形上跑，看会出现什么。

理由：若参数是在东亚数据上调出来的，每个参数都已悄悄吸收了东亚特有的东西，"东亚世界演化出了东亚式的历史"这句话就不再有内容。**代价**：水稻、黄土、季风等东亚特有参数无法从别处校准，这部分必须显式列为"东亚专用参数"，单独计入自由度预算、单独标注下游结论。

**判别测试 2（对应词典覆盖率）**：请一位不参与项目的人（或一个无上下文的模型）尝试构建"我们的世界史 → 真实中国史"的映射，报告能被映射覆盖的宏观事件比例。**覆盖率高 = 我们作弊了。**

**判别测试 3（盲测排序）**：给独立评审 5 份匿名编年史（我们的 1 份、真实中国 1 份、真实非中国文明 3 份），要求按结构相似度两两配对。若我们的产物**稳定地**和中国那份配对，结构已被编码。

**判别测试 4（自由度审计）**：维护机器可读的参数登记表与模式登记表，公开 `参数数 / 有效约束数`，以及**每个宏观模式是否消耗了新的自由参数**。规则：一个宏观现象只有在"没有为它新增或重调任何参数"的前提下被复现，才算被解释。

**校准靶的正确形状**：校准对象必须是**分布形状与关系**（寿命分布形状与变异系数、冲突规模谱指数落在 1–3、聚落标度指数、危险率是否随年龄上升），不是中国的具体数值。并采纳 `abm-methodology.md` §8.11 的验收标准：**真实历史的宏观指标应落在我们模拟集合的 5%–95% 分位之间，而不是等于中位数。**

### S7. 第 6 条只保证了可重放，没有保证概率分布是诚实的

**针对**：第 6 条 —— "随机事件必须受到环境和概率条件约束，并**记录随机种子**，以便重放和进行反事实实验"。

**失败机制**：记录种子让**抽签结果**可复现，但剧情树不住在骰子里，住在**分布的形状**里。`p(叛乱) = f(饥饿, 赋税, …)` —— 函数 `f` 就是剧本。如果一个罕见事件的概率被调到"大约每几百年一次"，这个调参就是剧情。

**并且要注意反向的错觉**：**确定性重放对剧情树同样成立，而且剧情树是最可重放的系统。** "我们能位级重放"这句话经常被当成科学性的证明，它不是；它与"我们理解了发生的事"完全正交。第 6 条提供的是一种**科学感的伪装**。

**判别测试（D 级概率质量占比）**：每个概率函数与分布携带元数据 `(evidence_level ∈ {A,B,C,D}, source)`。定期报告：**重大事件中由 D 级（我们发明的）分布生成的比例**。若 80% 的重大事件来自 D 级分布，这个世界是我们的发明加一层随机涂装 —— 这不必然是失败，但**必须写在首页**，不是藏在附录。配套：任何 D 级分布的**形状**（不只是参数）必须做敏感性分析 —— 指数换对数正态、幂律换截断幂律，宏观结论是否翻转。

### S8. 计算预算会通过细节层次（LOD）分配变成剧情通道

**针对**：Phase 0 待答问题"如何让数千年的模拟在计算成本上可行"与"不同粒度的人口/人物模拟"。纲领提了问题，没提这个问题的伪模拟风险。

**失败机制**：多尺度是必需的，但它的自然实现是"**在有意思的地方给高分辨率**"。于是：(i) 廉价近似里住着一条拟合出来的宏观律，而拟合出来的宏观律就是剧情树（Anasazi 的空模型，只是被放进了子区域）；(ii) 如果"哪里有戏"决定了"哪里有分辨率"，戏就被因果上过度决定了 —— 高分辨率区域会产生更多事件，仅仅因为它有更多状态可以变化；(iii) 分辨率切换是不可见的相变：低 LOD 升高 LOD 时要把聚合量"反卷积"成个体，这个反卷积是我们编的，它决定接下来发生什么。

**可观察症状**：重大事件在高 LOD 区域的密度显著高于人口/资源所能解释的水平；把某区域强制设为高 LOD，它就开始出事。

**判别测试 1（LOD 不变性）**：同一世界状态、同一种子，一支高 LOD、一支低 LOD 跑 200 年，比较**声明的摘要统计量的分布**（不是单次轨迹），必须统计不可区分。任何不可区分性检验失败的统计量，不得用于对外结论。

**判别测试 2（随机 LOD 对照）**：把 LOD 预算按**与"有趣程度"无关**的规则分配（随机，或按人口比例），重跑。若重大事件的空间分布显著改变，LOD 就是一条剧情通道。

**设计要求**：LOD 分配规则**只能**引用物理/信息量（人口密度、交互密度、状态变化率），**禁止**引用任何"重要性/戏剧性/关注度"变量；该规则本身进禁用清单的审查范围。

### S9. 第 4 条的信息边界，其实现方式本身是一条剧情通道

**针对**：第 4 条 —— "模拟器拥有全局状态，但 Agent 不能拥有上帝视角"。

**失败机制**：纲领声明了原则，但**计算 agent 视野的那段代码**是全世界最适合埋剧情的地方。典型实现是"把相关信息推送给相关 agent" —— "相关"由谁定义？若由事件系统定义（"叛乱发生了，通知皇帝"），信息就会在剧情需要它到达的时候到达。这是纯粹的叙事装置，而且它会通过第 4 条的审查，因为它看起来像在实现信息边界。

**判别测试与设计要求**：
1. **信息必须是被运输的物质对象**：一个信息副本有位置、载体、传播速度、失真概率、遗忘率。Agent 只能读取与自己共位的副本。
2. **类型层面禁止全局查询**：agent 决策函数签名只接受 `Perception`，`Perception` 只能由运输过程构造。CI 静态检查：**agent 决策模块不得 import 世界状态模块**。这是二值检查，值得在 Phase 0 就把代码结构定成这样。
3. **延迟分布测试**：测量重大事件传到各决策中心的"距离—延迟"曲线，必须与声明的运输速度一致，**并且必须有一部分是无穷大**（某些事永远没人知道）。
4. **最硬的症状**：如果历史上从来没有一次因为"关键人物不知道某事"而导致的重大后果，信息边界就是假的。`因信息缺失导致的决策失误占比` 必须是一个被统计、被公布的指标。

### S10. 路径依赖（第 3 条）与可校准性（第 8 条）在数学上互相拉扯，纲领没有裁决

**针对**：第 3 条（小事件长期改变未来）× 第 8 条（真实历史作为校准集）。

**失败机制**：强路径依赖 = 种子间方差大 = 宏观量置信区间宽 = 与任何校准靶都"不显著不符"也"不显著符合"。当校准做不动时，最省事的修法是降低方差 —— 加平滑、加均值回复、缩小随机项。**每一次降方差都在削弱路径依赖。** `abm-methodology.md` §8 AP2 已指出用平均误差校准会"把模型压成一个几乎确定性的系统"，但纲领本身对"我们想要多大的方差"没有立场。

**判别测试**：
- 把**输出方差本身**列为一个必须匹配的量，而不是要被消灭的东西。
- **分叉发散测试**：同种子重放，只翻转一次抽样（或在 10 年前杀死某个具体人物），测 200 年后世界状态的距离。**要求距离随时间发散而非收敛**，把发散率 `λ` 作为一等报告指标。
- **Phase 0 必须声明目标方差水平**（例如"政体最大规模在 t=3000 的种子间变异系数 ≥ 0.6"）。没有事先声明，方差会在无数次小修中被磨掉。

### S11. 回归测试即剧本：CI 上的宏观断言是被自动化强制执行的剧情树

**针对**：纲领全文未提测试策略。这是一条**工程层面必然发生**、且极难在事后拆除的通道。

**失败机制**：任何长期项目都会建回归测试。对一个历史模拟器，最自然的回归测试长这样：

```
assert 到 t=2000 至少存在一个人口 > 10000 的政体
assert 农业在 t=800 之前出现
assert 世界人口在 t=3000 落在 [2e6, 2e7]
```

**这些断言一旦进入 CI，就变成了世界必须满足的定律，并且由机器每天强制执行。** 与手写剧情树相比它更糟糕，因为：(i) 它不在内核里，任何"内核无硬编码"的审查都看不见它；(ii) 它把"结果不对"自动转化为红色失败，从而把 F2 的人手梯度下降**自动化、日常化、并赋予道德正当性**（"CI 挂了，得修"）；(iii) 修法永远是改内核或改参数，从来不是改断言。

**可观察症状**：CI 里存在任何对宏观历史结果的断言；出现过"为了让测试通过而调参"的提交；测试文件里有以模拟年份为条件的期望值。

**替代设计（红线）**：
- **CI 只允许断言不变量，永远不允许断言宏观结果。** 允许的断言：守恒律（物质/人口账目平衡）、确定性（同种子逐位相同）、调度顺序无关性（换容器遍历顺序输出不变）、`GATED` 计数不上升、读取集差集为空、类型删除测试通过、金丝雀检出率不下降。
- **宏观结果只能进仪表盘，不能进红/绿测试。** 仪表盘展示的是分布随内核版本的漂移，供人**观察和解释**，不触发失败。
- 若某个宏观量的漂移确实需要引起注意，正确形式是"版本间分布对比报告 + 人工判读记录"，且判读记录进 `change_log`（F2）。

### S12. 用 LLM 当"合理性"裁判 = 让生成者兼任评判者

**针对**：Phase 0 待答问题 "如何验证一个重大历史事件在逻辑上成立？" 与 "如何衡量一个模拟世界是否'合理但不必真实'？"

**失败机制**：这两个问题最省事的答案是"让一个 LLM 读因果链，判断它是否说得通"。这在工程上几乎不可抗拒（便宜、可扩展、输出好看）。但它是一台洗白机：
- **判官与生成者共享先验。** 若 LLM 也参与 agent 决策（第 5 条允许），那么生成分布与评判分布来自同一个模型，这个闭环会系统性保留**符合人类历史直觉**的事件、剔除真正陌生的事件 —— 恰好与第 8 条相反，且与 S1 的棘轮同向叠加。
- **它对 L1 的作弊无检出力。** 一条手写规则产生的事件在 LLM 看来"完全说得通"（因为它就是照人类常识写的），而一个真涌现的怪事会被判为"缺乏合理性"。**这个裁判的检出力是负的。**
- 第 7 条要求"越荒诞越需要强解释"，这就要求有一个荒诞度裁判。若这个裁判是 LLM 或人，它就是 S1 描述的那台确认偏误机的执行器。

**可观察症状**：验收流程里出现"LLM 评审通过率"这类指标；被 LLM 判为"不合理"的事件被删除或被追查机制，而被判为"合理"的从不被追查。

**替代设计**：
- **合理性判定必须是机械的，不得由 LLM 或人的直觉裁决。** "这个事件在逻辑上成立"的操作化定义只能是：(a) 它的读取集闭包非空且包含足够的结构性前因；(b) 对声称的关键前因做干预重放，事件概率显著下降；(c) 它没有违反声明的守恒律与信息边界。**三条全是可计算的，全部不需要"说得通"这个概念。**
- 若一定要用 LLM 做辅助筛查，必须先在**金丝雀集**上标定它：把 K1–K6 产生的脚本事件混进真实事件里让它判。**如果它对脚本事件的判"合理"率高于真实涌现事件（很可能如此），就必须公布这个数字，并禁止用它做任何筛除动作 —— 它只能被用来生成待人工检查的问题清单，永远不能删除或修改任何东西。**

### S13. "世界内的历史学家"会成为伪模拟的洗白层

**针对**：第 24 段 —— "可以让世界中的历史学家研究他们自己的历史"，以及第 9 条的多层叙事设计。

**失败机制**：这个设计本身是纲领最好的想法之一。但它有一个副作用：**世界内历史学家产出的叙事，会是整个系统里最可读的东西**。因果链是数据库查询结果，事件日志是状态差分，而世界内史书是完整的、有人物、有解释的散文。团队讨论会不可避免地开始引用世界内史书，而不是事实表。

于是：**一个不连贯的世界，只要配一个足够好的世界内史官，看起来就是连贯的。** 世界内历史学家会把我们内核的空洞、断裂、拟合痕迹全部圆过去 —— 这正是真实史官做的事，所以它甚至是"逼真的"。但它让我们**丧失了发现自己内核有病的能力**。如果这些史官由 LLM 驱动（几乎必然），那么它们讲的故事的连贯性来自模型先验，不是来自世界。

**可观察症状**：内部讨论引用世界内史书多于引用事件表；世界内史书的叙事质量明显高于我们自己的因果链摘要；没有人统计过世界内史书说错了多少。

**替代设计**：
1. **世界内历史学家的错误率是一等指标，必须被测量并公布。** 定义：世界内史书中的每条实质断言，与 `world_fact` 逐条比对，得到 `准确率 / 遗漏率 / 虚构率 / 归因错误率`，并按"事件距今年数"与"信息传播距离"分层。
2. **准确率过高是失败信号，不是成功信号。** 一个准确率 95% 的世界内史官，说明它在直接读数据库，说明第 4 条的信息边界在史学这一层没有被实现。合理的目标是准确率随时间距离显著衰减，且虚构率显著大于零。
3. **禁止在任何工程判断中把世界内叙事当作证据。** 世界内史书属于 `in_world_belief`，与 `world_fact` 在存储、UI、查询接口上物理隔离（S2 的三层结构）。任何验收报告里出现世界内史书的引文，都必须并列给出对应的 `world_fact` 差异。
