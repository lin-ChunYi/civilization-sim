## 0. 一句话判决

**这份纲领最大的问题不是某一条原则错了，而是它把三组互斥的目标同时写成了"必须"，却没有指定任何一条裁决规则；而在没有裁决规则的地方，实现者会按"最容易写出来的那一种"默认，于是纲领会以一种没人签字同意的方式被逐条改写。**

三组互斥是：

| # | 互斥 | 现状 |
|---|---|---|
| A | 真实东亚地图（第 3 行） ⊥ 拥有自己的历史（第 7 行） ⊥ 真实历史当校准集（第 8 条） | 三者两两可兼容，三者同时为真则**无 holdout、且宏观骨架高概率复演** |
| B | 允许荒诞（第 7 条） ⊥ 完整因果链（第 2 条） ⊥ 涌现（第 1 条） | 因果链把结果空间限制为机制库闭包，"荒诞"退化成数值尾部 |
| C | 强路径依赖（第 3 条） ⊥ 单条反事实（第 6 条 + 第 24 行） | 第 3 条越成功，单条反事实线越无信息；**这不是取舍，是数学上的互斥** |

除此之外，纲领有 **10 处关键规格缺口**是"事后加不进去"的类别（时间基准、随机数体系、存储与分叉、决策主体本体、显著性函数、机制版本与长跑的关系……）。第 6 节给出 20 项必须先裁决的事项与建议默认值。

**最尖锐的一条单点发现**：纲领第 9 行那份"重大事件"清单（战争、国家形成与灭亡、革命、宗教诞生、制度改革、技术突破、民族迁徙、经济危机、思想运动）是一份**历史教科书的章节目录**，9 项全是政治—思想类，没有一项是疫病、饥荒、水患、生育制度或农业产出。第 10 条要求"模拟与文学创作分离"，而**为了好写而保留戏剧结构这件事，在纲领自己写下这份清单的那一刻就已经发生了一次**。

## 2. 致命问题（不改就一定失败）

### F1【致命】地图、舞台、校准集三重身份不可兼得；"自主性"从未被定义，因此无法被保卫

**针对**：第 3 行"以中国及周边东亚地理环境为舞台" × 第 7 行"这个世界应该拥有自己的历史" × 第 8 条"真实历史是校准集"。

**失败机制**（分两条腿）：

**腿一：地理决定论会以正当的名义复演真实历史的骨架。** 这不是猜测，有量化：Turchin et al. 2013 的空间自回归（控制空间自相关后）显示，**距草原的距离是农业格帝国密度的最强预测因子**，与农业长期存在程度、高程三者共同解释 **42% 的方差**；把军事技术随机播种（即消掉草原效应）后，模型 **R² 从 0.65 掉到 0.17**（转引自 `complex-systems-emergence.md` §6.1，简报标注已核验）。Madge et al. 2019 的复现进一步显示，仅用**人口密度做基线**就能达到 **R² = 0.75**（转引自 `cliodynamics-secular-cycles` / `emergence-verifiability` 引用表）。

含义是残酷的：只要我们（a）用真实东亚地形，（b）把草原邻接—骑射技术—战争强度—制度选择压力这条链实现对，那么"北方农牧接触带高频出现大型政体""南北二元""盆地—走廊拓扑决定政治边界"这些结构就**几乎是地图的函数**。我们会把它们写进演示，说"看，我们的世界自己演化出了帝国"。这句话在字面上是真的，在信息量上等于"我们的世界正确实现了地理"。

**腿二：舞台与校准集同一，等于没有 holdout。** 第 8 条要用真实东亚历史校准机制；第 3 行又把真实东亚当运行舞台。于是我们在同一份地理上既拟合又检验。Kapoor et al. 2024 对 agent 类研究的四条批评之一正是"许多 benchmark 没有 holdout set，导致 agent 走捷径、过拟合"（转引自 `llm-agent-social-simulation.md` §2，简报标注已补齐摘要）。**没有 holdout 的"合理性"结论在方法学上不可证伪。**

**这一条还揭出了一个简报之间的真实冲突**（说明这不是我在挑刺）：

- `china-eastasia-geography-archaeology.md` §3.0 结论：「**用真实东亚地形做几何基底**……不要用纯合成大陆」，理由是 51,074 个遗址点、7,083 个 14C 年代、CHGIS、HYDE、CHELSA-TraCE21k 这一整套校准资源在合成大陆上**全部失效**。
- `east-asia-climate-environment.md` §11.2 结论：「**为什么不用一比一真实地形**：因为它会诱导'这里应该出现关中'这类思维」，主张主线跑在一次性创生扰动（镜像/旋转/河网重连/去名）之后的基底上。

**两篇简报对"正式历史线跑在哪张图上"给出了不同答案，而纲领第 3 行的字面读法（"以中国及周边东亚地理环境为舞台"）支持前者。这必须由人裁决，不能由先写代码的人默认。**

**可观察症状**：
- 盲测：把去名后的地图 + 某个时代的政体分布图给一个不知情的人看，他能以远高于随机的准确率说"这是中国"。
- 跨 200 个种子，政体重心位置的空间方差很小；"农牧分界线"的位置在所有种子里几乎重合。
- 捷径检验：仅用 `{距草原距离, 高程, 距大河距离, 年降水}` 的 GBM 预测政体密度，`R²_geo > 0.6`。按 `complex-systems-emergence.md` M6 的判据（`R²_shortcut > 0.8` 即判为非涌现），这类结论就该被降级。
- **而同一篇简报的 §6.1 又把草原链称为"我们可以直接继承的、非剧本的因果链"。判据与目标在同一份文件里互相否定，纲领没有提供裁决规则。**

**可执行替代设计**（三件事，缺一不可）：

1. **先把"自主性"定义成一个数，再谈保卫它。** 建议定义：
   `自主性 = H(宏观历史描述 | 地理, 机制, 参数) / H(宏观历史描述)`
   其中"宏观历史描述"是一个预注册的 K 维向量（政体数、最大政体规模、重心位置、城市化率、农牧线位置、宗教数、文字出现时间……）。跨 N≥200 个种子测量它。**Phase 0 就要把这个测量管线做出来，并在跑第一条正式历史线之前给出基线数字。**
2. **正式主线跑在扰动基底上，真实基底只在评估进程里出现。** 采纳 `east-asia-climate-environment.md` §11.2 的方案（真实骨架 + 一次性创生扰动 + 去名），并把 `china-eastasia-geography-archaeology.md` §3.0 的校准资源全部搬进**评估进程**（物理隔离、只读、与内核不同目录不同进程）。这样两篇简报的诉求都能满足：统计与拓扑性质留下，实例被打乱。
3. **建立"地理可解释份额"仪表盘**：每一条宏观结论都必须附带 `R²_geo`。预注册上限（建议政体密度类结论 `R²_geo ≤ 0.5`，D 级待标定）。超限时，该结论**只能表述为"我们复现了地理效应"，不得表述为"我们的世界演化出了 X"**。这是一条措辞纪律，成本为零，效果最大。

**纲领第 3 行建议改写为**：
> 以真实东亚地理的**统计与拓扑性质**为舞台。正式历史线运行在一次性创生扰动（镜像/旋转/河网局部重连/全面去名）之后的基底上；未扰动的真实基底仅用于校准与评估，且与模拟内核物理隔离。

### F2【致命】"荒诞"的上界是机制库的组合闭包，而第 7 条把它写成了概率尾部；照现在的写法，世界一定会平庸

**针对**：第 7 条"允许荒诞，但要求更强解释：越违反常识、越罕见的历史结果，越需要强大的前置条件和完整的演化过程" × 第 2 条（完整因果链） × 第 1 条（涌现）。

**先回答交办的问题：这一条是不是自相矛盾？** 严格说不是逻辑矛盾，但它是**范畴错误**，而范畴错误的后果和矛盾一样严重。第 7 条是一句关于**我们（审查者）应该用多强的证据门槛**的认识论陈述，却会被实现成一条关于**世界动力学**的本体论规则。两种落地方式都自毁：

- 落地成运行时规则（"稀有事件需要更多前置条件才被允许"）→ 这是一台把输出推回常规的保守棘轮，而且它是显式的剧情控制。
- 落地成评审门槛（"奇怪的结果我们要多看几眼"）→ 单侧门槛 = 人类回路的保守偏置，只有反常结果承担举证责任，常规结果免检。

**但真正的失败机制比上面两条更深，而且三篇已有审查都没说到：第 2 条已经把结果空间封顶了。**

要求"任何重大历史事件都必须能够追溯其形成过程"，等价于要求任何结果都必须由**已存在的机制**生成。于是：

```
世界能产生的结果集合 = 机制库在组合下的闭包
```

在这个框架里，"更荒诞"只有两种可能的来源：
- **(i) 数值尾部**：同一批机制的极端实现（史上最大洪水、最长干旱、最年轻的君主、最大的帝国）。
- **(ii) 组合新颖**：机制以前所未有的方式相互挂接（例如：继承权与债务凭证绑定的制度 × 以疫病周期为历法的宗教 × 由商队担保人演化出的司法权）。

**第 7 条的措辞（"罕见""违反常识"）指向的是 (i)，而"现实历史中从未出现过的文明形态"只能来自 (ii)。** 我们会把工程投资全部放在"扩大随机分布的尾部"和"给稀有事件加审查"上，而 (ii) 需要的是完全不同的投资：**机制必须写成可组合的效应算子，而不是 if-then 事件**。

雪上加霜的是：如果荒诞靠 LLM 提案，第 7 条会**彻底空转**。四条独立证据指向对齐模型系统性压缩尾部（Bisbee et al. 的合成调查响应方差显著低于真实；Padmakumar & He 的协作写作多样性下降；Mohammadi 观测到 token 熵下降并落入吸引子态；Verbalized Sampling 把 mode collapse 归因于标注者 51.6–60.8% 偏好"典型"回答；全部转引自 `llm-agent-social-simulation.md` M6 段）。

**可观察症状**：
- 世界里最"离奇"的事件全是数值极端，没有一个是结构新颖：我们能用现有词汇给每一个制度命名。
- `pseudo-simulation` 建议的**密封清单测试**（事先密封一份"我们想得到的事件清单"）跑出来，清单外簇的质量占比接近 0。
- 机制共现矩阵在 t=1000 之后不再出现新的非零格。
- 团队讨论里出现"这个世界太平淡了，要不要加点事件"——**这句话本身就是症状**。

**可执行替代设计**：

1. **把第 7 条改成组合口径**。荒诞度的定义改为：
   `absurdity(e) = -log P(该事件所涉机制组合 | 此前历史中的机制共现分布)`
   即**机制组合的新颖度**，不是结果数值的罕见度。这个量可算、可追踪、且不需要外部参考分布（`emergence-verifiability` F3 指出"罕见"缺参考分布而自毁——组合口径正好绕开了这个问题，因为参考分布是世界自己的历史）。
2. **审查门槛对称化**：常见结果与罕见结果适用**同一套**因果验收标准（读取集闭包、σ(e)、反事实脆弱度）。禁止把 `absurdity` 作为运行时变量喂回任何决定"是否允许"的地方——写成 lint 规则。
3. **把工程投资从"尾部"转向"可组合性"**：机制以 `(前置谓词, 效应算子, 作用域)` 三元组书写，任意两个机制的效应算子必须可以在同一 tick 内叠加而不需要专门的交叉代码。**验收指标：`新颖组合率` 随模拟时间不饱和。** 这是一条比"是否出现了荒诞事件"可靠得多的判据，因为它不能靠调大方差刷分。

### F3【致命】"AI 负责文化创造"与"AI 不决定客观结果"之间没有类型边界；文化的效力就是客观结果

**针对**：第 5 条"AI 可以负责人物和组织的判断、计划、解释、文化创造等难以公式化的部分，但 AI 不能直接决定客观结果"。

**失败机制**：文化 → 偏好权重 / 合法性 / 协调成本 / 通婚与继承规则 / 禁忌 → 行为 → 制度 → 客观结果。第 5 条只禁止了"**直接**决定"，而"直接"这个词在代码里没有对应物。

关键在于：**LLM 生成的文化内容天然带着数值后果**。"这个宗教禁止在春季屠宰耕牛"是一句文本，同时是一个生产函数修改。只要下游有任何一段代码把文本解释成参数——不管是人手写的映射表、还是又一次 LLM 调用——AI 就已经在决定客观结果了，而且这条通道**不会被"AI 不能写世界状态"这类检查抓住**，因为写状态的是那段解释代码，不是 LLM。

`llm-storytelling` 的 F3 已经指出文化创造是最大的真实历史泄漏通道。我要加的是**这条通道可以被一个二值检验彻底关死**，而这个检验目前没有人提出。

**可观察症状**：
- 因果链里出现"某教义导致该区域农业产量下降 15%"这类边，而 15% 这个数追溯不到任何规则，只能追溯到一次 LLM 调用。
- 换一个模型版本重跑（同种子），宏观分布显著漂移。
- 代码里出现 `interpret_doctrine(text) -> Dict[str, float]` 这种函数签名。**看到它就已经中了。**

**可执行替代设计 —— 文本自由、参数不自由**：

文化对象的类型强制拆成两半：

```
CultureObject = {
    params: Vector[float]      # 由规则从结构状态计算，LLM 只读不写
    labels: Text               # 由 LLM 填，任何代码不得据此计算数值
    label_provenance: LLMCallRef
}
```

规则层预先定义好文化能作用的**有限数量的数值通道**（建议 ≤ 12 条：内群偏好强度、时间贴现率、对权威的服从、协调成本折减、通婚半径、继承分割度、外群接触意愿、劳动季节性约束、储蓄倾向、暴力正当化阈值、知识传承保真度、创新接受度）。这些通道的**取值**由规则从结构状态（生业方式、亲属结构、资源波动性、外群接触频率、人口密度……）计算；LLM 只能给这套参数**取名字、编解释、写经文**。

**决定性的二值检验 —— 文化文本置换不变性**：

> 取一条已跑完的历史线，把所有 `CultureObject.labels` 替换成**另一条世界线**的文本（params 一字不改），从 t=0 重放。**世界事实层必须逐位相同。**

不相同 ⇒ 存在 文本 → 事实 的通道 ⇒ CI 失败，定位并封死。这个检验成本极低（一次重放），不能被调参绕过，且**它是"AI 不决定客观结果"这句话唯一可机械执行的定义**。

**第 5 条建议改写为**：
> AI 的输出只能是两类：(a) 在规则给定的**有限选择集**上的一次选择；(b) 不参与任何数值计算的**标签文本**。世界状态的每一个字段，其写权限属于规则层；AI 对世界状态的写权限恒为空集。文化对象的数值参数由规则计算，AI 只为其命名与解释。

### F4【致命】"从文明形成之前开始" + "有人物级 agent" 会把 LOD 提升规则变成一道隐藏的阶段门，直接违反第 1 条

**针对**：第 5 行"从文明形成之前开始模拟……人物……相互作用" × 第 1 条"不预先规定文明必须经历哪些阶段"。

**先回答交办的问题：人物粒度何时开始有意义？** 纲领把三件不同的事混成了一个词"人物"，这是问题的根源：

| 概念 | 什么时候存在 | 谁来实现 |
|---|---|---|
| **人口个体**（有年龄性别、会生会死） | t=0 起，永远 | 队列（cohort），不是 agent |
| **决策主体 Actor**（拥有资源、有效用、有受限信息视图、会做选择） | **t=0 起，永远**。前农业期的默认 Actor 是家户/营群 | 规则策略；极少数被提升的走 LLM |
| **历史人物**（被命名、被记住、被后世研究） | **当且仅当世界内出现能跨代承载专名的记录/记忆机制之后** | 记录层（第 9 条）的产物，不是模拟层的设定 |

第三行是关键：**"历史人物"不是一个模拟粒度选项，而是第 9 条记录层的涌现产物。** 这样第 4 条（信息边界）与第 9 条（事实/叙事分离）就接上了，而且"人物何时有意义"这个问题有了世界内的答案，不需要我们拍板。

**失败机制**：从文明前开始，就不可能给每个人一个 agent（算力见下），因此个体层必须在某个条件下"上线"。**而最自然、最省事的写法是把上线条件写成时代或政体的函数**：

```python
if year > SETTLED_ERA or polity_count > 0:
    enable_person_agents()
```

一旦这么写，"国家形成"就被写进了 LOD 调度表。第 1 条被违反，而且**这次违反不可见**——它住在性能/观测代码里，不住在机制代码里，任何"机制层不得包含阶段枚举"的检查都抓不到。

算力这一侧是硬的：Park 式全量 generative agent 的量级是 **10⁵ 个 agent 推进 10 步 = 5 张 A100 × 2 天**；本项目要推进 3000 步（年），同构外推 = **5 张 A100 × 600 天**（转引自 `llm-agent-social-simulation.md` §2，简报标注为该文献自报数据）。所以"每人一个 LLM agent"在任何预算下都不成立，LOD 是**强制**的，不是选择——这也意味着 LOD 规则一定会被写，一定要现在就定死。

**可观察症状**（三个都很容易测）：
- 跨 200 个种子，"首次出现 person-level agent"的模拟年份的**变异系数 < 0.2**（真涌现的量不会这么齐）。
- 活跃个体 agent 数与政体数的相关系数 > 0.9。
- 关掉个体层重跑：宏观分布**完全不变**（说明个体层是装饰，纲领第 5 行的"人物"是假的），或者**剧变**（说明性能层在改物理，更糟）。

**可执行替代设计**：

1. **三段本体分离**（上表），写进类型系统。`Actor` 是唯一的一等决策接口，家户是 t=0 的默认 Actor，聚落/血统/组织/政体都是 Actor 的组合或角色（AGR 范式，见 `abm-methodology.md` §2.16）。
2. **提升函数只读结构量**：控制的劳动/粮食份额分位、网络中介中心性、是否占据一个**被制度定义的职位**（而职位本身是涌现物）。**禁止读取年份、禁止读取"是否存在国家"、禁止读取任何全局阶段标志。** 这条写成 lint 规则。
3. **活跃个体预算 B**（建议 10⁴，见 `abm-methodology.md` M11），超出按重要性驱逐；降级时残余影响写回队列，个体状态归档进事件图而非丢弃。
4. **加 1% 随机提升对照组**：随机选一批不满足重要性判据的 Actor 也提升。这是唯一能测出"提升偏差"的办法——否则因果库里 90% 的人物级前因都来自"我们认为重要的人"，而"重要"的判据是我们写的，构成循环论证。
5. **LOD 不变性检验（二值）**：随机提升一个子集，宏观分布的移动必须落在噪声地板内。落不进去 ⇒ 表示层在改物理 ⇒ CI 失败。

## 3. 结构性问题（会长期腐蚀质量）

### F5【结构性】强路径依赖与单条反事实在数学上互斥；纲领同时承诺了两者

**针对**：第 6 条"记录随机种子，以便重放和进行反事实实验" × 第 3 条（路径依赖） × 第 24 行"可以进行'如果当时没有发生某件事'的反事实实验"。

**失败机制**：`complex-systems-emergence.md` M6 明确把"单点扰动后世界状态距离**随时间发散而非收敛**"当作路径依赖的证据。这是对的——但它同时意味着：

- 若路径依赖强 ⇒ 同一个干预跑 N 次得到 N 个互不相似的世界 ⇒ **单条分叉线上的任何"因为 X 没发生所以 Y 没发生"都是无信息的**。
- 若单条分叉线的反事实结论稳定 ⇒ 路径依赖弱 ⇒ 第 3 条失败。

**两者不能同时为真。** 这不是取舍，是硬约束。纲领同时把它们写成了成就目标。

还有一个更早的技术前提，纲领的措辞已经把它写错了：第 6 条只说"**记录随机种子**"（单数）。有状态 PRNG 下，"删掉一个事件"会重排此后**所有**抽样序列，那不是最小干预，那是换了一个世界。干净的做法是 counter-based RNG，`key = (world_seed, stream_id, tick, entity_id)`，stream 按机制分配（`abm-methodology.md` M4/M14 给了完整方案，并明确指出这是第 6 条"唯一干净的实现路径"）。**"记录种子"这个措辞会诱导实现者写一个全局 RNG，而那会在项目最贵的能力上留一个不可修的洞。**

**可观察症状**：
- 反事实界面上出现一条"另一条历史"，并且我们开始把它当故事讲。
- 没有人报告**噪声地板**：同一分叉点、不做任何干预、只重放两次，两条线的距离是多少。
- 反事实结论没有附带有效期。

**可执行替代设计**：反事实的合法输出只有三种形态，写进查询接口的类型：

1. **集合级**：N≥50 条干预支线 vs N 条**空干预**支线（分叉但不改任何东西），在 K 个预注册量上的分布差 + 效应量 + 功效分析。
2. **反事实有效期 `T_half`**：干预效应的信噪比降到 1 的时间。**每条反事实结论必须附带 `T_half`；超过 `T_half` 的推断在界面上被拒绝渲染。**
3. **单条支线只能作为插图**，界面上强制打"非结论"水印。

**第 6 条建议改写为**：
> 随机性由无状态的计数器型随机数发生器提供，按机制分流；每条历史线记录 `world_seed` 与全部流标识，使任意单点干预成为一次严格的最小改写。反事实的结论只能以支线集合的分布差形式给出，并必须同时报告空干预噪声地板与反事实有效期。

### F6【结构性】世界内史学如果产出自然语言，它会同时吃掉算力预算、存储预算，并从背后穿透第 5 条

**针对**：第 24 行"可以让世界中的历史学家研究他们自己的历史" × 第 9 条 × 第 39 行"如何让数千年的模拟在计算成本上可行"。

**失败机制**：文本是唯一不能压缩成状态量的对象。而第 9 条要求世界内叙事**会影响行为**（否则"官方历史/民间传说/宗教叙事"就只是装饰）。于是：

- 史学产出必须被**物化**（否则不能被后人抄写、争论、据以行动）；
- 物化的文本要被 agent 读，就要进 LLM 上下文，成本随 `记录存量 × 世纪` 增长（**超线性**，因为后世史学要读前世史学）；
- `writing-records-memory.md` 的 L4 层明确写了这个递归："世界内的史学研究改变了世界内的叙事"；
- 于是 LLM 虚构 → 世界内信念 → 决策 → 世界事实，**从背后绕过了第 5 条的墙**（`llm-storytelling` C5 已指出这条链，我要给的是它的工程解法）。

**可观察症状**：
- 单个模拟世纪的 LLM 调用量随模拟年份**单调上升**（健康的系统应该是常数上限）。
- 存储被文本占据；快照体积随时间超线性增长。
- 因果查询返回的"原因"越来越多来自史学叙事而非世界事实。
- 世界内史学家的正确率高得离谱（见 F8 的可知性上界检验）。

**可执行替代设计 —— 世界内不存在自然语言**：

史学的世界内表示是**命题图（claim graph）**，不是文本：

```
Claim = {
  id, 指涉的世界事实 id 或 null(纯虚构),
  失真算子链: [遗忘, 夸大, 张冠李戴, 合并, 道德化, 责任转移, 年代望远, ...],
  载体群体, 声望, 存活副本数, 首次出现 tick, 依据的 Claim 集合
}
```

- **史学家 = 规则 agent**，在命题图上执行外部批判 / 内部批判 / 来源独立性检验，输出新的 Claim 节点。其"史学水平"是 `writing-records-memory.md` M13 的 `D(t)`（实际重建度）与可知性上界 `U(t)`（在存活语料下任何完美推理者能恢复的上限）之差。**`D(t) - U(t)` 才是史学水平，`U(t)` 是史料条件**——这个分解让"这个文明的历史学家是笨，还是史料真的没了"变成一个可计算的问题。
- **文本只在世界外查询时按需渲染**，渲染产物写入 author 层，**永不回流为模拟输入**（类型级约束 + 序列化边界强制）。
- 校准锚点是现成的：手稿存活率 7%（普通抄本）/ 20%（高端抄本）；集体记忆对在位者之前 8–9 位前任呈**大致线性**遗忘；名人声望峰值后半衰期 **73 年**（全部转引自 `writing-records-memory.md` §2 与数据表，简报标注已核验摘要）。

**预算规则**：LLM 调用预算**按世纪封顶且与模拟年份无关**；世界内史学在模拟期的默认 LLM 预算份额 = **0**。这条不写下来，第 24 行会在 Phase 3 静默吃掉整个预算。

### F7【结构性】纲领第 9 行的"重大事件"清单是一份文学体裁目录；它已经在纲领里完成了一次"为了好写而保留戏剧结构"

**针对**：第 9 行的事件枚举 × 第 10 条"模拟与文学创作分离" × 第 24 行"最终可以……生成历史书、传记或长篇小说"。

**先回答交办的问题：小说目标会不会反向污染模拟设计？会，而且第一次污染已经发生了，就在纲领第 9 行。**

那份清单是：战争、国家形成与灭亡、革命、宗教诞生、制度改革、技术突破、民族迁徙、经济危机、思想运动。**9 项全部是政治—思想类；没有一项是疫病、饥荒、水患、生育制度变化、继承分家、水利失修、产量长期下降。** 而项目自己的三篇简报（`epidemics-disease`、`agriculture-carrying-capacity`、`population-dynamics`）讲的恰恰是后面这些。

这份清单是历史教科书的章节名，不是历史动力学的分类。

**失败机制**：如果 `significance(e)`（决定哪些事件必须保存因果链）按事件**类型枚举**定义，那么因果库只覆盖政治叙事，于是：

- 每一次崩溃都会被解释成政治原因（因为非政治的前因根本没进因果库）；
- `emergence-verifiability` F8 指出的"信念因被记成事实因"会与之叠加，把历史解释得**既过度政治化又过度理性化**；
- 几百年后我们问"为什么这个国家会灭亡"，得到的答案会像一篇本纪。**它会很好看，而"好看"正是警报**（`pseudo-simulation` F1）。

**可观察症状**：
- 因果链数据库 top-100 事件按类别统计，**非政治类占比 < 20%**。
- 从未出现一条完全非政治的主链，例如"连年疫病 → 劳动力短缺 → 水利失修 → 洪灾 → 迁徙 → 聚落重组"。
- 小说素材库里没有一个候选是"某地连续三十年产量下降"。
- 团队讨论里出现"这段历史很适合写"——这是选择偏差正在发生。

**可执行替代设计**：

1. **`significance(e)` 只由状态变化量定义**，与事件类型**完全解耦**：
   `significance = f(Δ人口, Δ迁移量, Δ死亡率, Δ产出, Δ制度参数) × 持续时间 × 空间范围 × 受影响人口`
   阈值以上全量记录，阈值以下按概率采样并记录采样率。
2. **预注册拒绝条件**：top-significance 事件中**非政治类别占比 ≥ 40%**（D 级，待标定）。低于此值判为显著性函数有偏。
3. **纲领第 9 行的清单降级为"示例，非枚举"**，并当场补上疫病、饥荒、水患、生育与继承制度变化、农业产出的长期趋势。
4. **小说方向的三个压力点各自设闸**（见 F11）。
5. **选择即抽样**：将来从世界史里挑一段写小说，必须记录**选择规则**与**被拒绝的段落数**。这条成本为零，但它是"文学不污染模拟"这句话唯一的可核查形式。

### F8【结构性】因果图属于哪一层没有裁决，而它是第 4 条最大的漏洞

**针对**：第 2 条（因果链） × 第 4 条（信息边界） × 第 9 条（事实/叙事分离）。

**失败机制**：因果图是一个全局的、跨 agent 的、上帝视角的对象。如果它是内核状态的一部分，那么任何能读内核的代码都有一条通往上帝视角的捷径——**而这条捷径逃得过"agent 模块不得 import 世界状态"的静态检查**，因为它 import 的是因果图，不是状态。最可能的犯案现场是：世界内史学家的实现（它显然"需要"知道因果）、以及提示词构造器（它"顺手"把原因塞进上下文让 LLM 的回答更连贯）。

`emergence-verifiability` C7 指出了"因果图属于哪一层"这个问题；我要补的是**它的执行后果和一个二值检验**。

**可观察症状**：
- 世界内史学家的正确率异常高，甚至**超过**在存活语料上任何完美推理者的上限。
- prompt 日志里出现 agent 不可能知道的因果表述（"由于三十年前的那次歉收……"）。

**可执行替代设计**：

1. **因果图住在观察层，物理隔离**：不同包、单向依赖、内核与 agent 模块对它**零可见性**，CI 强制。
2. **世界内史学家只能读记录物件层（L1）**，不能读因果图，不能读世界事实层（L0）。
3. **二值检验 —— 可知性上界不可超越**：世界内史学家对任一历史命题的正确率不得高于 `U(t)`（用 L1 存活语料能达到的理论上限）。超过即证明有泄漏，CI 失败。这个检验只有在我们的世界里才做得到（我们同时拥有真实 stemma 与存活语料），是一个漂亮的内建实验台。

### F9【结构性】机制版本没有与长跑绑定；长跑期间的补丁会静默产生"物理定律会变的世界"

**针对**：第 26 行"这是长期研究型项目，不追求尽快堆出大量代码" × 第 2 条 × 第 3 条 × 第 41 行"如何保证未来可以重放、分叉和比较不同历史线"。

**失败机制**：一次数千年的长跑会持续数天到数周。一个长期研究型项目**必然**会在这期间改机制——而且改动通常以"修 bug"的形式出现，这是最不像剧情注入、因此最不会被记录的一类改动。若允许热更新：世界的物理定律在第 1200 年变了一次，而因果链、路径依赖、反事实**全部假设定律恒定**。这条历史线在语义上不是一个世界。

**可观察症状**：
- 无法回答"这条历史线是用哪一版内核跑的"。
- 同种子重跑得不到同样结果，且没人知道从哪一年开始不一样。
- `git log` 里有大量 `fix: 修正饥荒判定` 这类提交，其时间戳落在某条长跑的运行区间内。

**可执行替代设计**：

1. `kernel_version_hash`（机制代码 + 参数集的内容哈希）写进**每个 tick** 的记录。
2. **机制变更 ⇒ 该世界作废，必须从 t=0 重跑。** 只有观察层与渲染层允许热更新（并同样记录版本）。
3. **推论（Phase 0 必须算出的一个数）**：单次长跑的目标时长必须**小于机制变更的预期间隔**。这个数同时决定算力预算和 Phase 划分。如果算出来"一次长跑要 30 天，而我们平均 5 天改一次机制"，那么当前的架构在方法学上不可能产出一条可信的历史线——**这个结论越早知道越好**。
4. 与 `pseudo-simulation` C9 的"未实现子系统必须返回不存在"配套：**占位实现从不被删除，它们会成为世界的物理定律。**

### F12【结构性】最高杠杆的时期恰好是证据最稀薄的时期

**针对**：第 5 行"从文明形成之前开始模拟" × 第 8 条（真实历史是校准集） × 第 3 条（路径依赖）。

**失败机制**：路径依赖意味着靠近 t=0 的参数与初始条件对三千年后的影响最大。而前农业期几乎没有可校准量：ArchaeoGlobe（*Science* 2019）明确指出考古数据分布严重不均、**覆盖峰值在 2000 BP**（转引自 `china-eastasia-geography-archaeology.md` §2.13，简报标注已验证含摘要）；粟的驯化期跨度 **8300–4300 BC**（Fuller 等，转引自 `agriculture-carrying-capacity.md`），即早期过程是千年尺度的缓变，在年 tick 上几乎没有任何约束。

于是项目把**最大的自由度**放在了**最不可检验的地方**，而这些自由度会通过路径依赖放大到整个历史。这不是"参数不准"，这是"自由度的位置错了"。

**可观察症状**：
- 敏感性分析显示 `t < 1000` 的参数解释了终态方差的绝大部分。
- 我们对早期参数的每一次微调都显著改变"这个世界的历史"，而没有任何外部判据说哪一次调对了。
- 早期机制的证据等级表里 C/D 级占多数，却没有人因此限制它们的作用。

**可执行替代设计**：

1. **早期是一个先验分布，不是一个设定**：t=0 参数不取点值，取分布；正式产物是**集合**而不是单一世界。第一条"正式历史线"这个概念本身在早期就不该存在。
2. **证据等级闸门**：早期（比如前 2000 模拟年）只允许 A/B 级证据支撑的机制生效，其余机制的对外接口返回"不存在/无效应"，而不是返回一个看起来合理的近似值。
3. **把"早期敏感度"做成一等报告**：终态方差中来自 t=0 抽样的份额，是必填字段。

## 4. 可接受的取舍（说明代价）

### F10【取舍】自主性可以测量，但测出来的数会很难看，必须现在就接受

在固定的真实东亚地理 + 校准过的机制下，跨种子的**宏观骨架**（农牧线位置、南北二元、主要政体重心、走廊决定的政治边界）大概率高度一致；自主性主要体现在**中层**：具体政体边界、政体寿命、制度组合、宗教内容、语言分化树、人物与家族。

**代价**：我们必须放弃"这个世界的宏观格局会和真实东亚很不一样"这个期待，把承诺改成"**这个世界的中层历史与真实东亚不同**"。

**为什么必须现在说**：如果半年后有人发现"我们的世界宏观上还是像中国"，最省事的反应是去动机制或动地图**让它不像**——那是把伪造引入项目的最典型路径，而且它会打着"增强自主性"的旗号。**事先把 F1 那个自主性数字的期望值写下来并签字，是最便宜的疫苗。**

### F11【取舍】小说目标会持续施压，压力点是可预测的三处，可以逐一设闸

| 压力点 | 小说要什么 | 会怎么改坏模拟 | 闸门 |
|---|---|---|---|
| **人物因果权重** | 要主角 | 抬高个体决策对宏观结果的影响份额 | 把"个体决策对政体寿命方差的贡献份额"做成**被测量的输出**，预注册一个带（建议 10–30%，D 级待标定）；越界视为机制问题，不是"很有戏剧性" |
| **事件密度** | 要节奏 | "无事发生"没有概率质量，事件密度 = 调用预算 | 事件密度是**输出**不是参数；"无事发生"必须显式占概率质量；密度随时间的曲线进预注册 |
| **身份连续性** | 要延续感 | 家族、王朝、民族被做成持久一等对象，边界比真实历史清楚得多 | 归属**可争议性**测试：多个独立检测器对"这是不是同一个政体/家族"的 Fleiss' κ **不得接近 1**，边界必须有模糊带 |

**证据支持第一行不是无害的美学选择**：Madge et al. 2019 复现 Turchin 2013 时把决策规则改成贪心，**R² 从 0.66 掉到 0.22–0.39，并抹平了草原的因果效应**（转引自 `emergence-verifiability` 引用表）。个体决策规则的形态对宏观统计有一阶影响。给人物加戏 = 改变世界的宏观动力学。

## 6. 纲领没说、但必须在写第一行代码之前决定的事（20 项，含建议默认值）

标注：**［不可事后补］** = 这个决定会长进内核的类型与接口，事后更改等于重写。

1. **时间基准与多速率调度** ［不可事后补］
   **建议默认**：主 tick = **1 年**；气候/地貌层 100 年一步并可插值到 10 年（`china-eastasia-geography-archaeology.md` §双时钟建议）；空间战争 1–2 年（Turchin 2013 用 2 年）。**所有概率以"年危险率"存储，禁止存 per-tick 常数。** CI 里放一个时间步收敛测试：tick 减半后年度聚合量的变化必须小于 X%。
   **理由**：一切速率、预算、LOD、事件密度都以 tick 计价；事后改 tick 会让所有已标定参数同时失效。纲领一个字没提。

2. **空间粒度** ［不可事后补］
   **建议默认**：25–50 km 网格（Turchin 用 100 km；`cliodynamics` 建议 25–100 km 并**明确警告缩小网格必须重新标定 δ_s，因为它按格数计**）；聚落是挂在格上的点对象。
   **理由**：格尺寸是一个隐藏参数，而且是所有空间机制的公共标定基准。

3. **地图基底与主线选择，以及 holdout 划分** ［不可事后补］
   **建议默认**：真实东亚为几何骨架 → **一次性创生扰动**（镜像/旋转/河网局部重连/全面去名）作为**唯一正式主线**；未扰动真实基底只在评估进程使用（物理隔离、只读）。是否把整个东亚设为 holdout，需要一次书面裁决。
   **理由**：两篇简报在这一点上给出了**不同的建议**（F1），必须由人裁决。

4. **t=0 初始条件包** ［不可事后补］
   **建议默认**：t0 取"末次冰消之后"；初始人群按**纯环境适宜度函数 + 种子**播撒，**禁止读取任何遗址坐标**；初始知识集合除觅食外为空；初始参数取**分布**不取点值。
   **理由**：这是整个项目最大的一次假设注入，纲领一个字没说（`pseudo-simulation` G1 亦指出）。

5. **世界的边界：东亚之外是什么** ［不可事后补］
   **建议默认**：有限世界 + 一个**显式的"世界外通量"接口**：外来技术、病原、人群以低频泊松流进入，到达率由地理通道成本（河西型走廊、海路）计算。参数冻结并公开。
   **理由**：纲领写的是"中国及**周边**东亚"，但没说边界怎么处理。这决定了**草原压力这一最强的宏观驱动到底是内生的还是外生注入的**——而 F1 已经证明它是最强预测因子。若做成外生流，我们等于手动注入了真实历史最重要的那个变量。**这是纲领最大的一个未提及的结构性决定。**

6. **决策主体的本体** ［不可事后补］
   **建议默认**：唯一的一等决策接口 `Actor`（拥有资源、有效用、有受限信息视图）；家户是 t=0 的默认 Actor；聚落/血统/组织/政体是 Actor 的组合与角色（AGR 范式）。
   **理由**：避免"个体 agent 在某一年上线"的阶段门（F4）。

7. **个体提升/降级规则与活跃预算 B**
   **建议默认**：B = 10⁴；提升判据只读结构量；1% 随机提升对照组；降级时残余影响写回队列、状态归档进事件图。
   **理由**：F4。算力上"每人一个 agent"被 5×A100×600 天的外推直接否决。

8. **LLM 部署形态与调用预算**
   **建议默认**：自托管开放权重 + 权重哈希入 ledger + 重放只读 ledger；调用预算**按世纪封顶且与模拟年份无关**；架构硬约束：**世界在 LLM 完全关闭时必须能独立跑完三千年**，且 LLM-off 孪生线是默认产物。
   **理由**：没有孪生线，所有污染指标都失去分母。

9. **随机数体系** ［不可事后补］
   **建议默认**：counter-based RNG（Philox 类），`key = (world_seed, stream_id, tick, entity_id)`，stream 按机制分配（气候、疾病、生育、战斗结算、发现、LLM 采样……）。
   **理由**：第 6 条的措辞会诱导全局有状态 PRNG，那会让最小干预、并行确定性、分叉全部失效（`abm-methodology.md` M4）。

10. **存储 / 快照 / 分叉模型与实体 ID 方案** ［不可事后补］
    **建议默认**：事件溯源 + 内容寻址的持久数据结构 + 写时复制分叉；快照 = 不可变根指针；**实体 ID = (branch_root_id, local_id)** 或内容哈希。
    **理由**：纲领要求"保存任意历史节点并建立平行世界"。分叉之后两条线各自新建实体，**ID 冲突是必然会踩的坑**，而 ID 方案是最难事后更改的东西。纲领完全没提。

11. **`significance(e)` 的定义** ［不可事后补］
    **建议默认**：只由状态变化量计算，与事件类型完全解耦；阈值以上全记，以下按概率采样并落盘采样率。
    **理由**：F7。它同时决定因果库覆盖什么、第 2 条是否可执行、以及小说素材库长什么样。

12. **因果记录的成本上限与降级策略**
    **建议默认**：读取集闭包按压缩指纹存储（不存全量）；每 tick 因果记录预算固定（例如 ≤ 状态字节数的 5%）；超预算时降采样并记录降采样率。
    **理由**：C11。"每一个重大事件"在数千年尺度上不可执行，与其失败不如公开覆盖率。

13. **叙事分层 schema 与查询默认层** ［不可事后补］
    **建议默认**：L0 世界事实 / L1 记录物件 / L2 世界内信念与史学 / L3 作者层（我们的解释、小说、可视化）。查询必须显式指定层；跨层写入禁止，CI 强制；因果图属于**观察层**（F8）。
    **理由**：第 9 条只分了两层，而"我们的解释"是第四层，它一定会存在。

14. **文本的地位** ［不可事后补］
    **建议默认**：世界内不存在自然语言；一切"文本"是结构对象的渲染视图；渲染产物**永不回流**为模拟输入（在序列化边界上强制）。
    **理由**：F6。同时解决成本、可重放、污染三件事。

15. **机制版本与长跑的绑定关系**
    **建议默认**：`kernel_version_hash` 写进每个 tick；机制变更 ⇒ 世界作废、从 t=0 重跑；只有观察/渲染层可热更新。**据此算出单次长跑时长上限，并把它作为 Phase 划分的输入。**
    **理由**：F9。这个数字可能会推翻当前的规划，越早算越好。

16. **语言与命名系统** ［不可事后补］
    **建议默认**：世界内音系/构词/音变引擎；**LLM 在任何 name 字段只能填 EntityRef，不能填字符串**（类型约束）。
    **理由**：专名是最强的真实历史泄漏通道，也是 F3 那条"文本自由"原则的唯一例外——专名不自由，因为它会被人读成"这是唐朝"。

17. **灭绝与永久停滞的合法性**
    **建议默认**：**允许**；预注册灭绝率的目标区间；**禁止任何形式的兜底重生**（`ensure_at_least_one_polity()` 这类函数写进 lint 黑名单）。
    **理由**：一个 200 种子上灭绝率恰为 0 的世界是可疑的。纲领没有回答"世界可以死吗"。

18. **单位体系与守恒审计**
    **建议默认**：物质以 kg 干重/年、能量以 kcal、人以人年计；每 tick 做守恒审计（粮食、人口、金属）；**标定优先用比率而非绝对值**（稻/麦单产比 ≈ 2.5–3.7、南北人口密度比），因为比率对历史单位混乱免疫（`agriculture-carrying-capacity.md` 明确给出这条策略；亩有 10 种大小、清代银两 56 种地区标准）。
    **理由**：单位混乱是历史数据的固有属性，不是可以事后清洗的噪声。

19. **tick 内的调度顺序规范** ［不可事后补］
    **建议默认**：phase 顺序显式版本化，是 spec 的一等公民；禁止依赖哈希容器迭代顺序；CI 里放"逆序遍历、输出必须逐位相同"的测试。
    **理由**：Kehoe 2016 证明 *Growing Artificial Societies* 出版 20 年后仍不可无歧义重实现，原因之一就是"书里没有说规则以什么顺序应用"（转引自 `abm-methodology.md`，简报标注读到全文）。**顺序是一个隐藏参数，而且是一等重要的参数。**

20. **算力预算的三方分配**
    **建议默认**：模拟 : 验证 : LLM = **5 : 4 : 1**，先写下来再说。
    **理由**：验证算力从来不进预算（`emergence-verifiability` F15），而它可能超过模拟本身。不预先切分，验证一定会被挤成零。

## 9. 一句话收尾

纲领里没有一条原则是错的；错的是**它假设这些原则可以同时最大化**。一份不做裁决的纲领，会在实现阶段被"哪种写法最容易"这个真实的、无人签字的优先级悄悄改写——而那个版本的纲领，我们永远看不到，因为它从来没有被写下来过。
