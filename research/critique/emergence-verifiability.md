## 0. 一句话判决

**纲领用十条原则规定了"什么被允许发生"，却从头到尾没有规定"什么会让我们判定这次模拟失败"。一个没有拒绝域的判据体系不是判据，是修辞；而 LLM 恰好是世界上最擅长为任何结果补一段合理解释的东西。** 在补上拒绝规则之前，"真正的涌现"和"合理但不必真实"这两句话在工程上等价于"我们看着办"，Phase 0 的成功标准（第 44 行）因此**无法被它自己验证**——它要求我们"建立一套足够严谨的基础"，但没有任何一条可执行的检查能判断这套基础是否已经建立。

## 2. 致命问题（不改就一定失败）

### F1. 「合理但不必真实」没有拒绝域

**针对**：原则 8「真实历史是校准集，不是答案……用真实文明检验我们的机制是否至少能够产生合理的社会现象」；Phase 0 待答问题「如何衡量一个模拟世界是否『合理但不必真实』」。

**失败机制**。纲领给出的全部约束都是**允许型**的（可以离奇、可以荒诞、不能无缘无故、越罕见越需要强解释）。允许型约束不产生拒绝：无论模拟输出什么，我们都可以追加一段前置条件说明它"不是无缘无故"。当第 18 个月世界跑出一个 5000 年不出现城市、全境由巡回仲裁者维持秩序的文明时，团队面对的问题是"这算成功还是失败"，而纲领对此**一个字都没有**。此时的默认行为是：谁能讲出更好的故事谁赢。这不是假设——`llm-agent-social-simulation` 与 `abm-methodology` 的简报记录了这个领域的实测现状：Larooij & Törnberg (2025) 的系统综述筛出 35 篇 LLM 社会模拟研究，**其中 15 篇完全依赖主观评估**，多数验证的是"生成文本的风格真实性"而不是底层机制（brief 标注 `[页面]`，PMC 全文抽取）。我们会成为第 36 篇。

**可观察症状**。(a) 团队讨论中出现"这个结果看起来挺合理的"作为通过依据；(b) 没有任何一次运行被正式标记为 FAILED；(c) 有人开始写"世界志"文档来解释输出，而不是写测试；(d) 当有人问"如果机制 X 是错的，我们会怎么发现"时，答案是"跑久了就会看出来"。

**替代设计**。Phase 0 必须产出一个**预注册的模式电池**（pattern battery），每条模式含七个字段：陈述、方向性或区间、口径三元组（阈值/定义/估计方法）、证据等级、数据来源、功效分析结果、归属（校准集 or 封存验收集）。文件哈希后提交，改动需要记录理由。通过规则也必须预注册（例如"A 级判据零失败 + B 级判据通过 ≥ k/n"），并对 p 值做 FDR 控制。这套东西的价值不在于它有多准，而在于**它把"合理"从一次事后辩论变成一次事前承诺**。POM 是这个思路的方法论依据（Grimm et al. 2005, *Science* 310:987–991，brief 标注 `[摘要]`），但必须注意 brief 自己的诚实提示：**POM 没有给出"多少条模式才够"的量化标准，文献未提供可用阈值**——所以这个数字只能由我们自己预注册，然后不许中途改。

### F2. LLM 在环使「重放 + 反事实」在根上不成立

**针对**：原则 6「记录随机种子，以便重放和进行反事实实验」与原则 5「AI 可以负责人物和组织的判断、计划、解释、文化创造」；最终目标里的"可以保存任意历史节点并建立平行世界""可以进行『如果当时没有发生某件事』的反事实实验"。

**失败机制**。原则 6 隐含一个假设：世界状态转移是 `(state, seed) → state'` 的纯函数。原则 5 把 LLM 放进这个函数里，假设就破了。`abm-methodology` §2.18 记录（brief 标注 C 级、来源为技术博客 + 未经同行评议预印本，方向性结论可用）：**即使 temperature=0、贪心解码、固定 seed，跨机器或不同 batch size 仍会产生不同输出**，归因于 batch-size 相关的浮点归约顺序、MoE 路由变异、服务端副本间负载均衡；一项预印本在 690 次 API 调用中报告即使强制贪心解码，7 个边界样本里仍有 1–2 个不可复现。`llm-agent-social-simulation` §2.1 进一步记录：Generative Agents 官方 repo 提供的 `replay` 端点回放的是**已保存的世界状态轨迹**，不是 LLM 调用的重放，README 自述其"primarily intended for debugging purposes"。

后果不是"偶尔对不上"，而是**反事实实验全部失效**。反事实的定义是"只改一个变量，其余不变"；如果 LLM 调用在重放时会自行漂移，那么"改了什么"就不可控，观察到的差异无法归因。纲领第 24 行承诺的"如果当时没有发生某件事"变成了一次不可控的重新生成。更糟的是这个失效**是静默的**：两次运行的差异看起来完全像是路径依赖（原则 3）的表现，团队会把 bug 当成特性。

**可观察症状**。同一存档、同一种子、同一 proposal 分支跑两次，事件流在前几十 tick 一致、之后逐渐分岔；有人解释成"混沌敏感性"；反事实实验的结论在不同机器/不同日期不可复现。

**替代设计**（这是 Phase 0 必须先定的架构决定，不是实现细节）：
1. 世界转移函数的签名固定为 `step(state, rng_stream, proposal_log) -> state'`，**对这三个输入是纯的**。
2. LLM 的输出（提案、效用权重、叙事）在产生的当刻**物化为 proposal_log 中的不可变记录**，带 `model_id + prompt_hash + response_hash + 世界时间戳`。
3. **重放 = 读日志，永不重调模型。** 重调模型在语义上是"开一条新分支"，必须显式标记为 `regenerated_branch`，且禁止与原分支做反事实对比。
4. 反事实实验只允许两种：`seed 分流`（改随机流，proposal_log 里被改动点之后的记录作废并标记为需重生成，重生成部分单独记账）与 `state 编辑`（直接改世界状态字段）。两者的差异必须分开报告。
5. CI 测试：同一 `(state, seed, proposal_log)` 重放两次，**逐位一致**；这是构建失败级别的断言。

### F3. 「越荒诞越需要强解释」没有度量荒诞的参考分布，两种自然读法都自毁

**针对**：原则 7「越违反常识、越罕见的历史结果，越需要强大的前置条件和完整的演化过程」。

**失败机制**。这条原则要求把"荒诞度"和"解释强度"放在同一个天平上，但纲领没有说这两个量对什么参考系测量。只有两种自然读法，**两种都与纲领的其他条款冲突**：

- **读法 A：相对真实历史。** "违反常识"= 真实人类历史中没出现过。这直接把真实历史变成先验分布，也就把它变回了软性剧情模板——违反开篇第 3 行和原则 8。更技术性的问题是：真实历史是**一次实现**。`complex-systems-emergence` §8.11 引 Clauset (2018) 的结论说明了这一点——1945 年后的"长和平"与之前的大暴力期**都不能与平稳过程的涨落区分**，要让"长和平"成为统计显著的趋势还需要再持续 100–140 年（brief 标注读到原文 PDF）。一次实现里的"罕见"根本不可估。
- **读法 B：相对模拟自身。** 用世界自己的历史分布定义罕见。那么一个从头到尾都是神权政体的世界里，神权政体永远不罕见，"荒诞"永远为零，原则 7 变成空转。而且这条读法会奖励单调性：世界越贫乏，越容易通过。

**可观察症状**。评审一个奇怪结果时，讨论迅速滑向"人类历史上有没有类似的"（读法 A 在偷偷生效）；或者反过来，团队宣称"在我们的世界里这很常见所以不荒诞"（读法 B 在偷偷生效）。两种情况下，"强大的前置条件"这句话从未被量化过。

**替代设计**：把原则 7 改写成一个可计算的不等式，参考系是**显式声明、版本化的参考集合（reference ensemble）**，既不是真实历史也不是本次运行：

```
surprise_bits(e)      = −log2 P(e | 参考集合)        # 荒诞度
explanation_bits(e)   = log2 [ P(e | 完整前因) / P(e | 参考集合) ]   # 解释力
原则 7 的可执行版本：  explanation_bits(e) ≥ surprise_bits(e) − τ
```

参考集合的定义必须是 Phase 0 的一个决定项，我建议由**三个空模型的输出**构成：(a) 纯地理/气候驱动的承载力模型（零 agent 行为）；(b) 打乱地理邻接后的同机制模型；(c) 全部机制开启但决策替换为随机基线的模型。这样"荒诞"就被定义为"我们的机制相对于这三个廉价解释多做了什么"，而不是"跟真实历史不像"。`P(e | 完整前因)` 必须由**固定种子重放 + 逐个关闭前因**测得（`complex-systems-emergence` M2 的 σ(e) 思路），不得由事件模板自报。

这条改写还顺带把纲领第 9 行的"不能因为『这样更有戏剧性』而发生"变成可计算的：戏剧性事件的特征就是 `surprise_bits` 高而 `explanation_bits` 低。

### F4. 「重大事件」未定义，因果链义务不可执行也不可证伪

**针对**：原则 2「每一个重大事件必须保存可追溯的原因」；第 9 行的重大事件清单；Phase 0 待答问题「如何验证一个重大历史事件在逻辑上成立」。

**失败机制**。整份纲领的可验证性都挂在"重大事件"这个词上，而它没有定义。三种落地方式都坏：
- 由事件类型枚举（战争、革命、宗教诞生……）：这就把 F5 的本体泄漏问题坐实了——我们提前规定了世界能产生哪几类重大事件。
- 由 LLM 判断"这件事重要吗"：循环性（`abm-methodology` AP9：Larooij & Törnberg 指出用 LLM 评估自身输出"引发关于循环性与偏置的实质性担忧"）。
- 由人事后指定：那么"每个重大事件都有因果链"就是**永真命题**——我们只会去指定那些恰好有因果链的事件。这是最可能发生的一种，也是最有害的，因为它让原则 2 看起来一直在被满足。

**可观察症状**。因果链数据库里 95% 的条目是战争和政权更替（因为那是我们记得要打点的）；当有人问"为什么这个地区的婚姻制度在三百年间从从夫居变成了从妻居"时，系统答不出，而这个变化在事后看比某场边境冲突重要得多。另一个症状：因果链的平均深度随时间单调下降（早期认真记，后期只记结果）。

**替代设计**：
1. **"重大"必须是一个对世界状态的可计算泛函，而不是一个类型标签。** 建议：`impact(e) = 用同种子重放、在 e 处翻转随机抽样，测量 T 年后世界状态向量的距离`，取多个 T（50 / 200 / 500 年）。这直接复用原则 3 想要的路径依赖测量，而且它的定义里没有任何事件类型词。
2. 因果留档分级：**所有**事件写入压缩的祖先指针（廉价）；`impact` 超过预注册分位数的事件在发生时**冻结祖先闭包**（昂贵但稀少）。`abm-methodology` AP13 明确警告全量逐 tick 因果图在工程上会失控（brief 自标 D 级），分级是必需的，而且**必须在写第一行模拟代码前定下来**。
3. 关键：`impact` 的计算发生在事件之后（需要 T 年），所以冻结策略必须是**乐观冻结 + 延迟裁剪**：先按廉价的启发式（涉及实体数、资源流量、控制关系变更数）冻结一批，T 年后按实测 impact 裁掉多余的。这是一个必须现在决定的存储权衡。

### F5. 目标清单本身泄漏了本体词汇；消融抓不住，需要类型抹除测试

**针对**：原则 1「不预先规定文明必须经历哪些阶段。国家、君主制、官僚体系、宗教、文字、货币、市场、帝国等都应该尽可能由更基础的机制演化出来」；与之直接冲突的是第 24 行"形成完全属于自己的**国家、民族、制度、宗教、文化、技术**和历史人物"。

**失败机制**。原则 1 说这些不能被预先规定，最终目标却把它们列为交付物。在代码里，这个矛盾会以最平凡的方式解决：出现 `class Religion`、`polity.type = "empire"`、`tech_tree.yaml`。一旦内核里存在一个 composite 类型标签，并且内核的任何一条规则**读取**它，剧情树就已经建成了——哪怕它是通过配置文件、字符串比较或间接查表实现的。这类耦合的隐蔽程度可以很高：`state_formation` 简报 §9.a 交付的"国家出现观测器"里，`exists_role(p,'administrative_specialist')` 这种读法一旦被内核而不是观测器调用，性质立刻从"观测"变成"触发"。

**为什么现有对策不够**。`abm-methodology` M7 的"词汇表检查"是静态分析（禁止 `if (conditions) then spawn_bureaucracy()`），这是对的但太弱：它抓不住"内核读取一个由观测器写回的宏观字段"，也抓不住通过数据表间接实现的同一件事。`complex-systems-emergence` §8.8 已经点出这个反模式（把宏观指标当触发器就是剧情树），但没给出可执行的检测。

**可观察症状**。(a) 代码里出现从内核指向观测器/分类器的 import；(b) 某个宏观量的时间序列在"国家出现"处是**单 tick 阶跃**而不是连续爬升；(c) 跨种子的"国家"实例在制度向量上高度相似（都长一个样）；(d) 删掉某一行代码，某个宏观现象整体消失——`cliodynamics-secular-cycles` AP-1 把这条直接写成判据："如果删掉某一行代码周期就消失，那这行代码就是剧本"。

**替代设计**（三层，全部可自动化）：
1. **类型抹除测试（type-erasure test）**：把所有 composite 标签替换为随机 UUID 后用同一 `(state, seed, proposal_log)` 重跑，世界轨迹必须**逐位相同**。任何读取标签的内核路径都会导致轨迹发散。这比静态词汇表检查强，因为它对实现方式不敏感。**[我的推断，无来源]**，但它是纯工程手段，成本低，且失败信号无歧义。
2. **单向依赖的构建期检查**：内核模块不得 import 观测器模块；观测器只能通过只读视图访问内核。CI 级别。
3. **阶跃探测**：对每个宏观判定量做变点检测，要求范畴 C 的出现处不是超过前驱波动 kσ 的单 tick 跳变。触发器的指纹就是阶跃。

并且，**最终目标清单必须重写**：交付物不是"国家、宗教、货币"，而是"一组由观测器识别、并通过涌现认证的宏观范畴，其中可能包含也可能不包含与人类历史上的国家/宗教/货币同构的东西"。这不是文字游戏——它决定了当世界跑了 3000 年却没有出现任何可被称为"宗教"的东西时，我们是判定失败还是判定这是一个合法结果。

### F6. 判据自身从未被标定：没人证明它能把剧情树世界打回去

**针对**：Phase 0 待答问题「如何产生真正的涌现，而不是隐藏的剧情树？」以及本文自己提出的全部判据。

**失败机制**。我们打算用一套判据（涌现度量、模式电池、消融矩阵）来判定世界是不是剧情树。但**没有人验证过这套判据的伪阳性率**。`complex-systems-emergence` 的作者在 §9（无来源判断）第 18 条里对此完全诚实：**"没有任何文献做过『剧情树能否骗过涌现度量』的研究"**，并且指出这可能是本项目可以做出原创贡献的地方，"但目前它是纯推测"。更具体的伪阳性风险简报自己也点了：判据 E1（动力学独立性 `T(X→Y|E)`）的最严重伪阳性正是**剧情树**——脚本驱动的宏观变量确实不由微观决定，所以 `T` 会极低，判据会给它满分。

如果判据本身没有标定，那么整个 Phase 0 的成功标准（"使未来发生一个荒诞事件时，可以解释它为什么发生"）是**不可验证的**：我们会拿到一份漂亮的认证报告，而不知道这份报告能不能区分认证过的世界和一个我们自己写的剧本。

**可观察症状**。判据全绿，但没人能说出"如果我们作弊，哪一条会先红"。有人提议加一条新判据时，讨论的是"这条听起来有道理吗"而不是"这条在诱饵世界上的伪阳性率是多少"。

**替代设计**：**Phase 0 必须交付三个诱饵世界（poison-pill benchmark）**，共用同一张地图、同一套观测器：
- **W1 剧情树世界**：国家/宗教/货币由显式触发器生成（`if pop > X and year > Y: spawn_state()`），其余机制照常。
- **W2 纯外生驱动世界**：宏观节律完全由外生气候序列注入，agent 决策替换为随机基线。这一条有强证据支持其必要性：Janssen (2009) 对 Artificial Anasazi 的复现证明，**一个零 agent 行为的纯外生承载力模型取得了只差 10–50% 的拟合，且两个模型的最优参数完全相同**，Janssen 的原话是 "the agent-based model acted as a smoothing function"（brief 标注 `[页面]`，JASSS 全文抽取）。
- **W3 纯噪声世界**：机制骨架保留，全部因果耦合切断。

然后交付一份**判据标定报告**：每条判据 × 每个诱饵世界的通过/失败矩阵。**任何在 W1 上不失败的判据，不得进入验收集**——它对我们要防的东西没有分辨力。这份报告的成本不低（三个世界 × 若干次长跑），但它是唯一能让"我们证明了涌现"这句话有意义的东西。

### F7. 消融实验在数学上无法区分「涌现」与「被拆散的触发器」

**针对**：原则 1；以及 `abm-methodology` M7 涌现认证的第 2 段（消融测试）。

**失败机制**。消融证明的是**必要性**，不是**非脚本性**。一个硬编码触发器 `if A and B and C: spawn_state()` 在消融 A 时同样会失败，同样表现为"存在承重机制"。把触发条件拆成三个模块，每个单独都不充分，消融矩阵看起来会非常健康。**消融与涌现之间没有逻辑蕴含关系**，这一点纲领和现有认证协议都没有说清楚。

Epstein 的表述给了这个问题的哲学版本（`abm-methodology` §2.12，brief 标注读到 JASSS 全文）：**"generative sufficiency is a necessary but not sufficient condition for explanation"**，以及 "Merely to generate is not necessarily to explain … A microspecification might generate a macroscopic pattern in a patently absurd—and hence non-explanatory—way."

**可观察症状**。消融矩阵漂亮（每个机制都承重），但跨种子的实例高度雷同；把某三个机制**同时**关掉，现象整体消失而不是渐变；现象的出现时间集中在一个很窄的窗口内。

**替代设计**：消融矩阵必须额外报告两个量，且这两个量才是涌现的正面指纹：
1. **部分可替代性**：存在机制子集 `{m_i}` 与 `{m_j}` 互不相交，各自被关闭时 P(C) 下降但不归零，且被关闭后的 C 实例在制度向量上**形态不同**。这是 Epstein 的 multiple generators 论点的可测版本——真涌现的范畴应该有多条生成路径。
2. **归零脆性**：若存在任一单机制使 P(C) 从 ~1 掉到 ~0，标红。这是触发链的指纹。

健康区间是中间地带：若干机制各自使 P(C) 显著下降但都不归零。**"可部分替代"是涌现的正面证据，"处处必要"反而可疑**——这一点纲领完全没有提到，而它比"我没写这条规则"（`abm-methodology` AP7 点名的反模式）强得多。

### F8. 因果图只有一层，会系统性把「信念因」记成「事实因」

**针对**：原则 2（因果链）× 原则 4（信息边界）× 原则 9（世界事实与历史叙事分离）三者的交点。

**失败机制**。原则 9 只区分了"世界事实"与"世界内的人所知道的"，但**因果图本身属于哪一层，纲领没说**。默认实现会把因果图放在世界事实层，边指向"当时的真实状态"。于是当一个政体因为一条**错误情报**开战时，因果链会记成"因为边境粮价上涨"（事实），而真实原因是"因为使者带回了一条假消息"（信念）。三百年后回答"为什么这个国家灭亡"，我们会得到一条**结构正确但归因错误**的链条。

这个错误是**系统性的、单向的**：它总是把历史解释得比实际更理性、更结构化。而这恰好是 LLM 最容易强化的方向——`complex-systems-emergence` §8.5 记录了 Madge et al. 的实测：把 Turchin 模型的攻击目标选择从随机改成贪心，`R²` 从 0.66/0.66/0.49 掉到 **0.22/0.39/0.26**，且草原起点的因果影响被完全抹平。让 agent 更"聪明"让宏观历史更不真实。

**可观察症状**。因果链里"因错误信息导致的重大事件"占比接近零；世界内部的历史学家（第 24 行的功能）写出的历史与世界事实层几乎一致，没有系统性误解可写；反事实实验"如果这条情报是真的"无法进行，因为系统里根本没有"这条情报"这个对象。

**替代设计**：
1. 因果边**必须带类型**：`caused_by_fact(X)` / `caused_by_belief(agent, X', t_belief_formed)` / `caused_by_absence_of_information`。信念边必须引用信念库中的具体条目及其注入路径（哪个信使、走了多久）。
2. 新增一个一等观测量：**信念—事实背离度**（belief-fact divergence）。它同时是三样东西：一个 bug 检测器（背离度恒为零 ⇒ 信息边界没生效）、一个合理性判据（真实历史里这个量显然不为零，且在信息基础设施改善时下降）、以及第 24 行"世界内历史学家"功能的数据源。
3. 三值逻辑是刚需：世界状态里"不存在"和"不知道"必须是两个不同的值。`cliodynamics-secular-cycles` AP-6 给了一个真实的教训——Beheim et al. 2021 发现 **61% 的缺失被重编码为"无道德神"，结论因此反转**。

### F9. 路径依赖越成功，任何分布型判据的统计功效越低

**针对**：原则 3（路径依赖）与任何"跨模拟稳健性 / 真实历史应落在集合分位内"的判据之间的数学冲突。

**失败机制**。"同一机制、不同种子应产生分布相同而实例不同的历史"这句话隐含**遍历性**假设。但强路径依赖 + 递增回报产生的正是**非遍历**过程：集合分布重尾、方差随时间发散。两个后果：
1. 有限次运行估不出这个分布。硬证据来自 Stonedahl & Wilensky（`abm-methodology` §2.8，brief 标注读到全文）：**用 30 次重复时 GA 参数（891.4, σ=65.8）显著优于 Janssen 参数（945.3, σ=80.0），t 检验 p<0.01；改用 100 次重复后变成 943.1 (σ=324.5) vs 930.6 (σ=194.4)，结论反转。** 误差分布非正态，"通常更好但偶有极端离群"。也就是说，**重复次数可以决定结论的方向**。
2. 判据的判别力与集合方差成反比。`complex-systems-emergence` §8.11 提出的验收标准"真实历史的宏观指标应落在我们模拟集合的 5%–95% 分位之间"（brief 自标 D 级、无文献先例），在集合足够宽时是**平凡满足**的——什么都落在里面。原则 3 越成功，原则 8 越无力。

**可观察症状**。同一版本的两次评审给出相反结论，差别只在跑了多少次；有人开始"多跑几次直到通过"；集合的分位带宽到任何历史都落在里面，而团队把这解读为"我们的世界很有可能性"。

**替代设计**：
1. **重复次数与检验统计量必须预注册**，且必须先做**功效分析**：给定当前集合方差，需要多少次运行才能以 80% 功效拒绝一个已知不同的机制版本？**若答案超过算力预算，该判据不得进入验收集**——它只是装饰。这是把"这条判据有没有用"变成可计算问题的唯一办法。**[我的推断，无来源]**
2. 统计量必须按遍历性分类：**率型**（战争频率、迁徙率、技术采纳速率——近似可估）进验收集；**身份型**（哪个政体统一了哪块地——非遍历）只能进多样性报告，永不进验收集。
3. 不检验"分布相同"，检验**种子可交换性**：对预注册的统计量做置换检验；配合能量距离/MMD 两样本检验，并报告其功效。
4. **"同一机制"的等价类必须包含参数**。Stonedahl & Wilensky 的对抗式敏感性分析显示：在校准点 **±10% 邻域内**，同一个模型既能产出人口爆炸，也能产出**公元 994 年归零的缓慢灭绝**（把目标换成最小化 Pearson r，得到平均 r = −0.18，单次最低 −0.6）。所以稳健性必须**同时**在 seed 与 NROY 参数集上抽样，否则报告的只是一个点的稳健性。

### F10. 把结构性统计当目标 = 换一种方式拟合真实历史

**针对**：原则 8；以及"用城市 rank-size、战争规模分布、财富分布服从幂律"这类判据的天真用法。

**失败机制**，分三段，每段都有硬证据：

1. **幂律是免费的。** `complex-systems-emergence` §2.3 引 Marković & Gros (2014, *Physics Reports* 536:41–74，brief 标注读到 arXiv 全文 PDF) 的结论：**任何把平均活动水平恒稳地维持在界限内的动力系统，在统计上等价于一个自组织临界分支过程，因此是标度不变的。** 我们的模拟必然有人口—资源稳态反馈，所以幂律**几乎必然出现**。把它写进验收集，我们买到的是虚假的安全感，不是约束。此外 HOT 与 coherent noise model 都能在非临界下产生重尾，所以"看到幂律 ⇒ SOC ⇒ 涌现"三个环节全断。

2. **有些幂律要求是错的。** Clauset, Shalizi & Newman (2009) 重新分析 24 个经典"幂律"数据集，**7 个被明确排除，其中就包括财富**；对数正态在 23/24 个数据集中都没有被排除，原文说"我们发现极难区分对数正态与幂律行为"（brief 标注读到原文 PDF）。**如果我们要求模拟的财富分布服从幂律，我们是在要求它违背这个领域最好的经验分析。**

3. **有些指数是内生的，固定它就是建模错误。** 战争规模的 α̂ = 1.53 ± 0.07 来自 Clauset (2018) 的 1823–2003 国际战争（95 场，x_min=7061 战斗死亡；`war-conflict-logistics` §2.2 标注全文已核验），而同一节明确写着"**只覆盖 1816 年后；前现代战争没有可比的伤亡数据库**"。更关键的是 Cederman, Warren & Sornette (2011) 论证幂律指数会随"民族主义 + 大规模动员"这一制度变迁而变化——**指数本身是内生的**。把 1.53 当成青铜时代东亚的目标，等于把工业化民族国家的动员结构强加给一个还没有常备军的世界。

同样的问题在 rank-size 上更严重：Cottineau (2017) 的 MetaZipf 元分析（86 项研究、1,962 个指数估计）给出**均值 α = 1.025、中位数 0.986、标准差 0.282**，并且 **40% 的指数变异来自技术选择**（口径、截断阈值、估计方法；巴西高达 80%）。而 Altaweel (2015) 在北 Jazirah 的对照给出了与直觉**相反**的方向：中青铜时代（政治碎片化）Zipf 偏离度 0.58，铁器时代（新亚述帝国统一行省治理）0.69——**帝国统一时期反而更凸，不是更 primate**（p<0.01）。`settlement-urbanization-spatial` §7 的作者据此明确写道："我倾向认为这个判据不可靠。"

**可观察症状**。有人报告"我们的战争规模服从幂律，α=1.6，很接近真实历史"，并把这当成成果；有人为了让 α 更接近 1.0 去调参数；某次改动让 α 从 1.4 变到 1.7，团队试图从政治上解释它（而实际上是把聚落截断阈值从 500 改成 1000 造成的）。

**替代设计**：
1. **单边排除，不做双边拟合。** 判据形如"若 α 落在人类所有已知系统的经验散布之外则失败"，例如 rank-size 只在 α ∉ [0.4, 1.8] 时报警。α → 1 **永远不是目标**。
2. **口径三元组强制随行**：任何 α 必须与（截断阈值、聚落定义、估计方法）一起报告；且必须报告多个阈值下的敏感性带。这在我们的世界里是免费的——我们可以自由改变"聚落"的定义。
3. **分布拟合与条件均值回归严格分开**：`P(x) ~ x^{-α}` 用 MLE + KS 定 x_min + ≥2500 个合成集算 bootstrap p 值 + 与对数正态/指数/拉伸指数/截断幂律做似然比（Clauset 程序，p ≤ 0.1 排除幂律）；`E[A|N] ~ N^α`（settlement scaling）用混合效应模型并显式建模波动（Leitão et al. 2016）。`complex-systems-emergence` §8.2 说混淆这两件事是这个领域最常见的技术错误。
4. **正面证据只能来自多指数自洽与标度坍缩**，不是单个指数。Lee et al. (2020, *Phys. Rev. E* 102:042312) 的 RBAC 给了范式：模型预测 δ_n/ζ = 1，数据 1.06 ± 0.05；组合检验 1 − γ_r − θ_r + δ_n/ζ ≈ 0.9（预测应为 1）；短长雪崩的归一化轨迹大体坍缩到一条普适曲线。**一个指数可以被拟合，五个指数之间的代数关系很难被拟合。**
5. **每条重尾判据必须配一个打乱基线**：把地理邻接打乱后重跑，若幂律依旧出现，则这个幂律与我们的地理机制无关，不得作为成果。

### F11. 「防止为戏剧性制造事件」没有可计算的检测量

**针对**：Phase 0 待答问题「如何防止模型为了戏剧性制造事件？」；原则 5 与第 9 行。

**失败机制**。纲领的对策是架构性的（AI 不决定客观结果），这是对的但不够——**AI 仍然决定"是否发动战争"，也就是决定了事件的发生本身**。戏剧性偏置会通过决策层而非结算层进入世界，而结算层的正确性完全掩盖不了这一点。而且这个偏置是有方向、可预测的：`llm-agent-social-simulation` §2.1 记录 Generative Agents 作者自述其 agent 因指令微调而**过度合作**（即使与自身既定利益冲突也答应请求）、**说话过度正式**；Larooij & Törnberg 的综述记录 LLM 回应"更长、更礼貌、更善表达、更尊重"。这些偏置在文明尺度上会累积成系统性的历史失真。

**可观察症状**。战争、革命、宗教诞生的时间间隔分布过于规整（没有长时间的无事期）；重大事件倾向于在"合适的时刻"发生；某类事件的发生率在 LLM 换模型后显著变化，而机制没动。

**替代设计**：一个可计算的**决策残差**。对每个由 agent 发起的动作：
```
用 agent 在 t⁻ 的信念状态重算效用分解  U(a) = Σ_i w_i · u_i(a | belief)
候选集 A 必须包含 "什么都不做" 与 ≥ k 个可行替代
irrationality_bits(e) = −log2 P_softmax(a_chosen | U, τ)
```
判据不是逐事件硬失败（那会把 agent 变成最优化器，而 `complex-systems-emergence` §8.5 证明那样更不真实），而是**分布性的**：
- `irrationality_bits` 的全局分布必须稳定；
- **不能被单个事件类型长期占据尾部**。若"战争"事件的残差系统性高于其他事件类型，说明 LLM 在战争上编故事。这是"为戏剧性制造事件"的可观测指纹。
- 关键工程约束：**效用分解必须在动作被裁决之前落盘并哈希**，事后不得修改；LLM 的自然语言理由是附件，不参与检查。权重 `w_i` 必须是 agent 的持久状态（有世界内的来源：家族、教育、经历），不能每次由 LLM 现编——否则整个检查是循环的。
- 配套消融（`complex-systems-emergence` §8.5 明确要求）：**把 LLM 决策换成随机基线，若宏观模式变好，说明我们的 LLM 接线方式是错的。**

### F12. 逐事件检查在数学上抓不住并发违约

**针对**：原则 2 的"每一个重大事件"这个逐事件框架。

**失败机制**。逐事件的合理性检查是局部的：每场战争单独通过后勤检查，但同一年三场战争合计超过全国盈余；每座城市单独在粮食半径内，但它们共享同一片腹地。**局部一致不蕴含全局一致**，这是合成谬误，而纲领的整个因果链框架是逐事件的，会诱导团队只做局部检查。

**可观察症状**。资源总量出现缓慢漂移（浮点误差之外）；政体能同时维持三条战线而财政从未见底；某个区域的粮食被两个城市各自"合法"消耗了一遍。

**替代设计**：在逐事件五闸门之上，必须有一层 **tick 级的守恒审计**：
- 每 tick 对每种守恒量（人口、粮食、金属、马匹、财政）做一次全局收支闭合检查，把所有并发事件的占用相加，容差为浮点误差量级。不平即构建失败。
- 每 tick 对每种共享资源做一次**并发占用检验**（同一片腹地不能被两个城市各自全量计入）。
- 这一层不产生"合理性"判断，它产生**硬 bug**。它的价值在于：它完全不引用真实历史，因此是"合理"里最硬、最便宜、最该先做的部分——**而纲领里一个字都没有提到守恒律**。

### F13. Goodhart：校准集与验收集未分离，而 POM 本身就是逆向参数化工具

**针对**：整个判据体系（包括本文提出的）。

**失败机制**。判据一旦进 CI，每一次参数调优就是对判据做梯度上升。这不是风险，是必然。而且问题比一般的过拟合更深：**POM 的三个标准用途里就包括"用多个弱模式同时约束来做逆向参数化（inverse modelling），把不可直接测量的参数间接定住"**（`abm-methodology` §2.4）。也就是说，POM 明确把模式当作**训练信号**。那么同一批模式在数学上**不可能**同时充当验收信号。纲领没有区分这两种用途，团队会在两年后拥有一个完美通过全部判据、但只是被拟合出来的世界。

配套的技术问题是多重检验：20 条模式 × 若干消融臂，在 α=0.05 下期望约 1 条假失败。没有预注册的通过规则，电池的结论可以靠挑选报告方式决定。

**可观察症状**。判据通过率随版本单调上升；某条判据从未失败过（说明它已被拟合，或它本来就是平凡的）；改动的 commit message 里出现"fix pattern battery"。

**替代设计**：
1. **模式预算账本**：记录每条模式被"看过"多少次（每次用它指导过参数调整就 +1）。看过 N 次以上的模式自动降级为校准集，永久移出验收集。
2. **封存验收集**：一部分模式在 Phase 0 结束时封存，只在预注册的版本里程碑开封一次，**开封即作废**（之后进入校准集）。
3. **持续补充**：验收集必须从"团队尚未读过的文献"中持续补新模式。这是唯一能长期维持判别力的机制。
4. **验收集只用序数/方向性判据**（"随复杂度上升更陡""在地形阻隔大的方向扩散更慢""制度变迁后指数向上移动"）。点值判据几乎总能被拟合，序数约束难得多。

### F14. 判据的形态偏置会以「可验证」之名重建一条隐形科技树

**针对**：原则 1（不预设阶段）与原则 7（允许荒诞）——这是判据体系对纲领最核心承诺的反噬。

**失败机制**。我们能拿到经验散布的量，全都是关于城市、战争、财政、政体规模的——因为只有这些有考古与统计数据。于是任何**不产生这些量**的文明形态（长期无城市的游耕体系、以仪式竞赛替代战争的秩序、无中心财政的分布式治理）会被判据系统性地判低分。团队会调参把世界推回"有城、有战、有税"的形态，因为那是唯一能让电池变绿的形态。**这就是一条隐形科技树，而且是我们以严谨之名亲手装上去的。**

这不是假想：`state_formation` §9.a 的六个"前置条件"表里，**协调收益、人口密度、粮食可储存性三条都有反证据**（Turchin 2022 中 Pop 未入选最佳模型；Infra、Irrigation、Cap、Market、Money、Info 全线无支持，功能主义模型 ΔAIC 23–63）。也就是说，我们直觉上认为"文明该有"的那些东西，最好的定量研究并不支持它们是驱动因素。如果判据体系编码了这些直觉，它编码的是被证伪的理论。

**可观察症状**。所有种子最后都长出结构相似的农业—城市—官僚世界；某次改动让世界出现了一种奇特形态，同时电池红了三条，团队回滚了改动而没有讨论这三条判据是否适用；判据集里没有任何一条允许"缺席"。

**替代设计**：
1. 判据必须**条件化在形态类别上**：先用无监督方法（对宏观状态向量做聚类）识别世界当前属于哪个形态类别，再套用该类别的判据集。跨类别的判据只能是守恒律与信息光锥这类普适约束。
2. 验收集里**必须包含至少一条"允许缺席"的判据**：例如"在 ≥10% 的种子中，5000 年内不出现文字/常备军/中心财政，且这不算失败"。若实际比例为 0%，说明世界被判据挤压成了单一形态——这本身应当报警。
3. **形态多样性账本**：记录每一次"为通过判据而做的参数改动"，定期报告"我们为了通过判据放弃了多少形态多样性"。这是一个治理机制，不是技术机制，但它是唯一能让 F14 在两年后仍被看见的东西。

### F15. 验证算力从未进预算，而它会超过模拟算力本身

**针对**：Phase 0 待答问题「如何让数千年的模拟在计算成本上可行？」与第 26 行"不追求尽快堆出大量代码"。

**失败机制**。纲领只把算力问题理解为"跑一次模拟贵不贵"，但真正的成本在验证侧，量级如下：
- 一次涌现认证需要 N ≥ 50 个独立种子（`abm-methodology` M7）。
- 一次消融矩阵需要 (|M|+1) 臂 × N 种子 × NROY 参数抽样。若 |M|=20、N=50、参数点 10，就是 **10,500 次完整长跑**。
- 对抗式敏感性分析：Stonedahl & Wilensky 在 12 参数、每点 15 重复下用 45,000 次运行完成**一次**搜索，5 次搜索约 **2500 CPU 小时**——而他们的模型是 80×120 格、700 年、单一族群的 Artificial Anasazi。我们的目标是东亚全域、数千年、多层级、带 LLM 调用。
- 事件级的 σ(e) 需要逐前因的留一重放。

结论：**验证算力会是模拟算力的一到两个数量级**。纲领没有为它留位置，实际后果是验证会被"以后补"，然后永远不补。

**可观察症状**。"这次先不跑全套电池，赶下个里程碑"出现第二次；消融矩阵的最后一次完整运行是三个月前；有人提议把 N 从 50 降到 10。

**替代设计**：
1. **验证预算必须被声明为总算力的固定下限**（我建议 ≥50%），并在里程碑评审时作为一项硬指标。
2. **必须有一个 CI 级的玩具世界**：小地图、300–500 年、简化机制，全套判据能在每次提交上跑完。全尺度长跑只在里程碑做。玩具世界的规格是 Phase 0 的交付物之一。
3. **机制数量上限 |M| 必须预先声明**（消融成本 ∝ |M|）。这条约束会反过来强迫我们做机制取舍，这是好事——`cliodynamics-secular-cycles` AP-4 引 Turchin 自己的警告："大型复杂模型往往结构不稳定，一个参数的小变化会导致动力学大变"，主张 "a spectrum of models, each simple enough"。
4. **所有判据必须能从压缩的事件日志计算**，不能依赖全状态转储。这是一个必须在写第一行代码前定的存储格式决定。

### F16. 拿学界无共识的经验结论当校准目标

**针对**：原则 8「用真实文明检验我们的机制是否至少能够产生合理的社会现象」。

**失败机制**。"政体寿命分布"看起来是最自然的一条合理性判据。但 `cliodynamics-secular-cycles` §2.9 列出了**四个互相矛盾的结论**：
- Arbesman 2011（41 个帝国）：指数分布，τ ≈ 220 年；
- Scheffer et al. 2023 *PNAS*（MOROS 324 个 + Seshat 291 个）：**饱和危险函数**，风险在前两个世纪陡升后饱和，寿命分布单峰、众数约 200 年，恒定风险模型拟合明显差；
- Ciliberti 2025（168 个政治实体）：**指数分布**，τ = 298 年，KS p = 0.71；
- Lu et al. 2021（22 个中国帝国）：**幂律**。

而 Wand 2024 对 Scheffer 数据的贝叶斯重分析指出，"年轻国家更稳"很可能是**幸存者偏差**——活不过 200 年的国家没留下足够痕迹进入数据库。brief 的原话是："**连『帝国寿命分布是什么形状』这个最基础的问题，学界都没有共识。**"

如果我们把其中任何一个当作验收目标，我们校准的是一场学术争论的某一方，而不是"合理性"。

**可观察症状**。校准文档里出现"目标：政体寿命 τ ∈ [200, 320]"这样的条目，引用一篇论文；有人发现换一篇论文目标就变了；为了打中这个区间调了继承制度的参数。

**替代设计**：
1. 争议量只能进**观察集**（报告我们的世界属于哪一族），不得进验收集。
2. 若一定要比，必须先跑**考古可见性滤镜**：模拟"如果只有留下足够痕迹的政体被记录，分布会变成什么样"，再与真实数据比。我们有完美的 ground truth，这个滤镜是可做的，而真实数据没有这个条件——这正是模拟相对经验研究的优势，不用白不用。
3. 同理适用于所有"共识度未标注"的判据。**每条判据都必须带证据等级，且 C 级判据一律不进验收集。**
4. 顺带：语言分化树的形状、思想运动的扩散、宗教内容的演化，我在现有 21 份简报里**没有找到任何可核验的经验散布**。这些量若强行进入验收集，阈值只能是我们编的。它们应当被明确列入"我们承认无法验证"的清单。

### F17. 信息边界没有可机械执行的定义

**针对**：原则 4「世界中的人物和组织只能根据自己当时合理能够获得的信息行动。模拟器拥有全局状态，但 Agent 不能拥有上帝视角」。

**失败机制**。"合理能够获得"是一个价值判断，不是一个谓词。在 LLM 架构下，泄漏有两条路径，而且都不会报错：
- **显式泄漏**：prompt 里塞进了 agent 不该知道的世界状态；
- **隐式泄漏**：prompt 里没塞，但 LLM 从训练语料里"知道"某类局面该怎么走，做出恰好正确的决策。Larooij & Törnberg 把这类现象归为 **selection bias / data leakage**——LLM 可能"复现既有研究结论"而不是动态生成行为。

第二条无法通过审查 prompt 发现。

**可观察症状**。远方的信息在没有信使的情况下影响了决策；agent 的决策质量与其信息基础设施（驿传、文书、商路）**不相关**；把 prompt 里的地理名称替换成随机字符串后，决策质量显著下降（说明模型在用真实世界知识）。

**替代设计**（两个都要）：
1. **信息光锥检查**（对显式泄漏，硬失败）：事件 e 的决策者 d 引用的每个命题 f，必须在 d 的信念库中，且该信念的注入路径可追溯到一条实际的传播链（信使/商队/俘虏/文书），累计传播时间 ≤ t − t(f)，速度取自地形与技术决定的传播速度表。`settlement-urbanization-spatial` §4.3 有 ORBIS 的运输速度表可以作为起点。**这是原则 4 唯一可机械执行的版本，Phase 0 必须先产出这张速度表，否则原则 4 只是一句愿望。**
2. **反事实盲测**（对隐式泄漏，统计判据）：把 prompt 中的真实事实随机替换为等概率的假事实，若决策分布不变，说明没泄漏；若显著改变，说明该 agent 在用不该有的信息。可自动化、可抽样执行。**[我的推断，无来源]**——我在简报里没看到有人做过这个，但它成本低且信号清晰。

## 4. 可接受的取舍（说明代价）

### F18. 可验证性天然偏袒「有城、有战、有税」的文明形态

这是 F14 的取舍版本：即使我们做了形态条件化和"允许缺席"判据，可验证性仍然会对**留下可测痕迹的形态**有系统性偏好，因为经验散布只在那里存在。**代价**：本项目最有价值的那类结果（人类历史上从未出现的文明形态）恰好是最难验证的。**接受这个取舍的正确方式**：显式声明"高验证等级"与"低验证等级"两类结果，后者可以生产、可以展示、但在任何"我们证明了 X"的表述里必须标注为未验证。不接受这个取舍的错误方式：假装判据是形态中立的。

### F19. 认真做验证会让项目慢 3–10 倍

**代价**：每加一个机制要付消融矩阵的成本；每次改判据要重跑历史结论；验证算力吃掉一半以上预算。**收益**：Phase 0 成功标准（"可以解释它为什么发生，而不是只能回答'因为 AI 生成了它'"）真的能被满足。**这个取舍必须被明确选择，不能默认。** 如果团队不接受这个代价，那么诚实的做法是把项目目标降级为"生成有内部一致性的历史文本"——这是一个正当的、有价值的目标，很多人会喜欢它——但**不能一边宣称是可验证的文明模拟，一边只做文本目标的验收**。这两者的区别恰恰是纲领第 44 行想要的区别。

## 6. 纲领没说、但必须在写代码前决定的事

1. **「重大事件」的可计算定义**（否则原则 2、7 都不可执行）。
2. **因果图 schema**：PROV-DM 风格的 Entity/Activity/Agent 三元组 + `wasGeneratedBy`/`used`/`wasDerivedFrom` 边（`abm-methodology` §2.19 指出这是现成形式化，不必自己发明），**外加双层边类型**（事实因 / 信念因 / 信息缺失因）与信念快照引用。并且：**schema 里不得存在"结构性前因权重"的自报字段**——σ(e) 只能由重放测得，字段不存在比"约定不使用"强。
3. **重放契约**：`step(state, rng_stream, proposal_log)` 纯函数签名；LLM 输出物化协议；"重调模型 = 新分支"的语义；逐位一致的 CI 断言。
4. **类型词汇表分层**：primitive（允许在 t0 存在）vs composite（必须由运行期规则实例化）；类型抹除测试；内核不得 import 观测器的构建期检查。
5. **判据治理**：预注册文件格式与哈希提交流程；校准集 / 封存验收集的划分；模式预算账本；开封即作废规则；FDR 控制；**以及一条元规则——判据失败时，谁有权改机制、谁有权改判据、改判据后必须重跑哪些历史结论。**
6. **参考集合（reference ensemble）的定义与版本**：荒诞度相对什么先验度量（我建议由三个空模型的输出构成，见 F3）。
7. **「同一机制」的等价类**：代码 + NROY 参数集。稳健性必须联合抽 seed 与 θ，不能只抽 seed。
8. **验证算力预算比例 + CI 级玩具世界规格**（小地图、300–500 年、全套判据每次提交跑完）。
9. **三个诱饵世界的规格**（剧情树 / 纯外生驱动 / 纯噪声）。
10. **三值逻辑**：世界事实层的"不存在" vs 记录层的"未知"，两个不同的值。
11. **事件本体的最小区分**：`政权更替`（统治集团更换，制度延续）/ `国家解体`（中央权威消失，制度部分保留）/ `社会崩溃`（人口、城市化、文字、分层同时下降）。`cliodynamics-secular-cycles` AP-11 引 Scheffer et al. 2023 明确区分：晚青铜时代克里特的终结带来人口、宫殿体系与文字的消失，而中国的很多朝代更替"基本上只是统治精英的替换"。**不做这个区分，"为什么这个国家灭亡"这个查询在语义上是三个不同的问题。**
12. **信息传播速度表**（按地形、技术、制度）与通行成本图——信息光锥检查的前提。
13. **效用分解 schema**：权重 `w_i` 的世界内来源、落盘时机（必须在裁决前）、哈希。
14. **机制数量上限 |M|** 与单次长跑的成本目标。
15. **事件日志的压缩格式**：所有判据必须能从日志算，不能靠全状态转储。
16. **调度顺序作为 spec 的一等公民**。这条纲领完全没提，但它是这个领域最著名的复现失败原因：Kehoe (2016) 对 Sugarscape 的形式化发现"**书里没有说规则以什么顺序应用**"，这是 Sugarscape 出版 20 年后仍无法被无歧义重实现的三大原因之一（brief 标注读到全文）。Epstein 2002 civil violence 模型更极端——Mesa 实现的注释明确写着公式里的取整操作"不在 PNAS 原文中，但没有它就不可能复现原文展示的动态"。**顺序是一个隐藏参数，而且是一等重要的参数。**

## 7. 正面交付：对四个问题的回答

### 7.1 不用真实历史当答案，怎么判断一个虚拟文明「合理」

分四层，**判别力从上到下递减，成本从上到下递增，而团队的自然倾向恰好是从第二层开始做**。

**L1 一致性判据（零真实历史输入，最硬，最便宜，纲领完全没提）**
- 守恒闭合：人口、粮食、金属、马匹、财政的每 tick 全局收支闭合到浮点误差。
- 后勤上界：任何军事行动的日耗 × 天数 ≤ 携行 + 沿途可征。`war-conflict-logistics` §4.1–4.3 有人畜日耗、载重、行军速度、纵队长度、就地征粮门槛的一手数字。
- 信息光锥：见 F17。
- 会计可枚举：精英 = 具名职位/爵位/土地阈值以上财产的**可枚举个体**（`cliodynamics-secular-cycles` AP-14）；官职槽位数 = 枚举；"精英过度生产" = 候选人数/空缺数这个**可数比值**，不是比例参数。
- 并发占用：同一片腹地不能被两个城市各自全量计入。
> 这一层的每条违反都是 bug，不是"不合理"。它应该是 CI 断言，且**应该先于任何统计判据实现**。

**L2 结构性统计判据（弱、序数、单边排除、带口径）**
用法必须是"落在人类所有已知系统的经验散布**之外**才算失败"，绝不是"打中某个值"。可用的与不可用的：

| 量 | 经验锚点 | 可用性 |
|---|---|---|
| 聚落标度 α（面积–人口） | 理论 [2/3, 5/6]；墨西哥盆地 N<5000 时 0.671 [0.651,0.691] (n=1510) | **最好的一条**。有理论闭式 + 跨大洲考古检验 + **出现时间**判据：Chelazzi & Lawrence 2026 显示新石器 β=0.051 (p=0.727) → 铜石并用 0.097 (p=0.427) → 青铜 0.246 (p<0.001)，标度关系是在青铜时代"打开"的 |
| 产出标度 1+δ ≈ 7/6 | 公共土丘建造速率 1.177 [1.028, 1.327] (n=48) | 可用，同上 |
| 城市 rank-size α | 均值 1.025、**sd 0.282**、40% 变异来自技术选择 | 只能单边排除（α ∉ [0.4,1.8] 报警）。**禁止**把 α 变化解读为政治整合：Altaweel 2015 显示帝国期反而更凸 |
| 战争规模重尾 | Clauset 2018: α̂=1.53±0.07, x_min=7061, n=95, p_KS=0.78 | 只能作为最低门槛。幂律是免费的（Marković & Gros）。指数是内生的（Cederman et al. 2011）。**正面证据必须来自多指数自洽 + 标度坍缩**（Lee et al. 2020） |
| 财富分布幂律 | **被 Clauset 等明确排除** | **反向判据**：若我们的财富分布是干净幂律，反而可疑 |
| 复杂度 PC1 方差占比 | Seshat: ~75%（414 社会、30 区域、51 变量） | **双边判据**（罕见的好东西）：99% ⇒ 机制退化为单驱动；40% ⇒ 维度间无耦合。两端都能失败 |
| 政体寿命分布 | **四个互相矛盾的结论**（见 F16） | **不得进验收集**。只进观察集，且比之前必须先过考古可见性滤镜 |
| 语言分化树形状 | 现有 21 份简报中**找不到可核验的经验散布** | **不得进验收集**。任何阈值都是我们编的 |

**L3 条件性/比较性判据（判别力最高，最少被使用）——这是我最想给纲领补的一层**

核心洞见：**边际分布是廉价的，条件关系才是贵的。** 任何过参数化模型都能拟合一条边际曲线；同时满足一批"如果扭动 X，Y 应该按已知方向移动"的比较静力学关系，难得多。而且这类判据**完全不要求复刻真实历史的任何数值**，只要求方向与序关系——它天然绕开了原则 8 的限制。候选（全部有简报支持）：

- 给定到草原前沿的距离，政体规模与军事技术应有梯度。这是最强的可测前置条件：Turchin 2013 的消融显示关掉"技术→同化"耦合会让 R² 从 **0.65 掉到 0.16**；草原前沿是最强的宏观地理预测因子。
- 给定继承制度稳定性 τ，政体寿命的方差应显著响应。Gavrilets 2010 的方差分解：**τ 占复杂酋邦寿命方差 55.5%**，"实力能否决定胜负的程度 α"占最大政体规模方差 **39.8%**——这两个因素比人口、粮食、地形封闭度都重要。
- 给定地形通行成本，政体半径分布应按 Spencer 的半天路程半径逻辑移动。
- 给定作物可征取性，抽取率 θ 与集中化程度应同向移动。
- 给定信息传播速度，帝国最大半径应有上界响应。
- 给定"决策温度 τ"（信息质量），宏观分布应按 Madge et al. 的方向变化：**决策越贪心，地理与技术造成的结构差异越被抹平**。这是一条可以直接用来检验"我们的 LLM 接线是否正确"的判据。
- 给定移动成本参数改变 2 倍，聚落标度 α 应按理论关系移动。**若 α 完全不动，说明它是硬编码的**——这条同时是 L3 判据和 F5 的反脚本检查。

**L4 跨模拟稳健性（按 F9 的方式做，不是按直觉做）**
- 预注册重复次数与统计量；先做功效分析，功效不足的判据不进验收集。
- 率型统计量进验收集，身份型只进多样性报告。
- 检验种子可交换性（置换检验）+ 能量距离/MMD，不检验"分布相同"。
- 联合抽 seed 与 NROY 参数，不只抽 seed。

### 7.2 「涌现了国家」 vs 「我们把国家的定义写进了触发条件」

**操作化定义。** 宏观范畴 C 在世界 W 中涌现，当且仅当六条全部成立：

- **D1 随附性**：C 的判定函数 `obs_C` 是微观状态的纯函数，且位于内核之外，内核对它无任何数据依赖（构建期检查）。这是硬前提——Rosas 的 Ψ 与 Barnett–Seth 的 T 都假设 `V_t = f(X_t)`；若 C 是脚本直接写入的字段，`Ψ` 会**异常地大**，度量给出的是伪阳性满分（`complex-systems-emergence` §8.9 与 M4 的伪阳性分析）。
- **D2 词汇表隔离**：内核类型词汇表中不存在 C 的标签；C 的构件只能是原语（角色、建筑、授权边、贡赋流、行走时间、继承计数）。`state_formation` §9.a 的观测器是一个好模板——它的每一项都是对已有状态的读取，"内核里没有任何一条规则形如『当 X 时进入国家阶段并解锁 Y』"。
- **D3 多重实现**：跨种子的 C 实例在制度向量空间中的两两距离，其分布显著大于同一实例的时间自距离。**不同世界的国家必须长得不一样。**
- **D4 有必要机制、无充分机制、且机制间部分可替代**：存在 m 使移除后 P(C) 显著下降；不存在 m* 使 P(C|m*)≈1 且 P(C|¬m*)≈0；且存在两个不相交的机制子集，各自被关闭后 C 仍以不同形态出现。见 F7——**第三项才是正面指纹**。
- **D5 路径依赖**：单点扰动（同种子，只翻转一次抽样）能显著改变 C 的出现时间与形态分布。若数十次单点扰动下 C 的出现完全不变，说明它对历史路径不敏感，与原则 3 矛盾。
- **D6 前驱连续性**：C 的判定量在出现前有连续爬升的前驱轨迹，而不是单 tick 阶跃。**阶跃是触发器的指纹。**

**消融实验设计（可执行）**：

```
机制集 M（|M| 预先声明上限，建议 ≤ 20）
臂：baseline + 每个 m_i 单独关闭 + 预先声明的 k 个二元组合（抓互补性）
每臂：N=50 种子 × NROY 参数 10 点 = 500 长跑
报告矩阵（照 Turchin Table 1 格式）：臂 × 模式 的通过率，不是单一 R²
额外三列（这三列才是新东西）：
  - P(C) 在该臂下的值（不是"是否通过"，是频率）
  - 该臂下 C 实例的形态多样性（制度向量的成对距离中位数）
  - 该臂下 C 出现处是否为阶跃（变点检测）
```

**判读规则（预注册）**：
- 关掉任一机制 C 都消失 ⇒ **标红**，触发链嫌疑。
- 关掉任何机制 C 都不变 ⇒ **标红**，硬编码或外生驱动嫌疑（Janssen 教训：纯外生承载力模型能达到 ABM 90% 的拟合）。
- 若干机制各自使 P(C) 下降但不归零，且被关闭后形态不同 ⇒ **通过**。
- 无论哪种结果，认证只授予"解释候选资格"，不是"已解释"。Epstein 的原话：多重生成者不是尴尬而是 "embarrassment of riches"；裁决多个生成者的唯一办法是**收集新的微观数据或设计新的微观尺度实验**。所以每份认证必须附一份"其他能产出同一现象的候选机制"清单，以及"要在它们之间做裁决需要什么新数据"。

**必须配套的三个非统计检查**（因为消融在数学上不够，见 F7）：类型抹除测试、内核→观测器单向依赖的构建期检查、阶跃探测。

**以及最重要的一条**：在诱饵世界 W1（剧情树）上跑完这套流程，报告它把 W1 打回去的成功率。**做不到这一点，上面全部是自我安慰。**

### 7.3 一个可机械执行的事件合理性检查器

**总原则（决定成败）**：**所有闸门的输入必须从世界快照重算，永不接受事件 payload 的自报。** 否则检查器验的是生成器写下的理由，而不是实际起作用的原因——那是 `abm-methodology` AP9（用 LLM 评估 LLM）的变形。

**Gate 1 — 前置条件充分性。** 事件类型 e 有前置谓词集 `Pre(e)`，全部对 `t⁻` 的世界快照求值。任一不满足 ⇒ 硬失败。`Pre(e)` 的资源/人力部分由守恒律**自动导出**，人工部分必须审计覆盖率。
- 抓得住：无中生有（没有军队的政体发动远征、没有铸币能力的政体发行货币）。
- 抓不住：谓词集本身写少了。这是不可自证的，只能靠覆盖率审计缓解。

**Gate 2 — 信息可得性（信息光锥）。** 见 F17。硬失败 + 反事实盲测。
- 抓得住：上帝视角泄漏。这是原则 4 唯一可机械执行的版本。
- 抓不住：LLM 通过训练语料"知道"而不显式引用。只能靠盲测统计地抓。

**Gate 3 — 资源与后勤可行性。** 展开为资源流账，每步收支非负、库存非负；检查后勤上界（人畜日耗、驮畜破产距离、纵队长度、就地征粮门槛）。硬失败。
- 抓得住：无后勤远征、超财政的常备军、超粮食半径的城市。
- 抓不住：**并发违约**。必须由 tick 级守恒审计（F12）在事件层之外补上。**这不是"检查器可以更好"，而是"逐事件检查在数学上不可能做到"。**

**Gate 4 — 动机与收益一致性。** 见 F11。输出 `irrationality_bits` 残差，不做逐事件硬失败，做分布判据。
- 抓得住：为戏剧性制造事件（作为分布异常，不是单例）。
- 抓不住：事后合理化 —— 缓解手段是效用分解在裁决前落盘并哈希；权重必须有世界内来源。
- 抓不住：**共享的系统性偏置** —— 所有 agent 的价值权重由同一个 LLM 生成时会共享它的偏置。缓解：人格来源审计 + "把 LLM 换成随机基线，若宏观模式变好则接线错了"的消融。

**Gate 5 — 时间尺度一致性。** 每个事件类型声明一个由物理过程决定的**最小完成时间下界**（行军距离/速度、建造工日/劳力、书写传播/识字率、代际更替/人口结构），并验证事件与其因果前驱的时间差不小于信息传播时间。
- 抓得住：一年建成运河、三年长出官僚体系、一代人完成语言分化。
- 抓不住：**过慢**（没有上界）。补充对称检查：若某过程的完成时间长期处于下界的 10 倍以上，说明它实际由别的瓶颈决定，机制归因写错了。

**跨事件审计层（纲领完全没有，但缺了它前五道闸门都可以被绕过）**
- **A1 守恒审计**（每 tick，见 F12）。
- **A2 链式不可能性账**：为每条因果链累计 `−log2 P`，报告"这段历史需要多少比特的运气"。世界的年度总运气预算应当稳定；单个事件若消耗超过预注册的阈值，必须显式列出。这把原则 7 变成可执行的（见 F3 的不等式）。
- **A3 归因残差**：σ(e) 由重放测得，schema 里不存在自报字段。注意留一法的已知失效：存在强互补性（两个前因单独关闭都无影响、同时关闭才有影响）时留一法给出全零，因此**至少要做到二阶交互**。

**这套检查器整体抓不住什么（必须写进文档）**
1. 谓词集不完整 —— 不可自证。
2. **世界本体本身错误** —— 如果我们的经济学模型错了，所有账都平，世界仍然荒谬。这是检查器的上限，只能靠 L3 条件性判据从外部抓。
3. **分布层面的荒谬** —— 每个事件都合理，整体历史却毫无结构（或只有一种模式）。逐事件检查对此完全失明。
4. **LLM 的系统性风格偏置** —— 更长、更礼貌、更善表达、过度合作。只能靠随机基线消融抓。
5. **被拆散的触发器** —— 每个闸门都通过，因为触发条件写在机制里而不是事件里。只能靠类型抹除测试抓。

### 7.4 反过来：这套判据本身会不会变成新的剧情约束

**会，而且有五种不同的机制。这不是"注意一下"，这是必须被主动对抗的东西。**

**(a) Goodhart 化是必然的，不是风险。** 见 F13。POM 本身就是逆向参数化工具，同一批模式在数学上不能同时充当训练信号与验收信号。**对策**：模式预算账本 + 封存验收集 + 开封即作废 + 验收集只用序数判据。

**(b) 要求幂律确实是在拟合真实历史，而且比想象的更糟。** 三重问题：幂律是免费的（Marković & Gros，所以要求它等于不要求）；有些幂律要求是**错的**（财富的幂律被 Clauset 等排除）；有些指数是**内生的**（Cederman et al. 2011：战争指数随动员制度变迁而变，所以固定目标值在理论上就错）。**对策**：α 只能是输出。若一定要判据，判据应当是**条件性的**——"α 的时间序列应随可动员比例的制度变迁而移动，方向与 Cederman 一致"。这是关于**变化方向**的约束，不是关于**水平值**的约束，因此不构成剧情。

**(c) 判据的形态偏置会重建一条隐形科技树。** 见 F14。这是最严重的一种，因为它**以严谨之名**运作，而且团队不会察觉——每一次为通过判据而做的改动单独看都是合理的。**对策**：形态条件化 + "允许缺席"判据 + 形态多样性账本（一个治理机制，不是技术机制）。

**(d) 判据的功效被路径依赖吞掉，于是判据变成装饰。** 见 F9。原则 3 越成功，判据越无力。**对策**：功效分析作为判据进入验收集的准入条件。**功效不足的判据不是"弱判据"，它是零判据，留着它比删掉它更危险**——因为它会一直显示绿色。

**(e) 判据本身从未被标定，我们不知道它的伪阳性率。** 见 F6。brief 自己承认"没有任何文献做过『剧情树能否骗过涌现度量』的研究"。**对策**：三个诱饵世界 + 判据标定报告，作为 Phase 0 的硬交付物。

**最后一条自我批评**：上面这一整套（守恒审计、光锥检查、类型抹除、诱饵世界、功效分析、预注册电池）本身也是我编的，其中相当一部分标着 **[我的推断，无来源]**。它们的共同优点是**成本低、失败信号无歧义、不引用真实历史**；它们的共同缺点是**没有人做过**。所以它们也必须服从自己的规则：先在玩具世界与诱饵世界上标定，再决定哪些进验收集。如果标定结果显示某条检查在 W1（剧情树世界）上也通过，那条检查应当被删掉，而不是被辩护。

## 8. Phase 0 必须产出、但纲领没有要求的东西

1. **预注册的模式电池 v0**（哈希提交）：每条含陈述、方向性/区间、口径三元组、证据等级、来源、功效分析、归属（校准集/封存验收集）。
2. **判据标定报告**：全套判据 × 三个诱饵世界（剧情树 / 纯外生驱动 / 纯噪声）的伪阳性/伪阴性矩阵。**在 W1 上不失败的判据不得进验收集。**
3. **事件合理性检查器的可执行规格**：五闸门 + tick 级守恒审计 + 链式不可能性账，**外加一份明示的"抓不住什么"清单**。
4. **因果图 schema**（PROV-DM 风格 + 双层边类型 + 信念快照引用 + 无自报 σ 字段），以及一个在玩具世界上跑通的"为什么这个政体解体了"示例查询。
5. **重放契约的可执行测试**：同一 `(state, seed, proposal_log)` 重放两次逐位一致；单点扰动后的状态距离随时间**发散而非收敛**的曲线（这同时是原则 3 的验收证据）。
6. **词汇表分层清单 + 类型抹除测试**在玩具世界上通过。
7. **算力预算表**：一次涌现认证 / 一次消融矩阵 / 一次对抗式敏感性分析各需多少核时，占总预算比例；CI 级玩具世界的规格。
8. **功效分析报告**：给定当前集合方差，每条验收判据能否以 80% 功效区分两个已知不同的机制版本。
9. **信息传播速度表**（按地形、技术、制度）第一版 —— 原则 4 的可执行前提。
10. **一份"我们承认无法验证什么"的清单**（语言分化树形状、思想运动、宗教内容、政体寿命分布形状……），并规定这些量只能进观察集。这份清单的长度是项目诚实度的直接指标。
11. **调度顺序规范**：tick 内规则执行顺序显式版本化；禁止依赖哈希容器迭代顺序；逆序遍历的 CI 测试。
12. **参数活性测试与矩位移测试**进 CI。这两条能自动消灭 Artificial Anasazi 里存活了十年的两个真实 bug：`HarvestVarianceYear`（声明后从未被引用的死参数）与 `HarvestVarianceLocation`（`quality = random-normal(0,1)*σ + 1.0` 后 `if quality<0 → 0`，导致**增大方差同时抬高均值**）。第二个 bug 尤其致命：它会让所有"波动性 vs 平均水平"的实验结论变成伪的。
