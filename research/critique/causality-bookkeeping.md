## 0. 一句话判决

**纲领第 2 条（可追溯的因果链）与第 3 条（小事件长期改变未来）要求同一个动力学参数朝相反方向取值，而纲领把两者都写成了不可让步的核心原则。** 路径依赖强 = 单点扰动的影响长期不衰减 = 任何事都是任何事的原因 = 因果链在信息上等于零；路径依赖弱 = 因果链干净可读 = 第 3 条是假的。我们不可能两个都要满额，只能**逐变量地测量**每个宏观量的"因果视界"，然后**只在视界内允许因果声明，并公开报告有多大比例的"为什么"是不可回答的**。

第二判决：**纲领把"因果链"当成一个要被保存的东西（第 34 行"如何保存因果关系"），这个措辞本身会把我们推向唯一一条既昂贵又无价值的实现路径。** 写入级 provenance 在存储上是 TB 量级/单跑，在认识论上等于让写代码的人自报动机——`pseudo-simulation.md` F3 已经指出自报即伪造。真正可辩护的实现是**不保存因果，保存可重算性**：比特级确定性 + 快照 + 按需干预重放。这把 Phase 0 的头号交付物从"因果链数据库 schema"换成"确定性契约与干预代数"。

## 1. 审查框架：因果记账的四个不可兼得

在展开之前先把结论的骨架摆出来。我们想要的四件事两两冲突：

| | 可读（人能看懂的少数主因） | 客观（不由作者自报） | 便宜（可随时查询） | 完整（不遗漏原因） |
|---|---|---|---|---|
| **可读** | — | 冲突：客观归因在非线性系统里必然是稀释的、多因的、带误差棒的 | 相容 | 冲突：完整 = 数万条微因 |
| **客观** | | — | 冲突：客观 = 干预重放 = CPU-天/次 | 相容（但更贵） |
| **便宜** | | | — | 冲突 |
| **完整** | | | | — |

纲领在第 2 条里同时要求了"可读"（一路追溯，人来问、人来看）与"完整"（每一个重大事件必须保存可追溯的原因），在第 24 行里又追加了"便宜"（可以查询任何重大事件的因果链，语气是即时可查），而第 8 条与整个项目的科学立场要求"客观"。**四个都要，就必然有一个是靠自欺满足的。经验上被牺牲的一定是"客观"，因为它是唯一一个不牺牲用户体验的选项。**

这就是本文的主线：不是"我们做不出因果链"，而是**我们一定做得出一条看起来很好的因果链，并且没有任何机制能让我们发现它是假的**。

## 2. 致命问题（不改就一定失败）

### F1. 第 2 条与第 3 条在动力学上互斥；纲领没有裁决，默认实现会同时假装两条都成立

**针对**：第 2 条"每一个重大事件必须保存可追溯的原因……一路追溯到更早的结构性变化和具体事件" × 第 3 条"曾经发生的小事件可以长期改变未来"。

**失败机制**。定义单点扰动响应 `D(Δ)` = 在 t 时刻翻转一次抽样（或抑制一个具体事件）后，t+Δ 时刻两条世界线在某个宏观观测量上的距离。两种极端：

- **高敏感区（第 3 条要的）**：`D(Δ)` 随 Δ 增长直到饱和。饱和之后，两条线在该观测量上完全去相关。此时对 t+Δ 的任何事件 e 做因果归因，**每一个 t 时刻的抽样点都会显示"翻转它，e 就不发生了"**——因为翻转任何东西 e 都不发生。归因结果是：几十万个前因，每个的"必要性"都接近 1，重要性完全均匀。这不是稀释，这是**归因的完全崩塌**。
- **低敏感区（可读因果链要的）**：`D(Δ)` 衰减到零。此时因果链干净——只有少数几个扰动会改变结局。但这等于说世界有强吸引子，小事件不改变未来，**第 3 条被证否**。

关键在于：**这两种情况我们都会解读成"成功"**。高敏感区我们会说"看，路径依赖非常强，第 3 条实现了"；低敏感区我们会说"看，因果链清清楚楚，第 2 条实现了"。**纲领没有给出任何一个判据能让我们说"这次不对"。**

更糟的是敏感度不是全局常数：它随观测量、区域、时代变化。人口总量可能有 50 年视界，"哪个家族坐在王座上"可能有 5 年视界，"这个地区是否形成了成文法传统"可能有 500 年视界。**一个全局的"我们的世界有因果链"的说法在数学上没有意义。**

**可观察症状**：
- 反事实实验的报告里，几乎所有干预都"显著改变了历史"。团队把它当作路径依赖的胜利。**这是崩塌，不是胜利。**
- 反过来：无论抑制哪个事件，200 年后人口曲线都回到同一条线。团队把它当作"机制稳健"。**这是第 3 条失败。**
- 从来没有人报告过"这个干预的效应在第 80 年后与随机扰动不可区分"。因为我们从来没建过随机扰动的对照。
- 因果链界面允许追溯到任意深度，且深度越深链条越漂亮——因为深处的节点是慢变量，慢变量总是"看起来相关"。

**替代设计（因果视界作为一等元数据）**：

1. **禁止无条件的因果声明。** 每一条因果声明的类型必须是 `(原因, 结果, 观测量, Δ, 证据种类, 置信区间)`，缺 Δ 的声明在系统里不合法。
2. **视界必须实测，且用同一批算力顺带产出**（见 §7 的分叉集合）。定义：观测量 `Y` 在 t 处的因果视界 `H_Y(t)` = 使得"一次典型单点扰动"造成的 `D_Y(Δ)` 仍显著大于**安慰剂对照分布**（F5）的最大 Δ。
3. **UI 必须有"不可归因"这个答案，并且它应该是最常见的答案之一。** 当被追问的因果距离超过 `H_Y` 时，系统必须回答"超出该观测量的因果视界（实测 H = 63 年），此处不存在可辩护的具体前因；可归因的只有慢变量与初始条件"。
4. **报告一个项目级指标：可归因率**（在多少比例的"为什么"查询上我们给出了视界内的答案）。**这个数字应该很低（我猜 20–40%），如果它超过 80%，说明我们的世界要么没有路径依赖，要么因果链是编的。**
5. 第 2 条与第 3 条必须在纲领层面被改写为：**"结构性慢变量的因果可追溯到数百年；身份型/时点型事实的因果只在实测视界内可追溯，视界外只能给出分布。"** 这不是妥协，这也是真实历史学的实际做法——结构史能追很远，事件史追不远。

**证据**：`emergence-verifiability.md` F9 已经从统计功效角度指出"路径依赖越成功，分布型判据的功效越低"，并引 Stonedahl & Wilensky 的重复次数反转结论（30 次 vs 100 次结论相反，`abm-methodology.md` §2.8 标注读到全文）。本条是它在**因果归因**侧的对偶：路径依赖越成功，归因的信噪比越低。两者是同一个非遍历性问题的两个面。

### F2. "保存因果关系"这个提法会把我们推向写入级 provenance；它同时是存储不可行的和认识论上无价值的

**针对**：Phase 0 待答问题第 34 行"如何保存因果关系？"、第 2 条"必须**保存**可追溯的原因"。

**失败机制**。"保存"暗示写入时记账。默认实现是：每次状态写入都附一条 `(target, cause_list, tick, mechanism_id)` 边。两个独立的致命问题：

**(a) 存储量。** 用简报自己的量级假设算：`abm-methodology.md` M11 给的活跃个体预算 10^4–10^5；`complex-systems-emergence.md` M1 建议主网格 10×10 km（东亚陆域按 1.1×10^7 km² 计 ≈ 1.1×10^5 格）。取 10^5 个体 × 20 次写/tick + 1.1×10^5 格 × 30 变量/tick ≈ 5.3×10^6 次写/年；3000 年 ≈ 1.6×10^10 次写。每条边最小 20 B（8B 目标 + 8B 父指针 + 4B tick），平均 3 个父 ≈ 44 B → **≈ 700 GB / 单次 3000 年长跑**，索引再乘 1–3 倍 → **1–3 TB/跑**。而 `abm-methodology.md` M7 的涌现认证要求 N ≥ 50 个独立种子 → **50–300 TB**，且这只是认证，不含反事实分叉。

简报 §2.19 已经预见到这一点，提出三级留档（滚动窗口 / 年度聚合 / 重大事件冻结闭包），并且诚实地标注："这条没有文献依据（**D 级**）"、"分级边界完全没有依据"。**但三级留档有一个它自己指出、却没有解决的死结：闭包必须在事件被标记为"重大"的那一刻立刻物化冻结，否则滚动窗口过期后祖先就找不回来了。** 而"重大"在事件发生的那一刻通常是不可知的——一次边境小冲突要到 80 年后才显出重要性。所以三级留档实际上要求我们**在事件发生时就预判它未来是否重要**。这是一个不可能的要求，我们会用启发式代替它，而启发式就是我们对"什么算重要历史"的先验——**剧情树从这里回流**。

**(b) 认识论。** 写入级 provenance 记录的是**写代码的人认为的原因**。`pseudo-simulation.md` F3 已经点明"自报的因果链等于伪造"。我要加一层更具体的：即使程序员完全诚实，`cause_list` 记录的最多是**读取集**（这次计算读了哪些状态），而读取集既不是原因的充分条件也不是必要条件：

- **过近似**：一个 `if (粮价 > 阈值 && 边军忠诚 < 阈值)` 的短路求值里，`粮价` 被读了但可能完全不影响结果（另一个条件已经决定了分支）。`max(a, b)` 读了两个值，只有一个决定输出。读取集会把它们全都记成原因。
- **欠近似（这一条是致命的）**：**没有被读的东西可以是原因。** "为什么这个国家灭亡" 的真实答案里有巨大一块是**缺席因**：因为改革没有发生、因为援军没有到、因为那三年没有下雨、因为没有人发明出可用的冶铁法。缺席不产生读取，不产生写入，不产生任何一条 provenance 边。**一个基于写入记账的因果图在原理上不能表示"什么没有发生"，而"什么没有发生"是历史解释的主干。**

**可观察症状**：
- 存储监控在第一次 1000 年长跑时爆掉，团队的反应是"先关掉细粒度 provenance"。之后再也没打开过。
- 因果链里从来没有一条边写着"因为 X 没有发生"。所有解释都是正向的、由发生的事推动的。**于是我们的历史里所有崩溃都是被打倒的，没有一个是自己烂掉的。**
- 有人写了一个 `mark_important()` 函数，它的调用点分布决定了我们的历史里什么算大事。
- 因果图的规模与代码里 `emit_event()` / `log_cause()` 的调用点数量高度相关，而不是与世界里发生的事情相关（可直接测：统计每类因果边的产出数 vs 代码中对应写入点的数量）。

**替代设计**：

1. **放弃写入级 provenance。改为"不保存因果，保存可重算性"**（详见 §7）。存储对象换成：`world_seed` + 配置内容哈希 + 内核版本哈希 + LLM 冻结账本 + 内容寻址快照。量级估算：状态本体约 1–2 GB（1.1×10^5 格 × 30 变量 × 8B ≈ 26 MB；10^5 个体 × 100 变量 × 8B ≈ 80 MB；文化/信念/制度对象按 10× 放大），每 50 年一快照、结构共享后 **≈ 30 GB / 跑**，比写入级 provenance 低 1–2 个数量级。
2. **缺席因必须显式建模为"近失账本"（near-miss ledger）**：凡是内核**评估过概率但没有触发**的抽样点，都是因果图的一等公民节点，字段为 `(site_id, tick, 分布参数, 抽到的分位 u, 触发阈值)`。它回答"为什么没有改革"：因为改革提案在 t=1240、1263、1288 三次被评估，触发概率分别是 0.11 / 0.19 / 0.07，都没过。
   - **存储代价为零**：在确定性重算架构下，近失点是重放时按需重建的，不需要落盘。
   - **它同时是第 4 条"这里本来有 30% 概率走向另一条路"的唯一可表示形式**（见 F6）。
   - **它有一个真实的局限，必须写进纲领**：只有"内核评估过的机会"能成为缺席因。世界里根本没有建模的可能性（"他们没有发明 X，因为我们的技术空间里没有 X"）永远不会出现在因果链里。这是不可修补的，只能声明（见 §8）。
3. **事件不得由代码作者手写 `emit_event()` 提名，必须由下游影响自动提名**（见 F7 与 §6 的"重大性的语义无关定义"）。

### F3. 结构性原因不是事件；把慢变量事件化就是把阈值写进内核，那正是剧情树

**针对**：第 2 条"一路追溯到更早的**结构性变化**和具体事件"、第 9 段列举的"地理条件、资源约束、人口变化、经济利益、社会结构、制度、文化"。

**失败机制**。"土地兼并加剧"不是一个事件。它是一个分布的漂移：地权基尼系数在 120 年里从 0.41 走到 0.72，没有任何一年发生了什么特别的事。事件图（PROV-DM 的 Entity/Activity + `wasGeneratedBy`/`used`/`wasDerivedFrom`）是一个**离散结构**，它没有表示"一个量在一段区间上单调漂移"的节点类型。于是只有两条路：

**路 A：把慢变量离散成事件。** `if gini > 0.65: emit("土地兼并危机")`。后果是灾难性的，而且是双重的：
1. 这个阈值是我们选的。世界里没有 0.65。**每一条因果链的终点都会停在一个我们亲手写下的数字上**，而追问"为什么会灭亡"的答案最终是"因为基尼超过了我们设的 0.65"。
2. 更糟：一旦 `emit("土地兼并危机")` 存在，它就是一个可被下游机制引用的一等对象，其他机制会开始 `if 存在土地兼并危机: ...`。**这在结构上与手写剧情树无法区分**——`emergence-verifiability.md` F5 的"目标清单泄漏了本体词汇"与 `pseudo-simulation.md` S5"分类即剧本"讲的是同一个通道，我这里指出的是：**因果链的可读性需求，会独立地、以"为了能解释"的名义，把这些语义对象重新塞回内核。** 这是一条即使我们已经防住了 S5 也还开着的门。

**路 B：让因果边指向轨迹。** 边的形式变成"`Gini` 在 [t0, t1] 上的上升，对 e 有贡献"。这在数据模型上可行，但它的**量化只能靠干预**——而对连续慢变量的干预是"钉住/冻结"（clamp），不是"删除事件"。而 clamp 立刻遇到一个纲领完全没提的问题：**干预必须修复不变量**。把地权分布钉在 t0 的值上，那 120 年里实际发生的每一笔土地交易的地要放到哪里去？把人口钉住，多出来的人怎么办？**每一个修复规则都是一个建模选择，并且它会把偏置直接注入因果结论。** 例如"多余的土地按原比例分配给所有家户"这个修复，等于在反事实世界里偷偷执行了一次土地改革——于是我们会得出"土地兼并是崩溃的主因"，而这个结论有一部分来自我们的修复规则而不是来自世界。

**W3C PROV 自己拒绝承担这个角色。** 这一点必须点名，因为 `abm-methodology.md` §2.19 明确写了"这正是 MANDATE 第 2 条'因果链'所需的现成形式化"。PROV-DM 规范原文（本次会话核验）：

> "PROV does not attempt to specify the conditions under which derivations exist; rather, derivation is considered to have been determined by unspecified means."

以及 `wasInfluencedBy` 被定义为 "a generic dependency of o2 on o1 that signifies some form of influence"——**是 dependency，不是 causation**。PROV 是"这条记录是怎么来的"的档案格式，它刻意不定义因果。把它当作因果模型是一个类别错误，而且是一个会被静默犯下的错误，因为它在数据结构层面工作得很好。

**可观察症状**：
- 代码里出现一批命名像历史学术语的常量：`LAND_CONCENTRATION_CRISIS_THRESHOLD`、`FISCAL_COLLAPSE_GINI`。
- 因果链的深度分布有一个尖峰：绝大多数链条恰好停在 3–5 层，因为再往下就是慢变量，而慢变量没有节点。
- 反事实实验里从来没有对慢变量做过干预，只对事件做过——因为对慢变量的干预没有实现。
- 我们能回答"为什么这场叛乱爆发"，但答不上"为什么这个社会变得这么脆弱"。

**替代设计（双节点类型 + 显式修复规则）**：

1. **因果模型有两种节点，不是一种**：
   - `Event(id, tick, site, 分布参数, u)` —— 离散、瞬时、对应一次抽样或一次规则触发。
   - `Channel(id, variable, [t0, t1], 轨迹摘要)` —— 连续、区间、对应一个慢变量在一段时间上的行为。**Channel 不需要阈值，它由变量本身与时间窗定义。**
2. **慢变量注册表是 Phase 0 交付物**，不是运行期发明的。哪些量算结构性慢变量、它们的时间尺度是多少，必须在写代码前列出来并且**允许事后追加**——而事后追加只有在重算架构下才可能（又一条支持 §7 的理由：注册一个新慢变量后，全部历史的因果分析可以重算，不需要重跑世界）。
3. **对 Channel 的干预必须是四种之一，且必须声明修复规则与其守恒代价**：
   - `clamp(v, c)`：钉在常数。修复规则必须显式，并且必须报告修复所搬运的物质/人口量（"本次干预人为消灭了 4.2% 的耕地"）。
   - `detrend(v)`：保留波动去掉趋势。
   - `shuffle_time(v)`：保留边际分布打乱时序（对应 `abm-methodology.md` M6 的外生序列置换检验）。
   - `resample_process(v)`：用同分布同自相关的替代序列。
   四种给出的答案不同，**必须四种都跑，并把四个答案一起报告**。如果四个答案不一致，正确的结论是"该慢变量的因果作用取决于我们如何设想它不发生"——这是一个真实的、诚实的结论，不是一个 bug。
4. **禁止任何 `if 慢变量 > 常数 then 语义事件` 的内核代码。** 这条要做成静态检查：内核层不得引用任何以人类历史学概念命名的符号。语义标签只能存在于 §7 的 L3 层。

### F4. 因果重要性没有客观总序；任何"主因排序"都是我们选了一组公理，而 UI 会把它显示成事实

**针对**：第 2 条隐含的"追溯"语义（追溯意味着沿着主要原因往回走）、第 24 行"可以查询任何重大事件的因果链"。

**失败机制**。用户视角要求的是"这个国家为什么灭亡"的一个**有序的、短的**答案。但把 n 个候选原因排出一个序，数学上必须选一组公理，而不同公理给出不同的序，**且它们都是自洽的**：

- **留一法（LOO）**：关掉单个原因看效应。在**过度决定**下全部返回零——两支军队各自足以灭掉这个国家，去掉任何一支它照样灭亡，于是"没有原因"。`complex-systems-emergence.md` M2 自己标注了这个失效条件："存在强互补性时留一法给出全零"。它给的补救是"至少做到二阶交互"，但过度决定可以是任意阶的。
- **Shapley 值**：满足效率（贡献之和 = 总效应）、对称、空玩家、可加。代价：效率公理**强制**把效应分解干净，即使系统根本不可加；对称公理把因果原因当成可交换的合作者，抹掉时间顺序（在历史里时间顺序是本质的）。计算量 2^n，采样近似需要 O(n/ε²) 次重放。
- **Pearl 的 PN / PS**（必要性概率 / 充分性概率）：`PN = P(结果不发生 | do(去掉原因), 实际上两者都发生了)`，`PS = P(结果发生 | do(加上原因), 实际上两者都没发生)`。这两个数**不能合成一个数**，而且它们对同一个原因经常给出相反的排名：一个高 PN 低 PS 的原因（必要但不充分，如"边境有草原邻居"）与一个低 PN 高 PS 的原因（充分但不必要，如"皇帝暴毙"）谁更重要？**这个问题没有客观答案。**
- **Halpern–Pearl 实际原因（actual causality）**：给出的是"是不是原因"的布尔判定，不是排序，而且判定本身是计算困难的。`[记忆，未核实]` 我的记忆是 Aleksandrowicz, Chockler, Halpern & Ivrii, "The Computational Complexity of Structure-Based Causality", *JAIR* 58 (2017) 证明了不同版本的 HP 定义分别落在 NP-complete 到 Σ₂ᴾ-complete 之间。**具体哪个版本对应哪个类我记不准，必须核实**；但方向性结论对我们够用：**"是不是实际原因"不是多项式时间可判定的，而且答案随定义版本变化。**

所以"给出主因排序"这个需求本身包含了一个不可消除的主观选择。纲领要求"不引入主观权重"（这是用户交办给我的角度里的原话），**在数学上做不到**。能做到的是：**把主观性从隐藏的权重挪到公开的公理选择上，并强制同时报告多个序。**

再叠加一层：**因果稀释是可以量化的，而量化之后我们会发现大部分事件确实没有主因。** 定义归因熵 `H_attr(e) = -Σ_i w_i log w_i`（`w_i` 为归一化的 |贡献|），有效原因数 `N_eff(e) = exp(H_attr)`。我预期一个千年尺度的国家灭亡事件的 `N_eff` 在 10^3–10^5 量级。**一个 top-7 列表在 N_eff = 4×10^4 时展示的信息量约为 0.02%，而它在界面上看起来像一个完整的解释。这就是自欺的具体形态。**

**可观察症状**：
- 因果链界面永远给出 top-k，从不给出 `N_eff`。
- 同一个事件在两次分析中给出不同的 top-3，团队认为这是 bug，去"修"它（实际上是两种归因公理的差异）。
- 从未出现过"此事件过度决定，最小充分前因集有 11 个，任意一个都足够"这样的答案。
- 有人问"这些百分比加起来是不是 100%"，而系统的回答是"是"。**能加到 100% 是效率公理的产物，不是世界的性质。**

**替代设计**：

1. **每个因果查询返回一个三元报告，不是一个排序**：
   - `N_eff(e)` 与归因熵。**当 `N_eff > 10k` 时，UI 必须拒绝显示 top-k 列表**，改为显示"此事件不存在少数主因（有效原因数 ≈ 4.1×10^4）"。这是最重要的一条反自欺规则。
   - 每个候选原因的 **(PN, PS) 二维散点**，不合成一维。
   - **最小充分前因集的枚举**（或采样估计），以及**过度决定度** `OD(e)` = 最小充分集的个数。
2. **"链"这个词要从设计文档里删掉。** 真实结构是带 AND/OR 的 DAG + 过度决定 + Channel 节点。叫"链"会让我们无意识地实现成 `parent` 单指针，然后所有 UI、所有查询、所有直觉都跟着错。用**因果场（causal field）**或直接叫**归因报告**。
3. **候选原因集必须显式声明并预注册**，因为 PN/PS/Shapley 全都依赖于"相对于哪个候选集"。改变候选集会改变所有数字。候选集的生成规则必须是机械的（例如：视界内、机械依赖闭包中、按 §6 的重大性度量取前 N），不能手挑。
4. **公理选择必须写在报告上**："本排序采用 Shapley（效率+对称+可加），若改用 PN 排序，第 1 与第 4 位互换。"

### F5. 反事实实验缺少安慰剂对照；没有它，每一次干预都会显得有效，而我们会把它读成路径依赖

**针对**：第 6 条"记录随机种子，以便重放和进行反事实实验"、第 24 行"可以进行'如果当时没有发生某件事'的反事实实验"。

**失败机制**。`complex-systems-emergence.md` M6 的"反事实脆弱度"是这么定义的："用同一种子重放，只把 e 的随机抽样结果翻转，记录 200 年后世界状态的距离。**路径依赖的证据 = 距离随时间发散而非收敛**。" 这个协议缺一个东西：**对照**。

在任何具有正向反馈与离散决策的系统里，**任意一次单点扰动**——包括一次完全无关紧要的扰动——都会在足够长的时间后产生宏观差异。原因很简单：状态空间是离散的，一次微小差异会在某个阈值比较处被放大成一个不同的分支决定，然后级联。于是：

- 翻转"某个关键将领在关键战役前病死" → 200 年后世界大不同。
- 翻转"东南某个渔村某年多生了一个孩子" → 200 年后世界也大不同。

**如果没有第二个实验，第一个实验的结果毫无意义。** 我们会报告"这位将领的死是这个王朝崩溃的关键原因"，而正确的结论是"在这个时间尺度上，任何单点扰动都会改变结局，所以'关键原因'这个说法在此不成立"。

这个错误特别危险，因为它**从不产生任何异常**。所有实验都成功，所有解释都成立，所有因果链都很有说服力。这正是"自欺"的定义。

**一个技术陷阱**：在 CBRNG 架构下（`abm-methodology.md` M4，key = hash(world_seed, stream_id)，counter = (tick, entity_id, purpose_id, draw_index)），**一次"什么都不改"的干预会产生逐位相同的输出**——因为随机数是计数器的纯函数。所以你不能用"推进一个没人用的随机流"当安慰剂：它的效应恒为零。**正确的安慰剂是：在同一 tick、同一机制类、可比的空间位置上，随机选择另一个抽样点做同类型的翻转。** 重复 ~100 次得到 `D_placebo(Δ)` 的分布。真实干预的效应量定义为 `D_real(Δ)` 在这个零分布中的分位。

这个协议顺带产出一件更值钱的东西：**`D_placebo(Δ)` 饱和的那个 Δ 就是该观测量的因果视界 `H_Y`（F1 所需）。同一批算力，两个产品。**

**统计功效的真实数字**（我自己算的，公式是标准两比例检验，可复核）。设我们想检验"抑制事件 e 后，某国在 200 年内灭亡的概率从 0.30 变为 0.45"，α = 0.05 双侧，功效 0.80：

```
n/arm = [ z_{α/2}·√(2·p̄·q̄) + z_β·√(p₁q₁ + p₂q₂) ]² / (p₂-p₁)²
      = [ 1.96·√(2·0.375·0.625) + 0.8416·√(0.21 + 0.2475) ]² / 0.15²
      = [ 1.342 + 0.569 ]² / 0.0225 = 3.653 / 0.0225 ≈ 163
```

**每臂 163 次重放，两臂 326 次，只为检验一个原因的一个效应。** 若效应更小（0.30 → 0.35），同样算法给出 **每臂 ≈ 1376，共 ≈ 2752 次**。

把它接到成本上：设一次完整 3000 年长跑为 `FR`（取 10 CPU 小时作例）。若干预点距事件 150 年，用快照续跑，单次重放 ≈ FR/20 = 0.5 h。一个原因 = 326 × 0.5 h ≈ **163 CPU 小时**。一个"为什么这个国家灭亡"若有 20 个候选原因 = **3,260 CPU 小时 ≈ 136 CPU 天**。加上安慰剂基线（100 次）与四种慢变量干预（F3）各自的成本，**一次严肃的因果回答在 5,000–10,000 CPU 小时量级**。

这个数字必须现在就摆在桌上，因为它决定了三件事：(a) 第 24 行"可以查询任何重大事件的因果链"作为一个交互功能是**不成立的**；(b) 因果算力必须进预算（`emergence-verifiability.md` F15 已为验证算力提过同样的要求，本条是它的因果侧独立追加项，两者不能共用同一笔预算）；(c) 我们一年能严肃回答的"为什么"是**个位数到几十个**，必须挑。

**可观察症状**：
- 反事实实验报告里没有"安慰剂"这个词。
- 所有反事实的结论都是"是的，这件事很重要"。**零否定结果。** 一个健康的因果实验体系应当有大量否定结果。
- 有人用 N=1 或 N=5 做反事实并下结论。
- "反事实实验"在演示里是秒级返回的。

**替代设计**：见 §7 的分叉集合；核心三条是：**(i) 安慰剂对照强制化**——没有零分布的反事实结果不得进入因果库；**(ii) 效应量而非二元判断**——报告分位与置信区间；**(iii) 功效预注册**——在跑之前算出需要多少次重放，若超预算则该因果问题标记为"算力不可回答"，**而不是用小 N 硬答**。

### F6. 已实现的历史里没有概率信息；不显式记录分布，"本来有 30% 概率走向另一条路"就永远无法表达，而必然性错觉是默认结果

**针对**：第 6 条"受约束的随机性……记录随机种子"、第 7 条"越违反常识越需要强大的前置条件"。

**失败机制**。事后看，每件事都有原因，每条因果链都完整——**这在数学上是必然的，因为我们只保留了实现了的那一条轨迹**。轨迹上的每一步都是确定的（给定种子），所以回溯必然成功，必然自洽，必然读起来像"这一切都是注定的"。

丢失的是什么？**丢失的是每一个抽样点上的分布。** 那个抽样点当时可能是 p=0.97（近乎必然）或 p=0.03（近乎奇迹），而实现之后两者在记录里长得一模一样：都是"发生了"。**第 6 条只要求记录种子，种子能重放出同一条轨迹，但重放不告诉你另一条路有多近。**

后果是双重的，且都很严重：

1. **对我们**：我们会系统性地高估历史的必然性，因为我们看到的每条链都完整。这会污染第 8 条的校准工作——我们会拿"我们的世界产生了一条自洽的兴衰因果链"当作机制正确的证据，而一个纯随机游走加事后叙述也能产出同样自洽的链。
2. **对世界**：第 7 条要求"越荒诞的结果需要越强的前置条件"。但**荒诞恰恰意味着低概率**，而低概率结果的因果分解在数学上必然是"一串各自不太可能的巧合的合取"，也就是**最弱、最分散、最不像"强前置条件"的那种归因**。于是第 7 条在最需要它的地方最难满足，而我们的自然反应会是**给荒诞事件补写解释**——这正是剧情树回流的入口（见 §5 的 C5）。

**可观察症状**：
- 历史数据库里的事件对象没有 `p` 字段。
- 没有人能回答"这个王朝的崩溃在同起点的平行线里出现了几次"。
- 阅读我们生成的历史时的主观感受是"很有历史感、很连贯"。**连贯是警报。** 真实历史读起来充满偶然、断裂与本可以不这样的时刻。
- 第 7 条从未被触发过：没有任何一个事件被判定为"太荒诞、前置条件不足、需要更强解释"。`llm-storytelling.md` F13 已经预言第 7 条会变成空条款；本条给出它变空的一个独立的、纯数学的原因。

**替代设计（必然性剖面 + 分位记账）**：

1. **每个抽样点必须记录（或可重算出）三样东西**：分布族与参数、抽到的分位 `u`、以及触发阈值。在 CBRNG 下 `u` 是计数器的纯函数，**免费**；分布参数是状态的纯函数，**重算即得**。所以这条要求的边际存储成本是零，前提是 §7 的重算架构。
2. **每个进入历史库的事件必须携带一个一等属性：必然性剖面 `p̂(Δ)`** —— 从事件发生前 Δ 年分叉、重采样所有非焦点随机流，该事件（或其等价类）在 Δ ∈ {10, 50, 200, 500} 年前分叉的 100 条平行线中出现的频率。UI 上它和日期并排显示：

   > 兴国之亡 · 世界历 3117 年 · 必然性剖面：10 年前分叉 96/100 · 50 年前 71/100 · 200 年前 23/100 · 500 年前 4/100

   这一行字比任何叙事免责声明都更能杀死必然性错觉，而且它是可计算的。
3. **剖面的形状本身是分类学**：`p̂(Δ)` 在 Δ=200 仍高 → 结构性必然；在 Δ=50 就塌 → 偶然事件主导；处处中等 → 真正的多因偶合。**这给了第 7 条一个可执行的形式**："荒诞事件"= 在真实历史参考类中极罕见的事件类型；"强前置条件"= 该事件的 `p̂(Δ)` 在较大 Δ 上仍显著高于同类事件的基率。**荒诞不是靠叙事解释的，是靠剖面证明的。**
4. **成本可控的关键**：分叉集合是**按分叉点共享**的，不是按事件。在同一区域同一时代分叉一次 100 条线，服务该窗口内的**所有**事件的剖面、所有安慰剂基线、所有视界测量。这把 F5 里那个吓人的数字摊薄了一到两个数量级。**这是整个因果基础设施唯一的规模化路径**（见 §7）。

### F7. entity_id 若由自增计数器分配，一切反事实实验静默失效；这是一条会在 18 个月后才被发现的实现级致命伤

**针对**：第 6 条（可重放、反事实）在工程上的落地；`abm-methodology.md` M4 的 counter = `(tick, entity_id, purpose_id, draw_index)`。

**失败机制**。CBRNG 的分叉安全性完全建立在一个前提上：**counter 的各个分量在干预前后保持稳定**。`tick` 稳定，`purpose_id` 稳定，`draw_index` 在给定 (实体, 用途, tick) 内稳定。**但 `entity_id` 不稳定**——如果新实体（出生的人、新建的聚落、新成立的组织）的 id 由一个全局自增计数器分配，那么：

抑制远洋某小岛上的一次生育 → 这个岛少了一个人 → 全局 id 计数器从此少加了 1 → **此后世界上每一个新出生的人都拿到了不同的 id** → 每个人的 counter 全变 → 每个人的每一次随机抽样全变 → 三年之内整个大陆的一切都不同。

我们会观察到什么？"抑制一次生育，100 年后世界完全不同。"**我们会把它写进论文，说这就是路径依赖。** 实际上它是一个 id 分配 bug，世界的真实动力学可能非常稳定。而这个 bug 与真实的路径依赖在**任何宏观观测量上都不可区分**——两者都产生"单点扰动 → 全局发散"。

同类陷阱至少还有四个，全都有同样的性质（静默、伪装成物理、破坏全部因果结论）：
- **容器迭代顺序**：`abm-methodology.md` M5 已经指出（Kehoe 2016 对 Sugarscape 的形式化分析），并给了逆序遍历 CI 测试。**但那条测试只保证同一次运行的可复现，不保证干预后的因果隔离。**
- **浮点归约顺序**：并行求和的分块边界随 agent 数变化 → 抑制一次死亡改变了某区域的 agent 数 → 求和顺序变了 → 最后一位不同 → 阈值比较翻转。
- **空间索引重建**：四叉树/网格哈希的桶内顺序依赖插入顺序。
- **LLM 调用序号**：若 LLM 账本按调用序号索引，干预导致调用次数变化会让整条账本错位。`llm-agent-social-simulation.md` §617 的设计（按 `view_snapshot_hash` 复用）是对的，但前提是 hash 稳定，而 hash 里若含 entity_id 就回到同一个坑。

**可观察症状**：
- **决定性症状**：做一次"抑制一个孤立小岛上的一次生育"的干预，检查 100 年后另一个大陆的状态。如果它变了（哪怕一位），我们中招了。**没做过这个测试，就等于中招了但不知道。**
- 反事实的散度曲线在极早期（1–5 年）就跳到饱和值，而且形状与干预的"重要性"无关——所有干预长得一样。
- 干预效应看起来像白噪声，而不像有传播结构的因果扩散（真正的因果扩散应该有空间梯度：靠近干预点的地方先变、变得多）。

**替代设计**：

1. **实体 id 必须是内容/血缘派生的确定性哈希，不得使用任何全局自增计数器。** 例如 `child_id = H(mother_id, father_id, birth_tick, birth_order_within_mother)`；`settlement_id = H(cell_id, founding_tick, founder_lineage_id)`。这样抑制一次生育只影响那一个 id，不重编号任何其他实体。
2. **两个 CI 级门禁测试（Phase 0 交付物，必须在写第一个机制之前就跑通）**：
   - **零干预测试**：把某个值"改成它原本的值"，要求输出逐位相同。抓住一切"重放不等于原跑"的漏洞。
   - **因果隔离测试**：在地理上/网络上完全隔离的两个区域 A、B（A 是一个没有航海能力的孤岛），对 A 做任意干预，要求 B 在 100 年内的状态**逐位相同**。这个测试同时抓 id 重编号、迭代顺序、浮点归约、索引重建、LLM 账本错位五类问题。**它是整个因果基础设施的地基测试**，比任何 schema 设计都重要。
   - 因果隔离测试还有一个副产品：它给了"信息边界"（第 4 条）一个机械可执行的定义——**如果 A 的事件在物理上无法影响 B，那么 B 的任何 agent 的任何决策都不得依赖 A 的状态，而这一点现在可以被逐位验证。** `emergence-verifiability.md` F17 指出信息边界没有可机械执行的定义；因果隔离测试是我能给出的一个。
3. **浮点确定性契约**：固定归约顺序（或全部改用定点/整数），禁止 `-ffast-math`，跨平台位相同性进 CI。`abm-methodology.md` §830 已把"跨版本、跨机器、并行化后结果漂移"列为失真方式之一。

## 3. 结构性问题（会长期腐蚀质量）

### S1. 因果结论会随内核版本失效，而我们不会重跑；因果库会变成不同内核版本结论的杂烩

**针对**：第 26 行"这是长期研究型项目"与第 2 条的长期承诺。

**失败机制**。重算架构（§7）的因果结论绑定在 `(kernel_hash, config_hash, world_seed)` 上。一个多年研究项目的内核会改几百次。每次改动之后，所有已发表的因果结论在形式上都失效了。重跑一次全套因果分析要几万 CPU 小时。**于是我们不会重跑。** 我们会说"这个结论是三个月前跑的，机制没大改，应该还成立"。三年后，因果库里躺着来自 40 个不同内核版本的结论，互相引用，没人知道哪些还有效。

这不是假想：它是所有长期模拟项目的实际归宿，而且它比一个明显的 bug 更有害，因为库看起来是完整的。

**可观察症状**：会议上出现"这个结论应该还成立吧"；因果库的条目没有 `kernel_hash` 字段，或者有但没人查；UI 允许把不同版本的结论并列比较。

**替代设计**：
1. 每条因果结论强制携带 `(kernel_hash, config_hash, seed_set, analyzer_version, N, CI, placebo_baseline_id)`。缺任一字段的条目不得写入。
2. **UI 层硬拒绝跨 kernel_hash 的比较与聚合**，报错而不是警告。
3. **"重算债务"仪表盘**：显示有多少条结论的 kernel_hash 落后于当前 HEAD、按重要性排序、以及重算它们需要多少 CPU 小时。这个数字应该出现在每次里程碑评审的第一页。
4. **内核变更分级**：`纯性能`（要求位相同，自动验证，债务为零）/ `参数`（债务 = 受影响结论集）/ `机制`（全部债务）。位相同性测试让"纯性能"这一档可以免费通过，这是保持项目可持续的关键。

### S2. 机制内的局部归因（几乎免费）与全局干预归因（极贵）会在 UI 里被混为一谈

**针对**：第 2 条"一路追溯"。

**失败机制**。`cultural-evolution.md` §658 明确说明了加性 logit 的一个好处："每个偏向对某次采纳的贡献可以直接记入因果链"。这是对的，而且很便宜——在一个 logit 危险率里，每个协变量对本次抽样的对数几率贡献是解析可得的，成本约为零。

问题是：**这只解释了最后一步。** 它回答"给定当时的粮价、人口压力、边军忠诚，这场叛乱的爆发概率是怎么算出来的"，但它完全不回答"为什么粮价是那个值"。而"一路追溯"要的是后者。递归下去，每一层都要展开成它自己的协变量，深度 20 层、每层 8 个协变量 = 8^20 条路径。**免费的局部归因不能递归，能递归的全局归因不免费。**

危险在于两者**在 UI 上长得完全一样**：都是"原因 A 贡献 34%"。一个是解析的、只对一步有效、条件于全部其他变量；另一个是干预实测的、跨越百年、带置信区间。混在一张图里，读者（包括我们自己）无法分辨。

**可观察症状**：因果链深度 20 层且在毫秒内返回；每层的百分比恰好加到 100%；没有任何一个节点带置信区间。

**替代设计**：
1. **因果边强制带 `evidence_kind` 类型标记**：`mechanical`（读取集依赖，客观但过近似，无权重）/ `local_analytic`（解析局部贡献，一步有效）/ `intervention_tested`（干预实测，带 N 与 CI）/ `statistical`（跨运行回归，有混杂风险）/ `narrative`（叙述性，零因果内容）。
2. **UI 必须用不同视觉通道渲染不同类型，且禁止跨类型排序与百分比合并。**
3. **硬规则：`narrative` 类型的边不得作为任何其他边的父节点**，防止叙事污染沿因果图反向传播。同理，`local_analytic` 的边不得跨越机制边界。
4. `local_analytic` 的默认渲染文案必须是"在此机制内部，给定其他变量"，而不是"原因"。

### S3. 事件是我们通过 `emit_event()` 选出来的；因果图的节点集与代码结构同构，而不是与世界同构

**针对**：第 2 条"每一个**重大事件**必须保存可追溯的原因"；`emergence-verifiability.md` F4 已指出"重大事件"未定义，本条是它在因果侧的具体后果。

**失败机制**。内核每年做 10^7 次状态转移，其中只有极少数会被命名为"事件"。谁来命名？默认是写机制的人：他实现完战斗结算，顺手加一行 `emit_event("battle", ...)`。于是：

- 我们实现得越细的领域，事件越多，因果图越密，解释越"深刻"。我们实现得糙的领域（比如日常经济活动、家庭内部决策）几乎不产生事件，于是**从来不会成为任何事的原因**。
- 因果图的形状 = 我们注意力的形状 = 我们的历史观。这是一个完美闭环的偏见：**我们认为重要的事，才会被记录成原因，然后我们回过头来发现历史确实是被这些事推动的。**
- 更具体的：战争、王朝更替、制度改革会有密集的事件流（因为它们戏剧性强、我们会仔细实现）；土壤肥力下降、识字率漂移、婚配网络重构不会。于是我们的世界的历史会是一部**政治军事史**，而这不是世界的性质，是我们代码的性质。

**可观察症状**：统计每类事件的产出数量，与代码中对应 `emit` 调用点的数量做相关——如果 r > 0.8，图的形状由代码决定；因果链里"经济"类节点占比 < 10%；没有一个重大事件的主因是一个从未被命名过的渐变。

**替代设计**：
1. **禁止手写 `emit_event()`。** 内核只写状态，不命名事件。
2. **事件由下游影响自动提名**：定义一个语义无关的重大性度量（见 §6），扫描转移记录，把度量超阈值的转移自动提名为事件。**提名可以延迟发生**——一次边境小冲突可以在 80 年后被提名。这在重算架构下完全可行（F2(a) 的"必须在事件发生时预判重要性"死结由此解开），在写入级 provenance 架构下不可行。**这是选择 §7 架构的第三个独立理由。**
3. **提名器必须是可替换、可版本化的**，且必须同时跑至少两个不同的提名器（例如"下游散度型"与"信息瓶颈型"），比较它们提名的事件集重叠度。重叠度低说明"重大性"这个概念在我们世界里不稳定——这本身是一个值得报告的发现。

### S4. 因果图若被放进"世界事实"层，第 9 条的叙事多元就退化成"错误程度不同的近似"

**针对**：第 9 条"模拟器保存'实际上发生了什么'……因此未来可以同时存在真实历史、官方历史、民间传说、宗教叙事和后世历史学研究" × 第 2 条 × 第 24 行"可以让世界中的历史学家研究他们自己的历史"。

**失败机制**。这是一个类别错误，而且它是纲领的措辞直接诱导的。第 9 条把世界分成两层：**世界事实**（模拟器保存）与**世内叙事**（部分、失真）。因果图放哪层？纲领没说，默认会放进第一层——因为第 2 条把它写成了"必须保存"的东西。

但**因果不是状态变量**。世界里没有一个字段叫"原因"。状态与转移是事实（可逐位重放校验）；因果归因是**我们对这些事实做的分析**，它有方法、有假设、有误差棒、会随分析器版本改变。把它塞进"世界事实"层的后果：

1. **世内历史学家被降格为噪声模型。** 我们会自然地问"这个历史学家的解释与真实因果链相符度是 73%"，于是第 9 条承诺的"多元叙事"变成"对同一个正确答案的不同程度的偏离"。这在概念上是贫瘠的，也是不真实的——真实的历史学分歧不是谁更接近一个上帝视角的答案，而是不同的问题意识、不同的因果概念、不同的相关性判断。
2. **第 10 条（小说只能在既有世界事实的约束下重建）会把小说锁死在我们的因果分析上。** 而我们的因果分析带着置信区间，小说会把它当成确定的。**结果是小说比让它自由发挥更失真**，因为它继承了我们的分析偏差并抹掉了不确定性。
3. **最危险的一条**：如果世内 agent（尤其是 LLM 驱动的世内历史学家）能读到因果库，第 4 条的信息边界就在最要命的地方被击穿——他们拿到的不是情报，是上帝视角的因果分析。而这种泄漏很容易发生：一个"让世内历史学家研究历史"的功能，最省事的实现就是把因果库喂给它。

**可观察症状**：数据模型里因果表和状态表在同一个 schema、同一个"世界事实"命名空间下；出现一个叫"历史学家准确率"的指标；世内历史学家写出的解释在结构上与我们的因果报告同构（同样的分层、同样的主因排序）；有人问"世内历史学家能不能看因果库"，而答案是"技术上可以"。

**替代设计（三层，不是两层；这是第 9 条必须的修订）**：

| 层 | 内容 | 认识论地位 | 谁能看 |
|---|---|---|---|
| **L1 机械事实** | 状态、转移、抽样点（分布 + 分位）、读取集闭包、近失集合 | **事实**。可逐位重放校验。无语义、不可读、不带权重。 | 我们 + 校验器 |
| **L2 因果分析** | 干预实测的效应量、PN/PS、必然性剖面、视界、`N_eff` | **我们的历史学**。有方法、有版本、有误差棒、可被推翻。 | 我们 |
| **L3 世内叙事** | 官方史、民间传说、宗教叙事、世内史学 | 世界内部的历史学 | 世内 agent + 我们 |

关键改动：
1. **第 9 条应改为："只有 L1 是世界事实。L2 与 L3 是同一类东西——对事实的解释——区别只在于 L2 的工具更好、信息更全。"** 这不削弱项目，它让"世内历史学家"这个功能第一次变得真正有意思：我们可以测量**在给定信息可得性约束下，L3 能逼近 L2 到什么程度**，以及**当我们改进分析器让 L2 变化时，L3 的"准确度"如何回溯性地改变**。后者是一个真实的科学哲学现象，我们的系统可以做实验研究它。
2. **L2 对世内 agent 永久不可见，且必须由进程/类型系统强制，不能靠约定。** 具体做法：L2 存在独立的存储与独立的进程，世内 agent 的上下文组装器在类型上无法引用 L2 的任何符号。CI 里加一条测试：任何 agent prompt 的构造路径若能到达 L2 命名空间，编译失败。
3. **L2 的每条结论都要带 `analyzer_version`，并且允许同时存在多个互相竞争的分析器。** 这与第 9 条的多元精神一致，只是把多元提前到了我们这一层。

### S5. LLM 参与的分支不能干净反事实，其结果是因果结论存在**已知方向**的系统偏差

**针对**：第 5 条"AI 可以负责人物和组织的判断、计划、解释、文化创造" × 第 6 条（反事实）× 第 2 条。

**失败机制**。`llm-storytelling.md` F4 与 `abm-methodology.md` §2.18 已经确立：LLM 调用不可复现（即使 temperature=0，跨机器/批大小仍会漂移；简报标 C 级但方向性结论是硬约束）。补救是冻结账本（`llm-agent-social-simulation.md` §617）：分叉点之前走账本，之后若 View 未变继续复用，View 变了则真调用。

我要补充的是这个补救的**代价方向**，因为它不是随机噪声，是偏差：

做反事实时，有两个选项，都错：
- **选项 A（复用账本）**：把 LLM 的决策当成外生固定输入。于是干预"下了一场大旱"之后，那位君主**做了完全相同的决定**——因为账本里就是这么记的。后果：我们测出来的旱灾效应完全不含"旱灾改变了君主的判断"这条通道。**系统性低估一切通过人的认知起作用的因果路径。**
- **选项 B（重新调用）**：新的调用来自一个（可能已升级的）模型，其分布与原来那次不同。于是我们比较的不是"同一个世界的两条路径"，而是"两个不同世界"。差异里混进了模型版本差异，且无法分离。

因为选项 A 更便宜、更"可复现"，我们一定会默认用它。**于是我们的因果结论会系统性地偏向物质/结构原因，低估决策、信息、误解、人物性格的作用。** 而这恰恰是纲领第 9 段明确列为因果来源的东西（"人物动机、信息条件"），也是 `emergence-verifiability.md` F8 担心的方向（因果图把信念因记成事实因）的一个独立放大器。

**可观察症状**：因果报告里，"决策/情报/误判"类原因的实测效应量普遍接近零，而结构变量的效应量显著；世内的重大转折点从来不追溯到某个人的判断；反事实实验从来没有过"如果他当时相信了那份情报"这一种。

**替代设计**：
1. **在 Phase 0 划一条硬线：哪些决策进入"可重算核"，哪些进入"冻结账本区"。** 可重算核里的决策必须由确定性的、可重算的策略函数产生（可以是从 LLM 蒸馏出来的小模型/查表/规则，只要是纯函数），LLM 只在账本区。**核里的因果结论可以是完整的；账本区的因果结论永久带星号。**
2. **星号必须是机器可读的**：任何一条因果路径若穿过账本区，报告上必须显示"此路径穿过 3 个不可重算决策点，其因果贡献为下界估计"。
3. **必须做一次"通道封闭偏差"的实测**：对一小批事件同时用选项 A 与选项 B 各跑一遍（B 用固定的模型版本、固定采样种子、多次采样求均值），测两者的效应量差。这个差就是偏差量级。**如果它很大（我猜很大），那么第 5 条与第 2 条的冲突不是理论问题，是必须在纲领层面裁决的问题。**
4. 长期方向：**把"人的判断"从 LLM 移进可重算核**——LLM 只用于生成决策策略的**结构**（一次性的、离线的、被人审阅的），运行期的每一次判断由确定性策略函数执行。这与第 5 条的字面不冲突（AI 仍然负责了"难以公式化的部分"），但把它移到了编译期。

### S6. 第 24 行承诺的"随时可查因果链"与 §2/F5 的重算成本冲突，缓存的启发式会变成事实上的因果理论

**针对**：第 24 行"可以查询任何重大事件的因果链"。

**失败机制**。F5 算出的数字是每个严肃因果回答 10^3–10^4 CPU 小时。UI 要求秒级。中间必然出现一个缓存/预计算层。预计算不可能对所有事件跑完整协议，所以它会用一个便宜的启发式（比如：取读取集闭包里权重最大的 7 个 + 局部 logit 贡献）。这个启发式会：

1. 覆盖 99.9% 的查询（因为严肃分析只做过几十个事件）。
2. 因此**成为我们（以及未来的读者、小说、世内历史学家的训练数据）实际接触到的"因果"**。
3. 且它与严肃分析的结论**没有被系统比对过**，因为没人有动力去做这件对比。

**可观察症状**：有一个叫 `quick_causes()` 的函数被到处调用；严肃因果分析的结果存在另一个表里，两个表从未被 join 过；演示里展示的因果链都来自快表。

**替代设计**：
1. **快表与慢表在类型上不同，且快表的每条结论必须显示"未经干预验证"的标记。** UI 上视觉差异必须显著到无法忽略。
2. **强制抽样对比**：每季度随机抽 10 个已有快表结论跑完整协议，报告一致率。**这个一致率是一个项目级健康指标**，若低于某个水平（我建议 60% 的 top-3 重叠），快表必须停用。
3. **把"随时可查"从纲领里删掉，改成"任何重大事件都可以被排队进行因果分析，分析是一个有成本、有排期、有结论版本的过程"。** 这不是降级，这是把它变成真的。

### S7. 过度决定与"链"的隐喻会让我们实现出错误的数据结构

**针对**：第 2 条"因果**链**"这个词本身。

**失败机制**。"链"暗示单指针、暗示可以一路往回走、暗示每一步有唯一（或主要）前驱。真实结构是：带 AND/OR 语义的 DAG + Channel 节点 + 过度决定 + 缺席因。用"链"命名会导致：数据模型有 `parent` 字段（哪怕是列表，语义上仍是"前驱"而不是"最小充分集之一"）；查询 API 是 `trace_back(event)`；UI 是一条从右往左的线；每个人的直觉都跟着这条线走。

**过度决定的具体后果**：一个王朝同时面临五个各自足以致命的问题（财政破产、边患、瘟疫、内乱、继承危机）。留一法对每一个都返回"去掉它，还是亡"。因果报告：**无原因**。这不是 bug，这是真相的一部分——但"链"式 UI 无法显示它，而我们会去"修"这个"bug"，修法通常是降低阈值或改用加权，于是重新引入主观权重（F4）。

**可观察症状**：数据模型里有 `parent_event_id`；UI 是一条线；"无原因"或"过度决定"从未在任何报告里出现过。

**替代设计**：
1. 命名改为**归因报告 / 因果场**；数据结构是 `(节点集, 带类型的边集, 最小充分集族, 过度决定度, N_eff)`。
2. **`OD(e)` = 最小充分前因集的个数**，作为一等字段。`OD(e) ≥ 3` 时 UI 必须把"此事过度决定"作为主答案显示在 top-k 之前。
3. 最小充分集的枚举在一般情况下是组合爆炸的，用**贪心 + 随机重启的近似**，并**报告近似性质**（我们找到了 K 个充分集，不保证最小、不保证穷尽）。

### S8. 因果库如果与状态库分别写入，两者会漂移，我们会有两个真相源

**针对**：第 2 条"保存"的实现细节。

**失败机制**。任何"写状态时同时写因果边"的架构都有两个写路径。一个 bug 让某处只写状态不写边（或反之），两库就分叉。因果库的错误极难发现，因为它没有独立的正确性判据——它长什么样都"说得通"。三年后两库的一致性无人知晓。

**可观察症状**：没有任何测试比对过两库；因果库的条目数与状态转移数的比值随版本漂移且无人解释。

**替代设计**：**重算架构下不存在这个问题**——只有一个真相源（状态 + 种子），因果是从它派生的。这是选择 §7 架构的第四个独立理由。若因故仍需物化缓存，则必须有一条 CI：随机抽 1000 个转移，从最近快照重算，与缓存逐位比对。

### S9. "结构性前因占比 σ(e) ≥ 0.5" 这条判据可以被刷分，而刷分方式恰好是好看的工程

**针对**：`complex-systems-emergence.md` M2/M6 提出的 `σ(e)`（结构性前因贡献占比），以及它作为反剧情树判据的用法。

**失败机制**。简报自己已经指出了刷分风险并给了防御（"σ(e) 必须通过实际重放计算，不能由事件生成器自报"）。我要指出防御不够：**即使 σ 完全由重放测出，它仍然可以被"多写几个结构变量"刷高。** 具体机制：把一个原本由单一随机抽样决定的事件，改写成"由 12 个结构变量加权后的 logit 决定 + 一次抽样"。重放测出的 σ 会显著上升，因为现在确实有 12 个结构变量在影响概率。但世界并没有变得更有因果性——我们只是把一个随机数换成了 12 个数的函数，而那 12 个数各自的来源可能同样浅。

而这个改写在代码评审里看起来是**质量提升**（"我们把这个机制做得更细致了"）。所以 σ 是一个会被诚实的工程努力自然推高的指标 —— 典型的 Goodhart。

**可观察症状**：σ 的项目均值随版本单调上升；机制的协变量数量也随版本单调上升；两者相关系数很高。

**替代设计**：
1. **σ 必须与 `N_eff`（F4）配对报告**。σ 高 + `N_eff` 也高 = 稀释，不是深度。健康信号是 σ 高且 `N_eff` 中等，且这些结构变量各自也有高 σ（**递归 σ**）。
2. **加一条"深度"指标**：从事件出发，沿实测因果边回溯，直到遇到外生输入（气候、地形、初始禀赋）或超出视界。**报告这条路径上的平均 σ 与总跳数。** 一个"浅"的世界会在 2 跳内触底到外生输入。这个指标不能靠加协变量刷高——加协变量会让首跳的 σ 上升但第二跳立刻触底。
3. 把协变量数量作为一个受监控的复杂度预算（`emergence-verifiability.md` F15 建议的机制数量上限 |M| 是同一件事的另一面）。

## 4. 可接受的取舍（说明代价）

### T1. 放弃写入级 provenance，接受"回答一个为什么要花小时到 CPU-天"

代价很具体：没有即时因果查询；调试期看不到"这个数为什么变了"（需要开一次带 taint 的重放，工程经验上软件级动态数据流追踪的开销常见报告在 2–20× 区间 `[记忆，未核实，必须自测]`）；新人上手更难。收益：存储从 1–3 TB/跑 降到 ~30 GB/跑；唯一真相源；事后可追加慢变量与事件提名器；因果结论可被验证。**这个取舍我认为是必须做的，但它的代价是真实的，会在日常开发中天天付。**

### T2. 大部分"为什么"的答案会是"不可归因"或"过度稀释"，UI 会很难看

如果 F1/F4 的建议被采纳，我预期最终产品的样子是：点开一个王朝的灭亡，看到的是"有效原因数 3.7×10^4；因果视界（人口）51 年、（政体存续）88 年；在 200 年前分叉的 100 条线中此事发生 23 次；最小充分前因集找到 6 个，任一即足；视界内可归因的具体事件 4 个，效应量 0.11–0.19（95% CI 跨零 2 个）"。**这远不如一条漂亮的因果链好看，也不如它好卖。** 但它是真的，而且它其实更接近一个严肃历史学家的答案。必须现在就接受这个审美，否则第一次演示的压力会把我们推回叙事。

### T3. 近失账本会暴露世界的"可能性空间"，这本身是一条新的剧情树通道

我在 F2 里提出用近失账本表示缺席因。诚实的自我反驳：一旦我们能看到"改革提案在 1240、1263、1288 三次差点通过，概率 0.11/0.19/0.07"，我们就会忍不住去想"这个概率是不是太低了"。**近失账本把概率参数变成了一个我们能直接盯着看、并且有强烈动机去调的东西。** 这与 `pseudo-simulation.md` F2 描述的"人类回路梯度下降"是同一个通道，只是更高带宽。缓解：近失账本的聚合统计（各类机会的触发率）必须进入预注册的验收集，任何对危险率参数的修改都要在提交信息里说明理由，并且要能通过一个"参数漂移审计"（某参数被连续多次同向微调 = 警报）。**但我不认为这个缓解足够，这是一个真实的、未解决的残余风险。**

### T4. 慢变量干预的修复规则一定带偏置，只能声明方向

F3 的四种干预各自给出不同答案。同时报告四个答案是诚实的做法，但它把"这个慢变量重要吗"从一个数字变成了四个数字加一段解释。用户体验很差，而且当四个答案不一致时我们没有裁决办法——**只能说"取决于你如何设想它不发生"**。这是真实的模态含混，不是我们的失败，但代价要认。

### T5. 因果分析的算力必须与模拟算力、验证算力三方分账，三者会互相挤压

`emergence-verifiability.md` F15 建议验证算力 ≥ 总算力的 50%。加上因果分析（F5 的量级），三方分账后真正用于"跑世界"的算力可能只剩 20–30%。**这意味着我们的世界会比同等预算下的天真实现小、慢、少。** 这是纲领第 26 行"不追求尽快堆出大量代码"的算力版本，应该被明确接受。

## 6. 纲领没说、但必须在写第一行内核代码之前决定的事

1. **确定性契约的精确范围。** 哪些计算保证跨机器、跨版本位相同？浮点归约顺序、并行分块、空间索引重建、容器迭代顺序各自的规范是什么？（没有这个，F7 的一切测试都无从写起。）
2. **实体 id 的生成规则。** 必须是内容/血缘派生哈希。这条一旦选错，18 个月后无法回改（全部历史作废）。
3. **干预代数（intervention algebra）的完整定义。** 至少需要：`flip(抽样点)` / `suppress(事件) + 修复规则` / `clamp(慢变量, 值) + 修复规则` / `detrend` / `shuffle_time` / `resample_process` / `branch(分叉点, 新种子集)`。每一种的**合法性检查器**（干预后世界是否仍满足人口/物质/土地守恒与所有不变量）与**修复规则的偏置声明**。
4. **可重算核 / 冻结账本区的边界。** 哪些决策类型必须由纯函数产生。这直接决定了因果结论的可信范围。
5. **抽样点的记账规范。** 每个抽样点是否必须能重算出"分布族 + 参数 + 分位 + 阈值"。我主张必须——它是必然性剖面（F6）与近失账本（F2）的共同前提，且在重算架构下成本为零。
6. **快照策略与预算。** 间隔（我建议 50 年，另在每次重大事件提名点加一个）、结构共享方案、内容寻址、单跑存储上限。
7. **"重大性"的语义无关定义。** 我的提议：`重要性(转移 τ) = E[ d(世界_有τ, 世界_无τ) ]` 在若干未来时点上的加权和，用一个共享分叉集合近似估计；或者信息论版本：`τ` 的输出对 T 年后宏观状态的互信息。**关键性质是它不引用任何历史学概念**，因此不会把本体偷渡进内核。必须在 Phase 0 定，因为事件提名器依赖它。
8. **慢变量注册表**（初版）+ 事后追加的机制。
9. **因果算力的年度预算**，与模拟算力、验证算力分账，写进里程碑评审指标。
10. **L2 对世内 agent 的隔离机制**（进程/类型级，不是约定）。
11. **因果结论的元数据 schema 与跨版本比较禁令。**
12. **归因公理的默认选择与必须并报的备选**（Shapley / PN / PS / 最小充分集）。
13. **玩具世界的规格**——`emergence-verifiability.md` F15 已经要求它用于验证；我要追加一条因果专用的要求：**玩具世界里必须有一个我们亲手植入的、已知的真因果结构**（例如"这个部落的衰落 100% 由 A 事件导致，B 事件完全无关"）。**没有一个已知答案的标定世界，我们永远不知道自己的因果分析器是不是在编。** 这是本文认为最重要的一条缺口。

## 7. 正面交付：我认为真正可行的因果模型

### 7.1 先解决"记录还是重建"这个假二分

纲领隐含只有两条路。实际有三条：

| | A. 写入时记账 | B. 事后从轨迹拟合 | **C. 可重算 + 按需干预** |
|---|---|---|---|
| 存储 | 1–3 TB/跑 | 极小 | ~30 GB/跑 |
| 查询成本 | 低 | 低 | 高（CPU-时到 CPU-天） |
| 认识论 | **作者自报**（`pseudo-simulation` F3） | **叙事/观察性推断**，混杂无法控制，非遍历下样本不独立 | **干预式因果**，唯一可辩护 |
| 能否表示缺席因 | 否 | 否 | **能**（近失账本） |
| 能否事后追加概念 | 否（闭包已冻结） | 能但无效 | **能**（重算） |
| 真相源 | 两个（会漂移） | 一个 | **一个** |

**选 C。** 它的唯一硬前提是比特级确定性，而第 5 条（LLM 参与决策）直接破坏这个前提——所以 C3 必须先裁决（可重算核 / 账本区）。

### 7.2 四层架构

```
L0  确定性基底
    CBRNG(key=H(world_seed, stream_id), counter=(tick, entity_id, purpose_id, draw_index))
    + 血缘派生的 entity_id  + 固定相位调度  + 浮点确定性契约
    + 内容寻址快照（每 50 年 + 提名点）  + LLM 冻结账本
    契约：任意 (tick, 实体) 的状态、任意抽样点的 (分布, 分位) 都能在有界时间内重算。
    门禁：零干预测试（逐位相同）+ 因果隔离测试（孤岛干预不影响远方）。

L1  机械依赖（无语义、客观、过近似）
    按需重放 + taint tracking → 某个转移的读取集闭包 + 近失集合。
    这是唯一可以叫"事实"的一层。不带权重、不带语义、不可读。

L2  干预实验（有方法、有误差棒、可被推翻）
    干预代数 + 安慰剂对照 + 功效预注册 + 集合级消融 + (PN, PS) + N_eff + 视界 + 必然性剖面。
    每条结论带 (kernel_hash, config_hash, analyzer_version, N, CI, placebo_id)。

L3  语义解释器（可替换、可竞争、可事后追加）
    把 L1/L2 映射到"土地兼并""财政危机"等人类概念。
    多个解释器并存，按 (对 L2 的拟合度, 简洁性, 对未见事件的预测力) 打分。
    ★ 世内历史学家是 L3 的一个特例，只是输入被信息边界削弱。
      → 这就是第 2 条与第 9 条的和解方式：因果解释本来就是多元的，我们只是有更好的工具。
```

### 7.3 唯一的规模化原语：共享分叉集合

不要围绕"事件图"建基础设施，围绕**分叉集合**建：

- 在时间 × 空间上铺一张**分叉点网格**（例如每 50 年 × 每个主要区域一个分叉点）。在每个分叉点跑 `N=100` 条平行线（重采样非焦点随机流），跑到下一个分叉点后若干年。
- **同一批集合同时产出四样东西**，这是成本可行的关键：
  1. **必然性剖面** `p̂(Δ)` —— 回答"本来有多大概率不这样"（F6）。
  2. **安慰剂零分布** `D_placebo(Δ)` —— 一切反事实的对照（F5）。
  3. **因果视界** `H_Y` —— 每个观测量、每个时代、每个区域一条（F1）。
  4. **事件的自动提名** —— 下游散度大的转移自动升格为事件（S3）。
- 只有通过提名、并且被人类明确排期的少数事件，才走**完整的定向干预协议**（候选集枚举 → 功效计算 → 消融矩阵 → PN/PS → 最小充分集 → `N_eff`）。这类回答一年做几十个，每个 10^3–10^4 CPU 小时。

### 7.5 三个反自欺的验收测试（我认为这是 Phase 0 最该交付的东西）

1. **已知答案标定世界。** 玩具世界里植入一个我们亲手设计的真因果结构（A 是真因，B 是精心构造的强相关伪因，C 是过度决定的第二充分因）。**因果分析器必须找到 A、拒绝 B、报告 C 的过度决定。** 做不到就不许用在真世界上。这是唯一能证明分析器不是在编的办法。
2. **因果链盲测（图灵测试）。** 取 20 个重大事件，每个准备两份归因报告：(A) 干预实测产出；(B) 让 LLM 只看事件摘要与时间线编一份。三名团队成员盲判。**若判别准确率不显著高于 50%，说明我们的因果链没有超出叙事，全部投入白费。** Phase 1 结束的目标：≥ 80%。**这个测试极便宜，而且它是唯一直接测量"自欺"的测试。**
3. **前瞻性因果预注册与校准。** 在跑干预之前，分析器必须先输出一个**预测**（效应量 + 区间）；跑完之后打分。累积几十次后检验**校准性**：当它说"PN = 0.7"时，是不是约 70% 的情形里去掉该因结果就不发生。**一个不能被校准检验的因果引擎与一个似真叙事生成器不可区分。** 这也顺带把 Phase 0 的成功标准从"能解释"升级为"解释可被打分"——与 `pseudo-simulation.md` F1 建议的"解释能被证伪"同向，但给了一个可以每周跑的量化版本。

## 8. 这个设计做不到什么（必须写进纲领的诚实清单）

1. **给不出唯一的"真正原因"。** 因果重要性不存在客观总序；不同公理给出不同序。我们能做的是并报多个序并公开公理。
2. **视界之外无法归因。** 对身份型事实（谁当皇帝、哪个国家统一了哪块地），视界可能只有几十年。"一路追溯到几百年前"这句承诺**只对慢变量成立**——制度、文化、技术存量、地权结构、族群分布。这不是缺陷，这是真实历史学的实际结构（结构史能追远，事件史追不远），但纲领现在的措辞承诺得更多。
3. **只有"被内核评估过的机会"能成为缺席因。** 世界里没有建模的可能性（"他们没有发明 X，因为我们的技术空间里没有 X"）永远不会出现在任何因果报告里。这在原理上不可修补，而它恰恰是真实历史中最重要的一类原因之一。**必须在每份报告的页脚常驻声明。**
4. **穿过 LLM 账本区的因果路径只有下界估计**，且偏差方向已知（低估认知、信息、误解、性格的作用）。
5. **慢变量干预的答案取决于我们如何设想它不发生**，四种干预可能不一致，此时没有裁决办法。
6. **我们的因果结论是我们的历史学，不是世界事实。** 它会随分析器版本改变，改变时旧结论作废而不是被"修正"。
7. **过度决定的事件没有主因，报告会是"无原因"**，而这是正确答案。
8. **因果分析的算力上限决定了我们一年能严肃回答几十个"为什么"**，不是几千个。哪些问题值得回答，是一个人为的、有偏的选择，必须留痕。

## 10. 本审查自身的不确定性

1. **F1（第 2 条与第 3 条互斥）依赖一个我没有证明的经验假设**：社会 ABM 的单点扰动响应会饱和。有可能我们的世界处在一个"中等敏感"的甜区，两条原则都能相当程度地满足。**但这必须被测量后才能主张，而纲领现在是把它当默认前提。** 无论结论如何，F1 建议的测量协议都是需要的。
2. **F5 的成本数字依赖于"一次完整长跑 = 10 CPU 小时"这个我编的基准。** 真实值可能差两个数量级（往哪边都有可能）。数量级结论（"因果分析比模拟本身贵"）我有较高把握；绝对数字不要引用。
3. **`N_eff` 会不会真的到 10^4 量级，我不知道。** 这是我的直觉。**它是可测的，且应该是 Phase 1 的第一批测量之一**——如果实测 `N_eff` 只有几十，那么 F4 的很多担忧就不成立，因果链会比我预期的可读得多。**这是本文最容易被证否的一条，我希望它被证否。**
4. **7.3 的分叉点网格（50 年 × 主要区域 × N=100）的参数完全是我拍的。** 正确的网格密度取决于实测的视界长度，是一个鸡生蛋问题：需要先粗测视界，再定网格，再精测。
5. **我可能低估了 L1（读取集闭包）的价值。** 我把它定位成"客观但不可读"，但也许配合好的可视化与聚合，它的可读性比我估计的高。这需要原型验证，不能靠争论。
6. **7.5 的盲测（因果链图灵测试）我没见过先例，是我为这个项目现造的。** 它可能有我没想到的失效模式（例如：评审看多了就学会认风格特征，而不是认因果内容）。缓解方式：轮换评审、控制表述格式一致、加入"两份都是真的"与"两份都是编的"的对照组。**但我仍然认为这是本文提出的最有价值的一条建议**，因为它是唯一一个直接测量"我们是不是在自欺"的操作。
