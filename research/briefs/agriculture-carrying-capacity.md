## 1. 本简报要回答的问题

本简报服务于 MANDATE 中的三个 Phase 0 关键问题：「哪些变化应该由数学/规则系统决定」、「如何处理我们无法获得准确历史参数的问题」、「如何产生真正的涌现而不是隐藏的剧情树」。落到农业领域，具体要回答：

1. **产量应该怎么算？** 用什么函数形式，才能让同一块地在不同年份、不同气候、不同耕作史下产出不同结果，而不是查一张「作物 × 技术等级」的表？
2. **承载力是什么？** 承载力应该是环境的一个常数，还是一个随技术、劳动、饮食结构、风险偏好共同变动的**导出量**？（结论：必须是导出量，且必须能报告「此刻是哪个约束在绑定」。）
3. **劳动怎么进入生产函数？** 劳动是线性投入、边际递减投入，还是「在时间窗内必须完成否则归零」的投入？（结论：三者同时存在，且第三种最容易被忽略、却最能产生历史性后果。）
4. **地力和休耕的状态变量是什么？** 是土壤氮，还是杂草种子库，还是两者？（结论：热带/半干旱轮垦系统中杂草是主导变量，这一点与直觉相反且有实验证据。）
5. **哪些量化参数是真实可用的？** 播种量、种子产出比、单产、人均口粮、人均耕地、单位面积劳动小时——哪些有 A 级来源，哪些学界根本没有可用数字。
6. **哪些数据集可以直接接进模拟器做标定？** 以及它们各自的循环论证风险。
7. **中国与东亚有哪些特有的、不能用欧洲/西亚参数替代的事实？**
8. **本领域最常见的建模错误是什么？** 尤其是那些会让模拟表面合理、实际上把因果链写死的错误。

**本简报不回答**：畜牧与游牧的完整生产模型（仅给出与农业耦合所需的最小接口）、水文与河流地貌演化、气候重建本身（属于另一份简报）、以及粮食市场与价格（属于经济简报）。

## 2. 已有成熟模型与理论

### 2.1 食物受限人口统计学（Food-Limited Demography, FLD）——Lee / Tuljapurkar / Puleston / Winterhalder

- **核心机制**：把「年龄结构人口 → 劳动供给 → 可耕作面积 → 千卡产量 → 与人口千卡需求之比（food ratio E）→ 年龄别生育率与存活率 → 人口」闭成一个环。密度依赖不是外加的 logistic 项，而是从「劳动能开垦的土地占可耕地的比例饱和」中涌现出来的。
- **形式化程度**：**完全形式化**，且有可运行的参考实现（R 代码 `github.com/puleston/spacelim`，本次已直接读取源码与参数 CSV）。
- **状态变量**：年龄别人口向量 `n_x`（1 岁一档，120 档）；随机年产量 `Y_t`；食物比 `E_t`；已耕作土地比例 `F_t`。
- **核心方程（本次从 `spacelim` 源码逐行核对，非转述）**：

  ```
  F_t   = 1 - exp( -h * Σ_x n_x,t * φ_x )                # 已耕作土地占可耕地的比例
  E_t   = ( Y_t * A_m * F_t ) / ( J * Σ_x n_x,t * ρ_x )  # 食物比
  p_x   = p*_x * Γcdf( E_t ; shape = α_x , scale = 0.1 ) # 年龄别存活率随食物比下降
  m_x   = m*_x * Γcdf( E_t ; shape = γ  , scale = 0.1 )  # 年龄别生育率随食物比下降
  Ȳ_t   = Y*(1-ρ_ac) + ρ_ac * Y_{t-1}                    # 产量均值的 AR(1)
  Y_t   ~ Gamma( shape = 1/CV² , scale = Ȳ_t * CV² )     # 产量的 gamma 抽样
  ```

  其中 `h = H·k/A_m`，`φ_x` 是年龄别劳动效率（0–1），`ρ_x` 是年龄别消费权重（0–1）。
- **参数（Winterhalder & Puleston 2018, Table 1；与 spacelim 的 `demog_vectors.csv` 完全一致）**：`Y = 21,000 kcal/ha/day`；`A_m = 1000 ha`；`H = 5 hr/day/个体`（= 10 hr/day/劳动者）；`k = 0.0944 ha-day/hr`；`J = 2785 kcal/day`；`h = 4.72×10⁻⁴`；`CV_Y = 0.3`；`ρ_ac = 0.25`（论文运行文件中改为 0.5）；`γ = 0.135`；`α_x ∈ [0.00279, 0.156]`；`b₀ = 0.0369`、`d₀ = 0.0192`、`r₀ = 0.0176`；平衡态 `Ê = 0.6683`、`b̂ = d̂ = 0.0328`、`e₀ = 45 yr`、`TFR_d = 2.44`。
- **适用范围**：自然生育率、无节育、以谷物为主、劳动可自由分配到土地上的定居农业人口。它的两阶段结构（**copial 阶段**：劳动受限、E>1、人口指数增长；**Malthusian 阶段**：土地受限、E<1、生育下降死亡上升）是这个模型最有价值的部分——它自然产生「可榨取剩余的峰值出现在人口达到平衡之前」这一结论，直接可用于我们的赋税/国家形成机制。
- **已知局限**：(a) 单一作物、单一地块、无空间；(b) 土地质量同质（`A_m` 是标量）；(c) 没有地力衰减、没有杂草、没有休耕；(d) 劳动到土地的映射 `1-exp(-hL)` 是**假定的干扰竞争形式**，作者自称「continuous exponential function that is nearly linear when the population is small」，不是实测拟合；(e) 平衡态数值极端：以基线参数解出 `N̂ ≈ 13,507` 人/1000 ha 可耕地 = **13.5 人/ha 耕地**，人均口粮仅 ≈162 kg/年（≈1,554 kcal/day），属于长期饥饿态。这说明**该模型的平衡点不能直接当作历史现实**，只能当作「若无任何风险规避、无迁移、无制度」时的极限。
- **出处**：Winterhalder & Puleston 2018, *Cliodynamics* 9(2):40–83 ✔本次已读全文；Puleston, Tuljapurkar & Winterhalder 2014, *PLoS ONE* 9(1):e87541 ✔本次读取 PMC 正文与 Table 1；`github.com/puleston/spacelim` ✔本次已读源码。

### 2.2 FAO 水分-产量生产函数：Doorenbos–Kassam（I&D 33）与 AquaCrop

- **核心机制（I&D 33 / 现 I&D 66 第 2 章）**：单方程经验水分生产函数

  ```
  1 - Ya/Yx = Ky * ( 1 - ETa/ETx )
  ```

  `Ky > 1` 表示对水分亏缺敏感（减产幅度超过缺水幅度），`Ky < 1` 表示耐旱，`Ky = 1` 表示成比例。
- **核心机制（AquaCrop）**：把 ET 拆成土壤蒸发 `Es` 与作物蒸腾 `Tr`，用蒸腾驱动生物量：

  ```
  Tr = Ks * (Kc_Tr,x * CC*) * ET0
  B  = WP* * Σ Tr
  Y  = f_HI * HI0 * B
  ```

  `WP*` 是对 CO₂ 浓度与大气蒸发需求归一化后的水分生产力，是本模型的「守恒的作物参数」。
- **形式化程度**：**完全形式化**，FAO 官方标定，AquaCrop 已对 16 种作物（含小麦、水稻、大麦、高粱、大豆、玉米）完成标定与验证。
- **参数（本次从原文读取）**：
  - `WP*`：C4 作物约 **30–35 g/m²**，C3 作物约 **15–20 g/m²**（AquaCrop Reference Manual Ch.1）。→ 粟、黍、高粱、玉米走 C4 档；小麦、水稻、大麦、大豆走 C3 档。
  - 季节 `Ky`（FAO I&D 33 原表，经 I&D 66 转载）：玉米 1.25、春小麦 1.15、冬小麦 1.05、高粱 0.9、大豆 0.85、豆类 1.15、马铃薯 1.1、甘蔗 1.2、花生 0.70、棉花 0.85、苜蓿 1.1、甜菜 1.0、向日葵 0.95、番茄 1.05、洋葱 1.1、甘蓝 0.95、红花 0.8、西瓜 1.1、辣椒 1.1、豌豆 1.15、香蕉 1.2–1.35。**原表中没有水稻**。
- **适用范围**：季节尺度（I&D 33）或日尺度（AquaCrop）的、水分是主要限制因子的草本作物。
- **已知局限（FAO 自己写在 I&D 66 第 2 章里，非我们的推断）**：「**同一作物内部的 Ky 变异可能与作物之间的变异一样大**」（引 Stanhill et al. 1985）；IAEA 独立标定与 FAO 33 原值的偏差在部分作物/生育期上达 +1170%。→ **不要把 Ky 当常数**，要把它当一个有先验分布的地方性参数。
- **出处**：FAO 2012, *Crop yield response to water*, I&D Paper 66, Ch.1–2 ✔本次已读全文；AquaCrop Reference Manual v7.3 Ch.1（KU Leuven）✔本次已读全文；Doorenbos & Kassam 1979 △仅确认存在（经 I&D 66 引用）。

### 2.3 FAO/IIASA GAEZ 农业生态区划（Agro-Ecological Zoning）

- **核心机制**：分层「潜力—约束」链条：辐射与温度 → 潜在净生物量 → 收获指数 → 生育期长度（LGP）与温度总和约束 → 作物需水与土壤水平衡 → 农业气候约束因子 → 农业土壤（edaphic）约束因子 → 农业生态潜力产量 → 实际产量与产量差。每一层都是**乘性折减因子**。
- **形式化程度**：**完全形式化**（官方模型文档共 12 个模块），但**本次会话未能取得方程原文**（gaez.iiasa.ac.at 与 openknowledge.fao.org 在本次均不可达/403）。我通过 FAO 的 GAEZ v4 FAQ PDF 与检索结果确认了模块清单与结构，但**净生物量方程、最大叶面积指数、Pm/Pc 值、收获指数表都没有读到**。
- **输出**：51 种作物、雨养与灌溉两种水分条件、两个（v4 文档中为多个）投入管理等级的适宜性与潜在产量栅格。
- **对本项目的价值**：GAEZ 的「乘性约束因子链」是我们应该照抄的**架构**，而不是照抄的数字。理由：GAEZ 的低投入管理等级最接近前工业，但它的作物品种仍是现代品种（见 §8 反模式 8）。
- **已知局限**：面向当代土地评价与气候变化影响评估，时间上不回溯；土壤图是当代土壤图（前工业土壤剖面不同）；管理等级是离散档位而非连续劳动投入。
- **出处**：Fischer, G., Nachtergaele, F.O., van Velthuizen, H.T., Chiozza, F., Franceschini, G., Henry, M., Muchoney, D., Tramberend, S. (2021) *Global Agro-Ecological Zones v4 – Model documentation*, FAO & IIASA △仅确认存在（题名/作者/年份经检索结果与 IIASA eprint 17175 条目确认，正文未读）；GAEZ v4 FAQ PDF ✔本次已读（仅确认模块清单）。

### 2.4 Shukurov 等的前工业农业「热量—土地—劳动」核算模型（Cucuteni–Trypillia）

这是本次检索中**最直接可工程化**的一份文献：它把「饮食需求 → 谷物需求 → 作物面积 → 含休耕的耕地面积 → 加上放牧与冬季饲草的聚落开发面积 → 各项农活的人日成本 → 劳动回报率 λ」全部写成闭式方程，并给出全套标称参数与结果表。

- **核心方程（原文 Eq. 4–6，本次已读）**：

  ```
  Y   = κ * Y0 * ( 1 - R/R0 - D/D0 )        # 产量随降水 R 与连作年数 D 线性衰减
  Yg  = ( 1 - δ_seed - δ_loss ) * Y          # 可食用谷物 = 总产 - 留种 - 损耗
  Ag  = ε_g * C / ( e_g * Yg )               # 人均作物面积
  Af  = Ag * ( 1 + δ_f ) / δ_a               # 人均含休耕的耕地面积（δ_a = 可耕地占比）
  ```

- **参数（原文 Table 3/6/8/9）**：见 §4 硬数字表。要点：休耕/作物面积比 `f = 2`；可耕地占比 `a = 0.35`；留种 12%；虫鼠损耗 25%；饮食 2500 kcal/人/日，其中谷物 40%、家畜产品 40%、野生动物 20%。
- **适用范围**：新石器—铜石并用时代、混合农牧、无灌溉、手工具或原始犁的定居村落（50–300 人，2–10 ha）。
- **已知局限（作者自陈）**：产量的降水/时间衰减系数 `R0`、`D0` 来自美国密苏里 Sanborn Field 连作试验（1888 起），**作者明确说无法把它们校正到前现代欧洲**；并且 Sanborn 的降水系数是**负的**（湿年淋失氮、倒伏），这只适用于湿润站点，直接搬到黄土高原会符号错误。
- **出处**：Shukurov, Videiko, Sarson, Davison, Shiel, Dolukhanov & Pashkevich (2015) *Productivity of pre-modern agriculture in the Cucuteni–Trypillia area*, arXiv:1505.05121（投 *Human Biology* 专辑）✔本次已读全文 49 页。

### 2.5 HYDE：全新世人类土地利用重建

- **核心机制**：两步。(1) **总量**：1960 年后直接用 FAO 统计；1960 年前用「人口 × 人均土地利用」外推，人均值不是常数而是沿一条国别曲线（凹形/钟形/凸形）变化。(2) **空间分配**：把国别总量按归一化权重图乘积分配到 5 弧分格网。

  ```
  W_crop,historic = W_pop · W_suit · W_river · W_coast · W_slope · W_temp
  ```

  硬阈值：人口密度 < 0.1 人/km² 不允许永久农业；年均温 < 0 °C 不能耕作；年均温 < −10 °C 不能放牧。土壤适宜性 `W_suit` 直接取自 GAEZ。2010 年卫星参考图的权重从 1500 CE 的 0% 线性升到 2010 CE 的 100%。
- **形式化程度**：完全形式化且数据公开。
- **对本项目的价值**：**权重乘积式空间分配是我们应该采用的定居/开垦分配算法原型**（它便宜、可解释、可回放）。总量层的「人口×人均」则**不能**采用（见 §8 反模式 1）。
- **已知局限（HYDE 作者自陈）**：「人均土地利用的外推是一种务实做法，但它对曲线形状极其敏感」；人均耕地的标准差在 1 CE 之前达到 ±1 ha/cap；人均放牧地的标准差在 1600 CE 前约 ±5 ha/cap，殖民时代高达 ±25 ha/cap；权重图使用**当代**气候与生物群区，全新世早期气候差异被忽略。
- **出处**：Klein Goldewijk, Beusen, Doelman & Stehfest (2017) *Anthropogenic land use estimates for the Holocene – HYDE 3.2*, *Earth Syst. Sci. Data* 9:927–953, doi:10.5194/essd-9-927-2017 ✔本次已读全文 27 页。

### 2.6 Boserup 的农业强化序列，以及对它的实证反驳

- **核心机制**：人口密度是采用集约技术的**前提**而非结果；随密度上升，休耕期缩短（森林休耕 → 灌木休耕 → 短休耕 → 年耕 → 多熟），单位面积产出上升而单位劳动产出下降。
- **形式化程度**：原著（Boserup 1965）是**定性理论**；后续有若干半形式化（可再生资源框架下的土壤肥力最优管理，把长休耕解释为生产技术非凸性的结果）。
- **对本项目的价值**：Boserup 提供的是**因果方向**（密度 → 强化），这正是我们需要的：强化不应该是一个「科技树解锁」，而应该是家户在土地稀缺时的**内生选择**。
- **已知局限（Johnston 2003 的实证反驳，本次已读全文）**：
  1. Boserup 的**阶段序列不是唯一路径**。在无犁、无畜力、无化肥的湿热低地，「延长耕作期」（cultivation lengthening，靠密集除草与覆盖）比「缩短休耕」更高产也更可持续。
  2. 提高复种频率不一定通过缩短休耕实现。
  3. Boserup 关于「哪些技术属于哪个阶段」的具体归属被多项研究否证。
- **出处**：Boserup 1965 *The Conditions of Agricultural Growth* △仅确认存在（经 EH.net 书评页确认）；Johnston, K.J. (2003) *The intensification of pre-industrial cereal agriculture in the tropics: Boserup, cultivation lengthening, and the Classic Maya*, *Journal of Anthropological Archaeology* 22:126–161, doi:10.1016/S0278-4165(03)00013-8 ✔本次已读全文。

### 2.7 轮垦（swidden）承载力公式，以及「承载力」概念本身的批判

- **核心机制**：给定四个量——每人所需耕作面积 `a`、耕作年数 `Y_c`、休耕年数 `R`、可耕地总量 `T`——可以算出人口上限。原始公式出自 Conklin (1959)、Carneiro (1960)、Brown & Brookfield (1963, 新几内亚高地)。
- **形式化程度**：完全形式化（简单代数）。
- **⚠️ 重要诚实声明**：**我本次没有读到 Carneiro 1960 的原文代数**。§3.7 给出的代数式是我自己按上述四个变量的定义重推的（标记为 D 级），不是 Carneiro 的原式转述。
- **已知局限（这是本领域最锋利的一处批判）**：
  - Brush (1975) 的结论：「承载力概念的主要经验弱点在于，它内含的稳态（homeostasis）理论既不可检验也不可否证」。
  - Street (1969) 论证轮垦者与环境保持整合、不趋近上限。
  - Stevens 等 (2024) 综述：「大多数小规模社会（狩猎采集或农业）运行在远低于承载力的水平」，并引 Shennan (2018) 认为承载力「更像一个随技术与社会组织变动的移动目标，而非绝对生态阈值」。
  - 亚马逊案例中，鱼与猎物可能是人口方程的必要项，而多数公式把它们省略了。
- **出处**：Brush, S.B. ### 2.8 内卷（involution）与家户生产：Philip C.C. Huang vs 李伯重 / Allen

- **Huang 的机制**：长江三角洲的稻作经济陷入「内卷式增长」：单位土地劳动投入不断上升，总产出上升但**边际报酬递减、人均产出与生活水平无改善、劳动生产率下降**。人口增长驱动商品化与「内卷式商品化」。
- **李伯重 / Allen 的反驳**：江南农业在此期间持续有技术进步（肥料、水利）；农场规模随人口下降**没有**造成劳动力闲置，相反双季稻等措施使**每劳动日产出上升**；把 Allen 对英国农场投入产出的测算与李伯重对江南家庭农场的分析并置，「以每千卡谷物所需工作日衡量的农业生产率是可比的」，这些数据**不支持** Huang 关于中国稻作经济劳动生产率长期下降的论断。
- **形式化程度**：**双方都只有定性理论 + 分散的核算表**，没有一个双方接受的形式化模型或参数化的劳动生产率时间序列。
- **对本项目的价值**：这是一个**必须建成争议、不能建成规律**的机制。见 §3.14 与 §8 反模式 11。
- **出处**：Huang, P.C.C. (1990) *The Peasant Family and Rural Development in the Yangzi Delta, 1350–1988*, Stanford UP △仅确认存在（Stanford UP 页面）；Huang, P.C.C. ### 2.9 全球狩猎采集人口密度的环境模型（Tallavaara et al. 2018）

### 2.10 轮垦产量衰减的杂草竞争模型（Johnston 2003 综述的实验证据链）

- **核心机制**：轮垦地块第二年之后的产量崩塌，**主因不是土壤养分流失，而是杂草侵入与竞争**。养分并未离开地块，而是从作物转移到杂草体内。
- **形式化程度**：半形式化（有实验数据与反比关系图，无闭式方程）。
- **关键实验数据（Johnston 2003 转述，一手为 Lambert & Arnason 1986 / Steggerda 1941 / Lal et al. 1975）**：
  - 伯利兹玛雅地块：**第 3 年谷物产量降至第 1 年的 25%，同期杂草生物量比第 1 年高 350%**；到第 3 年，地块植被中 **30–80% 的关键养分被固定在杂草体内**。
  - Steggerda 十年连作试验：前 4 年用砍刀式除草，产量逐年下降至第 1 年的 ~20%；第 5 年改为**连根挖除**，产量立刻超过第 1 年水平并维持到第 8 年（第 8 年因两年蝗灾崩溃）。结论：有效除草可把玛雅玉米耕作期从 3 年延长到 **7–8 年**。
  - 除草时机：播后 4 周除草的玉米田比 6 周除草的高产 **30%**；甘蔗前 6 周除草不足使产量降 **45%**，即使后期密集除草也无法挽回。
  - 覆盖（mulch）：尼日利亚雨林试验中仅需 **1 cm 覆盖**即使玉米产量高约 **50%**；干草覆盖 2.5–3.7 t/ha 使高粱增产约 **45%**。
  - 侵蚀：表土流失 **2.5 cm → 玉米减产 50%；7.5 cm → 减产 90%**（Lal et al. 1975，尼日利亚）。
- **已知局限**：证据集中在湿热低地（玛雅、尼日利亚、印度东北），**不能直接外推到华北黄土区**（那里水分而非杂草可能是主导，见 §6）。
- **出处**：Johnston 2003（同 §2.6）✔本次已读全文。

## 3. 可直接用于本项目的机制清单

以下每条给出：输入 → 输出、数学草图、时间尺度、空间粒度、证据等级、以及**为什么这样简化**。总体架构建议是一条**乘性折减链 + 三个路径依赖的状态存量 + 一次随机抽样 + 一个约束判定器**。

### 3.0 【总答】应该用什么样的生产函数？

**推荐形式（单地块 i、单年 t）**：

```
# 1) 物理上限：由气候与土壤决定的「潜在产量」
Y_pot(i,t) = HI_c * WP*_c * Σ_d Tr(i,t,d)              # AquaCrop 核心（水驱动）
             或  Y_ref_c * Π_j C_j(i)                   # GAEZ 核心（乘性约束链）

# 2) 折减链：三个路径依赖的存量 + 管理
Y_att(i,t) = Y_pot(i,t)
             * g_N ( N_i,t )          # 地力（氮/有机质存量）
             * g_W ( W_i,t )          # 杂草种子库存量
             * g_S ( S_i,t )          # 表土深度 / 盐分存量
             * g_M ( 管理强度, 除草时机, 覆盖 )

# 3) 随机性：气候年际波动（不是给均值加噪声，而是抽样）
Y(i,t) ~ Gamma( shape = 1/CV_i² , scale = Ȳ_i,t * CV_i² )
Ȳ_i,t  = (1-ρ) * Y_att(i,t) + ρ * Y(i,t-1)             # AR(1) 自相关

# 4) 劳动：三重约束，取最紧的那个
A_cult(i,t) = A_max,i * ( 1 - exp( -h_i * L_i,t ) )     # 干扰竞争饱和
L_window    = 各时间窗内可用人日（播种窗 ≤30 天、收割窗）
产出 = Y(i,t) * min( A_cult , A_窗口可完成 , A_水可灌 )

# 5) 输出的不只是数字，还有「谁在绑定」
binding_constraint ∈ {LABOUR, LAND, WATER, NITROGEN, WEED, TIME_WINDOW, SEED}
```

**为什么这个形式能避免「固定曲线」**（这是本简报的核心论点）：

1. **产量是抽样，不是取值**。Sanborn Field 连作小麦的实测变异系数是 **80%（无粪肥）/ 50%（施粪肥）**；FLD 模型的默认 `CV = 0.3`。任何把产量写成确定值的做法都会抹掉「歉收年」这一最重要的历史驱动力。
2. **抽样有自相关**。`ρ_ac = 0.25–0.5` 意味着**连续两三年歉收**是常态而非罕见事件。连续歉收才是饥荒、迁徙、叛乱的成因；独立抽样会把这类事件的概率压低一到两个数量级。
3. **绑定约束会切换**。FLD 模型的 copial→Malthusian 相变、灌溉的水量上限、播种窗的人日上限——这些让同一个「技术等级」在不同人口/气候下表现完全不同。**约束切换本身就是可追溯因果链的天然节点**。
4. **三个存量制造路径依赖**。氮存量、杂草种子库、表土深度都是**慢变量**，都受历史耕作选择影响，都能造成「几百年前的一个决定导致今天的减产」——正是 MANDATE 第 3 条要求的路径依赖。
5. **风险而非均值驱动行为**。Shukurov 等给出的关键对比：施粪肥地块产量低于 400 kg/ha 的年份占 **8%**，不施粪肥占 **27%**——粪肥的主要价值是**降方差**，不是提均值。这让「为什么农民愿意付出收集粪肥的额外劳动」有了可计算的动机，而不需要 LLM 编故事。
6. **参数是地方性的分布，不是全局常数**。FAO 自陈 Ky 的种内变异与种间变异同量级。我们应该给每个格网抽一个 `Ky_i ~ 先验分布` 并固定为世界事实，而不是全世界共用一个 1.05。

### 3.1 水驱动生物量核心（AquaCrop 简化版）
- **输入 → 输出**：日辐射/温度/降水/参考蒸散 ET0、土壤持水量、作物参数（`WP*`、`HI0`、`Kc_Tr,x`、生育期）→ 单地块潜在产量 kg/ha。
- **数学草图**：`Tr_d = Ks_d · Kc_Tr,x · CC*_d · ET0_d`；`B = WP* · ΣTr`；`Y = f_HI · HI0 · B`。`Ks_d` 是根区可用水的分段线性折减；`CC*` 是冠层覆盖度的 logistic 生长曲线。
- **参数起点**：`WP*` = 30–35 g/m²（粟、黍、高粱）/ 15–20 g/m²（小麦、水稻、大麦、大豆）；`HI0` 谷类取 0.35–0.50（**注意：`HI0` 的具体数值我本次未从原文读到，须标为待核**）。
- **时间尺度**：日步长积分，年输出一次。为算力可退化为**旬步长**或直接用生育期总蒸腾。
- **空间粒度**：地块/格网（建议 ≤5 km，见 §3.7 通勤半径）。
- **证据等级**：**A**（FAO 官方标定、16 作物验证、`WP*` 数值本次原文核对）。
- **为什么这样简化**：AquaCrop 的完整日模型对数千年 × 数万格网太贵。但 `B = WP*·ΣTr` 这一步是**保守参数**，是全模型中最不该被替换的一行。退化方案见 3.2。

### 3.2 单方程水分生产函数（算力受限时的退化方案）
- **输入 → 输出**：生育期实际蒸散 `ETa`、无胁迫蒸散 `ETx`、作物 `Ky` → 相对产量。
- **数学草图**：`Ya = Yx · [ 1 - Ky·(1 - ETa/ETx) ]`，并把 `Ky` 按生育期分段（营养期低、开花期/灌浆期高、成熟期低）。
- **参数**：见 §4 的 Ky 表。**每个格网从先验分布抽一个 Ky 并冻结**（因为种内变异 ≈ 种间变异）。
- **时间尺度**：生育期（季）。**空间粒度**：格网。**证据等级**：**A**（FAO 表值）/ **C**（把它当常数用则降为 C）。
- **为什么这样简化**：一个乘法就能表达「今年干旱减产多少」，且开花期干旱与成熟期干旱后果不同——这已经足够产生「同样降水总量、不同时序 → 不同历史」的分岔，成本几乎为零。

### 3.3 劳动→耕地的饱和映射与食物比（FLD 核心）
- **输入 → 输出**：年龄结构人口、劳动效率向量 `φ_x`、消费权重 `ρ_x`、可耕地 `A_m`、产量 `Y` → 食物比 `E`；`E` → 年龄别生育率与存活率。
- **数学草图**：见 §2.1 的五行方程。生育/死亡响应用 gamma CDF：`p_x = p*_x · Γcdf(E; α_x, 0.1)`。
- **参数**：全套见 §2.1 与 §4。`h = H·k/A_m`；`w = H·k·φ` = 人均可耕作面积（基线 0.348 ha/人，**每个成年劳动者 0.944 ha**）。
- **时间尺度**：年（人口投影矩阵一年一步）。**空间粒度**：聚落/区域（一个 `A_m` 对应一个农业社区的耕作圈）。
- **证据等级**：**A**（完全形式化、参数齐备、代码公开）；但 `1-exp(-hL)` 这一具体函数形式是作者假定的，该行降为 **B**。
- **为什么这样简化**：它用**一个标量 `E`** 把「吃得够不够」传给人口，避免为每个人建营养模型；同时 copial/Malthusian 两相自动涌现，不需要写「进入马尔萨斯陷阱」的剧本。
- **失效条件**：`E` 是社区平均值，抹掉了分配不平等。一旦引入地租、赋税、阶层，必须按阶层分别计算 `E`（Winterhalder & Puleston 2018 的赋税扩展正是这样做的）。

### 3.4 产量随机性：gamma 抽样 + AR(1)
- **输入 → 输出**：目标均值 `Ȳ`、变异系数 `CV`、自相关 `ρ_ac`、上一年实际产量 → 本年产量。
- **数学草图**（逐字来自 `spacelim` 源码）：
  ```
  Ybar_t = Y*(1-ρ_ac) + ρ_ac * Y_{t-1}
  Y_t    = rgamma( shape = 1/CV² , scale = Ybar_t * CV² )
  ```
- **参数**：`CV = 0.3`（FLD 默认）；`CV = 0.5`（施肥地块实测）；`CV = 0.8`（无肥连作实测）。`ρ_ac = 0.25`（参数表）或 `0.5`（论文运行文件）。
- **时间尺度**：年。**空间粒度**：格网，但**必须加空间相关**（同一年整个华北歉收 vs 只有一个村歉收，历史后果完全不同；用一个区域共同因子 + 格网独立因子分解）。
- **证据等级**：**A**（函数形式与参数均来自公开代码与实测试验）；空间相关结构为 **D**（我们自己加的）。
- **为什么这样简化**：gamma 分布天然非负、右偏（少数丰年、长右尾），与 Sanborn 实测的「峰值在 0.6 t/ha、有长正尾」形态吻合。用正态分布会产生负产量。

### 3.5 地力：氮存量与有机肥/绿肥/河泥/休耕
- **输入 → 输出**：氮输入（粪肥、夜香、绿肥固氮、河泥、降尘降雨、留种、豆科杂草）、氮输出（作物移出、淋失、挥发）→ 氮存量 `N_i,t` → 折减因子 `g_N`。
- **数学草图**：
  ```
  N_{t+1} = N_t + I_manure + I_legume + I_silt + I_atm - Uptake(Y_t) - Leach(降水)
  g_N     = N_t / ( N_t + N_half )        # Michaelis–Menten 型饱和
  ```
- **参数（本次已核）**：
  - 小麦在 1000 kg/ha 产量下**移出 20 kg N/ha/年**；可由降尘+降雨+鸟粪 **8–12 kg N/ha/年**、种子 **1 kg N/ha/年**（产种比 10:1）、豆科杂草 **2–10 kg N/ha/年** 补回——**在低产水平上氮预算可以在无粪肥情况下平衡**（Loomis 1978，经 Shukurov 等转述）。
  - 厩肥施用率：Sanborn 试验 **15 t/ha/年**；考古氮同位素推断的「中等施肥」**10–15 t/ha**、「高施肥」**35+ t/ha**（Wang et al. 2018 采用的欧洲标定阈值）。
  - 猪粪施肥使现代粟增产约 **18%**（Wang et al. 2018）。
  - 施肥的**方差效应**：产量 < 400 kg/ha 的年份从 27%（不施）降到 8%（施 15 t/ha）。
- **时间尺度**：年。**空间粒度**：地块。
- **证据等级**：氮平衡量级 **B**（单一二手来源 Loomis 1978，未读原文）；施肥率 **B**；施肥增产幅度 **B**；`g_N` 的具体函数形式 **D**。
- **为什么这样简化**：把「地力」压成一个标量存量，牺牲了 N/P/K 与有机质的区分，但保住了唯一真正重要的动力学：**地力是慢变量、可被历史决策消耗、可被劳动补充**。
- **失效条件**：水稻田不适用这套线性收支。见 §6.4 与 §7.3。

### 3.6 杂草种子库存量与除草劳动（本简报最容易被忽略但最有价值的机制）
- **输入 → 输出**：连续耕作年数、除草劳动投入与时机、休耕年数 → 杂草存量 `W_i,t` → 折减因子 `g_W`。
- **数学草图**：
  ```
  W_{t+1} = W_t * (1 + r_W) * (1 - kill(除草人日, 方法, 时机)) - decay(休耕年 * 遮荫)
  g_W     = 1 / ( 1 + β * W_t )
  ```
- **标定锚点（Johnston 2003 转述的实验）**：
  - 无有效除草：`g_W`(第3年) ≈ **0.25**，同期杂草生物量 ×4.5。
  - 砍刀除草：第 4 年 ≈ **0.20**。
  - 连根挖除：立刻恢复到 **> 1.0**（超过第一年），可维持 **7–8 年**。
  - 除草时机弹性：播后 4 周 vs 6 周 → 产量差 **30%**；前 6 周除草不足 → **−45%**，后期补救无效。
- **时间尺度**：年（时机效应在年内，用一个「时机质量」标量表达）。**空间粒度**：地块。
- **证据等级**：**B**（多个独立实验，但都在湿热低地；华北适用性未验证）。
- **为什么这样简化**：这一条让「Boserup 强化」有了**两条真实可选路径**而不是一条：缩短休耕（土地路径）vs 延长耕作+密集除草（劳动路径）。这是防止「农业强化 = 固定科技树」的关键。
- **失效条件**：在半干旱黄土区，水分可能比杂草更早成为限制因子；此时 `g_W` 的权重应下降。**我没有找到华北的对应实验数据**（§7.4）。

### 3.7 休耕—耕作循环的承载力代数
- **输入 → 输出**：可耕地 `T`、人均耕作面积 `a`、耕作年数 `Y_c`、休耕年数 `R` → 人口上限 `P`。
- **数学草图（⚠️ 这是我自己的重推，D 级；Conklin 1959 / Carneiro 1960 / Brown & Brookfield 1963 的原式我本次未读）**：
  ```
  每人需要的土地总量 = a * (Y_c + R) / Y_c
  P = T * Y_c / ( a * (Y_c + R) )
  ```
  等价写法：休耕/作物面积比 `f = R/Y_c`，则 `P = T / ( a * (1+f) )`。
- **参数**：`f = 2`（Shukurov 等的标称值）；华北粟作 `f = 0.5–1.0`（Ho 1975 描述的「休一年、种两三年、再休一年」轮作，经 Stevens 等 2024 转述）；粟作向西北推进时 `f` 升到「三年休两年或更多」。
- **时间尺度**：多年（循环周期）。**空间粒度**：聚落耕作圈。
- **证据等级**：代数 **D**（我的重推）；`f` 的取值 **B**；「承载力是常数」这一解读 **C（被否证，不要采用）**。
- **为什么这样简化**：这条代数的**唯一正当用途是给模拟输出做量级校验**（「这个聚落的人口密度是否落在轮垦系统的可能范围内」），**不能**用作模拟的驱动规则。理由见 §8 反模式 2。

### 3.8 通勤半径与耕作圈（空间粒度的物理依据）
- **输入 → 输出**：聚落位置、地形 → 可耕作圈面积与距离衰减权重。
- **数学草图**：`可耕权重(d) = exp(-d/d0)`，`d0` 标定使「多数耕地在 1–2 km 内、外缘 5 km」。
- **参数（本次已核）**：
  - 民族志范围 **1–11 km**；单程 **1 小时**为合理上限，**1.5–2 小时**为不可取上限（Jarman et al. 1982，经 Shukurov 等转述）。
  - 耕地外缘平均 **5 km**，多数在 **1–2 km** 内。
  - Higgs & Vita-Finzi：定居人口开发半径 **5 km**，半定居 **10 km**。
  - Stevens 等 2024 用 **3 km 半径 = 约 2950 ha** 作为「一个工作日步行范围」。
- **时间尺度**：结构性（随交通技术/畜力变化）。**空间粒度**：这直接决定了**格网尺寸的上限**。
- **证据等级**：**A**（多个独立民族志/考古来源，有数值范围）。
- **为什么这样简化**：这一条是**格网设计的硬约束**。如果格网边长 >5 km，「聚落只能耕作周边一圈」这一事实就无法表达，聚落裂变（fission）与外扩这一最重要的新石器人口机制就会消失。**建议格网 ≤3 km**。

### 3.9 季节劳动窗口（最容易漏、后果最大）
- **输入 → 输出**：作物面积、劳动效率、可用劳动者数、窗口天数 → 是否有产量损失。
- **数学草图**：
  ```
  播种所需人日 = A_crop / (s_till * H)      # s_till: m²/人时
  若 播种所需人日 / (w * N) > 30 天 → 减产（或必须缩减播种面积）
  ```
- **参数（本次全部从 Shukurov 等原文读取）**：
  - 手工具翻地 **15 m²/人时**（范围 10–25，虚土 2.5–6，石锄轻土 13–17，鹿角锄 6–17）
  - 原始犁（ard）**260 m²/人时**（≈ 手工具的 17 倍）
  - 收割 **30 m²/人时**（20–35）
  - 脱粒+扬场 **30 m²/人时**
  - 工作日 **10 小时**；工作年 **250 天**
  - 家庭中能承担重体力劳动的比例 `w = 1/3 ~ 1/2`
  - **播种与整地必须在 30 天内完成**，否则显著减产（Percival 1974，经转述）
  - 换算基准：**10 m²/人时 ≡ 100 人日/ha**（10 小时工作日）
  - 另一独立来源（Ellen 1982）：手工具整地 25 m²/时（1 ha 需 400 小时）；一对牛 150 m²/时（1 ha 需 65 小时）
- **时间尺度**：年内（季）。**空间粒度**：家户/聚落。
- **证据等级**：**A**（实验考古 + 民族志 + 罗马农书三源并置）。
- **为什么这样简化**：这一条解释了**为什么犁与畜力是断点式而非渐进式的技术**：它把「两个人耕完家庭田」从 52 天压到 3 天，从而解除窗口约束。它还解释了为什么「提高单产」不能替代「提高劳动效率」——Shukurov 等算出，若靠提高单产把整地压进 30 天，需要 **2200 kg/ha** 的不可信高产。**这是一个不需要 LLM 就能产生技术采纳压力的机制。**

### 3.10 劳动回报率 λ 作为可行性门槛
- **输入 → 输出**：产出千卡、投入人时 → `λ = 产出可维持的天数 / 生产所需工作天数`。
- **参数**：民族志下限 `λ ≈ 10`（Ellen 1982）；印尼轮垦园艺**仅种植部分** `λ = 2.4`；Shukurov 等的 CTU 谷物案例 `λ ≈ 5.5`；主要经济活动 **1750 kcal/人时**。逻辑门槛：一人自养需 `λ ≥ 1`；两个劳动力养六口之家需 `λ ≥ 3`；要产生可储存/可交换剩余需更高。
- **时间尺度**：年。**空间粒度**：家户。
- **证据等级**：**B**（民族志范围，非精确参数）。
- **为什么这样简化**：`λ` 是一个**可以直接暴露给因果链日志的单一标量**：「为什么这个村放弃了这块地？因为 λ 跌到 2.1，低于该文化的可接受下限」。它把「土地退化」翻译成「人会做的决定」。

### 3.11 驯化与作物改良作为 Y0 与 HI 的缓慢漂移
- **输入 → 输出**：累积栽培世代数、选择强度 → `Y0`、`HI0`、`WP*` 的缓慢上移。
- **参数（Stevens, Zhuang & Fuller 2024, Table 1，本次原文读取）**：
  | 作物 | 野生 → 驯化 单产 | 增幅 | 野生 → 驯化 回报率 |
  |---|---|---|---|
  | *Oryza rufipogon* → *O. sativa* | 232 → 850 kg/ha | +366% | 90 → 330 kcal/hr |
  | *Setaria viridis* → *S. italica* | 50.8 → 600 kg/ha | +1180% | 21.06 → 248.67 kcal/hr |
  | *Panicum ruderale* → *P. miliaceum* | 109.9 → 600 kg/ha | +546% | 30 → 163.8 kcal/hr |
  性状分解：粒重（水稻 +23.4%、粟 +130.8%、黍 +51.3%）、穗粒数（水稻 +132.8%、粟 +900%、黍 +294.7%）、闭穗、成熟收获、紧凑直立株型。
- **时间尺度**：世纪—千年。Fuller 等把粟的驯化期（不落粒、粒增大、穗发育）定在 **8300–4300 BC**。
- **空间粒度**：作物谱系（全局），可加区域品系分化。
- **证据等级**：**A**（多性状分解 + 独立实验测量），但表中若干条目作者自标为「本文估计，需观测研究」（闭穗 50%、紧凑株型 100%），这些条目为 **D**。
- **为什么这样简化**：这条数据的关键含义是——**驯化本身提供了 5–12 倍的产量提升，远大于任何前工业「技术」**。如果我们的模拟里作物参数是固定的，就等于把新石器时代最大的一次生产力革命写死了。同时这条数据也给了「为什么粟在后期超过黍」一个纯机制的答案（粟的穗粒数增益远大于黍）。

### 3.12 灌溉：投资、维护、边际收益与盐碱化
- **输入 → 输出**：水源可得性、干旱指数、坡度、集体劳动投入 → 灌溉面积；灌溉 → 产量提升 + 盐分存量上升。
- **数学草图（分配部分照抄 HYDE，A 级；后果部分为 C/D）**：
  ```
  W_irri = W_aridity * W_water_available * W_within_cropland     # HYDE 的分配规则
  盐分:  S_{t+1} = S_t + 灌溉水量*水盐浓度 - 淋洗(排水条件) 
  g_S    = f(S_t)  # 作物耐盐性差异：大麦 > 小麦
  ```
- **参数（本次已核）**：
  - 全球实际灌溉面积（HYDE 3.2）：5000 BCE **<0.2 Mha**；1 CE **2.6 Mha**；1000 CE **4.1 Mha**；1500 CE **4.2 Mha**（长期平台）；1800 CE 9.3；1900 CE 47.5；2015 CE 275.6。
  - 中国灌溉面积（HYDE 3.2，Mha）：4000 BCE 0.86 → 1 CE 1.28 → 1000 CE 1.9 → 1500 CE 1.0 → 1700–1800 CE 0.9 → 1900 CE 2.8 → 1960 CE 10.1 → 2015 CE 23.8。
  - **HYDE 自己的判断**：「古代灌溉技术只在本已有利的环境条件（降水、地形、坡度）下正常运作；当人口增长、农业扩张到条件较差的地区时，事情必须改变」——这正好是我们需要的**边际收益递减机制的定性依据**。
- **⚠️ 缺口**：**我本次没有找到任何可用的灌溉维护成本参数**（人日/km 渠道/年、淤积率、可用寿命）。见 §7.5。盐碱化的定量参数（灌溉水盐度 → 土壤 EC 上升速率 → 减产）同样未取得。
- **证据等级**：分配规则 **A**；灌溉面积序列 **B**（HYDE 的前 1700 年数据不确定度 ≥25%，1 CE 达 ±75%）；边际收益递减 **B（定性）**；维护成本 **D（无来源）**；盐碱化速率 **D（无来源）**。
- **为什么这样简化**：灌溉是本项目中最诱人也最危险的机制——它太容易被写成「解锁灌溉 → 产量 +50% 永久」。正确写法是：**灌溉是一笔需要持续维护劳动的资本，它把水约束换成了盐分约束与制度约束**。在没有参数之前，宁可把维护成本设为一个显式的、标记为 D 级的可调参数，也不要设为零。

### 3.13 饮食结构与家畜/野生资源的耦合
- **输入 → 输出**：谷物/家畜/野生三部分的热量占比 → 人均作物面积、放牧面积、饲草面积。
- **数学草图**：`A_g = ε_g·C / (e_g·Y_g)`，`A_f = A_g·(1+f)/a`，家畜与野生部分同法。
- **参数（Shukurov 等 Table 8/9，本次原文读取）**：饮食 2500 kcal/人/日；谷物 40%、家畜 40%、野生 20%；谷物热值 3150 kcal/kg（斯佩尔特）/ 3567 kcal/kg（一粒小麦）；结果为人均作物 **0.26 ha**、休耕 **0.53 ha**、田区总计 **2.25 ha**、放牧区 **26.63 ha**、饲草区 **0.69 ha**；人均牲畜 5.2 头（牛 1.8、羊 1.3、猪 1.7、马 0.4）。
- **关键对比**：若假设谷物是**唯一**热量来源，人均需谷物 **250–350 kg/年**、作物面积 **0.4–0.5 ha/人**；而混合饮食下只需 **100–140 kg/年**、**0.2–0.3 ha/人**。作者明确说前者是**高估**，而古经济估算「常常」隐含这一假设。
- **时间尺度**：年。**空间粒度**：聚落。
- **证据等级**：**A**（闭式核算 + 全套参数 + 与骨骼组合数据交叉）。
- **为什么这样简化**：这条给了我们一个**2 倍量级的校验尺**：任何把人均耕地算到 0.4–0.5 ha 以上的模拟，很可能是忘了肉、奶、鱼、坚果和野菜。它也让「农业强化」不必只走增产一条路——降低谷物在饮食中的占比也是一条路（Shukurov 等算出：谷物占 20%、家畜占 60%、单产 1100 kg/ha 也能解除窗口约束）。

### 3.14 内卷 / 家户劳动配置（混合机制，必须双轨）
- **输入 → 输出**：家户人口结构、地块面积、地租/赋税率、非农机会 → 单位面积劳动投入、单位劳动产出。
- **建议实现（这是本条的核心）**：**不要**在内核里写「内卷定律」。而是：
  1. **数学侧**只负责计算：给定劳动投入，产出多少（由 §3.1–3.9 决定）；给定家户成员数与地块，家户有多少空闲劳动。
  2. **Agent 侧**（家户 LLM 或规则化家户）负责决定：多余劳动是投到自家地块（→ 单位劳动产出下降但总产上升）、雇工、副业、还是迁移。
  3. 于是「内卷」成为一个**可能的涌现结果**，而不是一条规律。同一个世界在土地市场发达处可能不内卷，在土地不可分割处可能内卷。
- **可用的实证锚点（Buck 1929–33 调查，经 Deng & O'Brien 转述，本次原文读取）**：中国全境呈现**规模不经济**——小农场每公顷产量一贯高于大农场（全国：小 1723.4 vs 极大 1455.4 kg/ha）。这个「反向农场规模—土地生产率关系」是内卷争论双方都要解释的核心事实。
- **时间尺度**：代际（家户生命周期）。**空间粒度**：家户。
- **证据等级**：反向规模关系 **A**（Buck 大样本）；「内卷是长期趋势」**C**（Huang vs 李伯重/Allen 实质争议）；Chayanov 的家户均衡理论 **✗ 本次未验证**。

### 3.15 侵蚀与表土深度
- **输入 → 输出**：坡度、覆盖度、降雨强度、耕作方式 → 表土流失 → `g_S`。
- **参数（唯一取得的定量锚点）**：尼日利亚农田表土流失 **2.5 cm → 玉米减产 50%；7.5 cm → 减产 90%**（Lal et al. 1975，经 Johnston 2003 转述）。覆盖 1 cm → 玉米增产约 50%（同源）。
- **时间尺度**：年累积，后果在世纪尺度。**空间粒度**：地块（需坡度）。
- **证据等级**：**C**（单一二手来源，热带砂质土；黄土高原的土壤—产量关系与之不同：黄土深厚，减产机制更可能是水分与肥力而非「土层耗尽」）。
- **为什么这样简化**：侵蚀是本项目最好的「不可逆路径依赖」候选之一——它能制造真正无法回退的区域衰败。但**我们目前没有中国黄土区的定量参数**（§7.4），所以这条应该以显式 D 级参数实现，并在标定阶段优先补齐。

## 6. 中国与东亚特定证据

### 6.1 粟作（华北）：产量、休耕与承载力
- 传统粟作单产可推为与旱稻相当：**500–650 kg/ha**（Stevens, Zhuang & Fuller 2024）。
- 黄土的天然肥力较高，可能降低对休耕的需求；但**黄土的固有肥力受水分限制**（Ho 1975 的判断，经 S24 转述）。
- 轮作模式（Ho 1975 描述）：**第一年休耕、第二三年种植、然后再休一年**。晚商甲骨文（1250–1046 BC）也显示规律休耕，休耕地在不耕之年用于狩猎（Peng 1989，经 S24 转述）。→ 这给了我们一个具体的 `f ≈ 0.5–1.0` 的华北先验，而不是热带轮垦的 `f = 2–10`。
- 粟作向西北推进时休耕加重到「三年休两年或更多」。
- 承载力推算：3 km 半径（约 2950 ha）内自给，最大约 **2000 人**（相当于 40 ha 聚落）；但这意味着周边几乎无林地留给狩猎与柴薪，柴薪与狩猎必须去更远处。
- **裂变机制**：S24 明确写出「当人口达到周边景观的承载力时，导致社群裂变（community fission），随后向外扩张、在此前无农业的地方建立新的农耕聚落，可能距原聚落相当远」。**这正是我们需要的、无需剧本的聚落扩散机制。**

### 6.2 稻作（长江及以南）：产量与土地需求
- 新石器水稻 **800–900 kg/ha**；新石器旱稻 **~600 kg/ha**。
- 水稻的土地效率远高于粟：**每 1 ha 聚落面积需 8 ha（区间 8–9.75）稻田**；且水稻**不需要休耕**（这是与旱作最重要的结构差异）。
- 旱稻需要休耕，「或许每两年或三年一次」，因此 50 人需约 35 ha 耕地（其中至多一半休耕）。
- 汉代杭州一带水稻 ~1000 kg/ha；10 世纪日本 ~1300 kg/ha。
- Buck 1929–33 实测：稻作大区 2489.6 kg/ha、双季稻区 3680.0、西南稻区 3731.1 kg/ha——**是小麦大区（1013.3）的 2.5–3.7 倍**。这个南北差是中国历史地理最基本的量化事实之一，必须在地图上表达。

### 6.3 驯化事件与年代
- 常见黍（*Panicum miliaceum*）：磁山遗址储藏坑的稃壳植硅体与生物分子标记定年 **约 10,300–8,700 cal yr BP**；**8,700 cal yr BP 之后**谷物中开始出现少量粟。
- 粟的驯化过程（不落粒、粒径增大、穗发育）被 Fuller 等定在 **8300–4300 BC**。
- 西南（白羊村）定居农业约 **2650 BCE** 开始，同时栽培已驯化的稻、黍、粟。
- 驯化的产量增益（§4.1 / §3.11）：**粟 +1180%、黍 +546%、稻 +366%**；粟的增益远大于黍，Stevens 等据此解释「前仰韶期以黍为主、后期粟占优势」不必归因于气候恶化或人口压力。
- 遗传证据支持黍起源于**中国西部**（*Panicum miliaceum* 的西中国起源假说）。
- 华北粟作向东北与俄罗斯远东的扩散：Leipe et al. 2019 *Science Advances* 5(9):eaax6225 论证其为**不连续扩散**（discontinuous spread）——即扩散不是均匀波前。

### 6.4 施肥：华北新石器的猪粪循环
- 陕西白水河谷 7 处遗址（5575–4070 cal BP，晚仰韶—庙底沟二期—龙山）的粟黍 δ¹⁵N：粟 5.2 ± 0.8‰、黍 5.5 ± 0.9‰，全部 >3‰，**36% >6‰**。按欧洲麦类标定阈值，对应「中等（10–15 t/ha）到高（35+ t/ha）施肥」。作者结论：有机施肥「对于支撑晚新石器黄土高原的农业与文化扩张是必要的」。
- **但这个结论有实质争议**（S24 明确指出）：Wang et al. 2018 依赖的是**为欧洲小麦大麦开发的**阈值，且与考古草食动物推断的背景植被相矛盾。大地湾的同位素研究更可靠（它对同一遗址的粟、猪、人做了全食物链取样，还做了当地现代植被与粟的基线小研究），该研究（Yang et al. 2022b）提示仰韶时期**猪（也许还有人）吃粟或粟的食物废料，再把粪返还粟田**。
- **C4 作物的混杂因素**：C4 粟类的光合作用会通过减少气孔开度、提高水分利用效率来影响氮同位素水平；一些研究发现 δ¹⁵N 与灌溉量/降水量有初步关系但未确证；非洲采集的粟种质显示 δ¹⁵N 与降水正相关，而另一项 *Pennisetum glaucum* 浇水试验未发现强影响。→ **δ¹⁵N 目前不能作为施肥率的定量标尺**，只能作为「有/无施肥」的弱证据。

### 6.5 汉代作物组合（关中）
Liao et al. (2022) 对西安地区汉墓 45 件陶仓模型的作物遗存分析：**粟 44%（n=20）、黍 29%（n=13）、大豆 11%（5）、赤豆 8%（4）、大麦 7%（3）、稻 2%（1）、麻 2%、小麦 2%**。龙枣村 M111（西汉晚期）5 件陶仓全部只有粟黍，**无小麦**。作者推断这是**以粟为核心的多作物种植**而非小麦专业化，阻碍小麦采纳的因素包括：干旱气候不足以满足小麦需水、磨面技术尚未普及（唐代才流行）、以及政治经济因素（粟支配着税收、仓储与官俸等级）。

> **对本项目的重要启示**：这是一个**制度锁定生产选择**的实例，而且是可机制化的：税以何物计征 → 何物有市场与储存基础设施 → 何物被种。这条链条应该在我们的模拟中可用，且它天然产生「技术上更优的作物因制度惯性而不被采纳」这类合理但反直觉的结果。

### 6.6 中国史料的量化陷阱（方法论）
Deng & O'Brien（LSE EH WP 359）系统列出了为什么中国的历史农业数字不能直接用：
- **亩的混乱**：官方以「6 步 × 6 步（步）」定亩，但步长因人而异；即使步长统一，**亩至少有约 10 种大小，从 240 步到 1200 步，相差五倍**。
- **土地清丈极其稀疏**：1072 年宋神宗下令全境清丈，是帝国建立千余年后的第一次有记载的尝试；25 个宋路中只有 5 个实际完成，清丈率仅 20%。三个世纪后的 1387 年才有下一次。此后 1578、1654、1690 三次，间隔 191、76、35 年。1712 年康熙「永不加赋」后清丈废弃，**农田、农业产出与农村人口从此与税收脱钩**。
- **货币混乱**：清代银两有 56 种地区标准（35.14–37.50 克），其中只有 4 种通行全国；另有铜钱与多重汇率；以米为基准衡量时银铜都不稳定。
- **对我们的直接后果**：任何「某朝亩产 X 石」的陈述都要先问「哪种亩、哪种石、哪年清丈」。**在模拟中，我们不应该用绝对单位标定，而应该用比率标定**（例如「稻作区/小麦区单产比 ≈ 2.5」，这个比率比任何绝对值都稳健）。

### 6.7 中国的「反向农场规模—土地生产率关系」
Buck 数据显示：**小农场每公顷产量一贯高于大农场**，在所有区域皆如此（全国：小 1723.4、中 1726.6、中大 1673.6、大 1621.1、极大 1455.4 kg/ha）。同时役畜密度随农场增大而下降（1.24 → 0.53 头/ha）。Deng & O'Brien 把这解释为「规模不经济」，并认为大分流「深深根植于中国一侧的规模不经济」。

> **注意**：这一事实**同时**是内卷论与反内卷论的弹药。它可以读成「劳动被过度投入到小块土地」（Huang），也可以读成「小农场对劳动的配置更有效率」（李伯重/Allen 方向）。**我们不应该在内核里选边**（见 §8.11）。

## 7. 学界争议与未解决问题

### 7.1 「承载力」这个概念本身是否可用
- Brush (1975)：承载力概念内含的稳态理论「既不可检验也不可否证」。
- Street (1969)：轮垦者与环境整合，不趋近上限。
- Stevens 等 (2024) 的立场：多数小规模社会运行在远低于承载力的水平；承载力更像随技术与社会组织移动的目标（引 Shennan 2018）。
- **本项目的处置**：承载力**只作为诊断输出**（每 tick 报告「若无迁移与贸易，此地的自给上限是多少」），**绝不作为驱动规则**。人口动态由 §3.3 的食物比 `E` 驱动，而 `E` 从来不需要知道承载力是多少。

### 7.2 中世纪/前工业的种子产出比之争（对我们的量级标定影响最大）
- 悲观派（Duby，源头是 Slicher van Bath 对 800 年前后里尔附近皇庄粮食清册的计算，得 1:1.3–1:3）：早中世纪产量极低。
- Jarrett (2019) 的反驳：Duby 反复错读或不充分解读史料；「该领域的农业史学者现在很大程度上一致认为他错了」；Fossier 在 1990 年不得不承认自己在该领域孤立。
- 实验考古（Reynolds 1998，本次读全文）：所有显著试验的比值**一律超过 1:10**，多在 1:15–1:70；「产量比 1:3 在视觉上意味着彻底歉收」。Reynolds 主张文献比值是「收成经各项支出后的最终结算」，甚至可能是「公布的收入」而非实际毛产量。
- **未决**：文献比值到毛产量的换算系数没有共识。撒播鸟害（~50% 播种量）与虚土/肥力差异都能解释一部分差距，但不足以解释一个数量级。
- **本项目的处置**：以实验考古为毛产量先验（1:15–1:30 为常态区间），并显式建模「毛产量 → 留种 → 损耗 → 地租/税 → 净口粮」的每一层扣除。这样文献比值就成为**模拟中的官方账目**，与世界事实的毛产量分离——恰好对应 MANDATE 第 9 条「世界事实与历史叙事分离」。

### 7.3 前工业农业的氮预算能否长期平衡
- Loomis (1978) 的论证（经 Shukurov 等转述）：在 1000 kg/ha 的低产水平上，作物移出 20 kg N/ha/年可由降尘/降雨/鸟粪（8–12）、种子（1）、豆科杂草（2–10）补回，**无需施肥即可平衡**；他引亚洲现存耕作系统数千年维持这种平衡为证。Rothamsted 无肥小区一般稳定在 1000–2000 kg/ha。
- 反面：Sanborn 无肥小区在 30 年内未出现任何趋于平衡的迹象；施肥小区可能在 15–20 年达到平衡。
- **未决**：低产平衡态是否存在、在什么单产水平上存在、以及水稻田（有蓝藻固氮与灌溉水带入养分）是否遵循完全不同的收支。
- **对我们的影响很大**：如果低产平衡态存在，那么「地力耗尽导致文明崩溃」这条剧情线在前工业条件下大体不成立，衰败必须另有机制（水、盐、侵蚀、杂草、制度）。**我倾向于把「氮预算在 ~1000 kg/ha 水平上可平衡」实现为可开关的假设，并在标定阶段用两种设定跑对照。**

### 7.4 华北黄土区的轮垦/连作衰减机制未量化
杂草竞争主导说（§2.10、§3.6）的实验证据全部来自湿热低地（伯利兹、尼日利亚、印度东北）。华北半干旱黄土区的对应实验数据**本次未找到**。同样未找到的是黄土高原侵蚀量与产量的定量关系（唯一可用的 Lal et al. 1975 是尼日利亚砂质土）。**这是本简报最大的区域性缺口。**

### 7.5 灌溉的成本、维护与盐碱化，无可用参数
- 我**没有找到**任何可用的量化参数：渠道维护人日/km/年、淤积速率、灌溉系统可用寿命、水盐浓度 → 土壤 EC 上升速率、EC → 减产函数。
- 定性证据是清楚的：HYDE 明确写「古代灌溉技术只在本已有利的条件下正常运作」；Jacobsen & Adams (1958) 的经典盐碱化论证（南美索不达米亚小麦被更耐盐的大麦取代，最终小麦在南部冲积平原完全消失）在文献中被广泛引用，且后续有专门的「进步性盐碱化理论辩护」文章，说明该理论**仍有争议**。
- **数值警告**：检索片段中出现「约公元前 2400 年大麦平均单产 2537 lt/ha」以及小麦占比从 3500 BC 的 50% 降到 ~2500 BC 的 17%、2100 BC 的 <2%、1700 BC 归零的序列。**我未能读到 Jacobsen & Adams 原文或任何一手转载**，因此这些数字在本简报中标为 **C 级、待核**，不得直接写入参数文件。

### 7.6 内卷：无共识的定量结论
Huang（劳动生产率长期下降）与李伯重/Allen（每劳动日产出上升、以工作日/千卡衡量的生产率与英国可比）在**同一批史料上得出相反结论**。没有任何一方提供了可供我们直接采用的劳动生产率时间序列。**处置见 §3.14。**

### 7.7 从狩猎采集到农业的密度跃迁没有机制模型
Tallavaara 等给出了狩猎采集密度的环境响应面（A 级数据、模型系数未取得），FLD 给出了农业人口的食物受限动态（A 级），但**没有任何模型把两者接起来**——即「在什么条件下农业的 λ 超过采集的 λ，且这个超越能抵消风险与劳动痛苦的上升」。Stevens 等给出的驯化前后回报率（稻 90→330、粟 21→249、黍 30→164 kcal/hr）是目前最接近可用的一组数字，因为它可以与采集的回报率直接比较——但我**本次未取得采集资源的对应回报率**。

### 7.8 GDD 与物候参数缺失
本次未能取得权威的粟/黍/稻在中国条件下的基点温度与生育期热量需求（GDD）参数集。仅取得零散信息：小麦 GDD 常以 0 °C 为下限阈值（NDAWN 实践）；粟（*Setaria italica*）在 13–30 °C 区间内环境温度与生长速率正相关，高温促进抽穗。**这不足以标定物候模型**，需下一阶段专门检索（建议入口：AquaCrop 作物参数文件、GAEZ v4 的 crop calendar / temperature sum 模块、以及中国农业气象学文献）。

### 7.9 HYDE 3.3/3.4 的方法变更未核实
本简报的 HYDE 方法与数字全部来自 **3.2 版论文（2017）**。门户页显示当前为 **3.4 版（10,000 BCE – 2025 CE），3.5 版在准备中**。3.3/3.4 的方法学变更（尤其是是否仍用「人口 × 人均」外推）**本次未核实**。使用前必须读 3.4 的方法文档。

## 8. 反模式：本领域常见的错误建模方式

### 8.1 用「人口 × 人均耕地」推出耕地，再用耕地论证承载力（循环论证）
这是 HYDE 自己的总量方法，HYDE 作者明确承认它「对曲线形状极其敏感」，并指出人均耕地的标准差在 1 CE 前达 ±1 ha/cap。**如果我们用 HYDE 的耕地数据去校准我们的承载力模块，我们校准的其实是 HYDE 的人均系数假设，不是历史。** 正确用法：只用 HYDE 的**空间分配算法**和**总量的量级区间（含其不确定度带）**，承载力必须由我们的生物物理内核独立算出，然后与 HYDE 比对。

### 8.2 把承载力 K 当作环境常数写进格网
被 Brush 1975（不可否证）、Street 1969、Dewar 1984、Shennan 2018 系统批判。K 依赖饮食结构（2 倍差异，§3.13）、技术、劳动可得性、风险偏好、贸易——它是导出量。**在格网上存一个 `K` 字段，就等于把这些因果关系全部隐藏掉，直接违反 MANDATE 第 2 条。**

### 8.3 把轮垦休耕建模为纯粹的土壤养分恢复
Johnston 2003 综述的实验证据链表明：第 2 年之后产量崩塌**主因是杂草侵入**，养分并未离开地块而是转移到杂草体内；有效除草（连根挖除）能把耕作期从 3 年延长到 7–8 年。**如果我们只有土壤肥力这一个状态变量，就会推出「除草没用、只有休耕有用」，从而丢掉 Boserup 的第二条强化路径（劳动密集化）。**

### 8.4 把 Boserup 序列当固定科技树
Boserup 的五阶段被 Johnston 2003 与 Kirch 1994、Morrison 1994 等否证：强化路径至少有三条（缩短休耕、延长耕作+密集除草、转湿作/水田），并且技术与阶段的对应关系不成立。**「解锁犁 → 解锁短休耕 → 解锁年耕」这种实现方式恰好是 MANDATE 第 1 条禁止的「固定科技树」。** 正确做法：让家户在土地稀缺时面对多条可行的强化选项，每条有不同的劳动/风险/地力后果，由 Agent 选择、由数学结算。

### 8.5 把文献种子产出比当田间毛产量
文献 1:2–1:4 与实验 1:15–1:70 差一个数量级（§7.2）。**若采用文献值，整个前工业农业的生产力会被低估 5–10 倍**，进而使任何城市、军队、官僚体系在模拟中都无法被养活，逼迫我们去人为调高产量参数——这就把一个史学争议变成了一个隐藏的魔法系数。

### 8.6 用确定性产量曲线（哪怕加上白噪声）
- 实测 CV 是 **0.5–0.8**（Sanborn），FLD 默认 0.3。
- 且有**年际自相关 ρ = 0.25–0.5**，意味着连续歉收是常态。
- 且施肥的主要价值是**降方差**（<400 kg/ha 年份从 27% 降到 8%），不是提均值——若不建模方差，粪肥这一整套劳动组织与畜牧—农耕耦合就失去动机。
- 且极端年份的后果是非线性的：L'Esquerda 1994 年春播作物**完全绝收**，仅因 3–5 月降水虽总量勉强够、但「每月一半以上降水集中在一天以内的短时暴雨，径流使作物无法受益」。**降水总量相同、时序不同 → 绝收 vs 正常。** 任何用年降水总量做输入的产量函数都无法表达这个。

### 8.7 把 Ky、Kc、WP* 当全球常数
FAO 自己在 I&D 66 中写：`Ky` 的**种内变异可能与种间变异一样大**；IAEA 独立标定与 FAO33 原值偏差最大 +1170%。**正确做法**：给每个格网/作物组合从先验分布抽一个参数并冻结为世界事实，让「这块地对干旱特别敏感」成为一个可被世界中的人发现的地方性知识。

### 8.8 用现代传统农法产量当史前产量
驯化本身带来 366%–1180% 的产量提升（§3.11）。Stevens 等明确警告：「现代传统产量可能不是史前的完美类比，因为土地利用系统和作物本身都改变了」。**用现代 1897 kg/ha 的水稻产量去算河姆渡的承载力，会高估 2 倍以上。**

### 8.9 忽略通勤半径，假设行政边界内的土地都可耕
民族志上单程 1 小时是合理上限、1.5–2 小时是不可取上限；耕地外缘平均 5 km，多数在 1–2 km 内。Stevens 等用 3 km 半径（2950 ha）作为一个工作日的步行范围。**如果格网边长 >5 km，「聚落只能耕作周边一圈、达到上限后裂变外扩」这个新石器最核心的人口空间机制就消失了。** 建议格网 ≤3 km。

### 8.10 直接采用历史单位与史料数字
亩有约 10 种大小（240–1200 步，相差五倍）；步长因人而异；清代银两有 56 种地区标准；土地清丈间隔可达 191 年，1712 年后彻底与税收脱钩。**用比率而非绝对值标定**（例如稻区/麦区单产比、南北人口密度比），因为比率对单位混乱免疫。

### 8.11 把「内卷」写成规律
Huang 与李伯重/Allen 在同一批史料上得出相反结论（§2.8、§7.6）。Buck 的反向农场规模关系同时支持两种解读。**在内核里写「随人口密度上升，劳动生产率下降」就等于在一场未决的学术争论中偷偷选边，并把它变成模拟世界的物理定律。** 正确做法见 §3.14：数学只算「投入 X 劳动得到 Y 产出」，是否内卷由家户决策与土地制度共同涌现。

### 8.12 假设谷物是唯一热量来源
Shukurov 等直言「古经济估算常常（显式或隐式地）假设谷物是新石器饮食的唯一成分」，而这会把人均土地需求从 0.2–0.3 ha 高估到 0.4–0.5 ha（约 2 倍）。**这是一个纯粹由建模疏忽造成的 2 倍系统偏差。**

### 8.13 把灌溉当作免费的单调升级
灌溉需要持续维护劳动（→ 需要集体行动或强制，→ 制度后果）；它把水约束换成盐分约束（→ 长期不可逆退化）；且 HYDE 指出古代灌溉技术只在本已有利的条件下有效，扩张到边际土地时会失效。**我们目前没有维护成本与盐碱化速率的参数（§7.5），但把它们设为零远比设为一个标记为 D 级的猜测更危险**——因为零会让灌溉在模拟中无限扩张。

### 8.14 假定始终是同一个约束在绑定
FLD 模型的核心洞见之一：人口增长过程中，先是**劳动受限**（copial 阶段，E>1，指数增长），然后切换到**土地受限**（Malthusian 阶段）；而**可榨取剩余的峰值出现在切换之前**，不是在平衡态。Winterhalder & Puleston 由此推出「在小而增长的人口中征实物税更有效；接近密度依赖平衡时征劳役更有效」。**如果我们的农业模块只有一个瓶颈，就会丢掉这类相变，也就丢掉了国家形成时机的内生解释。**

### 8.15 忽略年内时间窗
Shukurov 等的关键发现：即使产量足够，**整地播种必须在 30 天内完成**这一约束本身就可能不可满足；而提高单产**不能**解除它（需要不可信的 2200 kg/ha），只有提高劳动效率（犁、畜力）或降低谷物在饮食中的占比才能。**这是「为什么犁是断点式技术」的完整机制解释，而它完全依赖于建模年内时间窗。** 只有年尺度总量的模型无法产生它。

### 8.16 用 δ¹⁵N 反推定量施肥率
Wang et al. 2018 使用的阈值是为**欧洲小麦大麦**开发的；C4 粟类的气孔行为会干扰氮同位素；δ¹⁵N 与降水的关系在不同研究中不一致。**δ¹⁵N 目前只能支持「有/无施肥」，不能支持「10–15 t/ha vs 35 t/ha」。**

## 9. 无来源判断（D 级，明确标记为 LLM 常识，不得当作历史规律）

以下全部是**我为了让模拟能跑而做的设计判断**，没有文献来源，不得写进任何声称有实证依据的文档：

1. **乘性折减链的整体架构**（§3.0 的 `Y_pot × g_N × g_W × g_S × g_M` 形式）。GAEZ 是乘性链、AquaCrop 有乘性胁迫系数、我把它们和地力/杂草/侵蚀存量拼在一起——这个特定组合是我的设计，没有文献做过。
2. **杂草种子库的状态方程形式**（`W_{t+1} = W_t(1+r_W)(1-kill) - decay`）与折减函数 `g_W = 1/(1+βW)`。文献只给了产量比值（第 3 年 25%），没给动力学方程。
3. **地力折减函数 `g_N = N/(N+N_half)`**（Michaelis–Menten 形式）。文献给了氮收支的通量，没给产量对氮存量的响应形式。
4. **把 Carneiro 型承载力写成 `P = T·Y_c/(a(Y_c+R))`**。这是我按四个变量定义重推的代数，不是 Carneiro 1960 原式的转述（我未读原文）。
5. **产量随机性的空间相关结构**（区域共同因子 + 格网独立因子）。FLD 只有单地块，没有空间。
6. **建议格网 ≤3 km**。这是我从「3 km 步行耕作圈」与「多数耕地在 1–2 km 内」推出的工程决定，不是文献建议。
7. **把 `binding_constraint` 作为显式状态输出**用于因果链追溯。这是本项目的设计发明。
8. **把 `Ky` 等参数「抽一次然后冻结为世界事实」**的做法。文献只说变异大，没说该怎么处理。
9. **把「内卷」实现为可能的涌现结果而非规律**。这是我基于争议未决状态做的建模判断。
10. **用比率（稻/麦单产比 ≈2.5、南北密度比）而非绝对值做标定**的策略。这是我对单位混乱问题的应对，不是史学界的既有方法。
11. **对 FLD 平衡态的量级判断**（「1351 人/km² 可耕地、162 kg/人/年属长期饥饿态，不能当历史常态」）。数值求解是我做的（输入参数是 A 级），但「不能当历史常态」这个判断是我的。
12. **Buck 数据的剩余率推算**（2786.9 kg/农场输出 vs 279 kg/人/年谷物消费 ⇒ 约 40% 产出流向地租/税/种子/牲畜/市场）。这是我在 A 级输入上做的算术，Deng & O'Brien 没有做这个计算，且我不知道农场平均人口（未验证），所以这个 40% 极不可靠。
13. **「氮预算在 ~1000 kg/ha 水平上可平衡」应实现为可开关假设并跑双设定对照**。这是我的方法论建议。
14. **认为盐碱化应实现为存量而非事件**。设计判断。
15. **认为水稻田不适用旱作的线性氮收支**。这是我基于「稻田有蓝藻固氮与灌溉带入养分」的常识推断，**本次未找到任何来源**。
16. **AquaCrop 的 CO₂ 归一化基准年浓度 369.41 ppm**——这是我凭记忆写的数字，本次未在原文中看到，**必须核实后才能使用**。
17. **谷类 `HI0` 取 0.35–0.50** ——凭常识给的区间，本次未从 AquaCrop 参数表读到。
