## 0. 阅读本简报的方式（给建模者的三句话）

1. **本领域唯一真正"可以直接编译成代码"的东西是 Lee–Tuljapurkar–Puleston 的 food-ratio 人口生态模型**（§2.1、§3.1）。它有完整方程、完整参数表、公开 R 代码，并且已经被用来推导出"盈余在均衡人口的 25% 处达到峰值""固定额度税收在数学上不稳定"这类**可以直接生成因果链的结论**。建议它成为人口内核的骨架。
2. **本领域最大的陷阱是古人口学数据**。骨骼样本推出的"史前 e0 = 15–20 岁"几乎肯定是系统性偏差的产物（§8.2）；放射性碳日期 SPD 曲线的逐点数值不可用于回归或求变化率（§8.4）。真实历史只能校准**相对变化模式**，不能校准绝对水平。
3. **队列（cohort）与个体（individual）的切换标准不是"人口多少"，而是"这个机制的输出是否依赖于'谁'"**（§3.11、§6.4）。世系灭绝、继承、联姻、精英过度生产这四类机制在数学上无法用队列表示——队列不能灭绝。

## 1. 本简报要回答的问题

1. 前工业人口的增长/衰减由什么决定？Malthus 与 Boserup 的对立在今天怎么被综合，综合后的模型能不能算？
2. 前工业人口—工资—技术的均衡有多强、多快？（关键：如果反馈太强，模拟里不会有历史；太弱，模拟里不会有约束。）
3. 史前和农业社会的出生率、死亡率、期望寿命、TFR、自然增长率、人口密度上限，各自的**可用数值区间**是多少？
4. 古人口学（骨骼、墓地、放射性碳）作为校准集，哪些结论可以信，哪些绝对不能信？
5. 危机死亡率（饥荒、疫病、战争）的量级是多少？它在长期人口动力学中占多大份量？
6. 婚姻市场与家户形成如何充当生育的"阀门"？欧洲模式与东亚模式的差别在机制层面（而非文化标签层面）是什么？
7. 技术实现：SOCSIM 这类微观人口模拟能跑到多大、多久？亲属网络的计算和存储极限在哪？
8. **核心问题**：如何设计一个既能跑数千年、又能在需要时下钻到具体人物与家族的分层人口表示？在什么条件下必须从队列表示切换到个体表示？

## 2. 已有成熟模型与理论

### 2.1 Lee–Tuljapurkar–Puleston 食物依赖人口生态模型（food-limited / space-limited population ecology）★ 首选骨架

- **核心机制**: 年龄结构人口 → 年龄别劳动供给 → 与环境参数（面积、单产）交互产生食物 kcal → 与年龄别热量需求相除得到**食物比 E** → E 决定年龄别生育率与存活率 → 更新 Leslie 矩阵 → 下一年人口。
- **形式化程度**: **完全形式化**。Leslie 矩阵投影 + 显式弹性函数；均衡通过求"使食物依赖 Leslie 矩阵主特征值 = 1 的 E"得到。公开 R 代码：<https://github.com/puleston/spacelim>（Winterhalder & Puleston 2018 正文给出）。
- **状态变量**: 年龄别人口向量 `N_x`；食物比 `E`；耕作面积比例 `F`；（加税收版本）税额 `T`。
- **参数**（Winterhalder & Puleston 2018 Table 1，本次已抓到完整表格）:

  | 符号 | 含义 | 值/单位 |
  |---|---|---|
  | `Y` | 单位面积单产 | 21,000 kcal/ha/day |
  | `H` | 劳动最强年龄组的日工作时长 | 5 hr/day/ind（= 10 hr/day/worker） |
  | `k` | 每小时可耕作面积 | 0.0944 ha·day/hr |
  | `φ_x` | 年龄 x 相对工作投入 | 0 ≤ φ_x ≤ 1；`φ0 = 0.738`，`φ̂ = 0.723` |
  | `J` | 需求最高年龄组的基线热量 | 2,785 kcal/day |
  | `ρ_x` | 年龄 x 相对消费 | 0 ≤ ρ_x ≤ 1；`ρ0 = 0.832`，`ρ̂ = 0.827` |
  | `j` | 年龄结构加权人均消费 | `j0 = 2,318`，`ĵ = 2,303` kcal/day |
  | `A_m` | 可耕地 | 1,000 ha（基线） |
  | `w = H·k·φ_x` | 劳动有效性 | `w0 = 0.3483`，`ŵ = 0.3413` ha/person |
  | `γ` | E=1 处生育率弹性 | 0.135 |
  | `a_x` | E=1 处年龄别存活率弹性 | 0.00279 ≤ a_x ≤ 0.156；`a_25 = 0.00464` |
  | `b0, d0, r0` | 基线（copial 期）粗出生/死亡/增长率 | 0.0369 / 0.0192 / 0.0176 per yr |
  | `b̂, d̂, r̂` | 均衡值 | 0.0328 / 0.0328 / 0 per yr |
  | `E_m, Ê_m` | 无穷小人口的食物比（copial / 均衡年龄结构） | `Y·H·k·φ0/(J·ρ0) = 3.16`；`3.11` |
  | `TFR_d` | 基线女儿数 TFR（Puleston et al. 2014 Table 1） | 2.44 |
  | `e0` | 基线期望寿命（同上） | 45 yr |

- **适用范围**: 自然生育（无避孕）、以农业为主、单一环境常数、土地面积受限的前工业人口；1,000 ha 尺度（一个聚落群/一条河谷）。
- **已知局限**（作者自陈 + 我的补充）:
  - 单性别（unisexual）模型，隐含 1:1 性比。无婚姻市场、无家户，因此**无法**表示欧洲/东亚婚姻阀门差异（§2.6）。
  - 工作投入 `φ_x` 与消费 `ρ_x` 假定为常数，不随食物丰裕度调整——作者明确承认这排除了 Chayanov 式/时间最小化式的劳动响应。**这是 Boserup 机制的缺口**（见 §7.3）。
  - 无储备粮跨年结转（另一篇 Winterhalder, Puleston & Ross 2015 处理了这个）；无种子留存、无租税损耗、无非粮食土地用途。
  - `A_m = 1,000 ha → N̂ = 13,509` 意味着 ~1,350 人/km²**耕地**（≈9 人/ha）。这是"全部热量来自粮食、零损耗"的上限，绝不能当作**领土密度**用（见 §8.9）。

- **出处**: Lee, Tuljapurkar & Vitousek, Theoretical Population Biology 73:473–482 (2008)；Puleston & Tuljapurkar, TPB 74:147–160 (2008)；Lee, Puleston & Tuljapurkar, TPB 76:179–188 (2009)；Puleston, Tuljapurkar & Winterhalder, PLoS ONE 9(1):e87541 (2014)；Winterhalder & Puleston, Cliodynamics 9(2):40–83 (2018)。

### 2.2 "The Invisible Cliff"：三相动力学（copial / transition / Malthusian）

- **核心机制**: 新占领一片栖地的自然生育人口会经历三个相：(1) 长期的 **copial 相**（食物盈余、生命率恒定）；(2) 短暂的 **transition 相**（食物短缺迅速抬高死亡率、压低生育率）；(3) 无限长的 **Malthusian 相**（生命率与生活质量被显著压低）。
- **形式化**: 完全形式化，与 §2.1 同一内核。作者定义 **MTI (Malthusian Transition Interval)** = 从"第一次感到饥饿"到"人口倍增时间放慢到 1000 年"的时间跨度。
- **量化结果**（基线情形）: copial 相 **346–347 年**；MTI **约 40–65 年**（较低背景死亡率下从 65 缩短到 48 年）；均衡人口 **13,509**；均衡期望寿命 **30.0 年**（基线 45）；均衡食物比 **Ê = 0.668**；`E_{t=0} = 2.99`。
- **敏感性**（作者列出，可直接当作我们的参数扫描先验）:
  - 建立人口规模 `N0`：对数线性缩短 copial 相；**不影响 MTI**
  - 栖地面积 `A_m`：对数线性延长 copial 相（面积 ×10 → +131 年）；**不影响 MTI**
  - 单产 `Y`：延长 copial 相，**缩短** MTI
  - 期望寿命 `e0`、生育率：条件变好则两相都缩短，且均衡饥饿更严重
  - 生命率弹性：**不影响** copial 相，弹性越高 MTI 越短
- **为什么这条对本项目至关重要**: **人口曲线是平缓的 S 型，但福利曲线是断崖。** 一个只汇报 `N` 的模拟会完全错过历史上最有后果的那个事件。因此 `E` 必须是一等状态变量，而且 Agent 感知的应该是 `E`（饥饿）而不是 `N`。
- **出处**: Puleston, Tuljapurkar & Winterhalder 2014, PLoS ONE 9(1):e87541, doi:10.1371/journal.pone.0087541。

### 2.3 Winterhalder & Puleston 2018：盈余、税收与国家崩溃的可计算机制 ★ 直接服务于"国家灭亡的因果链"

- **核心机制**: 在 §2.1 内核上加入精英抽取（抽取实物 kcal 或抽取劳动时间），推导盈余的时间形状与税收的稳定性。
- **关键量化结果**（全部来自本次抓到的正文）:
  - **copial 盈余定义**: `S_t = N_t (E_t − 1) j_0`
  - **盈余峰值出现在人口仅为均衡人口 25% 时**（N = 3,382 vs N̂ = 13,509），第 293 年，此时 `E = 1.82`，`S* = 6.41×10⁶ kcal/day`。盈余**不是**人口的单调函数。
  - 时间地标：盈余峰值 = 第 293 年；`E` 首次跌破 1 = 第 347 年；人口增长率峰值（157 人/年）= 第 352 年。**人口动量导致 5 年滞后**。
  - 均衡时总产量比基线需求短缺 `1.03×10⁷ kcal/day`。
  - **最大可持续固定税额 = 9.55×10⁶ kcal/day，对应 N̂ = 4,507（人均 2,120 kcal/day）**。即：重税把均衡人口压到无税时的 1/3。
  - **固定额度（fixed-quota）税收存在两个均衡：小人口高税率（不稳定）与大人口低税率（稳定）**。不稳定分支上任何向下扰动都会触发"人口下降 → 人均税负上升 → E 进一步跌破替代 → 人口再下降"的自强化崩溃螺旋。这是**一条完全内生、完全可追溯的国家崩溃因果链**。
  - **随机单产下的半衰期"折肘"形状**: 单产服从 gamma 分布，均值 21,000 kcal/ha/day，基线 CV = 0.20（600 年模拟实现值：均值 20,847，SD 4,238，CV = 0.203，最低 9,253，最高 34,283）。税率 = 最大确定性税额的 40% 时：**CV < 0.28 → 近乎无限存续；CV > 0.38 → 几乎立即崩溃**。CV < 0.20 → 60% 税率可近乎无限持续；CV > 0.50 → 20% 税率已构成严重危险。
  - **抽取形式的最优选择随人口而变**: 人口小且在增长时抽取实物更有效；人口接近密度依赖均衡时抽取劳动更有效。
- **形式化程度**: 完全形式化。
- **已知局限**: 精英人口不建模（假定数量小且稳定）；不含再分配；单一环境；无战争。
- **出处**: Winterhalder & Puleston 2018, Cliodynamics 9(2):40–83；开放获取 <https://escholarship.org/uc/item/1p67f693>。

### 2.4 Wood 1998：Malthus–Boserup 综合与 "well-being"

- **核心机制**: 以 **well-being**（影响个体生存与繁殖能力的生理状态）为中枢变量，把 Malthus（人口压低福利）与 Boserup（压力诱发技术/强化）合并。后续被形式化为 **MaB Ratchet（Malthus–Boserup 棘轮）**：反复出现的 Malthusian 萧条与恢复，其间采纳"提高适合度的文化创新"，从而**可持续地抬升由生态—文化共同塑造的 Malthusian 上限**。
- **形式化程度**: 原论文为**半形式化**（概念模型 + 简单模型）；MaB ratchet 在后续考古应用中被算子化。
- **为什么重要**: 它给出了本项目需要的"上限本身会移动"的结构——K 不是常数，而是一个被历史事件抬升的棘轮。注意它与 §2.1 的关系：§2.1 的 `Y`（单产）和 `w`（劳动有效性）就是棘轮的物理载体。
- **已知局限**: well-being 缺可观测代理；棘轮"何时咬合"没有定量条件。**这是本领域最大的未形式化缺口**（§7.3）。
- **出处**: Wood, J. W., "A Theory of Preindustrial Population Dynamics: Demography, Economy, and Well-Being in Malthusian Systems," *Current Anthropology* 39(1), 1998（DOI 10.1086/204700）。MaB ratchet 应用见 *Journal of Anthropological Archaeology* 2021（Malthus–Boserup ratchet，狩猎采集者人口扩张）与 *Quaternary International* 2023（阿根廷中西部多代理研究）。

### 2.5 Lee & Anderson 2002：前工业 Malthusian 系统的"弱稳态"

- **核心机制**: 把 Malthusian 系统写成状态空间模型（生育率、死亡率、人口规模、实际工资全部内生，另有劳动需求变动与健康变动等不可观测影响），用 Kalman 滤波反复迭代求最大似然。数据：英格兰年度数据 1540–1870。
- **形式化程度**: 完全形式化（状态空间 + Kalman filter）。
- **量化结果**（**注意：以下数值来自检索摘要，本次未能打开原文核验，见 §10；证据等级 C**）:
  - 生育率对工资弹性 **+0.12**，死亡率对工资弹性 **−0.08**
  - 冲击回归均衡的**半衰期约 107 年**
  - 1600–1795 年人口增长 **0.47%/年**，由约同速率的技术进步支撑，与实际工资恒定相容
  - 生育率与死亡率方程的**截距随时间大幅变动**，即多数生命率变化与工资无关
- **对本项目的意义（极重要）**: Malthusian 反馈是**弱且慢**的。一个"每代人口都被拉回 K"的模拟在经验上是错的。同时，"多数生命率变动与工资无关"意味着我们必须给生命率留一个独立于经济的外生/制度性通道（疾病环境、卫生、婚姻制度）。
- **出处**: Lee, R. D. & Anderson, M., "Malthus in state space: Macro economic-demographic relations in English history, 1540 to 1870," *Journal of Population Economics* 15(2):195–220 (2002)。

### 2.6 Hajnal 的欧洲婚姻模式 vs 东亚模式：两种不同的"生育阀门架构"

- **欧洲模式（EMP）**: 女性初婚年龄晚 + 高终身独身率 + 新居制核心家庭。
  - 量化（Devolder, CED WP 163，本次抓到全文）: 16 世纪西欧女性初婚年龄**在一个世纪内从约 20 岁升到 25 岁以上**；Hajnal 线为圣彼得堡–的里雅斯特；**男性初婚年龄在转变前后都是 28–30 岁**，且大致等于父亲去世的平均时点。区域异质性显著：加泰罗尼亚、瓦伦西亚、波河平原**始终低于 23 岁**，尽管社会经济与人口密度与西北欧相似；英格兰在 17 世纪初已经很高，且整个 18 世纪在**下降**。
  - **Devolder 的关键形式化论点（对我们非常有用）**: 女性晚婚把人口推向零增长；**男性初婚年龄在理论上与增长率无关**。所以在 1:1 性比的模拟里，**人口阀门必须挂在女性婚配上**；男性婚配只影响不平等与社会结构。他进一步论证 EMP 的原因是**制度性的**（永久租佃转为短期租佃/分成租，农民失去对土地的控制），而非 Malthus 式的人口过剩——并指出"从增长率下降推断人口过剩"是循环论证。
  - 摘要级别（证据 C）: Hajnal 的判据包含女性终身未婚比例 >10%；线以西约 3/4 的女性在 25 岁未婚，线以东约 3/4 在 25 岁已婚；Hajnal 发明了 SMAM（singulate mean age at marriage）方法。
- **东亚模式**: 早婚、普婚，**但**婚内生育率远低于欧洲水平，加上广泛的女婴杀害、堕胎、收养与低男性婚配率（Lee & Wang Feng 1999）。作者把根源归于"集体权威"相对于"个体权利"的普遍性。
- **量化（清代东北，Wei 2025，本次抓到）**:
  - 调整后总婚内生育率 TMFR：辽东旗人 **4.0–7.0**；双城 **5.1–5.8**
  - 男性年龄别生育率峰值在 **26–35 岁**
  - **登记前婴儿死亡估计 200–300‰**（辽东更高）
  - 女性出生严重漏登记，1840 年后辽东尤甚
  - 社会地位效应：官员/兵丁比农民**生子概率高 36–68%**；户主比非主干亲属**高 6–124%**；祖父母双在显著提高生育概率
- **摘要级别（证据 C）**: 辽东 1810–1909 年基于男性出生的队列 TMFR 从 1.75 升到 2.0；双城 1866–1905 从 2.5 升到 2.8。女婴杀害比例：辽宁农业人口 1774–1873 约 **20–25%** 的女婴；清皇族 1700–1830 约 **10%**。
- **对本项目的设计结论（这是本简报最重要的"涌现"设计点）**: 同一个总增长率可以由两种完全不同的制度架构产生——
  - **架构 A（欧式）**：门控**进入婚姻**（推迟 + 排除一部分人）
  - **架构 B（东亚式）**：允许普婚，门控**婚内产出与婴儿存活**（间隔、堕胎、杀婴、收养、男性婚配率）
  两者都必须可实现，且**都不能硬编码**。让制度、继承规则、土地获取方式决定采用哪种，这正是纲领第 1 条（涌现）要求的东西。
- **出处**: Hajnal 1965（经 Devolder 2000 引用，p.134）；Devolder, D., "Hajnal's European Marriage Pattern and the Evolution of Agrarian Structures in Western Europe from the Fifteenth to the Eighteenth Centuries," Centre d'Estudis Demogràfics Papers de Demografia 163；Lee, J. Z. & Wang Feng, *One Quarter of Humanity: Malthusian Mythology and Chinese Realities, 1700–2000*, Harvard University Press, 1999（ASA 人口分会 2000 年 Otis Dudley Duncan 奖）；Wei, S., "Institutional, social, and household determinants of reproduction in Northeast China, 1789–1906," *History of the Family* 30(2):133–165 (2025), doi:10.1080/1081602X.2024.2431494。

### 2.7 Turchin 的人口—结构（demographic-structural）理论

- **核心机制**: 人口增长超过土地生产力增益 → 通胀、实际工资下降、农村贫困、城市迁移、粮食骚乱；同时**精英职位的追逐者数量增加** → 精英内部竞争与派系化 → 国家崩溃 → 人口下降。反向通道：不稳定破坏生产能力（国家提供保护使全部可耕地可用；国家投资灌溉/道路/防洪；长期内战摧毁这些基础设施）。
- **形式化程度**: 概念理论完全形式化（Turchin 2003c 等有微分方程模型）；本文（2005）用的是**线性自回归时间序列检验**：
  `X(t) = a0 + a1 X(t−τ) + a2 Y(t−τ) + ε_t`（X = 人口压力，Y = 不稳定指数），另有对应的 Y 方程；`τ = 30 年 ≈ 一代`；还测试了含二次项的非线性版本（结论不变）。
- **理论预测**: 人口应以**约 200–300 年**周期振荡；不稳定以同周期振荡但**相位滞后约 1/4 周期**。
- **中国实证结果**（本次抓到表 2）: 汉（BCE 200–CE 300）人口 R² = 0.42、不稳定 R² = 0.78；唐（600–1000 CE）人口 0.64、不稳定 0.63。互反效应的 F 统计量全部 p<0.001。**样本外交叉验证相关系数**：汉人口 0.86 / 0.52；汉不稳定 0.86 / 0.79；唐人口 0.76 / 0.84；唐不稳定 0.80 / 0.94。图 6a 显示汉代人口在约 **20–60 百万**之间振荡。
- **数据来源（可作为我们的校准集）**: 中国人口 = **Zhao & Xie 1988**（赵文林、谢淑君《中国人口史》），用 10 年带宽指数核插值后按 10 年重采样；中国不稳定 = **J. S. Lee 1931**，按 5 年区间统计内战次数，30 年带宽平滑。英格兰人口 = Wrigley et al. 1997 Table A.9.1 + Hatcher 1977。
- **已知局限（作者自陈，对我们是重要警告）**: 中国户口数据存在官员伪造（引 Ho 1959）；应税户数到实际人口的换算系数**未知且逐朝改变**；国家控制区域不断变化；难以区分"户数下降是死亡/迁出"还是"国家失去了统计能力"。作者明确说：**绝对水平有争议，但相对变化有相当共识**——这正是我们校准时该用的层次。
- **出处**: Turchin, P., "Dynamical Feedbacks between Population Growth and Sociopolitical Instability in Agrarian States," *Structure and Dynamics* 1(1), Article 3 (2005), doi:10.5070/SD911003259；Turchin & Nefedov, *Secular Cycles*, Princeton University Press, 2009。

### 2.8 Siler 竞争风险死亡率模型（+ Gurven & Kaplan 的经验参数表）★ 首选死亡率内核

- **核心机制**: 三分量风险
  `h(x) = a1·exp(−b1·x) + a2 + a3·exp(b3·x)`
  存活函数
  `l(x) = exp[−(a1/b1)(1 − exp(−b1 x))] · exp(−a2 x) · exp[(a3/b3)(1 − exp(b3 x))]`
  - `a1` = 初始婴儿死亡率水平，`b1` = 幼年死亡率下降速率；幼年死亡占比 = `exp(−a1/b1)`
  - **`a2` = 年龄无关死亡率，通常解释为环境条件造成的外生死亡** ← 这是我们表示战争/饥荒/疫病/治安的**唯一正确挂载点**
  - `a3` = 初始成年死亡率，`b3` = 老化速率；**MRDT（死亡率倍增时间）= ln2/b3**
- **形式化程度**: 完全形式化，5 参数，闭式存活函数。
- **经验参数**（Gurven & Kaplan 2007 Table 2，本次抓到完整表格，见 §4.1）。
- **适用范围**: 小规模自然生育人口的全生命周期；也拟合了 1751–59 年瑞典（e0 = 34）。
- **已知局限**: 作者明确说 Gompertz 分量"不是从生物学第一原理推出的"，Weibull/Gamma 常常拟合得同样好；且要遵守 **Strehler–Mildvan 补偿律**：高初始成年死亡率与低死亡率斜率相互抵偿（`a3` 与 `b3` 负相关）——**随机生成参数时必须尊重这条约束**，否则会造出不存在的死亡率形状。
- **出处**: Gurven, M. & Kaplan, H., "Longevity Among Hunter-Gatherers: A Cross-Cultural Examination," *Population and Development Review* 33(2):321–365 (2007), doi:10.1111/j.1728-4457.2007.00171.x。原始 Siler 模型：Siler 1979（经 Gurven & Kaplan 引用）。

### 2.9 模型生命表：Coale–Demeny、UN、以及 log-quadratic 替代方案

- **Coale–Demeny (1966/1983)**: 四族（West/North/East/South）区域模型生命表 + 稳定人口。
- **在史前的适用性争议**: 当代模型生命表**无法**准确重建前工业人口的死亡模式；Coale–Demeny（1983）或 Lederman（1969）生命表可能错误表征某地远古的生命表形态。**关键技术事实**：Coale–Demeny 原表所依据的人口**没有一个 e0 < 30 岁**，e0 更低的参数是**外推**出来的。Séguy 等因此专门为前工业人口构建了一套考虑理论增长率的死亡率模型。基于考古数据直接构建的生命表（如 Acsádi & Nemeskéri）则被骨骼性别/年龄鉴定方法的系统误差污染。
- **log-quadratic 模型（Wilmoth et al. 2012）★ 首选生命表生成器（在其支撑范围内）**:
  `log(m_x) = a_x + b_x·h + c_x·h² + v_x·k`
  - `h = log(₅q₀)`（5 岁以下死亡概率的对数，即死亡率总水平）
  - `k` = 相对成年（15–59 岁）死亡率对典型模式的偏离，默认 0，历史取值通常在 **−2 到 +2**
  - 系数估计：先对每个年龄组做 `log(m_x)` 对 `log(₅q₀)` 的二次回归得 `â_x, b̂_x, ĉ_x`；再对残差做 SVD 得 `v̂_x`
  - **拟合数据**: HMD 的 719 张生命表，>72 billion 人年暴露
  - **精度对比（e0 的 RMSE）**: 仅给 ₅q₀ 时 log-quad **1.62 年（女）/ 2.55 年（男）**；给 ₅q₀ + ₄₅q₁₅ 时 **0.70 / 0.59**；Coale–Demeny West **2.73 / 4.09**；UN General **4.50 / 5.67**
  - 代码与数据: R 程序公开于 <https://www.mortality.org/LogQuad>
  - **局限（我方判断，见 §9）**: 拟合基础是 HMD（现代、e0 多数 >30），因此外推到 e0 = 20–25 的史前区间**同样是出样本的**。
- **工程结论（本项目的设计决定）**: **史前/无国家阶段用 Gurven–Kaplan 的 Siler 拟合；农业国家阶段用 log-quadratic（h, k 二参数）；任何情况下不使用 e0 < 30 的 Coale–Demeny 水平。**
- **出处**: Coale, A. J. & Demeny, P., *Regional Model Life Tables and Stable Populations*, Princeton, 1966（经 Gurven & Kaplan 引用）；Séguy et al., "Model Life Tables for Pre-Industrial Populations: First Application in Palaeodemography," in Springer (doi:10.1007/978-1-4020-6424-1_4)；Wilmoth, J., Zureick, S., Canudas-Romo, V., Inoue, M. & Sawyer, C., "A flexible two-dimensional mortality model for use in indirect estimation," *Population Studies* 66(1):1–28 (2012), doi:10.1080/00324728.2011.611411。

### 2.10 SOCSIM 与微观人口模拟

- **核心机制**: 随机微观模拟（stochastic microsimulation）。初始人口承受给定的生育、死亡、婚配（含离婚）率；**每个个体面临的每个事件被建模为分段指数分布（piece-wise exponential）**，按对应人口率随机生成到各事件的等待时间；**最短等待时间的事件即为该个体的下一个事件**（竞争风险）。
- **封闭人口（closed model）**: 配偶必须在现有模拟人口内找到。每个成员保存指向其**每个伴侣、父母、最年幼子女、以及经由母亲和父亲的次年长同胞**的链接——由此可以追溯任意血缘或姻亲关系（含已故亲属）。作者明确对比：开放模型（需要时创造一个配偶）无法研究一般亲属关系，因为新造的配偶没有人口学背景。
- **婚姻市场算法**: 未婚成人按年龄/性别/婚姻状态别婚配率进入"合格池"；用**评分算法**匹配，偏好夫妻年龄差约 2 岁，且**男方不得比女方年轻 5 岁以上或年长 10 岁以上**；含兄妹与亲子的乱伦禁止。可替换为促进（如传统日本、部分南亚）或禁止（如 11 世纪天主教会禁七等以内亲属通婚）近亲婚的规则。
- **实际计算规模（这是本简报最硬的工程约束）**: Murphy 2004 报告，为处理多条降系必须**重新设计亲属网络数据结构**；可行范围是**至多 10,000 人 / 约 600 年**，**单次模拟需要数小时**（2004 年硬件）。他的实际实验配置：N=4,000 跑 600 年，N=10,000 只跑 300 年（"因为机器限制"）。
- **烧机时间（burn-in）**: 从一群**互不相关、从未结婚**的初始人口出发，**约 50 年后**模拟人口才具有真实的年龄性别结构和完整的婚姻/生育史。
- **有效繁殖群体规模**: 真实人口不封闭，且人类有效繁殖规模难以估计；作者引 Cavalli-Sforza & Bodmer (1971, p.482) 的**帕尔马河谷上游 = 278** 作为一个"重要但确实相当任意"的参数值。因此他选 4,000 与 10,000 代表城市级有效繁殖群体。
- **祖先爆炸（存储层面的硬约束）**: 非去重祖先数按代倍增——10 代（300 年）= 1,024；20 代（600 年）= 1,048,576；**30 代（900 年）= 1,073,741,824**；35 代（1050 年）= 3.4×10¹⁰。Wachter (1978) 用"球投桶"简化模型估计：当代英国人的祖先覆盖 1066 年在世者的**约 85%**。
- **英格兰前转变期率（可作为农业国家的默认参数）**: 1300–1800 年，TFR 约 **3.45–3.75**，男性 e0 约 **40–41 岁**，男性初婚年龄约 **28.8–29.6 岁**（见 §4.4）。0.2%/年增长 → 倍增时间约 350 年。
- **现代实现**: `rsocsim` R 包（MPIDR），输入为**逐月**年龄别生育与死亡率文件 + 监督文件（.sup）+ 初始人口文件；输出为"所有曾活过的人"的矩形数据文件，每人一行，含人口学特征与关键亲属关系的 ID。安装：`remotes::install_github("MPIDR/rsocsim@v1.9.9")`。原始 C 代码由 Gene Hammel 与 Ken Wachter（Berkeley）与 Peter Laslett（Cambridge）开发（Hammel, Wachter & Laslett 1978；Hammel, Mason & Wachter 1990）。
- **已知局限**: 封闭人口；无空间；无经济；无制度；亲属链接的组合爆炸；不能超过约 10⁴ 人。**因此 SOCSIM 不能作为本项目的人口内核，只能作为"个体层"的设计参考与验证基准。**
- **出处**: Murphy, M., "Tracing Very Long-Term Kinship Networks Using SOCSIM," *Demographic Research* 10(7):171–196 (2004)；rsocsim: <https://mpidr.github.io/rsocsim/>，<https://github.com/MPIDR/rsocsim>。

### 2.11 Super-individuals（超个体）聚合技术

- **核心机制**: 每个模型个体代表**固定数量**的真实个体（representative number / sample expansion factor / weight / internal amount），从而在速度与内存两方面大幅提效。
- **形式化程度**: 完全形式化（就是一个权重）。
- **已知局限（原作者明确列出，对我们是硬警告）**: 减少模型个体数会导致**方差丢失、动力学不规则、以及对随机数种子的高度敏感**。
- **工程结论**: 超个体**只能用于匿名人口的总量流动**；任何依赖方差与稀有事件的机制（世系灭绝、瓶颈、创始人效应、精英过度生产）**绝不能**用超个体表示。
- **出处**: Scheffer, M., Baveco, J. M., DeAngelis, D. L., Rose, K. A. & van Nes, E. H., "Super-individuals: a simple solution for modelling large populations on an individual basis," *Ecological Modelling* 80:161–170 (1995)。另见 Hellweger 等关于"固定超个体密度"的空间显式版本（*Computers & Geosciences* 34:144, 2008）。

### 2.12 Artificial Anasazi（作为反面教材的经典 ABM）

- **模型规格**（Long House Valley, Arizona, 800–1350 CE；每个 agent = 5 人的家户，每年决定耕作地点与聚落）:
  - 生育窗口：家户年龄 16–30
  - 分裂概率：`p_f = 0.125`/年
  - 新家户获得母家户玉米存量的 **33%**
  - 家户最大寿命 30 年（校准区间 26–40）
  - 移除条件：耗尽储备后仍无法满足年度营养需求（**800 kg 玉米/年**）
  - 单产：`BY = y × q × Ha`，其中 `y` 为由 PDSI（Palmer 干旱严重度指数，5 个等级）决定的分区单产，`q` 为土壤质量方差，`Ha` 为收成调整水平
- **决定性的批判（Janssen 2009 复现）**: 拟合考古人口数据主要依赖两个参数——**收成调整水平从 1.0 降到 0.54–0.56**，**收成方差从 0.1 提到 0.4**。这两个调整改变的是**景观承载力（可耕地块数）**，而不是 agent 行为的精巧程度。把完整 ABM 与只用承载力计算的**零模型**对比，两者对人口数据的拟合**几乎相同**，因为 ABM 通过储粮与繁殖延迟"对不规则的承载力曲线起了平滑函数的作用"。人口学参数（死亡年龄、生育年龄、分裂概率）只有**次要**重要性：只要家户寿命超过 30 年、平均每 6–8 年繁殖出一个新家户，人口趋势就跟随承载力。
- **对本项目的强制要求**: **如果我们声称人口曲线由 agent 层解释，必须证明它与纯承载力零模型不同。**否则我们只是在用 ABM 做平滑。
- **出处**: Axtell, R. L., Epstein, J. M., Dean, J. S., Gumerman, G. J., Swedlund, A. C., Harburger, J., Chakravarty, S., Hammond, R., Parker, J. & Parker, M., "Population growth and collapse in a multiagent model of the Kayenta Anasazi in Long House Valley," *PNAS* 99(suppl. 3):7275–7279 (2002), doi:10.1073/pnas.092080799；Janssen, M. A., "Understanding Artificial Anasazi," *JASSS* 12(4):13 (2009), <https://jasss.soc.surrey.ac.uk/12/4/13.html>；代码：CoMSES <https://www.comses.net/codebases/2222/>。

## 3. 可直接用于本项目的机制清单

> 每条给出：输入 → 输出、数学/算法草图、时间尺度、空间粒度、证据等级、简化理由、以及**失效条件**。

### 3.1 【核心】食物比驱动的生命率（rules_math，证据 A）

- **输入**: 年龄别人口 `N_x`；可耕地 `A_m`；单产 `Y`（受气候/技术/土壤模块驱动）；劳动系数 `H, k, φ_x`；消费系数 `J, ρ_x`
- **输出**: 食物比 `E`；年龄别生育率 `m_x`、存活率 `p_x`；下一年 `N_x`
- **算法草图**:
  ```
  # 每个人口单元，每年
  cultivated = min(A_m, H*k*Σ_x φ_x*N_x)          # 空间受限
  production = Y * cultivated                      # kcal/day
  requirement = J * Σ_x ρ_x*N_x                    # kcal/day
  E = production / requirement
  if E >= 1:  m_x, p_x = m_x0, p_x0                # copial 相
  else:
      m_x = m_x0 * g_fert(E; γ=0.135)              # 伽马 pdf 形状的响应
      p_x = p_x0 * g_surv(E; a_x∈[0.00279,0.156])  # a_25 = 0.00464
  N' = L(m_x, p_x) @ N                             # Leslie 投影
  ```
  响应函数形状要求（来自原文）：短缺不大时敏感度很小，当食物降到基线的 **约 50%** 时敏感度变得很大。
- **时间尺度**: 年（tick = 1 年）。**不要用更粗的步长**：作者的 MTI 只有 40–65 年，10 年步长会把整个转变相变成 4–6 个 tick。
- **空间粒度**: 一个"耕作流域/聚落群"，基线尺度 `A_m = 1,000 ha`（10 km²）。
- **为什么这样简化**: 这是本领域唯一有完整参数表 + 公开代码 + 已发表动力学分析的人口—食物耦合模型。用它可以直接得到 copial→transition→Malthusian 三相、盈余峰值位置、税收稳定性这些**可生成因果链的结构性结论**。
- **失效条件**:
  - 有大规模跨区粮食贸易时（`E` 不再由本地生产决定）→ 必须改为区域食物市场清算
  - 有多年储粮时（Winterhalder, Puleston & Ross 2015 处理）
  - 劳动投入可调时（Chayanov/时间最小化）→ `φ_x` 必须内生
  - 非粮食生计（游牧、渔猎）占主导时，`Y × ha` 的形式不适用

### 3.2 【核心】Siler 死亡率内核 + `a2` 作为外生冲击通道（rules_math，证据 A）

- **输入**: 生计类型/发展阶段（选基线 Siler 参数集）；`E`（内生调节）；外生冲击列表（战争、饥荒、疫病、治安、卫生）
- **输出**: 年龄别死亡风险 `h(x)`、存活曲线 `l(x)`、`e0`、`e45`、MRDT
- **算法草图**:
  ```
  h(x) = a1*exp(-b1*x) + a2_eff + a3*exp(b3*x)
  a2_eff = a2_base + Σ_shocks Δa2_i(t)     # 外生死亡率叠加
  # 约束：随机化 a3,b3 时必须尊重 Strehler-Mildvan 补偿律（a3 高 ⇒ b3 低）
  ```
  基线参数选取（见 §4.1）：狩猎采集平均 `a1=0.422, b1=1.131, a2=0.013, a3=1.47e-4, b3=0.086`；人类总体平均 `0.309, 1.138, 0.009, 1.31e-4, 0.090`；瑞典 1751–59 `0.400, 1.074, 0.008, 2.01e-4, 0.083`。
- **时间尺度**: 年（风险函数），冲击可以按事件注入。
- **空间粒度**: 人口单元。
- **为什么这样简化**: 5 个参数、闭式存活函数、有 20 个真实人口的经验拟合值可以查表。而且 `a2`（年龄无关外生死亡）给了我们一个**语义清晰、可解释、可追溯**的挂载点：所有"世界事件"都通过修改 `a2` 影响死亡率，因果链天然可记录。
- **失效条件**:
  - 冲击是**年龄选择性**的（战争杀青年男性、天花杀儿童、饥荒杀老幼）→ 不能只改 `a2`，需要年龄别乘数
  - 冲击是**社会选择性**的（穷人先死）→ 见 §3.9
  - `a2` 被推得过高时，Siler 的三分量分解失去意义（Agta 的 `a2` 在原表里是 N/A，因为拟合退化）

### 3.3 【核心】队列级增长率闭式解：TFR + l15 → r（rules_math，证据 A）

- **输入**: TFR，15 岁存活率 `l15`
- **输出**: 内在增长率 `r`
- **算法草图**（Gurven & Kaplan 2007 脚注 5，完整可实现）:
  ```
  l25 = 0.9973*l15 - 0.0422        # R² = 0.98, p < 0.0001
  R0  = (TFR / 2.06) * l25         # 2.06 = 出生性比调整
  r   = ln(R0) / T,  T = 28 年     # 稳定人口下 R0 = exp(r*T)
  ```
- **经验锚点**（同源）: 觅食者平均 `l15 = 0.55` 时 `r = 0` 需要 TFR ≈ 4；觅食者平均 TFR = 5.7 时 `r = 0` 需要 `l15 = 0.41`。
- **时间尺度**: 世代（28 年）；也可用作年度增长率的解析检查。
- **空间粒度**: 任意（这是一个纯人口学恒等式）。
- **为什么这样简化**: 它让我们可以用**两个数字**（TFR, l15）完整描述一个人口的增长制度，不必维护完整生命表。这对"数千年 + 上千个人口单元"的计算预算是决定性的：队列层可以只存 (TFR, l15) 两个标量，需要时再展开成完整 Leslie 矩阵。
- **失效条件**: 假定稳定人口（stable，非 stationary）。人口正处于急剧转变（NDT、疫病、迁徙）时，年龄结构远离稳定态，该公式的误差不可控——此时必须切换到显式 Leslie 投影。

### 3.4 生命表生成器：log-quadratic 二参数（rules_math，证据 A）

- **输入**: `₅q₀`（儿童死亡水平）、`k`（成年死亡偏离，−2..+2）
- **输出**: 完整年龄别死亡率 `m_x` 与生命表
- **算法草图**: `log(m_x) = a_x + b_x·h + c_x·h² + v_x·k`，`h = log(₅q₀)`；系数表从 <https://www.mortality.org/LogQuad> 取。
- **时间尺度**: 与 tick 无关（查表）。**空间粒度**: 人口单元。
- **为什么这样简化**: 精度显著优于 Coale–Demeny 与 UN 表（e0 的 RMSE 1.62 vs 2.73 vs 4.50 年，仅给 ₅q₀ 时），且只要两个语义清晰的输入。`k` 正好可以承载"成年男性因战争/劳役而超额死亡"这类制度效应。
- **失效条件**: `₅q₀` 高到 HMD 支撑之外（对应 e0 < ~30）时是外推。此时改用 §3.2 的 Siler 经验参数。

### 3.5 新石器人口转变（NDT）：生计转换触发的生育率抬升（hybrid，证据 B）

- **输入**: 人口单元的生计结构（栽培/驯养占比）、定居度
- **输出**: 基线 TFR 的分阶段抬升 + 滞后的死亡率抬升
- **算法草图**:
  ```
  target_TFR = TFR_forager + 2.0 * f(cultivation_share, sedentism)
  TFR 以 200–500 年时间常数向 target 收敛      # 原文：转变在 <1 千年内完成
  a2_base（疾病/卫生环境）以更长滞后随定居度与人口密度上升
  ```
- **量化锚点**: **TFR 增加约 2 个孩子/妇女**（Bocquet-Appel 2011, Science 333:560–561）；机制是"出生率上升，死亡率滞后上升"。
- **时间尺度**: 世纪（收敛时间常数 200–500 年）。**空间粒度**: 人口单元。
- **为什么这样简化**: `+2 births` 是本领域唯一被广泛引用的定量 NDT 幅度。把它写成"目标值 + 时间常数"而不是瞬时跳变，可以自然产生 Bevan 等观察到的早期新石器 SPD 变化率 >1%/年 的"boom"。
- **失效条件**: 该幅度是**跨大陆平均**（约 100 个北半球墓地：欧洲、北非、北美）。单个区域可以完全不同；也不能用来推断绝对水平。
- **为何是 hybrid**: 幅度与时间常数由规则给定；**"这个聚落是否/何时开始栽培"应该由 agent 与环境共同决定**，不能由规则预设。

### 3.6 婚姻与家户形成阀门（hybrid，证据 B）

- **输入**: 土地/生态位（niche）可得性；继承规则（长子继承/均分/分家）；租佃形式；户主死亡事件；性比；文化规范
- **输出**: 女性初婚年龄分布、终身未婚比例、家户形成率、（东亚支）婚内生育间隔与女婴存活率
- **算法草图（两条并行支路，制度选择哪条）**:
  ```
  # 支路 A（门控进入婚姻）
  female_marriage_hazard(age) ∝ availability_of_household_niche
  niche 由：可耕地余量、继承规则、租佃形式（永久 vs 短期）共同决定
  → SMAM_female ∈ [20, 26+]，终身未婚 ∈ [3%, 30%]

  # 支路 B（门控婚内产出）
  普婚：female_marriage_hazard 在 15-20 岁很高
  婚内 TMFR 由：夫妻同居时长、哺乳/间隔规范、堕胎、经济状况 决定 → 4.0-7.0
  female_infant_survival = 1 - infanticide_rate(household_resources)
  ```
- **量化锚点**: 西欧女性初婚 20 → 25+ 岁（一世纪内）；男性 28–30 岁且约等于父亲去世时点；南欧部分区域始终 <23 岁；清代东北调整 TMFR 4.0–7.0（辽东）/5.1–5.8（双城）；登记前婴儿死亡 200–300‰；官员/兵丁生子概率比农民高 36–68%。
- **时间尺度**: 个体事件（年）；制度变化按世纪。
- **空间粒度**: 家户 / 人口单元。
- **为什么这样简化**: Devolder 的论证给了我们一个关键的形式化简化——**只有女性婚配影响增长率**。所以队列层只需要一个 `female_marriage_schedule`；男性婚配可以留给个体层（它影响不平等与世系存续，而不影响总量）。
- **为何是 hybrid**: 阀门的**数学后果**必须由规则计算（谁能结婚、生几个）；**"这个社会为什么选择推迟婚姻"** 涉及规范、宗教、家族策略，适合 LLM agent 在家族/宗族层面表达，但其输出必须被压缩成可计算的门控参数。
- **失效条件**: 高性比失衡（杀婴/战争）会破坏婚姻市场清算——必须显式建模男性婚姻挤压，不能假定普婚。

### 3.7 危机死亡率：重尾冲击 + 慢回归（rules_math，证据 C/D）

- **输入**: 单产实现值（气候模块）、疫病模块、战争模块、储粮、市场整合度
- **输出**: 该年 `Δa2`、年龄别死亡乘数、迁徙压力
- **算法草图**:
  ```
  crisis_severity ~ heavy_tailed(local scope)     # 参数需自定，见下
  Δa2 = f(crisis_severity, storage, market_integration)
  mortality 冲击后按 §2.5 的慢回归（半衰期约 100 年量级）恢复到趋势
  ```
- **可用锚点（都很弱，必须诚实标注）**:
  - **单产随机性有可用参数**: gamma 分布，CV = 0.20 是 Winterhalder & Puleston 的基线；600 年模拟中实现 CV 0.203，极值 9,253 ~ 34,283（均值 21,000）kcal/ha/day。**这条是 A 级，应该作为危机的上游驱动而不是直接给死亡率赋值。**
  - **崩溃阈值有可用参数**: 税率 40% 时 CV<0.28 安全 / CV>0.38 立即崩溃；CV<0.20 时 60% 税率可持续；CV>0.50 时 20% 税率已危险。
  - 黑死病 1347–1351 死亡率 **30–60%**；Benedictow 用 65% 于约 8,000 万欧洲人口得约 5,200 万死亡；274 个有数据地点的计算约 **38.9%**——但也有学者认为高估（过度依赖城镇）。**证据 C，且检索来源为二手（Medievalists.net、工作论文）。**
  - **Wrigley & Schofield 的"危机"贡献仅占 1600–1750 年英格兰总死亡的约 5%**；Fogel 对 1541–1871 全期的读解也是 **<5%**。**这是本条最重要的一条，且它反驳了直觉。证据 C（来自二手引用）。**
  - 饥荒强度：19 世纪末/20 世纪初的"强烈"饥荒常超过 **100 人/10 万全国人口**；大跃进饥荒峰值 >**500/10 万**。**来源为 World Peace Foundation / OWID，证据 C。**
- **文献未提供可用参数的部分（必须诚实）**: **我没有找到任何同行评议来源给出"前工业危机死亡率的分布形式与参数"**。地方性/区域性/系统性危机的死亡率分位数、频率、空间相关长度，本次检索均未获得可用值。§9 给出我们自拟的 D 级假设。
- **失效条件**: 若把危机当作主要的人口调节器，模拟会系统性地偏离历史——因为慢性死亡率（Siler 的 `a1, a2, a3` 基线）在多数世纪里主导。

### 3.8 盈余—税收—国家稳定性耦合（rules_math，证据 A）

- **输入**: `N`, `E`, `j0`；税制类型（人均定率 / 固定额度 / 劳役）；税率
- **输出**: 可抽取盈余 `S`；被抽取后的 `E'`；均衡人口 `N̂(tax)`；崩溃风险
- **算法草图**:
  ```
  S_t = N_t * (E_t - 1) * j0
  # 抽取实物：从 production 中扣除
  # 抽取劳动：从 Σφ_x N_x 中扣除，但 requirement 不变（劳役者仍要吃饭）
  E' = (production - tax_goods) / requirement
  # 稳定性判据（关键）：
  #   固定额度税 → 存在不稳定均衡分支，向下扰动触发崩溃螺旋
  #   人均定率税 → 自稳定
  ```
- **量化锚点**: 盈余峰值在 `N = 0.25 N̂`（3,382 / 13,509），`E = 1.82`，`S* = 6.41×10⁶ kcal/day`；最大可持续固定税 `9.55×10⁶ kcal/day` 对应 `N̂ = 4,507`（人均 2,120 kcal/day）；小而增长的人口抽取实物更有效，接近均衡时抽取劳动更有效。
- **时间尺度**: 年（税收），世纪（政策变化）。**空间粒度**: 人口单元 → 政体聚合。
- **为什么这样简化**: 这是我见到的**唯一**能从人口学第一原理推出"国家为什么会灭亡"且**每一步都可追溯**的机制。它天然产生纲领要求的因果链：气候方差上升 → 单产 CV 上升 → 固定额度税跨过折肘 → 人口下降 → 人均税负上升 → 崩溃螺旋 → 政体解体。
- **失效条件**: 假定精英数量小且稳定（不建模精英人口）。当精英过度生产成为主导（§3.10）时，必须加入精英人口方程。

### 3.9 财富分层队列（rules_math，证据 B）

- **输入**: 财富/地位分位（建议 5 档）、`E`、危机冲击
- **输出**: 分位别生育率与死亡率；危机后的选择性存活
- **算法草图**: 把队列从 `[age × sex]` 扩展为 `[age × sex × wealth_quintile]`；给每档不同的 `E_q`（可支配食物）和不同的 `a2_q`；危机时低分位的 `Δa2` 更大。
- **量化锚点**: 清代东北——官员/兵丁比农民生子概率高 **36–68%**；户主比非主干亲属高 **6–124%**（Wei 2025）。
- **为什么这样简化**: 这是**在不引入个体的前提下**表示选择性死亡与差别生育的最小扩展。它同时解决了 Wood et al. 1992 指出的"frailty 异质性"问题的一半——异质性被显式表示了，只是粒度是分位而不是个体。
- **为什么不用"典型个体"**: 单一代表性家户会**丢掉方差**，而不平等、世系灭绝、精英过度生产全部是方差现象。**分位队列优于典型个体。**
- **失效条件**: 需要表示**具体某个家族**的兴衰时，分位队列不够（见 §3.11）。

### 3.10 人口—不稳定的世代滞后反馈（hybrid，证据 B）

- **输入**: 人口压力 `X`（= N/K 或 `1/E`）；30 年前的不稳定 `Y(t−30)`
- **输出**: 不稳定强度 `Y(t)`；对生产能力的破坏（可耕地可用比例、灌溉资本）
- **算法草图**:
  ```
  τ = 30 年（≈ 一代）
  X(t) = a0 + a1*X(t-τ) + a2*Y(t-τ) + ε     # a2 < 0：不稳定压低人口
  Y(t) = b0 + b1*Y(t-τ) + b2*X(t-τ) + ε     # b2 > 0：人口压力抬高不稳定
  # 生产侧通道（Turchin 明确列出的机制，应该直接实现而不是拟合）：
  usable_arable_fraction = g(state_strength)   # 无国家时只能耕作要塞附近
  Y_yield *= irrigation_capital               # 长期内战摧毁灌溉/道路/防洪
  ```
- **量化锚点**: 预测周期 **200–300 年**，不稳定滞后人口约 1/4 周期；汉代 R² 0.42（人口）/0.78（不稳定），唐代 0.64/0.63；样本外相关 0.52–0.94；汉代人口在 20–60 百万间振荡。
- **为什么这样简化**: 我们**不应该**直接实现 Turchin 的 AR 模型（那是一个检验用的统计模型，不是机制）。应该实现的是他列出的**因果通道**：精英追逐者数量、保护→可耕地可用性、内战→基础设施折旧。AR 模型的参数只用作**验收指标**：我们的模拟跑出来的人口—不稳定序列，应该在 τ=30 年的 AR 回归下表现出正确符号和 0.4–0.8 的 R²。
- **为何是 hybrid**: 精英的动机、派系形成、叛乱决策适合 LLM agent；**人口后果与胜负必须由规则计算**（纲领第 5 条）。
- **失效条件**: Turchin 自己排除了汉—隋之间的分裂期，因为理论是"以国家为中心"的，不适用于多国体系。我们的模拟必须能处理多国体系，所以这条机制在无霸权期需要改写为体系级版本。

### 3.11 【核心】分层人口表示与队列↔个体切换（hybrid，证据 B/D）

详见 §6.4（问题专答）。这里只给算法接口:

- **L0 队列层**: `[unit × age(1yr or 5yr) × sex × wealth_quintile]` + `(E, TFR, l15, a2_eff)`。全部人口单元、全部时间都存在。
- **L1 家户层**: 家户原型 × 计数（archetype × count），不是个体。承载继承、分家、婚姻市场清算的**总量**。
- **L2 个体层**: 完整个体 + 亲属指针（父、母、伴侣、最幼子、经父/母的次长同胞——照 SOCSIM 的最小链接集）。**只对"被点名的"实体存在**。
- **提升（promote, L0→L2）**: 从队列的年龄—性别—财富联合分布中抽样，赋予队列隐含的风险函数；**必须保证期望计数守恒**。
- **降级（demote, L2→L0）**: 聚合回队列；但**已点名个体的身份记录与亲属链接永久保留在历史库中**，即使其后代已降级——否则纲领第 2 条（几百年后仍可追溯）无法满足。
- **一致性不变量（可测试）**: 同一初始条件下，纯队列投影与"提升为个体再跑再聚合"的平均轨迹应在 Monte Carlo 误差内一致，检验窗口 ≥200 年。这条应该写成回归测试。

### 3.12 校准管线：从模拟生成合成考古记录（rules_math，证据 A）

- **输入**: 模拟历史（聚落、活动强度、埋葬）
- **输出**: 合成 SPD、合成墓地年龄分布、合成遗址计数——**用同一套真实方法处理**，再与真实数据比较
- **算法草图（照 Bevan et al. 2017 的方法，本次抓到完整 Methods）**:
  ```
  1. 从模拟活动强度按概率生成"样本"，赋予测量误差（高斯）
  2. 反校准到 14C 年，再正向校准 → 后校准概率分布
  3. 同一遗址内 100 年以内的日期用完全连接凝聚层次聚类合并（binning），
     池化后除以该 bin 内日期数，再跨遗址求和
  4. 不要在求和前归一化每个日期的后校准分布（会在校准曲线陡处造成尖峰假象）
  5. 拟合理论零模型（指数/逻辑/均匀），反校准、模拟等量日期、校准求和，
      重复 1,000 次 → 全局拟合优度检验 + 95% 临界包络
  6. 置换检验：固定日期、打乱标签（区域/材料/物种），1,000 次 → 区域别偏离
  ```
- **为什么这样简化**: 这是**唯一诚实的校准方式**。直接把模拟的人口数与真实 SPD 比是错的（SPD 不是人口）。把模拟送进同一个有偏管线，比较**输出**，才能对齐。
- **工具**: `rcarbon` R 包 <https://github.com/ahb108/rcarbon>（含 Timpson 2014 的 Monte-Carlo 模拟检验、Crema 2016 / Bevan 2017 的随机标记置换检验、Edinborough 2017 的点对点检验、Crema/Bevan/Shennan 2017 的空间置换检验）。
- **失效条件**: 埋葬/取样行为本身随社会变化时（仪式行为改变、生计策略改变、现代研究策略偏差），管线的偏差不是常数——这正是 SPD 批评者的核心论点。

## 6. 中国与东亚特定证据

### 6.1 史前与新石器：证据基础与其形状

- **遗址计数序列**: Hosner et al. 2016 把 25 个省/区/市的《中国文物地图集》数字化，得 **51,074** 个遗址（约 BCE 8000–500，73–131°E / 20–53°N），并配了可动态分析的映射软件，明确用途包括**人口增长与迁徙、农业扩散、生计策略变化**。数据在 PANGAEA。**这是本项目最重要的东亚空间校准集。**
- **粟作扩散与人口**: 检索到 *Science Advances* (2019) doi:10.1126/sciadv.aax6225 "Discontinuous spread of millet agriculture in eastern Asia and prehistoric population dynamics"：华北粟作农业支撑了 **BCE 6000–2000 的准指数人口增长**；BCE 2000 后**东北继续增长，而黄河上/中游转为衰退**（本次仅得检索摘要，全文 403；证据 **C**）。这个"同一大区内的区域分岔"正是 Crema et al. 在日本发现的模式（下）。
- **日本绳文（最完整的东亚 SPD 研究）**: Crema, Habu, Kobayashi & Madella 2016, PLoS ONE 11(4):e0154809。1,433 个 14C 日期（关东 406/47 遗址、青森 432/58、北海道 595/82），7,000–3,000 cal BP。三区域都呈"升—降"总模式：BCE 7 千纪初开始稳定增长，公元前 4 千纪中期衰退达最深。但**区域分岔显著**：关东在 5,700 cal BP 显著下降、约 5,000 cal BP 达峰、随后持续下降到 3,700 cal BP；青森与北海道在 5,500–4,000 cal BP 呈**高密度平台**，衰退晚于关东（4,000 cal BP 后）。关东 vs 青森在 Early–Middle Jomon（7,000–4,420 cal BP）差异 **p = 0.0039**。作者引入了跨多组 SPD 的**非参数置换检验**（随机置换每个 bin 的组归属，保持各组 bin 数不变）。
- **绳文绝对人口**: 作者明确说本研究不提供绝对人口数，并指出 **"Koyama 的研究至今无可匹敌，其绝对人口规模估计仍是唯一的尝试"**。→ **东亚史前绝对人口水平没有可信来源。**
- **朝鲜半岛**: 检索到 *Radiocarbon* 上 "Population Fluctuation and the Adoption of Food Production in Prehistoric Korea: Using Radiocarbon Dates as a Proxy for Population Change"（未取全文；证据 C）。

### 6.2 历史时期：户口数据的性质与不可靠性

Turchin 2005 对中国人口数据的评估是本项目最该内化的一段（本次抓到原文）：
- 中央政权（在其存在时）为税收进行详细户口统计；
- 但**腐败或懒惰的官员经常伪造或编造人口数据**（引 Ho 1959）；
- **应税户数到实际人口的换算系数常常未知，更糟的是这些系数很可能逐朝改变**；
- 国家控制的区域不断变化；
- **常常难以判断"动乱时期应税户数下降"是人口变化（死亡与迁出）的结果，还是国家失去控制与统计能力的结果**；
- 专家对峰值与谷值的**绝对水平**有争议（Ho 1959; Durand 1960; Song et al. 1985），但对**人口密度的相对变化有相当共识**。

**工程结论**: 中国历史人口只能校准**相对变化的形状与时序**（周期长度、峰谷比、下行的陡度），**不能**校准绝对水平。我们的模拟"人口"与史料"户口"之间应该显式插入一个**国家统计能力**变量——这本身就是纲领第 9 条（世界事实与历史叙事分离）的一个绝佳实现点：模拟保存真实人口，政权只看到它能数出来的那部分，而"户数骤降"在世界内部会被误读为"人口骤降"。

**具体数值（全部证据 C，均来自检索摘要而非原文）**:
- 前汉（BCE 206–CE 8）记录 12.233 百万户 / 95.594 百万人；因晚期登记制度相当完善而被认为"相当可靠"
- 宋代之前约一千年间，中国人口在 37–60 百万间波动、无一致趋势；持续增长始于 11 世纪后半
- 曹树基估计明代人口峰值（1630）约 192.51 百万，1644 年约 152.47 百万（→ 14 年内下降约 21%）
- Turchin 图 6a 显示汉代人口在约 20–60 百万间振荡（图轴读数，证据 A）

### 6.3 汉与唐的人口—不稳定周期（证据 A）

Turchin 2005 用 τ=30 年的线性 AR 模型检验人口与不稳定的互反反馈:
- 汉（BCE 200–CE 300）: 人口方程 R²=0.42（互反效应 F=15.55, p<0.001）；不稳定方程 R²=0.78（F=36.47, p<0.001）
- 唐（600–1000 CE）: 人口 R²=0.64（F=50.48）；不稳定 R²=0.63（F=13.96）
- 样本外交叉验证相关：汉人口 0.86/0.52；汉不稳定 0.86/0.79；唐人口 0.76/0.84；唐不稳定 0.80/0.94
- 作者**排除了汉—隋之间的分裂期**，理由是人口—结构理论是"以国家为中心"的，不适用于中国当时的多国体系。**这是我们必须补上的缺口**：我们的东亚舞台会长期处于多国体系，需要一个体系级（而非单一国家级）的不稳定—人口反馈机制。
- 中国不稳定数据来自 J. S. Lee 1931，是**按 5 年区间统计的内战次数**（从局部起义到大规模叛乱与内战），Turchin 用 30 年带宽指数核平滑。→ 这给了我们一个可以直接对齐的验收指标格式：**把模拟的"内战事件"按 5 年计数、30 年平滑，再与人口做 τ=30 年 AR 回归，看符号与 R² 是否落在 0.4–0.8。**

### 6.4 东亚人口体制的机制特征（本简报最重要的东亚发现）

**Lee & Wang Feng 1999 的核心主张**: Malthus 描绘的中国（早婚普婚 → 高生育 → 高死亡）是错的。实际上中国通过多种做法有效调节了人口增长：**把婚内生育率压到远低于欧洲的水平**，以及**广泛的杀婴与堕胎**。他们归纳出中国人口模式的四个特征：**高女婴杀害率、低男性婚配率、低婚内生育率、高收养率**；并把这种"理性决策"的来源归于**集体权威的普遍性**（相对于西方对个体权利的强调）。该书获 2000 年 ASA 人口分会 Otis Dudley Duncan 奖。

**这在建模上意味着什么（关键）**: 欧洲和中国用**两个完全不同的控制点**达到了相似的低增长:
- 欧洲：控制**婚姻的进入**（推迟 + 排除）
- 中国：允许普婚，控制**婚姻的产出**（间隔、堕胎、杀婴、收养）+ 控制**男性**的婚配（男性婚配率低意味着大量男性被排除在再生产之外）

对本项目：这两条都必须是可实现的**制度选项**，由继承规则、土地获取方式、宗族组织、性别规范决定，**不能硬编码为"文化类型"**。这正是纲领第 1 条要求的涌现。

**争议（必须标注）**: 近期学术界挑战"东—西二分"的修辞，认为它过于简化，因为主要基于社会规范与总量统计的研究（见 *Similarity in Difference: Marriage in Europe and Asia, 1700–1900*, MIT Press，本次仅得检索摘要，证据 **C**）。→ **不要把"东亚 = 正向抑制"或"东亚 = 反向抑制"任何一种当作定律。**

**量化（Wei 2025，本次抓到，证据 A）**: 见 §4.5。特别注意三点建模含义:
1. **登记前婴儿死亡 200–300‰** 意味着历史户籍数据对婴儿的漏记极其严重；我们的"国家统计能力"变量必须包含**年龄选择性漏记**。
2. **女性出生严重漏登记，1840 年后辽东尤甚** → 性比数据不可直接采信；杀婴与漏记在史料中不可分。这是一个必须承认的**根本性识别问题**。
3. **地位对生育的效应极大（+36%~68% 官员/兵丁 vs 农民；+6%~124% 户主 vs 非主干亲属；祖父母双在显著提高生育概率）** → 财富/地位分层队列（§3.9）在东亚场景下不是可选项，是必需项；而且"户内地位"（是否户主）与"职业地位"至少同等重要（作者对双城的结论）。

### 6.5 东亚地理对人口模块的特定要求（我方综合，D 级推论但基于上述 A/B 级证据）

1. **区域分岔是常态**: 绳文日本内部（关东 vs 青森/北海道，p=0.0039）与华北内部（黄河上中游衰退 vs 东北增长）都出现了同大区内的相反趋势。→ **空间粒度必须是一等参数**，不能用"东亚"或"中国"这样的单一人口单元。建议以流域/生态区为人口单元（`A_m` 1,000 ha 量级的聚落群向上聚合成流域）。
2. **稻/粟二元**: 黄河粟作与长江稻作是两个独立起源中心，单产、劳动强度、水利需求、承载密度都不同。→ `Y`、`w`（劳动有效性）、`A_m`（可耕地的水利依赖）必须是作物系统的函数，而不是全局常数。
3. **水利资本作为国家—人口耦合的物理载体**: Turchin 明确列出"国家投资灌溉/道路/防洪，长期内战摧毁这些生产力增强基础设施"。在东亚（尤其稻作与黄河治理）这个通道的权重应该更大。→ 建议 `Y = Y_base × f(hydraulic_capital)`，而 `hydraulic_capital` 有折旧、需要国家投资、被内战摧毁。这条同时提供了一条极其干净的因果链：内战 → 水利失修 → 单产下降 → E 下降 → 人口下降 → 税基下降 → 国家更弱 → 更多内战。

## 7. 学界争议与未解决问题

### 7.1 新石器 boom–bust 是内生的还是气候驱动的？（未解决）

- **内生派**: Shennan, Downey, Timpson, Colledge, Edinborough, Kerig, Manning & Thomas, "Regional population collapse followed initial agriculture booms in mid-Holocene Europe," *Nature Communications* 4:2486 (2013)。结论：农业到达引发人口暴增，数百年后急剧下降；**波动与主要气候事件没有直接联系**，因此原因更可能是新石器早期社会经济演化过程中的**内生原因**。
- **气候派**: Bevan, Colledge, Fuller, Fyfe, Shennan & Stevens, *PNAS* 114(49):E10524–E10531 (2017)。用采样密度前所未有的英国—爱尔兰序列，发现跨区一致的人口下行**与北大西洋气候更突变的时段吻合**，并伴随生计响应（转向更耐寒的谷物、增加畜牧、采集资源）。作者明确说：**"对新石器而言，这些证据质疑了既有的完全内生的人口 boom–bust 模型"**；对更广的全新世，则表明**气候相关扰动一直是社会与生计变化的准周期驱动**。注意 Shennan 是两篇的共同作者，说明证据把他自己的立场往回拉了。
- **对本项目的处理方式**: 不要选边。**两条通道都实现**（内生的 §3.1/§3.2 三相动力学 + 外生的气候→单产 CV），然后用"我们的模拟能否在不同参数下同时产生两种模式"作为机制正确性的检验。

### 7.2 SPD 到底是不是人口代理？（实质争议）

- **支持**: Downey, Bocaege, Kerig, Edinborough & Shennan, PLoS ONE 9(8):e105730 (2014)。101 个墓地的少年指数 P(5–19) 与 SCDPD 的 Pearson r = **0.855**（未缩放）/ **0.883**（缩放），24 个欧洲区域，8,023 个日期。作者自陈局限：**"用少年指数测增长率明显受骨骼数据稀少的限制"**。
- **反对**: Carleton & Groucutt, "Sum things are not what they seem: Problems with point-wise interpretations and quantitative analyses of proxies based on aggregated radiocarbon dates," *The Holocene* (2021), doi:10.1177/0959683620981700。核心论点：**代理把过程变异与年代学不确定性混在一起**，因此**不适合逐点比较**——不能用来识别变化率、不能用来直接比较变量、不能用来估计回归参数。作者强调"既有代理极易被误读"这个关键问题一直未受重视。复现代码 <https://github.com/wccarleton/sumthings>。
- **另一路批评**: 检索到 *Journal of Archaeological Science* (2015) "Neolithic population and summed probability distribution of 14C-dates"（doi 未取），论点是 SPD 受**三种人为偏差**影响——仪式行为改变、生计策略改变、现代研究策略——并特别质疑 SPD 在**社会经历转型过程的时期**作为人口代理的有效性（证据 C，仅得检索摘要）。**注意这个批评正好打中新石器转变期，也就是我们最想校准的那一段。**
- **方法学演进（可用工具）**: Timpson, Colledge, Crema, Edinborough, Kerig, Manning, Thomas & Shennan, *JAS* 52:549–557 (2014) 提出改进方法与 Monte-Carlo 模拟检验；Crema et al. 2016 的随机标记置换检验；Edinborough et al. 2017 的点对点检验；Crema, Bevan & Shennan 2017 的空间置换检验；全部在 `rcarbon` 中实现。另有更新的贝叶斯路线：*JAS* (2021) "End-to-end Bayesian analysis for summarizing sets of radiocarbon dates"；ABC 路线见 *Nature Communications* 12 (2021) 关于 Rapa Nui 人口韧性的研究；以及 arXiv:2501.15980 用 Poisson 过程严格识别 14C 样本发生率的变化点。
- **本项目立场**: 采用 §3.12 的"把模拟送进同一个有偏管线"方案。这个方案对争议是**免疫的**：不管 SPD 是不是人口代理，只要我们用同一算子处理模拟与真实数据，比较就是有意义的。

### 7.3 Boserup 机制（棘轮咬合条件）没有被形式化（重大缺口）

- Wood 1998 提供了 Malthus–Boserup 综合的**概念**框架，MaB ratchet 提供了叙述（反复的 Malthusian 萧条与恢复 + 采纳提高适合度的文化创新 → 可持续抬升 Malthusian 上限）。
- 但 **Lee–Tuljapurkar–Puleston 内核里的 `Y`（单产）、`w`（劳动有效性）、`A_m`（可耕地）都是外生常数**，且作者明确承认"我们假定这些为常数，无论生产多少食物"，并点出时间最小化（Smith 1987）或 Chayanov 式（1977）的方法会让生产者持续调整劳动投入。
- **结果**: 我们有一个精确的 Malthus 内核和一个定性的 Boserup 故事，**没有连接两者的定量规则**。"什么条件下、多长时间内、`Y` 会因为人口压力而上升多少"这个问题**文献没有提供可用参数**。
- **这是本项目必须自己做假设的地方**（§9.3）。也是最应该做参数敏感性扫描并保留多个平行世界的地方。

### 7.4 前工业危机死亡率的分布参数（文献未提供）

- 我确认到的定性结论：Wrigley & Schofield 定义的"危机"事件对总死亡水平的贡献**很小**（1600–1750 年英格兰约占总死亡的 **5%**）；Fogel 对 1541–1871 全期的超额死亡计算也是**不足总死亡的 5%**（证据 C，二手引用）。
- 但**危机死亡率的分布形式、按空间尺度的分位数、空间相关长度、频率**，本次检索**未获得任何可用的同行评议参数**。黑死病的 30–60% / 65% / 38.9% 三个数字互相冲突且都有争议。饥荒强度的"100/10 万"与"500/10 万"来自非同行评议来源。
- **诚实结论：文献未提供可用参数。** §9.4 给出我们自拟的 D 级假设，并标明它是假设。

### 7.5 古人口学的三个方法学问题（Wood et al. 1992，共识存在但未解决）

Wood, Milner, Harpending & Weiss, "The Osteological Paradox: Problems of Inferring Prehistoric Health from Skeletal Samples," *Current Anthropology* 33(4) (1992), doi:10.1086/204084（页码在检索中出现 343–358 与 343–370 两个版本，含评论与回复）。三个混淆解释的根本概念问题:
1. **人口非稳定性（demographic nonstationarity）**——年龄别死亡分布同时取决于死亡率和增长率
2. **选择性死亡（selective mortality）**——墓地是死亡样本，不是活人样本
3. **未测量的个体层 frailty 异质性**

作者用"个体 frailty 与各年龄死亡风险"的简单模型证明：**关于从狩猎采集向定居农业转变的骨骼证据，与"健康改善"和"健康恶化"两种解释同等相容。** 三十多年后这个问题仍是活跃争论（见 *Journal of Archaeological Research* 上的进展综述，doi:10.1023/A:1021200925063）。

### 7.6 其他未解决问题

- **绝对人口水平的重建**: 无公认方法。绳文日本至今只有 Koyama 一个绝对估计尝试。中国历史户口的换算系数逐朝未知。
- **生命率对食物的弹性**: Puleston et al. 说是"从经验数据参数化"，但 `γ = 0.135`、`a_x ∈ [0.00279, 0.156]` 这些值本身没有独立测量。而弹性恰好是决定 MTI（转变相长度）的最敏感参数之一。
- **东亚"低婚内生育率"是刻意控制还是副产物**（营养、夫妻分离、哺乳期）：Lee & Wang Feng 的"刻意"论有争议。
- **Coale–Demeny / log-quadratic 在 e0 < 30 区间的效度**: 两者都是外推。Séguy 等的前工业模型是一个补丁，但我未能获得其参数表。
- **多国体系下的人口—不稳定反馈**: Turchin 明确排除了这种情形。对东亚舞台是致命缺口。
- **Tallavaara et al. 2018 的完整回归系数与密度分布**: 因付费墙未取到（PNAS 403、ScienceDirect 403）。

## 8. 反模式：本领域常见的错误建模方式（我们必须避免的）

### 8.1 固定 K 的逻辑增长（logistic with constant carrying capacity）
逻辑曲线暗示：人口平滑趋近 K，且在 K 处生活正常。**两者都错。** Puleston et al. 2014 的结果是：人口曲线是**平缓的 S 型**，但福利在 **40–65 年内断崖式下跌**，均衡处的食物比是 **Ê = 0.668**——即长期的 **33% 热量赤字**，均衡期望寿命从 45 掉到 30。**均衡人口不是吃饱的人口。** 一个只有 `N` 和 `K` 的模型在结构上无法表示这个最重要的历史事实。
**替代方案**: 把 `E` 作为一等状态变量（§3.1），让 K 成为涌现量而不是参数。

### 8.2 把墓地年龄—死亡分布当生命表用
Wood et al. 1992 的三个混淆（非稳定性、选择性死亡、frailty 异质性）使这种推断**在原则上**不可靠。Gurven & Kaplan 提供了压倒性的量化证据：史前生命表复合曲线在 **45 岁的死亡率超过民族志觅食者 7 倍以上，比圈养黑猩猩还差**；史前生命表的 l50 = 2–9%、e45 = 3–7 年，而民族志觅食者是 l45 = 26–43%、e45 = 14–24 年。因为这些人群"遗传上不可能与被调查人群差别很大"，**必然存在系统偏差**。
**替代方案**: 用民族志拟合的 Siler 参数作为史前基线；把"旧石器 e0 = 15–20 年"这类数字当作**有偏观测**，只在 §3.12 的合成管线里用来检查我们的偏差模型。

### 8.3 用 e0 < 30 的 Coale–Demeny 水平
Coale–Demeny 原表依据的人口**没有一个 e0 < 30**；更低水平是外推。Séguy 等专门为此构建了前工业模型。而 log-quadratic（拟合 HMD）在同一区间也是外推。
**替代方案**: 史前用 Siler 经验参数；国家阶段用 log-quadratic（RMSE 1.62 年 vs CD West 2.73 年 vs UN General 4.50 年）；**明确记录"该区间为外推"作为不确定性元数据**。

### 8.4 把 SPD 曲线的数值当人口数用
Carleton & Groucutt 2021：SPD **把过程变异与年代学不确定性混在一起**，不适合逐点比较、变化率估计、或作为回归变量。另外两个具体的技术陷阱（Bevan et al. 2017 Methods 明确指出）:
- **求和前归一化每个日期的后校准分布会在校准曲线陡处产生突兀的尖峰**（因为归一化后各日历年不再有相等的出现概率）→ Bevan 等选择**不归一化**。
- **同遗址过度取样必须先 binning**（他们用 100 年阈值的完全连接凝聚层次聚类，池化后除以 bin 内日期数）。
**替代方案**: §3.12。

### 8.5 假定 Malthusian 反馈强而快
Lee & Anderson 的估计（证据 C）：弹性仅 **+0.12 / −0.08**，冲击半衰期约 **107 年**，且**多数生命率变动与工资无关**。Wrigley & Schofield 的描述是"**弱稳态**（weak homeostasis）——大冲击 + 缓慢回归到一个 1800 年前保持恒定的均衡实际工资，该工资水平可支撑约 **0.5%/年**的人口增长"。
**替代方案**: 用两个时间尺度：食物比 `E` 的年度反馈（快，§3.1）+ 实际工资/技术的世纪反馈（慢，弹性 0.1 量级）。**不要让人口每代都吸附到 K。**

### 8.6 把危机当作主要的人口调节器
危机死亡在英格兰 1541–1871 只占总死亡的 **<5%**。一个"人口由瘟疫和饥荒调节"的模拟会系统性错误——**慢性死亡率才是主导**。这一点在游戏化的历史模拟里几乎总是被搞错，因为危机戏剧性强。
**替代方案**: 基线 Siler 的 `a1, a2, a3` 承载慢性死亡率的绝大部分；危机只是 `Δa2` 的重尾脉冲。检验指标：模拟中"危机年份"的超额死亡占总死亡的比例应落在个位数百分比量级（除非我们在模拟一个真正异常的世纪）。

### 8.7 Malthusian 中国神话
Malthus 描绘的中国是早婚普婚 → 高生育 → 高死亡。Lee & Wang Feng 1999 用证据推翻：中国的婚内生育率**远低于欧洲水平**，加上广泛的杀婴与堕胎、低男性婚配率、高收养率。
**替代方案**: 不要硬编码"某文化 = 正向抑制/反向抑制"。把控制点（婚姻进入 vs 婚内产出 vs 婴儿存活 vs 男性排除）都做成机制，让制度决定。**同时**：不要把 Lee & Wang Feng 的结论反过来硬编码——东—西二分的修辞本身受到近期学界挑战。

### 8.8 单一"典型个体/代表性家户"
代表性个体丢掉了方差，而**不平等、世系灭绝、创始人效应、精英过度生产全部是方差现象**。Scheffer et al. 1995 对超个体的警告完全适用：减少个体数导致**方差丢失、动力学不规则、对随机种子高度敏感**。
**替代方案**: 分位分层队列（§3.9），至少 5 档财富/地位；再加上被点名实体的真个体层（§3.11）。

### 8.9 把耕地密度当领土密度
`A_m = 1,000 ha → N̂ = 13,509` 是 **1,350 人/km² 耕地**（≈9 人/ha）。这个数在"全部热量来自粮食、零种子留存、零储损、零租税、零非粮土地用途"的假设下才成立。同时对照民族志狩猎采集者：平均约 **11 人/100 km²**（= 0.11 人/km²，证据 C），苔原/北方针叶林 >10 人/100 km² 已不现实。**两者相差四个数量级**，混用会立刻毁掉整个模拟的空间尺度。
**替代方案**: 显式区分 `arable_area`、`territory_area`、`arable_fraction`，并把 §4.3 的换算链（kcal/ha/day → kg/ha/yr → kg/person/yr → persons/ha）写成代码里的显式函数，附单位测试。

### 8.10 用民族志的 TFR / 增长率作为长期参数
Gurven & Kaplan 自己指出这个矛盾：民族志觅食者平均增长率约 **+1%/年**，觅食—园艺者与牧民 **>2%/年**——这些速率**不可能长期代表祖先人口**（1%/年持续 1,000 年就是 ×21,000）。
**替代方案**: 民族志率是**扰动后/扩张中**的率，只能用作 copial 相（§2.2）的参数，绝不能用作均衡参数。均衡参数必须从 §3.1 的内核求解出来（`r̂ = 0`, `b̂ = d̂ = 0.0328`）。

### 8.11 拟合了人口曲线就宣称 agent 解释了它
Artificial Anasazi 的教训（Janssen 2009）：拟合考古人口数据主要靠**两个承载力参数**（收成调整 1.0→0.54–0.56、收成方差 0.1→0.4），不是 agent 行为；**纯承载力零模型拟合得几乎一样好**，因为 ABM 通过储粮和繁殖延迟"对不规则的承载力曲线起了平滑函数的作用"；人口学参数（死亡年龄、生育年龄、分裂概率 0.125）只有次要重要性。
**替代方案（应写入验收标准）**: 任何"agent 层解释了历史"的主张，都必须附带与**同承载力零模型**的对比。如果零模型拟合得一样好，我们的 agent 层就只是一个平滑器。

### 8.12 存储完整祖先树
非去重祖先数按代倍增：30 代（900 年）= **1.07×10⁹**，35 代（1050 年）= 3.4×10¹⁰。而 SOCSIM 的输出模型是"所有曾活过的人各一行"——在数千年 × 10⁵–10⁶ 活人的规模下，这是 10⁹–10¹⁰ 行。
**替代方案**: 只存父/母指针 + 伴侣 + 最幼子 + 经父/母的次长同胞（SOCSIM 的最小链接集，足以遍历任意血缘/姻亲关系）；亲缘度按需计算，绝不物化祖先树；死后的匿名个体聚合为"人口尘埃"，除非被某条因果链引用。

### 8.13 用单一全局人口单元
区域分岔是常态：绳文日本内部关东 vs 青森 p=0.0039；华北内部黄河上中游衰退 vs 东北增长。反过来，Bevan 等在不列颠—爱尔兰发现的却是"跨区域高度一致"。**两种情况都会出现**，所以空间粒度和空间相关长度必须是可调参数，不能是隐含假设。

### 8.14 用比 MTI 更粗的时间步长
Malthusian 转变相只有 **40–65 年**。10 年步长会把整个转变压成 4–6 个 tick，"断崖"就变成了一条直线，而这正是我们最想捕捉的历史事件。**tick = 1 年**是人口模块的硬要求（更慢的模块可以以 1 年的倍数运行）。

### 8.15 忘记人口动量
`E` 跌破 1 之后，人口增长率还要 **5 年**才转向（`d²N/dt² = 0` 出现在第 352 年，而 `E<1` 在第 347 年）。任何"资源耗尽立即导致人口下降"的实现都是错的，而且这个滞后正是历史上"崩溃前的最后繁荣"的机制来源。

## 9. 无来源判断（D 级，明确标记为 LLM 常识，不得当作历史规律）

以下全部是**我为了让模拟能跑而做的假设**，没有文献来源。任何依赖它们的结论都必须在因果链里标注为"基于 D 级假设"。

### 9.1 分层表示的切换阈值
- 人口单元内**可繁殖人口 < 500** 时切换到个体表示。**依据链条**：Cavalli-Sforza & Bodmer 的有效繁殖规模 278（B 级）；SOCSIM 的封闭婚姻市场在 4,000–10,000 规模下能清算，但**没有在更小规模测试**（A 级事实，但推论是我方的）；Scheffer et al. 关于个体数过少导致方差丢失与种子敏感的警告（A 级事实，阈值是我方的）。**500 这个数字是我拍的。**
- 队列层年龄分组用 **1 年**（而非 5 年）当 `E < 1.2`（转变期），其余时段用 5 年。**纯属计算权衡，无来源。**
- 提升/降级的滞回带（避免抖动）设为 ±20%。**无来源。**

### 9.2 计算预算估算
- 队列层：2,000 个人口单元 × 2 性别 × 20 年龄组 × 5 财富分位 = 4×10⁵ 个浮点数/tick × 5,000 tick → 完全可行。
- 个体层：SOCSIM 在 2004 年做 10⁴ 人 × 300 年需要"数小时"。假设现代专用引擎能做到 10⁵–10⁶ 人年/秒，则 5,000 年 × 10⁵ 活人 = 5×10⁸ 人年 ≈ 8 分钟–1.5 小时/次。**因此个体层活人上限约 10⁵ 量级。**
- 把整个东亚（10⁷–10⁸ 人）做成个体是 10¹¹–10¹² 人年，**不可行**。
- 存储：个体记录 64–128 字节 × 10⁹ 曾活个体 = 64–128 GB。→ "所有曾活过的人"必须分层持久化：被点名者永久，匿名者死后聚合。
- **以上全部是我的估算，没有基准测试来源。**

### 9.3 Boserup 棘轮的咬合规则（§7.3 的缺口）
建议实现（**全部 D 级**）:
```
# 当 E 长期低于 1 时，创新压力累积
innovation_pressure += max(0, 1 - E) * dt
# 创新以 Poisson 到达，速率随压力和信息连通度上升
P(innovation) = 1 - exp(-λ * innovation_pressure * connectivity)
# 创新抬升 Y 或 w，但有劳动成本（Boserup 的核心：强化 = 更多劳动换更多产出）
Y *= (1 + δ);  H *= (1 + ε)    # δ, ε > 0，ε/δ 是"强化的代价比"
```
λ、δ、ε、以及"代价比" **文献未提供可用参数**。建议做参数扫描并保留多个平行世界（纲领允许分叉）。**特别提醒：这条机制是我们最可能无意中制造"科技树"的地方**——必须让创新的方向由环境和已有技术决定，而不是从预设列表里解锁。

### 9.4 危机死亡率的分布假设（§7.4 的缺口）
建议实现（**全部 D 级**，但上游驱动是 A 级）:
```
# 上游：单产随机性（A 级参数）
yield ~ Gamma(mean=Y, CV=0.20)      # 气候恶化时 CV 上升；CV 0.28/0.38 是崩溃折肘
# 危机严重度按空间尺度分层（D 级）
local (聚落, ~10^3 人):    重尾, P95 死亡率约 20-40%
regional (流域, ~10^5 人):  重尾, P95 死亡率约 5-15%
systemic (大区, ~10^7 人):  仅当新病原进入 naive 人口时可达 30-60%
# 缓冲
Δa2 = f(severity) / (1 + storage_years) / (1 + market_integration)
```
**这些分位数是我拍的。** 唯一有文献支撑的锚点是：(a) 危机死亡长期只占总死亡的 <5%（C 级），因此上述重尾必须**低频**；(b) 黑死病量级的 30–60% 需要"新病原 + naive 人口"这个前提条件（C 级）。

### 9.5 队列—个体一致性的验收标准
建议：同初始条件下，纯队列投影与"提升为个体→模拟→聚合"的平均轨迹在 200 年窗口内的相对偏差 < 5%（20 次 Monte Carlo）。**5% 和 200 年都是我拍的。**

### 9.6 "国家统计能力"变量
史料户口 = 真实人口 × `enumeration_capacity(state_strength, distance, age, sex)`。年龄选择性（婴儿严重漏记，Wei 2025 的 200–300‰ 登记前死亡是 A 级证据）与性别选择性（女性漏记，A 级证据）**存在**，但**具体函数形式无来源**。

### 9.7 其他 D 级假设
- 人口单元的空间相关长度（气候冲击的相关半径）：无来源。
- 迁徙的推拉函数形式：本简报未研究迁徙（属于另一个简报的范围），但注意 Bevan et al. 明确说早期新石器 SPD 变化率 >1%/年 **必须部分归因于迁入农民**，所以迁徙不能省。

## 附录 A：本简报对"分层人口表示"问题的完整答案（§6.4 的正式版）

因为这是任务明确点名的核心问题，这里给出完整设计。

### A.1 三层结构

| 层 | 表示 | 存在范围 | 承载的机制 | 计算量级 |
|---|---|---|---|---|
| **L0 队列** | `[unit × age × sex × wealth_quintile]` + `(E, TFR, l15, a2_eff, Siler params)` | **全部单元、全部时间** | 食物比、生命率、总量流动、税基、劳动供给、迁徙量 | 2,000 单元 × 2 × 20 × 5 ≈ 4×10⁵ floats/tick |
| **L1 家户原型** | `[unit × archetype × count]`，原型 = (规模, 世代深度, 财富档, 土地保有形式, 继承阶段) | **有农业/定居的单元** | 婚姻市场清算总量、家户形成与分裂、继承、租佃、分家 | 2,000 × 约 50 原型 |
| **L2 个体** | 完整个体 + SOCSIM 最小亲属链接集（父、母、伴侣、最幼子、经父/母的次长同胞） | **仅被点名实体及其相关者**，上限约 10⁵ 活人 | 世系存续与灭绝、继承的具体归属、联姻、精英招募、传记、因果链的人物端 | 5,000 年 × 10⁵ 活人 = 5×10⁸ 人年 |

### A.2 必须切换到个体表示的条件（按强制性排序）

**A. 结构性必须（队列在数学上无法表示）**

1. **身份必须持续且可以灭绝的实体**：世系、王朝、家族、爵位。这是 Galton–Watson 分支过程（Murphy 2004 引 Galton & Watson 1874 并指出 Bienaymé 1845 才是正确解）。**队列不能灭绝**——一个 `count` 字段永远可以是 0.3。而"某个家族在第七代绝嗣"这类事件是路径依赖与历史连续性（纲领第 3 条）的主要来源。→ **任何有名字的世系必须是个体/分支过程。**
2. **输出依赖于"谁"的机制**：某块具体田产/爵位/官职的继承；两个具体家族之间的联姻；某个具体人物的死亡时点。队列只有边缘分布，没有身份。
3. **纲领第 2 条的要求**：几百年后仍要能追溯"为什么这个国家会灭亡"到具体事件。事件的人物端必须有稳定 ID。

**B. 统计性必须（队列会系统性偏误）**

4. **可繁殖人口小到随机人口学主导时**。阈值我拍在 **500 人**（D 级，§9.1），依据是有效繁殖规模 278（B 级）与 SOCSIM 封闭婚姻市场只在 4,000–10,000 规模下验证过（A 级）。低于这个规模，队列的期望值与实现值差距巨大，且创始人效应、瓶颈、性比失衡都无法表示。
5. **frailty 异质性 + 选择性死亡决定结果时**。Wood et al. 1992 证明忽略这两者会让推断在原则上不可靠。**部分**可以用财富分位队列（§3.9）缓解——Wei 2025 显示地位效应达 +36%~124%，分位化能吃掉大部分。但当"谁在饥荒中活下来"决定了后续的土地集中格局时，必须个体化。
6. **精英过度生产（elite overproduction）**。Turchin 的机制是"精英职位追逐者数量增加 → 内部竞争 → 派系化"。这是一个**身份承载实体的计数比**（追逐者/职位），队列无法表示"某人是某个精英家族的次子因而没有继承资格"。

**C. 可以留在队列层的（明确列出，避免过度个体化）**

- 总人口、总食物需求、总劳动供给、税基、迁徙量
- 平均生命率与其对 `E` 的响应
- 疾病的宏观传播（SIR 类，属另一个简报）
- 只要 N > 约 5,000 且问题是总量问题

### A.3 提升与降级协议

```
    # 从 L0 的 age×sex×wealth 联合分布中抽样 n 个
    # 赋予队列隐含的 Siler 风险与生育率
    # 不变量：Σ promoted individuals 的期望流量 == 队列该子集的流量
    # 若 filter 指定了家族，从 L1 原型展开出家户结构

demote(individuals):
    # 聚合回 L0，但：
    #   - 已点名个体的身份记录 + 亲属链接 永久保留在历史库
    #   - 其后代的"世系归属"作为标签保留在 L1 原型上
    #   - 只有真正的匿名个体成为"人口尘埃"
```
- **滞回带 ±20%**（D 级）防止在阈值附近反复提升/降级。
- **烧机时间**：SOCSIM 需要约 **50 年**才让年龄性别结构与婚育史变真实（A 级）。因此提升时**不能**只抽一个横截面——必须给被提升个体合成一段过去（至少婚姻与生育史），或者在提升后允许 50 年的"结构成熟期"再让其参与关键决策。
- **超个体只用于 L0/L1 的匿名流动**，绝不用于 L2；理由是 Scheffer et al. 的方差丢失与种子敏感警告（A 级）。

### A.4 存储策略

- 个体记录 64–128 字节 → 10⁹ 曾活个体 = 64–128 GB（D 级估算）。因此:
  - **绝不物化祖先树**（30 代 = 1.07×10⁹ 非去重祖先，A 级事实）
  - 只存 SOCSIM 最小链接集，亲缘度按需 BFS 计算
  - 分层持久化：被点名者 + 被任一因果链引用者 → 永久；其余匿名个体死后 N 年（可配置）聚合为统计摘要
  - 世系（lineage）作为一等对象，比个体活得长；世系的"绝嗣"是一个可被查询的历史事件

### A.5 验收标准（应写成回归测试）

1. **一致性**：纯 L0 投影 vs "L0→L2→L0" 的平均轨迹，200 年窗口相对偏差 < 5%（20 次 MC）。阈值 D 级。
2. **三相形状**：给定 `A_m = 1,000 ha`、`N0 = 20` 与 §4.3 参数，模拟应产出 copial 相约 346 年、MTI 约 40–65 年、`N̂ ≈ 13,509`、`Ê ≈ 0.668`、均衡 `e0 ≈ 30`。**这是对 A 级文献的直接复现，是最强的验收测试。**
3. **盈余峰值位置**：盈余应在 `N ≈ 0.25 N̂` 处达到峰值。
4. **税收不稳定性**：固定额度税制应在向下扰动后产生崩溃螺旋；人均定率税制不应。
5. **崩溃折肘**：税率 40%（相对最大确定性税额）时，单产 CV 从 0.28 提到 0.38 应把人口半衰期从"近无限"压到"近立即"。
6. **人口—不稳定周期**：模拟的人口与内战计数序列（按 5 年计数、30 年指数核平滑），在 τ=30 年的 AR 回归下应给出正确符号且 R² 落在 0.4–0.8。
7. **与零模型的差异**（Artificial Anasazi 教训）：agent 层的人口曲线必须与"同承载力零模型"显著不同，否则 agent 层只是平滑器。
8. **iso-growth 恒等式**：任何时刻从模拟读出 (TFR, l15)，用 `r = ln((TFR/2.06)·(0.9973·l15−0.0422))/28` 算出的 `r` 应与实测增长率一致（在稳定人口假设成立的时段）。
